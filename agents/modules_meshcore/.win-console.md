Windows console management utility that provides programmatic control over a Windows console window and system tray icon functionality via native Win32 API calls.

## Key Components

- **`WindowsConsole`** — Main class (Win32 only) that wraps `kernel32.dll`, `user32.dll`, and `Shell32.dll` via `_GenericMarshal` native proxy bindings.
- **`minimize / restore / hide / show`** — Methods wrapping `ShowWindow` to control console window visibility state.
- **`_loadicon(imagePath)`** — Loads an icon from disk using `LoadImageA` with `LR_LOADFROMFILE | LR_SHARED | LR_DEFAULTSIZE` flags.
- **`SetTrayIcon(options)`** — Creates a system tray icon with optional balloon/toast notification support. Returns a tray icon handle object with event emitters.
- **`TrayIconFlags`** — Constants mapping `NIF_*` and `NIM_*` Win32 flag values for `NOTIFYICONDATA` struct manipulation.

### Tray Icon Events

| Event | Trigger |
|---|---|
| `ToastClicked` | User clicks the balloon notification |
| `IconHover` | Mouse hovers over the tray icon |
| `ToastDismissed` | Balloon is dismissed (when `balloonOnly` is set) |

## Usage Example

```javascript
var wc = require('./win-console');

// Control console window visibility
wc.hide();
wc.show();
wc.minimize();

// Add a system tray icon with a tooltip and balloon
var icon = wc._loadicon('C:\\path\\to\\icon.ico');
var tray = wc.SetTrayIcon({
    icon: icon,
    szTip: 'My App',
    szInfo: 'Application is running',
    szInfoTitle: 'Status'
});

tray.on('ToastClicked', function () {
    console.log('User clicked the notification');
    wc.show();
});

tray.on('ToastDismissed', function () {
    console.log('Notification dismissed');
});
```

> **Note:** This module is a no-op on non-Windows platforms. The exported singleton returns an empty object when `process.platform !== 'win32'`.
