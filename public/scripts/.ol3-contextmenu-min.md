Minified build of the `ol3-contextmenu` library (v2.5.0), providing a customizable right-click context menu control for OpenLayers 3 maps.

## Key Components

| Export/Class | Description |
|---|---|
| `ContextMenu` | Main UMD-exported class extending `ol.control.Control` |
| `Internal` (`m`) | Handles event listeners, menu positioning, open/close state, and coordinate tracking |
| `Html` (`f`) | Builds and manages the DOM container, menu entries, submenus, and separators |
| `utils` (`p`) | DOM utility helpers: class manipulation, element finding, viewport sizing, ID generation |
| `defaultItems` (`d`) | Built-in Zoom In / Zoom Out entries with animated `ol.View` transitions |

## Usage Example

```javascript
// Initialize the context menu control
const contextMenu = new ContextMenu({
  width: 170,
  defaultItems: true, // includes Zoom In / Zoom Out
  items: [
    {
      text: 'Add Marker',
      classname: 'some-style-class',
      callback: function(evt, map) {
        console.log('Coordinate:', evt.coordinate);
      }
    },
    '-', // renders as a separator
    {
      text: 'Submenu',
      items: [
        { text: 'Option A', callback: function(evt, map) {} }
      ]
    }
  ]
});

map.addControl(contextMenu);

// Listen to lifecycle events
contextMenu.on('open', function(evt) {
  console.log('Menu opened at pixel:', evt.pixel);
});

// Dynamically add/remove entries
contextMenu.push({ text: 'New Entry', callback: fn });
contextMenu.pop();
contextMenu.clear();
```
