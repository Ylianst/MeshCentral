Minified utility library providing common DOM manipulation helpers, binary data encoding/decoding functions, string utilities, and miscellaneous JavaScript helpers used throughout the MeshCentral web interface.

## Key Components

### DOM Helpers
- **`Q(id)`** — Shorthand for `document.getElementById()`
- **`QS(id)`** — Returns element style object (with error suppression)
- **`QE(id, enabled)`** — Toggles `disabled` state on an element
- **`QV(id, visible)`** — Toggles element visibility via `display` style
- **`QH(id, html)` / `QA(id, html)`** — Sets or appends `innerHTML`
- **`QC(id)`** — Returns element `classList`
- **`QVH(id, visible)`** — Toggles Bootstrap `visually-hidden` class

### Binary Encoding / Decoding
- **`ReadShort` / `ReadShortX`** — Reads big-endian / little-endian 16-bit integers from strings
- **`ReadInt` / `ReadIntX` / `ReadSInt`** — Reads 32-bit integers (signed/unsigned, big/little-endian)
- **`ShortToStr` / `ShortToStrX`** — Converts 16-bit integers to 2-char binary strings
- **`IntToStr` / `IntToStrX`** — Converts 32-bit integers to 4-char binary strings
- **`hex2rstr` / `rstr2hex` / `char2hex`** — Hex ↔ raw string conversions

### String & HTML Utilities
- **`EscapeHtml(s)`** — Escapes HTML special characters
- **`EscapeHtmlBreaks(s)`** — Same as above, also converts `\r\n\t` to HTML entities
- **`isSafeString(s)` / `isSafeString2(s)`** — Validates strings against dangerous characters
- **`encode_utf8` / `decode_utf8`** — UTF-8 encode/decode
- **`trademarks(s)`** — Replaces `(R)` / `(TM)` with HTML entity equivalents

### Data & Object Utilities
- **`Clone(obj)`** — Deep-clones an object via JSON round-trip
- **`ObjectToString(obj)`** — Recursively serializes an object to an HTML string
- **`MakeToArray(val)`** — Wraps non-array/non-null values in an array
- **`parseUriArgs(decode)`** — Parses current URL query parameters into an object
- **`joinPaths(...parts)`** — Joins path segments with `/`, stripping trailing slashes
- **`data2blob(str)` / `utf2blob(str)`** — Converts raw or UTF-8 strings to `Blob` objects
- **`jsonToCamel(obj)`** — Recursively converts object keys to camelCase
- **`zeroPad(n, width)`** — Left-pads a number with zeros

## Usage Example

```javascript
// DOM manipulation
QH('status-panel', '<b>Connected</b>');
QV('spinner', false);        // hide spinner
QE('submit-btn', true);      // enable button

// Binary protocol encoding
const packet = IntToStr(0x0001) + ShortToStr(payload.length) + payload;

// Safe HTML rendering
const safe = EscapeHtml(userInput);
QA('log-output', safe + '<br/>');

// URL argument parsing
const args = parseUriArgs(true);  // { id: 42, token: "abc" }

// Path joining
const url = joinPaths('/meshcentral/', 'api/', '/devices');
// → "/meshcentral/api/devices"
```
