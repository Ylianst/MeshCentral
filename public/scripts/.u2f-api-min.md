Minified JavaScript polyfill implementing the FIDO U2F (Universal 2nd Factor) browser API for hardware security key authentication across multiple browser environments and platforms.

## Key Components

| Export / Symbol | Description |
|---|---|
| `u2f.EXTENSION_ID` | Chrome extension ID for the Google U2F browser extension |
| `u2f.MessageTypes` | Enum of message type strings for register/sign/version requests and responses |
| `u2f.ErrorCodes` | Enum of U2F error codes (`OK`, `OTHER_ERROR`, `BAD_REQUEST`, `DEVICE_INELIGIBLE`, `TIMEOUT`, etc.) |
| `u2f.sign()` | Initiates a U2F authentication (sign) request |
| `u2f.register()` | Initiates a U2F device registration request |
| `u2f.getApiVersion()` | Queries the JS API version from the active transport port |
| `u2f.getMessagePort()` | Detects the runtime environment and returns the appropriate transport port |
| `WrappedChromeRuntimePort_` | Transport adapter for Chrome extension messaging via `chrome.runtime` |
| `WrappedAuthenticatorPort_` | Transport adapter for Android Chrome via intent URLs |
| `WrappedIosPort_` | Transport adapter for iOS Chrome via `u2f://auth` URL scheme |
| `u2f.getIframePort_()` | Fallback transport using a hidden iframe and `MessageChannel` |

## Usage Example

```javascript
// Register a new U2F security key
const appId = 'https://example.com';
const registerRequests = [{ version: 'U2F_V2', challenge: '<server-challenge>' }];
const registeredKeys = []; // existing keys to exclude

u2f.register(appId, registerRequests, registeredKeys, function(response) {
  if (response.errorCode) {
    console.error('Registration failed:', response.errorCode);
    return;
  }
  // Send response.registrationData and response.clientData to server
  console.log('Registration successful:', response);
}, 30 /* timeout seconds */);

// Authenticate with a registered U2F key
const signRequests = [{ version: 'U2F_V2', challenge: '<server-challenge>', keyHandle: '<key-handle>', appId }];

u2f.sign(appId, '<server-challenge>', signRequests, function(response) {
  if (response.errorCode) {
    console.error('Sign failed:', response.errorCode);
    return;
  }
  // Send response.signatureData and response.clientData to server
  console.log('Authentication successful:', response);
});
```

## Notes

- Only initializes if `window.u2f` is not already defined (safe to include alongside native implementations).
- Automatically selects the correct transport: Chrome extension → Android intent → iOS URL scheme → iframe fallback.
- Supports both API v1.0 and v1.1 request formats via `js_api_version` detection.
- Source: [`u2f-api-min.js`](https://github.com/flamingo-stack/meshcentral/blob/main/u2f-api-min.js)
