Service Worker script that handles browser push notifications — receiving them and responding to user clicks.

## Key Components

### `push` Event Listener
Processes incoming push notification payloads. Expects a JSON object with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `title` | ✅ | Notification title |
| `body` | ✅ | Notification body text |
| `url` | ✅ | URL to open on click |
| `icon` | ❌ | Icon identifier (resolves to `/images/notify/icons128-{icon}.png`) |

Falls back to `/favicon-303x303.png` if no icon is provided.

### `notificationclick` Event Listener
Closes the notification and opens the associated `url` in a new browser window/tab when the user clicks the notification.

## Usage Example

```javascript
// Registering the service worker from your main app
if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/serviceworker.js');
}

// Example push payload (sent from your server via Web Push API)
const payload = JSON.stringify({
  title: "New Alert",
  body: "You have a new message from MeshCentral.",
  url: "https://your-meshcentral-instance.com/messages",
  icon: "message" // resolves to /images/notify/icons128-message.png
});
```

## Notes

- The service worker silently ignores push events with no data (`event.data == null`)
- The `url` field in notification data controls where the user is directed on click — empty or null URLs are safely ignored
- Icons follow a naming convention of `icons128-{icon}.png` under `/images/notify/`
