Browser utility helper that initializes the `Mstsc` global object, providing DOM, browser detection, and locale utilities used throughout the mstsc.js RDP client.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `$` | Method | Shortcut for `document.getElementById()` |
| `elementOffset` | Method | Computes cumulative top/left offset of a DOM element, accounting for scroll position |
| `browser` | Method | Detects the current browser (`firefox`, `chrome`, `ie`, or `null`) |
| `locale` | Method | Returns the user's browser language/locale string |

## Usage Example

```javascript
// Access the global Mstsc instance
var el = Mstsc.$('canvas-container');

// Get absolute screen position of an element
var offset = Mstsc.elementOffset(el);
console.log(offset.top, offset.left);

// Check browser type for compatibility branching
var browser = Mstsc.browser();
if (browser === 'firefox') {
    // Firefox-specific handling
}

// Read user locale for keyboard/input mapping
var lang = Mstsc.locale();
console.log(lang); // e.g. "en-US"
```

## Notes

- The module uses an IIFE to define `Mstsc` as a constructor, then immediately instantiates it as a singleton via `this.Mstsc = new Mstsc()`.
- `browser()` detection uses legacy heuristics (`InstallTrigger`, `window.chrome`, `documentMode`) — note a typo exists in the IE check: `document.docuemntMode` (missing `u`) which will always return falsy.
- Source: [`mstsc.js`](https://github.com/flamingo-stack/meshcentral/blob/main/mstsc.js)
