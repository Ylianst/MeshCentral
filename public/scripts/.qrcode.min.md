A minified JavaScript library that generates QR codes in the browser, patched from the KeeeX fork of qrcodejs to support encoding strings longer than 192 characters via proper UTF-8 multi-byte handling.

## Key Components

| Export / Class | Description |
|---|---|
| `QRCode` | Top-level namespace exposed globally |
| `QR8bitByte` (inner `t`) | Encodes input strings as UTF-8 byte arrays, prepending BOM (`0xEF 0xBB 0xBF`) when multi-byte characters are detected |
| `QRCodeModel` (inner `e`) | Core QR matrix builder — manages modules, masking, timing/alignment patterns, and Reed-Solomon error correction |
| `QRPolynomial` (`p`) | Galois Field polynomial arithmetic used for RS error correction |
| `QRRSBlock` (`m`) | Reed-Solomon block descriptor (total count / data count) with a full lookup table covering QR versions 1–40 |
| `QRBitBuffer` (`_`) | Bit-level write buffer used when encoding data into the QR codeword stream |
| `g` (util object) | Static helpers: mask pattern selection, BCH type info/number, pattern positions, lost-point scoring |
| `d` (GF256 object) | Galois Field GF(256) exp/log tables for polynomial math |

## Usage Example

```javascript
// Basic instantiation (QRCode public API)
const qr = new QRCode(document.getElementById('qrcode'), {
  text: 'https://flamingo.run',
  width: 256,
  height: 256,
  colorDark: '#000000',
  colorLight: '#ffffff',
  correctLevel: QRCode.CorrectLevel.H
});

// Update content dynamically
qr.makeCode('https://openframe.ai');

// Clear the QR code
qr.clear();
```

## Notes

- **Source:** Patched from [`KeeeX/qrcodejs`](https://github.com/KeeeX/qrcodejs) to fix encoding failures beyond 192 characters
- **Encoding:** Always operates in `MODE_8BIT_BYTE` with UTF-8 conversion; BOM is prepended automatically for non-ASCII input
- **Error correction levels:** `L`, `M`, `Q`, `H` via the `QRCode.CorrectLevel` enum
- **Rendering:** Supports both Canvas and DOM (table) rendering depending on browser capability
- **No dependencies** — pure vanilla JavaScript, no external libraries required
