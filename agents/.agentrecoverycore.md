Provides the recovery core functionality for MeshCentral agents, enabling remote console, terminal, and tunnel management when an agent operates in recovery mode.

## Key Components

| Export / Symbol | Description |
|---|---|
| `meshCoreObj` | Core identity object broadcast to the server declaring this as a "MeshCore Recovery" agent with console + terminal capabilities (bitmask `14`) |
| `sendConsoleText(msg)` | Sends a console message back to the managing MeshAgent session |
| `path.join(...args)` | Minimal path utility that normalizes and joins path segments using `/` |
| `objToString(x, p, pad, ret)` | Recursive object serializer for debugging; depth-limited to 8 levels |
| `splitArgs(str)` | Splits a CLI-style string into tokens, respecting quoted strings |
| `parseArgs(argv)` | Converts a token array into a named argument map (handles `--key value` flags) |
| `getServerTargetUrl(path)` | Constructs an absolute server URL from the agent's known `ServerUrl` and a given path |
| `onTunnelUpgrade(response, s, head)` | WebSocket upgrade handler; routes the socket to TCP relay or KVM/Terminal/Files based on tunnel type |
| `Connected` event handler | Fires on agent connect; retrieves OS name and sends core capability announcement |
| `AddCommandHandler` callback | Dispatches inbound MeshAgent commands — routes `console` type to the CLI processor and `tunnel` type to the WebSocket tunnel setup logic, including file upload/download and terminal (`/bin/sh` or `win-terminal`) spawning |

## Usage Example

```javascript
// This module runs automatically inside the MeshAgent runtime.
// The agent loads it and the Connected event bootstraps the session:

require('MeshAgent').on('Connected', function () {
    require('os').name().then(function (v) {
        sendConsoleText("Mesh Agent Recovery Console, OS: " + v);
        require('MeshAgent').SendCommand(meshCoreObj); // Announces recovery mode
    });
});

// Incoming tunnel requests are handled transparently:
// Server sends: { action: 'msg', type: 'tunnel', value: '*/meshrelay.ashx?...' }
// The handler upgrades to WebSocket and spawns a shell or relays TCP traffic.
```

## Notes

- On Windows, terminal sessions use the `win-terminal` native module; on POSIX systems `/bin/sh` is spawned via `childProcess.execFile` with `SpawnTypes.TERM`.
- File uploads are handled inline on the tunnel's `data` event: chunks are written synchronously via `fs.writeSync`, and `uploadack` is sent after each chunk.
- Source: [`agentrecoverycore.js`](https://github.com/flamingo-stack/meshcentral/blob/main/agentrecoverycore.js)
