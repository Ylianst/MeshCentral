Parses Intel AMT (Active Management Technology) WSMAN XML responses into structured JavaScript objects, and provides a lightweight XML parser that works without external dependencies.

## Key Components

| Export / Function | Description |
|---|---|
| `ParseWsman(xml)` | Parses a WSMAN XML string or DOM object into a `{ Header, Body }` JSON structure |
| `_ParseWsmanRec(node)` | Recursively converts XML nodes to JS objects, auto-converting booleans and integers |
| `_PutObjToBodyXml(resuri, putObj)` | Serializes a JS object back into WSMAN body XML (internal utility) |
| `_turnToXml(text)` | Drop-in XML parser — converts raw XML strings to a DOM-like object tree without external dependencies |
| `_turnToXmlRec(text)` | Recursive XML tokenizer used by `_turnToXml` |
| `_treeBuilder` | Stack-based element builder used during XML parsing, including namespace resolution |

## Usage Example

```javascript
const amtXml = require('./amt-xml');

// Parse a raw WSMAN XML response string
const rawXml = `<Envelope>
  <Header><a:Action>GetResponse</a:Action></Header>
  <Body><g:Get_OUTPUT><g:Status>0</g:Status></g:Get_OUTPUT></Body>
</Envelope>`;

const parsed = amtXml.ParseWsman(rawXml);

// Result shape:
// {
//   Header: { Action: 'GetResponse', Method: 'Get' },
//   Body:   { Status: 0 }
// }

console.log(parsed.Header.Method); // 'Get'
console.log(parsed.Body.Status);   // 0 (integer, auto-converted)
```

> **Note:** `ParseWsman` accepts either a raw XML string or a pre-parsed DOM-like object. Boolean strings (`"true"` / `"false"`) and integer strings are automatically coerced to their native JS types. Repeated sibling elements are collected into arrays automatically.
