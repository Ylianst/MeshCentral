Minified bundle of Select2 4.0.13, a jQuery-based UI component that transforms native `<select>` elements into feature-rich dropdown widgets with search, tagging, AJAX data loading, and accessibility support.

## Key Components

- **`select2/utils`** — Core helpers: `Extend`, `Decorate` (mixin pattern), `Observable` (event emitter), data caching (`StoreData`, `GetData`, `RemoveData`), and markup escaping
- **`select2/results`** — Renders and manages the dropdown results list, handles highlighting, scrolling, loading states, and ARIA attributes
- **AMD/Almond loader** — Embedded lightweight RequireJS-compatible module loader; supports AMD, CommonJS, and global `jQuery` environments

## Usage Example

```javascript
// Basic initialization
$('#mySelect').select2();

// With options
$('#mySelect').select2({
  placeholder: 'Search...',
  allowClear: true,
  multiple: true,
  ajax: {
    url: '/api/search',
    dataType: 'json',
    processResults: function(data) {
      return { results: data.items };
    }
  }
});

// Programmatic control
$('#mySelect').select2('open');
$('#mySelect').select2('close');
$('#mySelect').val('option-value').trigger('change');

// Destroy
$('#mySelect').select2('destroy');
```
