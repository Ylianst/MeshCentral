A cross-browser file saving library that implements the `saveAs()` API, enabling client-side file downloads from Blob objects or URLs with fallbacks for legacy browsers.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `saveAs(blob, name, opts)` | Function | Primary API — triggers a file download from a Blob or URL string |
| `bom(blob, opts)` | Internal | Prepends UTF-8 BOM to text/XML blobs when `autoBom: true` |
| `download(url, name, opts)` | Internal | Fetches a URL via XHR and pipes result to `saveAs` |
| `corsEnabled(url)` | Internal | Synchronous HEAD check to detect cross-origin availability |
| `click(node)` | Internal | Cross-browser anchor click dispatcher |

**Browser strategy cascade:**
1. Native `<a download>` attribute (modern browsers)
2. `navigator.msSaveOrOpenBlob` (IE/Edge legacy)
3. `FileReader` + popup fallback (Safari/Chrome iOS)

## Usage Example

```javascript
// Save a Blob as a file
const data = new Blob(['Hello, world!'], { type: 'text/plain' });
saveAs(data, 'hello.txt');

// Save from a URL
saveAs('https://example.com/report.pdf', 'report.pdf');

// Save with UTF-8 BOM (useful for CSV files opened in Excel)
const csv = new Blob(['name,age\nAlice,30'], { type: 'text/csv;charset=utf-8' });
saveAs(csv, 'data.csv', { autoBom: true });
```
