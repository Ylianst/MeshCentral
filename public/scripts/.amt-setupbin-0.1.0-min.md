Minified JavaScript library for encoding and decoding Intel AMT (Active Management Technology) Setup Binary (`.bin`) configuration files used in Intel vPro provisioning workflows.

## Key Components

| Export | Type | Description |
|---|---|---|
| `AmtSetupBinSetupGuids` | `string[]` | Four binary GUID markers identifying AMT setup file types |
| `AmtSetupBinVarIds` | `object` | Nested map of module/variable IDs to types, descriptions, and enum values for AMT configuration fields |
| `AmtSetupBinCreate` | `function` | Initializes a new AMT setup binary object |
| `AmtSetupBinDecode` | `function` | Parses a raw binary string into a structured AMT setup object with records and typed variables |
| `AmtSetupBinEncode` | `function` | Serializes a structured AMT setup object back into a raw binary string |
| `AmtSetupBinVariableCompare` | `function` | Comparator for sorting variables by `moduleid` then `varid` |
| `AmtSetupBinScrambleRecordData` | `function` | Applies a simple byte offset (+17) obfuscation to record data |
| `AmtSetupBinDescrambleRecordData` | `function` | Reverses scrambling (+239 mod 256) to recover original record data |

## Usage Example

```javascript
// Decode a raw AMT setup binary string (e.g., loaded from a .bin file)
const rawBinary = loadFile('setup.bin'); // string of binary data
const decoded = AmtSetupBinDecode(rawBinary);

if (decoded) {
  console.log('File type:', decoded.fileType);
  for (const record of decoded.records) {
    for (const variable of record.variables) {
      console.log(`[${variable.desc}]:`, variable.value);
    }
  }
}

// Modify a value and re-encode
decoded.records[0].variables[0].value = 'NewPassword123!';
const reEncoded = AmtSetupBinEncode(decoded);

// Create a fresh setup binary object
const newSetup = AmtSetupBinCreate(1, 0);
newSetup.records.push({ typeIdentifier: 1, flags: 0, variables: [] });
const binary = AmtSetupBinEncode(newSetup);
```

> **Note:** This library depends on helper functions (`ReadShortX`, `ReadIntX`, `ShortToStrX`, `IntToStrX`) expected to be available in the global scope. It operates on raw binary strings, not `Buffer` or `Uint8Array`.
