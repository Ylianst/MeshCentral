Intel AMT Redirection Transport Module for Node.js that establishes TCP/TLS connections to Intel AMT devices and handles the AMT redirection protocol for Serial-over-LAN (SOL), KVM (remote desktop), and IDER (remote media) sessions.

## Key Components

| Export/Property | Description |
|---|---|
| `CreateAmtRedirect(module)` | Factory function that creates an AMT redirect object wrapping a terminal/desktop module |
| `obj.Start(host, port, user, pass, tls, ...)` | Initiates TCP or TLS connection to an AMT device |
| `obj.xxOnSocketConnected()` | Handles post-connection setup; sends protocol-specific redirect start sequences |
| `obj.xxOnSocketData(data)` | Parses incoming AMT binary protocol messages from the accumulator buffer |
| `obj.onCheckServerIdentity(cert)` | Validates TLS certificate fingerprint against expected value |
| `obj.protocol` | Numeric protocol selector: `1` = SOL, `2` = KVM, `3` = IDER |
| `obj.amtaccumulator` | Rolling `Buffer` that accumulates partial AMT protocol frames |
| `obj.onStateChanged` | Callback hook invoked on connection state transitions |

**AMT Protocol Command Codes Handled:**

| Code | Constant | Description |
|---|---|---|
| `0x11` | `StartRedirectionSessionReply` | Initiates authentication query |
| `0x14` | `AuthenticateSessionReply` | Performs MD5 digest auth handshake |
| `0x21` | Settings Response | Confirms serial/KVM settings, starts keepalive |
| `0x29` | Serial Settings | Acknowledges serial configuration |

## Usage Example

```javascript
const AmtTerminal = require('./amt-terminal'); // SOL inner module
const CreateAmtRedirect = require('./amt-redir-duk');

const terminal = AmtTerminal.create();
const redirect = CreateAmtRedirect(terminal);

redirect.onStateChanged = function (state) {
    console.log('AMT connection state:', state);
    // States: 0=idle, 1=connecting, 2=connected, 3=session active
};

// Connect using TLS with optional fingerprint pinning
redirect.Start(
    '192.168.1.100', // AMT host
    16993,           // AMT TLS port
    'admin',         // username
    'P@ssword1',     // password
    true,            // use TLS
    null,            // tlsFingerprint (null = accept and log)
    {}               // tlsOptions
);
```

## Notes

- Source: [`amt-redir-duk.js`](https://github.com/flamingo-stack/meshcentral/blob/main/amt-redir-duk.js)
- Authentication uses MD5 digest (`hex_md5`) — requires a companion utility; basic auth and bare digest (type 3) are intentionally disabled in comments
- KVM and IDER traffic bypasses the accumulator and is forwarded directly to the inner module once authenticated
- SOL sessions start a 2-second keepalive timer (`setInterval`) after the session is established
