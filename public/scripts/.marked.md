Bundled distribution of **marked v14.1.3**, a fast, compliant Markdown-to-HTML parser supporting CommonMark and GitHub Flavored Markdown (GFM).

## Key Components

| Export / Class | Description |
|---|---|
| `exports.defaults` | Global parser configuration (async, breaks, gfm, pedantic, etc.) |
| `changeDefaults()` | Updates global defaults at runtime |
| `_Tokenizer` | Core block-level tokenizer class (space, code, fences, heading, hr, blockquote, list, table, etc.) |
| `escape$1()` | HTML entity escaping helper; supports encode and no-encode modes |
| `edit()` | Regex builder utility for composing complex grammar rules |
| `cleanUrl()` | URI-encodes link `href` values safely |
| `splitCells()` | GFM table row cell parser, handles escaped pipes |
| `outputLink()` | Constructs link or image tokens from captured groups |
| `indentCodeCompensation()` | Strips leading indentation from fenced code blocks |
| `rtrim()` | REDOS-safe trailing character trimmer |
| `findClosingBracket()` | Bracket-depth tracker for nested link/image parsing |

## Usage Example

```javascript
// Browser (UMD global)
const html = marked.parse('# Hello, **world**!');

// CommonJS
const { marked } = require('./marked.js');
const html = marked.parse('## Heading\n\nParagraph with `code`.');

// Override defaults
marked.setOptions({
  gfm: true,
  breaks: true,
  async: false,
});

// Async usage
const html = await marked.parse('# Async Markdown', { async: true });
```
