Lightweight factory module that creates an Intel AMT Serial-over-LAN (SOL) communication object, handling state transitions, data processing, and bidirectional text transmission over an AMT connection.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CreateAmtRemoteSol` | Factory Function | Creates and returns a SOL session object |
| `obj.protocol` | Property | Fixed value `1`, identifies this as a Serial-over-LAN protocol handler |
| `obj.debug` | Property | Toggle for verbose console logging |
| `obj.onData` | Callback | User-assignable handler invoked when data is received |
| `obj.xxStateChange` | Method | Responds to connection state changes; triggers `Start` at state `3`, `Stop` at state `0` |
| `obj.Start` | Method | Called when SOL session becomes active |
| `obj.Stop` | Method | Called when SOL session is terminated |
| `obj.ProcessData` | Method | Handles incoming data and forwards it to `onData` callback |
| `obj.Send` | Method | Transmits text through the parent transport layer |

## Usage Example

```javascript
const CreateAmtRemoteSol = require('./amt-sol');

const sol = CreateAmtRemoteSol();

// Enable debug logging
sol.debug = true;

// Attach to a parent transport (e.g., AMT WSMAN/WebSocket connection)
sol.parent = amtTransport;

// Handle incoming serial data
sol.onData = function (solObj, data) {
    console.log('Received from AMT device:', data);
};

// Simulate a state change to active (3 = connected)
sol.xxStateChange(3);

// Send a command to the remote AMT device
sol.Send('reboot\n');
```

> **Note:** `obj.parent` must be set to a transport object that exposes a `Send` method before calling `sol.Send()`. This module is typically instantiated by a higher-level AMT connection manager. See the full implementation at [`amt-sol.js`](https://github.com/flamingo-stack/meshcentral/blob/main/amt-sol.js).
