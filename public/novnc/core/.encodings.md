Defines the RFB (Remote Framebuffer) protocol encoding constants and a utility function for resolving encoding names used by the noVNC HTML5 VNC client.

## Key Components

### `encodings` (exported object)
A named map of RFB encoding type constants, including:
- **Standard encodings**: `encodingRaw` (0), `encodingCopyRect` (1), `encodingRRE` (2), `encodingHextile` (5), `encodingTight` (7), `encodingZRLE` (16), `encodingTightPNG` (-260), `encodingJPEG` (21)
- **Pseudo-encodings**: Capability negotiation extensions such as `pseudoEncodingDesktopSize`, `pseudoEncodingCursor`, `pseudoEncodingFence`, `pseudoEncodingExtendedClipboard`, QEMU key/LED events, and compression/quality level hints

### `encodingName(num)` (exported function)
Resolves a numeric encoding ID to its human-readable string name. Returns `"[unknown encoding <num>]"` for unrecognized values. Only covers standard (non-pseudo) encodings.

## Usage Example

```javascript
import { encodings, encodingName } from './encodings.js';

// Reference an encoding constant for protocol negotiation
const preferred = encodings.encodingTight; // 7

// Resolve a numeric ID received from the server to a readable label
console.log(encodingName(encodings.encodingZRLE));    // "ZRLE"
console.log(encodingName(encodings.encodingCopyRect)); // "CopyRect"
console.log(encodingName(999));                        // "[unknown encoding 999]"

// Use pseudo-encoding constants for capability advertisement
const caps = [
    encodings.pseudoEncodingDesktopSize,
    encodings.pseudoEncodingFence,
    encodings.pseudoEncodingExtendedClipboard,
];
```
