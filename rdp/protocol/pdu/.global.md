Implements the RDP Global channel for graphic updates, capabilities exchange, and input handling in the node-rdpjs library. Provides both a base `Global` class and a `Client` subclass that manages the full RDP connection automata state machine.

## Key Components

- **`Global`** — Base class extending `EventEmitter`. Manages transport references, user ID, and server/client capability sets. Provides `sendPDU` and `sendDataPDU` helpers for formatting and dispatching PDU messages.

- **`Client`** — Extends `Global`. Implements the client-side RDP connection sequence automata, including:
  - Capability negotiation (general, bitmap, order, pointer, input, brush, glyph cache, etc.)
  - Connection handshake states: `recvDemandActivePDU` → `recvServerSynchronizePDU` → `recvServerControlCooperatePDU` → `recvServerControlGrantedPDU` → `recvServerFontMapPDU`
  - Fast-path update handling via `recvFastPath` (bitmap and pointer updates)
  - Ongoing PDU dispatch via `recvPDU` and `readDataPDU`

**Events emitted:**
| Event | Trigger |
|-------|---------|
| `connect` | Connection sequence complete |
| `bitmap` | Bitmap update received |
| `pointer` | Pointer/cursor update received |
| `session` | Session info PDU received |
| `close` | Transport closed |
| `error` | Transport error |

## Usage Example

```javascript
var global = require('./global');

// Create a client instance with primary and fast-path transports
var client = new global.Client(transport, fastPathTransport);

client.on('connect', function() {
  console.log('RDP Global channel ready');
});

client.on('bitmap', function(rectangles) {
  // Handle bitmap screen updates
  rectangles.forEach(rect => renderRect(rect));
});

client.on('session', function() {
  console.log('Session info received');
});

client.on('error', function(err) {
  console.error('Channel error:', err);
});
```
