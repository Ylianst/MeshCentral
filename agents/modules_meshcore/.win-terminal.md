Provides a Windows-specific terminal session manager for MeshCentral, spawning and controlling a hidden console process (cmd.exe or PowerShell) via native Win32 API calls and exposing it as a Node.js Duplex stream.

## Key Components

- **`windows_terminal` (constructor)** — Initializes native proxies for `User32.dll` and `Kernel32.dll`, setting up all required Win32 method bindings for console control.
- **`StartEx(width, height, terminalTarget)`** — Launches a legacy terminal session (fixed at 80×25), allocates a hidden console, and returns a Duplex stream for I/O.
- **`ClearScreen()`** — Clears the console buffer by filling it with blanks and resetting cursor/window position using `FillConsoleOutputCharacterA` and related APIs.
- **`SendCursorUpdate()`** — Reads `CONSOLE_SCREEN_BUFFER_INFO` and emits cursor position updates when the cursor moves.
- **`PowerShellCapable()`** — Checks for PowerShell availability at the standard filesystem path for the current architecture (`x64` vs other).
- **Win32 constants** — Defines console event codes (`EVENT_CONSOLE_*`), window flags (`SW_HIDE`, `STARTF_USESHOWWINDOW`), and input types (`KEY_EVENT`) used throughout.

## Usage Example

```javascript
var winTerminal = require('./win-terminal');

var term = new winTerminal();

if (term.PowerShellCapable()) {
    var stream = term.StartEx(80, 25, 'powershell');
} else {
    var stream = term.StartEx(80, 25, 'cmd');
}

// Write input to the terminal
stream.write('dir\r\n');

// Read terminal output
stream.on('data', function (chunk) {
    console.log('Terminal output:', chunk.toString());
});

stream.on('end', function () {
    console.log('Terminal session ended.');
});
```
