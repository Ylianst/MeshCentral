Custom context menu control for OpenLayers 3+ maps, providing right-click (or custom event) menus with support for submenus, icons, separators, and default zoom actions.

## Key Components

### `ContextMenu` (class, extends `ol.control.Control`)
Main export. Integrates with OpenLayers as a map control.

| Method | Description |
|---|---|
| `push(item)` | Add a menu entry |
| `pop()` | Remove the last menu entry |
| `shift()` | Remove the first menu entry |
| `extend(arr)` | Add multiple entries at once |
| `clear()` | Remove all menu entries |
| `close()` | Programmatically close the menu |
| `enable()` / `disable()` | Toggle menu activation |
| `isOpen()` | Returns open state |
| `getDefaultItems()` | Returns built-in Zoom In/Out items |
| `updatePosition(pixel)` | Reposition an open menu |

### Internal Modules
- **`Internal`** — Handles event listeners, coordinate tracking, and menu open/close logic
- **`Html`** — Creates and manages DOM elements (container, list items, submenus)
- **`p` (utils)** — DOM helpers: `addClass`, `removeClass`, `find`, `offset`, `mergeOptions`, `createFragment`, etc.

### Default Options
```javascript
{ width: 150, scrollAt: 4, eventType: 'contextmenu', defaultItems: true }
```

### Events Dispatched
`beforeopen`, `open`, `close`, `add-menu-entry`

## Usage Example

```javascript
const contextMenu = new ContextMenu({
  width: 170,
  defaultItems: true, // includes Zoom In / Zoom Out
  items: [
    {
      text: 'Mark Location',
      classname: 'some-style-class',
      callback: (evt, map) => {
        console.log('Clicked at', evt.coordinate);
      }
    },
    '-', // separator
    {
      text: 'Sub Menu',
      items: [
        { text: 'Option A', callback: (evt, map) => {} }
      ]
    }
  ]
});

map.addControl(contextMenu);

contextMenu.on('open', (evt) => {
  console.log('Menu opened at pixel', evt.pixel);
});
```
