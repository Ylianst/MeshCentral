Minified JavaScript module that creates and manages an RDP (Remote Desktop Protocol) desktop session within an HTML canvas element, handling WebSocket communication, input events, and screen rendering.

## Key Components

| Export / Symbol | Description |
|---|---|
| `CreateRDPDesktop(e, t)` | Factory function — returns an RDP session controller object bound to a canvas element |
| `n.Start(nodeid, port, credentials)` | Opens a WebSocket (`wss://`) to the MeshCentral relay and initiates the RDP session |
| `n.Stop()` | Closes the WebSocket and clears the canvas |
| `n.m.mousemove / mousedown / mouseup / mousewheel` | Mouse event handlers with Nagle-style buffering (50ms delay on move) |
| `n.m.handleKeyDown / handleKeyUp` | Keyboard handlers that send scancode messages via `Mstsc.scancode()` |
| `n.m.sendcad()` | Sends a Ctrl+Alt+Del scancode sequence |
| `n.m.setClipboard / getClipboard` | Clipboard read/write over the WebSocket channel |
| `n.m.SendStringUnicode(str)` | Sends a Unicode string as a `utype` message |
| `n.m.SendKeyMsgKC(e, t, s)` | Sends key events using a built-in keycode-to-scancode map `c` |
| State machine (`n.State`) | `0` = disconnected, `1` = connecting, `2` = connected, `3` = active session |

**WebSocket message types handled:** `rdp-connect`, `rdp-bitmap`, `rdp-pointer`, `rdp-close`, `rdp-error`, `rdp-clipboard`, `ping`.

## Usage Example

```javascript
// Initialize the RDP desktop on a canvas element
const rdp = CreateRDPDesktop('myCanvas', '/relay/');

// Listen for state changes
rdp.onStateChanged = (session, state) => {
  console.log('RDP state:', state); // 0=off, 1=connecting, 2=open, 3=active
};

// Start a session
rdp.Start('node-id-123', 3389, {
  username: 'Administrator',
  password: 's3cr3t',
  domain: 'CORP',
  width: 1280,
  height: 1024,
  savecred: false,
  servercred: false
});

// Wire up input events from the canvas element
const canvas = document.getElementById('myCanvas');
canvas.addEventListener('mousemove', rdp.m.mousemove);
canvas.addEventListener('mousedown', rdp.m.mousedown);
canvas.addEventListener('mouseup',   rdp.m.mouseup);
canvas.addEventListener('wheel',     rdp.m.mousewheel);
window.addEventListener('keydown',   rdp.m.handleKeyDown);
window.addEventListener('keyup',     rdp.m.handleKeyUp);

// Send Ctrl+Alt+Del
rdp.m.sendcad();

// Disconnect
rdp.Stop();
```
