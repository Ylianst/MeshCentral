A bundled UMD/IIFE module that provides **image rendering support for the xterm.js terminal emulator**, implementing sixel graphics and inline image decoding via WebAssembly.

## Key Components

| Export | Description |
|--------|-------------|
| `ImageAddon` | Main xterm.js addon class that enables image rendering in the terminal |
| `Decoder` / `DecoderAsync` | Synchronous and asynchronous sixel image decoders backed by a WebAssembly core |
| `decode` / `decodeAsync` | Convenience functions returning `{ width, height, data32, data8 }` pixel data |
| `LIMITS` | Constants for `CHUNK_SIZE`, `PALETTE_SIZE`, `MAX_WIDTH`, and embedded WASM bytes |
| Color utilities | `toRGBA8888`, `fromRGBA8888`, `nearestColorIndex`, `normalizeRGB`, `normalizeHLS` |
| Built-in palettes | `PALETTE_VT340_COLOR`, `PALETTE_VT340_GREY`, `PALETTE_ANSI_256` |

## Usage Example

```javascript
import { Terminal } from '@xterm/xterm';
import { ImageAddon } from './xterm-addon-image.js';

// Attach the addon to an xterm.js terminal instance
const terminal = new Terminal();
const imageAddon = new ImageAddon({
  memoryLimit: 128 * 1024 * 1024, // 128 MB
  sixelColor: 0xFFFFFFFF,
  paletteLimit: 256,
  truncate: true
});
terminal.loadAddon(imageAddon);
terminal.open(document.getElementById('terminal'));

// Decode a sixel image directly
import { decode } from './xterm-addon-image.js';

const sixelData = new Uint8Array(/* ... sixel bytes ... */);
const { width, height, data8 } = decode(sixelData, { paletteLimit: 256 });

// Draw decoded pixels onto a canvas
const ctx = canvas.getContext('2d');
const imageData = new ImageData(data8, width, height);
ctx.putImageData(imageData, 0, 0);
```

## Notes

- The decoder uses an **embedded WebAssembly binary** (base64-encoded) for performance-critical sixel parsing.
- Supports both **raster** (fixed-size) and **streaming band** decoding modes.
- Maximum image width is capped at **16,384 pixels** (`LIMITS.MAX_WIDTH`).
- Memory usage is bounded by the configurable `memoryLimit` option (default: 128 MB).
