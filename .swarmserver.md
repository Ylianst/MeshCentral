MeshCentral v1 legacy Swarm Server module that facilitates migration of legacy mesh agents to MeshCentral2, handling TLS connections, agent updates, and protocol translation.

## Key Components

- **`CreateSwarmServer(parent, db, args, certificates)`** — Factory function that creates and returns the Swarm Server instance
- **`LegacyMeshProtocol`** — Enumeration of all legacy mesh protocol message types (100+ constants covering node management, agent communication, user authentication, AMT provisioning, etc.)
- **`loadMigrationAgents()`** — Scans the `migrationagents` directory and loads agent executables into memory, indexed by architecture and version
- **`onData(data)`** — Handles incoming binary data from legacy agents, supporting relay socket passthrough, debug logging, and HTTP detection
- **`obj.stats`** — Runtime statistics object tracking connection counts, byte transfer, HTTP requests, pushed agents, and agent types
- **`obj.legacyAgentConnections`** — Registry of active legacy agent connections
- **`obj.migrationAgents`** — In-memory cache of migration agent binaries, keyed by `[arch][version]`
- **TLS Server** — Created via Node.js `tls.createServer()` with mutual certificate authentication (`requestCert: true`, `rejectUnauthorized: false`)

## Usage Example

```javascript
const swarmServer = require('./swarmserver.js');

// Instantiate the legacy swarm server
const server = swarmServer.CreateSwarmServer(
  parent,       // MeshCentral parent object
  db,           // Database instance
  { swarmport: 8080, swarmdebug: false, exactports: true },
  certificates  // TLS certificates including swarmserver key/cert
);

// Access runtime stats
console.log(server.stats.connectCount);

// Check loaded migration agents
// Agents are loaded from: <datapath>/migrationagents/meshagent-<version>.<arch>
console.log(server.migrationAgents); // { [arch]: { [version]: { arch, ver, path } } }
```

Migration agent binaries should be placed in `<datapath>/migrationagents/` following the naming convention `meshagent-<version>.<arch>` (e.g., `meshagent-400.3`).
