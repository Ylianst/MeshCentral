RSA public-key encryption utilities built on big-integer arithmetic, providing key construction and encryption for use in the RDP protocol implementation.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `publicKey` | Function | Constructs a public key object from a modulus buffer and public exponent |
| `encrypt` | Function | Encrypts data using modular exponentiation (`m^e mod n`) |

**Dependencies:** [`jsbn`](https://github.com/flamingo-stack/meshcentral/blob/main/node_modules/node-rdpjs/rsa/jsbn.js) — big-integer library providing `BigInteger` with `modPowInt` and `toBuffer` support.

## Usage Example

```javascript
const rsa = require('./rsa');

// Construct a public key from a modulus buffer and exponent
const modulus = Buffer.from('...'); // raw modulus bytes from server certificate
const pubExp = 65537;               // common RSA public exponent
const key = rsa.publicKey(modulus, pubExp);

// Encrypt a data buffer (e.g., a 32-byte pre-master secret)
const plaintext = Buffer.from('secret-data');
const ciphertext = rsa.encrypt(plaintext, key);
// ciphertext is a Buffer containing the result of plaintext^e mod n
```

## Notes

- Encryption is raw RSA (textbook RSA, no padding). Suitable for the RDP handshake where the protocol defines its own structure around the encrypted payload.
- Both `modulus` and the return value of `encrypt` are `Buffer` instances; `pubExp` is a plain integer.
- This module is intentionally minimal — decryption is not implemented, as the client only needs to encrypt the pre-master secret sent to the server.
