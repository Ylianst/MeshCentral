Compiler, decompiler, and interpreter for binary AMT (Intel Active Management Technology) scripts, providing a stack-based virtual machine for executing management operations against AMT devices via WSMAN.

## Key Components

### Function Tables

| Table | Type | Description |
|-------|------|-------------|
| `script_functionTable1` | Core commands | Built-in opcodes: `nop`, `jump`, `set`, `print`, `dialog`, string ops, WSMAN ops |
| `script_functionTable2` / `script_functionTableX2` | Utility functions | Encoding (`atob`/`btoa`, `hex2str`), hashing (`md5`), binary read helpers |
| `script_functionTable3` / `script_functionTableX3` | Optional/feature-gated | AMT data pulls (`PullSystemStatus`, `PullEventLog`, etc.), conditionally compiled via `###BEGIN###`/`###END###` blocks |

### `script_setup(binary, startvars)`

Initializes the script runner from a binary blob. Validates magic header (`0x247D2945`) and version, then returns a runner object with:

- **`obj.reset()`** — Resets instruction pointer and variables to initial state
- **`obj.start(stepspeed)`** — Begins stepping via `setInterval`
- **`obj.stop()`** — Clears the execution timer
- **`obj.step()`** — Executes one instruction; handles argument decoding, variable interpolation (`{varname}` syntax), and dispatch
- **`obj.getVar(name)` / `obj.setVar(name, val)`** — Dot-notation variable accessor/mutator (e.g., `"foo.bar.baz"`)

### Opcodes (cmdid 0–22+)

| Opcode | Mnemonic | Description |
|--------|----------|-------------|
| 0 | `nop` | No operation |
| 1 | `jump` | Unconditional or conditional branch (`<`, `<=`, `=`, `!=`, `>=`, `>`) |
| 2 | `set` | Assign or delete a variable |
| 3 | `print` | Output to console/callback |
| 4 | `dialog` | Show modal dialog, suspend execution |
| 5–15 | String/array/math ops | `substr`, `indexOf`, `split`, `join`, `length`, `jsonparse`, `jsonstr`, `add`, `substract`, `parseInt` |
| 16–22 | WSMAN ops | `BatchEnum`, `Put`, `Create`, `Delete`, `Exec`, `Subscribe`, script speed control |

## Usage Example

```javascript
// Initialize the script runner with a binary AMT script blob and starting variables
var runner = script_setup(binaryScriptBlob, { deviceIp: '192.168.1.100' });

if (runner) {
    // Attach callbacks
    runner.onConsole = function(msg) { console.log('[Script]', msg); };

    // Wire in the AMT WSMAN stack
    runner.amtstack = myAmtStackInstance;

    // Start execution, stepping every 100ms
    runner.start(100);

    // Stop when done
    // runner.stop();
}
```

> **Note:** The binary format requires a 6-byte header: 4-byte magic (`0x247D2945`) + 2-byte version (`<= 1`). Arguments support inline variable interpolation using `{varName}` syntax within string literals.
