A minified build of Chart.js — a full-featured, browser/Node-compatible charting library that renders interactive charts on HTML5 Canvas.

## Key Components

| Export | Description |
|--------|-------------|
| `Chart` | Root class; attached to `window.Chart`, AMD, or CommonJS `module.exports` |
| `Colors` | Built-in color palette plugin |
| `Decimation` | Data decimation plugin for large datasets |
| `Filler` | Area fill plugin |
| `Legend` | Chart legend plugin |
| `SubTitle` / `Title` | Chart title/subtitle plugins |
| `Tooltip` | Interactive tooltip plugin |

**Core utilities exposed internally:**

- `Y` / `$` — deep-merge helpers (`merger`, `safeMerger`)
- `bt` / `f` / `xt` — binary-search helpers for pixel/value lookups
- `l` (Animator) — `requestAnimationFrame`-based animation scheduler
- Color parsing (`Nt`, `Ht`, `jt`, `Yt`) — HSL/HWB/HSV ↔ RGB conversion
- `yt` / `Mt` — array mutation listeners for reactive dataset updates

## Usage Example

```javascript
// ESM / CommonJS build entry point
const Chart = require('./charts-min.js');

const ctx = document.getElementById('myChart').getContext('2d');
new Chart(ctx, {
  type: 'bar',
  data: {
    labels: ['Jan', 'Feb', 'Mar'],
    datasets: [{
      label: 'Revenue',
      data: [120, 190, 300],
    }]
  },
  options: {
    plugins: {
      legend: { position: 'top' },
      tooltip: { enabled: true }
    }
  }
});
```

## Notes

- Source: minified bundle — see the unminified source at [`flamingo-stack/meshcentral`](https://github.com/flamingo-stack/meshcentral/blob/main/charts-min.js) for debugging.
- Supports UMD (browser global), AMD (`define`), and CommonJS (`module.exports`).
- Animation loop uses `window.requestAnimationFrame` with a Node.js polyfill fallback.
