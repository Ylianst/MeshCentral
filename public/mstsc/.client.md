Browser-side RDP client implementation for the mstsc.js library, handling mouse/keyboard input capture, WebSocket communication with the RDP relay, bitmap rendering, and bidirectional clipboard synchronization.

## Key Components

### `mouseButtonMap(button)`
Maps browser mouse button indices to RDP protocol button values (left=1, right=2, other=0).

### `Client(canvas)`
Main client class instantiated with a canvas element. Manages:
- **`canvas`** — rendering target
- **`render`** — `Mstsc.Canvas` renderer instance
- **`socket`** — WebSocket connection to the RDP relay
- **`activeSession`** — tracks live session state
- **`mouseNagleTimer/Data`** — debounce buffer for mousemove events (50ms Nagle-style coalescing)

### `Client.prototype` Methods

| Method | Description |
|--------|-------------|
| `install()` | Binds all canvas mouse events (`mousemove`, `mousedown`, `mouseup`, `contextmenu`, `mousewheel`) and window keyboard events (`keydown`, `keyup`) |
| `connect(ip, domain, username, password, options, next)` | Opens a WSS WebSocket to `/mstscrelay.ashx`, sends session info, starts clipboard polling every 1000ms |
| `disconnect()` | Closes the WebSocket connection |

### WebSocket Message Handling
Inbound JSON messages dispatched by `msg[0]` key:
- `rdp-connect` — activates the session
- `rdp-bitmap` — triggers canvas render update with preceding binary frame data
- `rdp-close` / `rdp-error` — deactivates session and calls `next` callback
- `rdp-clipboard` — writes remote clipboard text to the local clipboard via `navigator.clipboard.writeText`

### `MstscClient`
Global factory object exposed to the page.

## Usage Example

```javascript
var canvas = document.getElementById('rdp-canvas');
var client = MstscClient.create(canvas);

client.connect(
  '192.168.1.100',  // RDP host IP
  'DOMAIN',         // Windows domain
  'Administrator',  // username
  'password',       // password
  {},               // options
  function(err) {   // callback on close/error
    if (err) console.error('RDP error:', err.code, err.message);
    else console.log('Session ended');
  }
);

// To disconnect
client.disconnect();
```

> **Note:** Firefox clipboard polling is intentionally skipped to avoid browser permission prompts appearing every second.
