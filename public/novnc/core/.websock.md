A high-performance WebSocket/RTCDataChannel wrapper with built-in binary buffering for both send and receive queues, used by noVNC for efficient binary protocol communication.

## Key Components

- **`Websock` (default export)** — Main class wrapping a raw WebSocket or RTCDataChannel with buffered I/O
- **Receive Queue (`rQ*`)** — 4 MiB ring buffer with methods to read binary data: `rQpeek8`, `rQshift8/16/32`, `rQshiftBytes`, `rQshiftStr`, `rQwait`
- **Send Queue (`sQ*`)** — 10 KiB accumulation buffer with methods to stage outgoing data: `sQpush8/16/32`, `sQpushBytes`, `sQpushString`
- **`flush()`** — Sends all staged data in the send queue over the underlying socket
- **`attach(rawChannel)`** — Binds any WebSocket-compatible object (must implement `send`, `close`, `readyState`, etc.)
- **`open(uri, protocols)`** — Creates a native WebSocket and attaches it
- **`on(evt, handler)` / `off(evt)`** — Registers/removes handlers for `message`, `open`, `close`, `error` events
- **`_expandCompactRQ(minFit)`** — Internal: compacts or resizes the receive buffer, capped at 40 MiB

## Usage Example

```javascript
import Websock from './websock.js';

const ws = new Websock();

ws.on('open', () => {
    // Stage binary data in the send queue
    ws.sQpush8(0x01);
    ws.sQpush16(256);
    ws.sQpushString("hello");
    ws.flush(); // transmit all staged bytes
});

ws.on('message', () => {
    // Check availability before reading
    if (!ws.rQwait("header", 4)) {
        const type = ws.rQshift8();
        const length = ws.rQshift16();
        const payload = ws.rQshiftBytes(length);
    }
});

ws.on('close', (e) => console.log('Closed', e));
ws.on('error', (e) => console.error('Error', e));

ws.open('wss://example.com/vnc', ['binary']);
```
