Provides the complete UI controller for the noVNC HTML5 VNC client, managing the visual interface, settings, connection lifecycle, and all user interactions including keyboard, touch, clipboard, and fullscreen behaviors.

## Key Components

### Utility Functions
- **`isAlphaNumeric(str)`** — Validates strings contain only alphanumeric characters
- **`isSafeString(str)`** — Sanitizes strings against XSS-dangerous characters
- **`parseUriArgs()`** — Parses and sanitizes URL query parameters into a safe key-value map

### UI Object (Main Export)

**Lifecycle Methods**
- **`prime()`** — Entry point; initializes WebUtil settings then calls `start()` when the DOM is ready
- **`start()`** — Renders the UI, binds all event handlers, applies saved settings, and optionally auto-connects
- **`initSettings()`** — Populates default values for all connection/display settings (host, port, quality, resize, etc.)
- **`initFullscreen()`** — Conditionally shows the fullscreen button based on browser support

**Event Handler Registration**
- **`addControlbarHandlers()`** — Binds mouse/keyboard events for the draggable control bar
- **`addTouchSpecificHandlers()`** — Sets up virtual keyboard and touch gesture support
- **`addExtraKeysHandlers()`** — *(partial)* Registers handlers for special key combinations
- **`setupSettingLabels()`** — Associates `<label>` elements with their corresponding inputs

**State Properties**
- `connected`, `desktopName`, `reconnectCallback`, `reconnectPassword` — Connection state
- `controlbarGrabbed`, `controlbarDrag` — Control bar drag interaction state
- `lastKeyboardinput`, `defaultKeyboardinputLen` — Virtual keyboard fallback state

## Usage Example

```javascript
import UI from './ui.js';

// Initialize and start the noVNC UI
UI.prime().then((rfb) => {
  // rfb is the RFB instance if autoconnect is enabled
  console.log('noVNC UI ready', rfb);
}).catch((err) => {
  console.error('Failed to start noVNC UI', err);
});
```
