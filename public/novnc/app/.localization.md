Provides localization utilities for the noVNC HTML5 VNC client, handling language detection, dictionary loading, and DOM translation.

## Key Components

- **`Localizer` (class)** — Core localization manager with three-pass language matching (exact match → English fallback → language-family fallback)
  - `setup(supportedLanguages, baseURL)` — Async initializer; detects browser language preferences and fetches the appropriate JSON translation dictionary
  - `_setupLanguage(supportedLanguages)` — Matches browser languages (`navigator.languages` / `navigator.language`) against supported locales
  - `_setupDictionary(baseURL)` — Fetches `<baseURL>/<language>.json` translation file; skips fetch for English
  - `get(id)` — Returns translated string for a given key, falling back to the key itself if not found
  - `translateDOM()` — Traverses `document.body` and translates text nodes and translatable attributes (`title`, `placeholder`, `alt`, `label`, etc.) respecting the HTML `translate` attribute spec

- **`l10n`** — Pre-instantiated singleton `Localizer` exported for shared use
- **Default export** — `l10n.get` bound to the singleton, for convenient inline translation lookups

## Usage Example

```javascript
import l10n, { l10n as localizer } from './localization.js';

// Initialize with supported locales and translation file base path
await localizer.setup(['de', 'fr', 'es'], '/app/translations');

// Translate a string key
const label = l10n('Connect'); // Returns translated string or 'Connect' as fallback

// Translate all eligible DOM elements after page render
localizer.translateDOM();
```

Translation files are expected as JSON dictionaries at `<baseURL>/<language>.json`:

```json
{ "Connect": "Verbinden", "Disconnect": "Trennen" }
```
