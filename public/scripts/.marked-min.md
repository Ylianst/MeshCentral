Minified build of the [marked](https://marked.js.org/) Markdown parser library (v15+), bundled for use in MeshCentral's web interface. It exposes a universal module (UMD) compatible with CommonJS, AMD, and browser globals.

## Key Components

| Export | Description |
|--------|-------------|
| `marked` | Main namespace/global; entry point for parsing Markdown |
| `marked.defaults` | Default parser options (`gfm`, `breaks`, `pedantic`, `async`, `silent`, etc.) |
| `Tokenizer` (class `m`) | Converts raw Markdown text into a token stream (block and inline rules) |
| Block rules | `space`, `code`, `fences`, `heading`, `hr`, `blockquote`, `list`, `html`, `def`, `table`, `lheading`, `paragraph`, `text` |
| Inline rules | `escape`, `tag`, `link`, `reflink`, `emStrong`, `codespan`, `br`, `del`, `autolink`, `url`, `inlineText` |
| `l()` | HTML escape utility used throughout rendering |
| `a()` | Regex builder helper for composing grammar rules |
| `h()` | Table cell splitter, handles escaped pipe characters |
| `j()` | Link/image token factory |

## Usage Example

```javascript
// CommonJS (Node.js)
const { marked } = require('./marked-min.js');

// Parse a Markdown string to HTML
const html = marked('# Hello\n\nThis is **bold** text.');
console.log(html);
// <h1>Hello</h1><p>This is <strong>bold</strong> text.</p>

// With custom options
marked.setOptions({
  gfm: true,
  breaks: true,
  silent: false
});

const tableMarkdown = `
| Column A | Column B |
|----------|----------|
| value 1  | value 2  |
`;
console.log(marked(tableMarkdown));
```
