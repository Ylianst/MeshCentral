Connection relay module for MeshCentral that manages WebSocket relay sessions between clients and devices, handling authentication, device sharing, session recording, and access rights enforcement.

## Key Components

- **`CreateMeshRelay(parent, ws, req, domain, user, cookie)`** — Main exported factory function. Validates device share public identifiers before delegating to `CreateMeshRelayEx`.
- **`CreateMeshRelayEx(parent, ws, req, domain, user, cookie)`** — Core relay session constructor. Handles cookie expiry, authentication checks, slow relay configuration, protocol patching, and session lifecycle management.
- **`checkDeviceSharePublicIdentifier(parent, domain, nodeid, pid, extraKey, func)`** — Validates a public device sharing identifier against the database before allowing a connection.
- **`recordingEntry(logfile, type, flags, data, func, tag)`** — Exported utility that writes binary or text-format session recording entries to a log file with timestamps and structured headers.
- **Mesh Rights Constants** — Bitmask constants (e.g., `MESHRIGHT_REMOTECONTROL`, `MESHRIGHT_NODESKTOP`, `MESHRIGHT_RELAY`) used to enforce per-user access control.
- **Protocol Constants** — Numeric protocol identifiers for relay types (Terminal=1, Desktop=2, Files=5, Web-RDP=10, Web-SSH=11, Messenger=200, etc.).

## Usage Example

```javascript
const meshrelay = require('./meshrelay');

// Start a relay session (called internally by the WebSocket server)
meshrelay.CreateMeshRelay(parent, ws, req, domain, user, cookie);

// Write a text recording entry to a session log
meshrelay.recordingEntry(logfile, 2, 2, 'Hello from user', function(logfile, tag) {
  console.log('Entry written, log size:', logfile.size);
}, myTag);
```

## Notes

- Connections without valid authentication (`user`, `ruserid`, or `nouser` flag) are immediately dropped.
- Device share sessions subscribe to `removedDeviceShare` events and auto-disconnect if the share is revoked.
- Recording supports both **binary** (structured 16-byte header blocks) and **text** (UTC-timestamped lines) formats.
- Slow relay throttling can be applied via the `slowrelay` query parameter (1–999 ms).
