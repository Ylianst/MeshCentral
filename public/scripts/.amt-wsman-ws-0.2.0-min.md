Provides a WebSocket-based WS-Management (WSMAN) communication client for Intel AMT (Active Management Technology), handling HTTP-over-WebSocket relay with Digest authentication.

## Key Components

| Function/Property | Description |
|---|---|
| `CreateWsmanComm(host, port, user, pass, tls)` | Factory function that creates and returns a WSMAN communication object |
| `o.PerformAjax` | Queues or immediately dispatches a WSMAN request, supporting priority insertion |
| `o.PerformAjaxExNodeJS2` | Core request dispatcher with retry logic (default 3 attempts) and socket state management |
| `o.sendRequest` | Constructs and sends an HTTP/1.1 chunked request over the WebSocket relay with optional Digest auth headers |
| `o.parseDigest` / `o.renderDigest` | Parses and formats HTTP Digest authentication challenge/response headers |
| `o.xxConnectHttpSocket` | Opens a WebSocket connection through a `/webrelay.ashx` proxy endpoint to reach the AMT host |
| `l` (onmessage handler) | Accumulates and parses raw HTTP responses received over the WebSocket binary stream |
| `u` (response handler) | Processes parsed HTTP responses, handles 401 Digest auth challenges (up to 3 retries) |
| `g` (onclose handler) | Handles socket disconnection and triggers retry logic for pending requests |
| `o.CancelAllQueries` | Cancels all pending requests and closes the WebSocket connection |

## Usage Example

```javascript
// Create a WSMAN communication channel to an Intel AMT device via WebSocket relay
var comm = CreateWsmanComm(
  "192.168.1.100",  // AMT host
  16992,            // AMT port (16992 = HTTP, 16993 = TLS)
  "admin",          // username
  "P@ssw0rd!",      // password
  0                 // TLS disabled (1 = enabled)
);

// Send a WSMAN request
comm.PerformAjax(
  "<soap envelope body>",  // request body
  function(responseBody, status, args) {
    if (status === 200) {
      console.log("Response:", responseBody);
    } else {
      console.error("HTTP error:", status);
    }
  },
  { /* args passed back to callback */ },
  0,        // priority (1 = high priority / unshift queue)
  "/wsman"  // endpoint path
);

// Abort all in-flight and queued requests
comm.CancelAllQueries(503);
```

## Notes

- Requests are relayed through a same-origin `/webrelay.ashx` WebSocket proxy rather than connecting directly to the AMT device.
- Digest authentication is handled automatically with `qop=auth` or `qop=auth-int` support using `hex_md5` (expected as a global dependency).
- Maximum concurrent requests is capped at 1 (`MaxActiveAjaxCount=1`); additional calls are queued.
