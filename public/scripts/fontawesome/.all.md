This file is the Font Awesome Free 6.7.2 icon library bundle (`all.js`), which registers SVG icon definitions and style mappings for use in web applications via the Font Awesome JavaScript API.

## Key Components

- **Environment Detection** — Safely detects browser/DOM availability and IE compatibility at runtime
- **Style/Family Mapping Tables** — Lookup dictionaries (`PREFIX_TO_STYLE`, `STYLE_TO_PREFIX`, `FONT_WEIGHT_TO_PREFIX`, etc.) translating between CSS class prefixes (e.g., `fas`, `far`, `fab`), style names (`solid`, `regular`, `brands`), and font families (`classic`, `sharp`, `duotone`)
- **`familyProxy(obj)`** — Wraps style mapping objects in a `Proxy` that falls back to the `classic` family when an unknown family is requested
- **`defineIcons(prefix, icons, params)`** — Registers icon SVG data into the global Font Awesome namespace; triggers `addPack` hook if registered, otherwise merges directly into `namespace.styles`
- **`normalizeIcons(icons)`** — Flattens expanded icon objects into a canonical `{ iconName: iconData }` map
- **`bunker(fn)`** — Error boundary wrapper that swallows exceptions silently in production
- **Global Namespace (`___FONT_AWESOME___`)** — Shared window-level object holding `styles`, `hooks`, and `shims` for cross-script coordination
- **Icon Definitions** — Inline SVG path data for all bundled icons (e.g., `monero`, `hooli`, `yelp`, etc.)

## Usage Example

```javascript
// Font Awesome auto-initializes when the script is loaded.
// To programmatically add custom icons:
defineIcons('fas', {
  'custom-icon': [512, 512, [], 'e001', 'M256 ...svgPath...']
});

// Access the global namespace directly if needed:
const fa = window['___FONT_AWESOME___'];
console.log(fa.styles['fas']); // Registered solid icons

// Style prefix lookup (used internally by FA's DOM watcher):
const style = PREFIX_TO_STYLE['fas']; // → 'solid'
```
