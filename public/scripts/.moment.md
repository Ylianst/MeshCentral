Moment.js is a comprehensive JavaScript date and time manipulation library that provides parsing, validation, formatting, and arithmetic operations for dates across multiple locales and time zones.

## Key Components

- **`moment()`** — Primary factory function for creating Moment objects from strings, Date objects, arrays, or timestamps
- **`Moment`** — Core prototype class wrapping a JavaScript `Date` with extended functionality
- **`Locale`** — Internationalization class managing locale-specific formatting rules and configurations
- **`hooks`** — The main export object (aliased as `moment`) exposing the public API
- **`isValid()`** — Validates parsed date objects against overflow, format errors, and meridiem conflicts
- **`createUTC()`** — Creates Moment instances in UTC mode
- **`createInvalid()`** — Constructs explicitly invalid Moment objects with optional parsing flags
- **`deprecate()` / `deprecateSimple()`** — Deprecation warning system with configurable handlers
- **`copyConfig()`** — Deep-clones Moment configuration including plugin-registered properties
- **`defaultParsingFlags()`** — Returns a fresh parsing state object tracking parse errors and warnings

## Usage Example

```javascript
// CommonJS
const moment = require('./moment');

// Create and format a date
const now = moment();
console.log(now.format('YYYY-MM-DD HH:mm:ss'));

// Parse from string
const birthday = moment('1995-12-25', 'YYYY-MM-DD');
console.log(birthday.isValid()); // true

// UTC mode
const utc = moment.utc('2024-01-15T10:30:00Z');
console.log(utc.format());

// Check if moment instance
console.log(moment.isMoment(now));  // true
console.log(moment.isMoment(new Date())); // false

// Suppress deprecation warnings
moment.suppressDeprecationWarnings = true;
```

## Notes

- Ships as a UMD module (CommonJS, AMD, or browser global)
- Locale support is built-in via the `Locale` class; load additional locales as needed
- Plugin authors should register custom properties via `hooks.momentProperties` to ensure correct cloning behavior
