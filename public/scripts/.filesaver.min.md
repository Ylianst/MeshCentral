Minified implementation of the FileSaver.js library, providing a cross-browser `saveAs()` API for triggering client-side file downloads from Blobs, URLs, or data streams.

## Key Components

- **`saveAs(blob, filename, options)`** — Primary export; detects the best download strategy for the current browser environment
- **`autoBom`** — Option flag that prepends a UTF-8 BOM (`\uFEFF`) to text/XML Blobs when enabled
- **XHR downloader (`c`)** — Fetches a URL as a Blob via `XMLHttpRequest` when direct anchor navigation isn't viable
- **CORS check (`d`)** — Performs a synchronous `HEAD` request to verify same-origin accessibility before downloading
- **Click dispatcher (`e`)** — Fires a synthetic `MouseEvent` click on an `<a>` element, with a legacy `initMouseEvent` fallback
- **Environment detection** — Resolves the global object across `window`, `self`, and `global` contexts (browser, worker, Node)

### Download Strategy Fallback Chain

```text
HTML5 <a download>  →  msSaveOrOpenBlob (IE/Edge legacy)  →  window.open + FileReader/ObjectURL
```

## Usage Example

```javascript
// Save a Blob as a file
const blob = new Blob(["Hello, world!"], { type: "text/plain;charset=utf-8" });
saveAs(blob, "hello.txt");

// Save from a URL
saveAs("https://example.com/report.pdf", "report.pdf");

// Enable BOM for UTF-8 text files (Excel compatibility)
const csvBlob = new Blob([csvData], { type: "text/csv;charset=utf-8" });
saveAs(csvBlob, "data.csv", { autoBom: true });
```
