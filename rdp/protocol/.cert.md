Handles parsing and decoding of RDP server certificates, supporting both proprietary (version 1) and X.509 certificate chain (version 2) formats as defined by the Microsoft RDP protocol specification.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CertificateType` | Object | Enum constants for certificate format versions (`CERT_CHAIN_VERSION_1`, `CERT_CHAIN_VERSION_2`) |
| `certificate()` | Function | Factory that reads and dispatches to the correct certificate parser based on `dwVersion` |
| `proprietaryCertificate()` | Function (internal) | Parses Microsoft proprietary RSA certificate blobs (version 1) |
| `x509CertificateChain()` | Function (internal) | Parses X.509 certificate chains (version 2) |
| `rsaPublicKey()` | Function (internal) | Parses the RSA public key structure embedded in certificates |
| `certBlob()` | Function (internal) | Parses individual X.509 certificate blob entries |

Both `proprietaryCertificate` and `x509CertificateChain` expose a `getPublicKey()` method that returns an RSA public key object with modulus and exponent.

## Usage Example

```javascript
const cert = require('./cert');
const type = require('../core').type;

// Parse a raw certificate buffer received during RDP handshake
const certComponent = cert.certificate();
certComponent.read(new type.Stream(rawCertBuffer));

// Extract the RSA public key from whichever certificate type was parsed
const publicKey = certComponent.obj.certData.obj.getPublicKey();
// publicKey => { n: <modulus BigNum>, e: <exponent integer> }
```
