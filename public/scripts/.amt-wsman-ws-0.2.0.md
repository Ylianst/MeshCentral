WSMAN communication layer that implements Intel AMT management protocol over WebSocket relay connections, handling HTTP digest authentication, chunked transfer encoding, and request queuing.

## Key Components

- **`CreateWsmanComm(host, port, user, pass, tls)`** — Factory function returning a WSMAN communication object configured for a specific AMT target
- **`obj.PerformAjax(postdata, callback, tag, pri, url, action)`** — Public entry point for queued HTTP requests; supports priority ordering
- **`obj.PerformAjaxEx / PerformAjaxExNodeJS2`** — Internal retry logic (up to 3 attempts) with timeout handling (HTTP 408)
- **`obj.sendRequest(postdata, url, action)`** — Builds and sends HTTP/1.1 requests over the WebSocket relay using chunked transfer encoding with optional Digest auth headers
- **`obj.xxConnectHttpSocket()`** — Opens a WebSocket to the relay endpoint (`/webrelay.ashx?p=1&...`) bridging to the AMT host
- **`_OnMessage(e)`** — Parses incoming HTTP responses supporting `Content-Length`, `Transfer-Encoding: chunked`, and connection-close framing
- **`_ProcessHttpResponse(header, data)`** — Handles HTTP 401 challenges by parsing `WWW-Authenticate` headers and retrying with Digest credentials
- **`obj.parseDigest / renderDigest`** — Parses and serializes HTTP Digest `Authorization` headers
- **`obj.FailAllError`** — Global error flag; set to `999` to silently suppress all responses

## Usage Example

```javascript
// Create a WSMAN communication object targeting an AMT device
var wsman = CreateWsmanComm('192.168.1.100', 16992, 'admin', 'P@ssw0rd', 0);

// Send a WSMAN POST request
wsman.PerformAjax(
    '<soap:Envelope>...</soap:Envelope>',  // SOAP postdata
    function(data, status, tag) {          // Callback
        if (status === 'success') console.log('Response:', data);
    },
    'myTag',   // tag
    0,         // priority (1 = high)
    '/wsman',  // URL
    'POST'     // HTTP action
);
```

## Notes

- Requests are serialized (`MaxActiveAjaxCount = 1`) to prevent AMT connection overload
- Digest auth uses MD5 (`hex_md5`) with `auth` and `auth-int` QOP support
