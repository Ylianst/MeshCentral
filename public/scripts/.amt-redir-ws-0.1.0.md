Provides WebSocket-based transport for Intel AMT (Active Management Technology) redirection sessions, supporting SOL (Serial-over-LAN), KVM (remote desktop), and IDER protocols via a WebSocket relay.

## Key Components

- **`CreateAmtRedirect(module, authCookie)`** — Factory function that constructs an AMT redirect object wrapping an inner module (Terminal/Desktop)
- **`obj.Start(host, port, user, pass, tls)`** — Initiates a WebSocket connection to the relay endpoint (`webrelay.ashx`) with protocol and auth parameters
- **`obj.xxOnSocketConnected()`** — Sends the protocol handshake magic bytes on connection (SOL: `0x10...`, KVM: `0x10 0x01...`, IDER: `0x10...`)
- **`obj.xxOnMessage(e)`** — Core message dispatcher handling the AMT redirection protocol state machine:
  - `0x11` — `StartRedirectionSessionReply`: triggers auth query
  - `0x14` — `AuthenticateSessionReply`: performs MD5 Digest authentication with realm/nonce/QOP
  - `0x21` — Settings response: starts keepalive timer (SOL) or signals connected state
  - `0x2A` — Incoming display data: forwards to inner module via `ProcessBinaryData`/`ProcessData`
  - `0x41` — KVM initialization reply
- **`randomHex(length)`** — Generates a random hex string for use as `cnonce` in Digest auth
- **`arrToStr(arr)`** — Converts a byte array to a string via `String.fromCharCode`

## Usage Example

```javascript
// Create a KVM (remote desktop) redirect session
var kvmModule = CreateKvmModule(); // your KVM inner module (protocol: 2)
var redirect = CreateAmtRedirect(kvmModule, 'your-auth-cookie');

// Start connection to AMT device
redirect.Start('192.168.1.100', 16994, 'admin', 'password', 0);

// Listen for state changes
redirect.onStateChanged = function(state) {
    // state 1 = connecting, 2 = handshaking, 3 = connected
    console.log('AMT redirect state:', state);
};
```
