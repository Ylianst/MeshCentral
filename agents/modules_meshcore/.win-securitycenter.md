Windows Security Center integration module that queries firewall, antivirus, and auto-update health status via the Windows `Wscapi.dll` native API, and emits change events when security provider state changes.

## Key Components

- **`getStatus()`** — Calls `WscGetSecurityProviderHealth` for firewall, antivirus, and auto-update providers, returning an object with string statuses (`'OK'`, `'WARNING'`, `'PROBLEM'`, `'UNKNOWN'`).
- **`statusString(val)`** — Maps WSC health integer codes to human-readable status strings.
- **`changed` event** — Emitted via `WscRegisterForChanges` callback whenever the Windows Security Center state changes.
- **WSC constants** — Provider flags (`WSC_SECURITY_PROVIDER_FIREWALL`, `WSC_SECURITY_PROVIDER_ANTIVIRUS`, `WSC_SECURITY_PROVIDER_AUTOUPDATE_SETTINGS`) and health state codes.
- **Platform guard** — Throws if not running on `win32` or if `Wscapi.dll` is unavailable.

## Usage Example

```javascript
// Module throws on non-Windows platforms
var secCenter = require('./win-securitycenter');

// Query current security status
var status = secCenter.status();
console.log(status.firewall);    // 'OK' | 'WARNING' | 'PROBLEM' | 'UNKNOWN'
console.log(status.antiVirus);   // 'OK' | 'WARNING' | 'PROBLEM' | 'UNKNOWN'
console.log(status.autoUpdate);  // 'OK' | 'WARNING' | 'PROBLEM' | 'UNKNOWN'

// Listen for security state changes
secCenter.on('changed', function () {
    var updated = secCenter.status();
    console.log('Security status changed:', updated);
});
```

## Notes

- Requires Windows and the `_GenericMarshal` native module to function.
- The module registers a native callback with `WscRegisterForChanges` and automatically unregisters (`WscUnRegisterChanges`) when the object is garbage collected via the `~` destructor event.
