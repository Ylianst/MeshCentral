WSMAN communication factory for AMT (Intel Active Management Technology) using the Duktape JavaScript runtime's HTTP stack with digest authentication support.

## Key Components

### `CreateWsmanComm(host, port, user, pass, tls)` _(factory function)_

Returns a WSMAN communication object with the following members:

| Member | Description |
|---|---|
| `PerformAjax(postdata, callback, tag, pri, url, action)` | Public entry point; queues or immediately dispatches an HTTP POST request. Pass `pri=1` for high-priority (front-of-queue) placement. |
| `PerformNextAjax()` | Dequeues and executes the next pending request when a slot is available. |
| `PerformAjaxEx(postdata, callback, tag, url, action)` | Executes a single HTTP/HTTPS POST to `/wsman` using `http-digest` and `http` Duktape modules. |
| `gotNextMessages(data, status, request, callArgs)` | Success handler; invokes the caller's callback with response body and HTTP status. |
| `gotNextMessagesError(request, status, errorThrown, callArgs)` | Error handler; invokes callback with structured error info. |
| `CancelAllQueries(s)` | Drains the pending queue, calling each callback with status `s`. |
| `FailAllError` | Non-zero value causes all requests to fail with that status code; `999` suppresses callbacks silently. |

## Usage Example

```javascript
var CreateWsmanComm = require('./amt-wsman-duk');

// Initialize with positional args
var comm = CreateWsmanComm('192.168.1.100', 16992, 'admin', 'Password1!', 0);

// Or with a config object (token-based auth)
var comm = CreateWsmanComm({
    host: '192.168.1.100',
    port: 16993,
    authToken: 'mytoken',
    tls: 1
});

// Send a WSMAN request
comm.PerformAjax(wsmanXmlBody, function(data, status, tag) {
    if (status === 200) {
        console.log('Response:', data);
    } else {
        console.log('Error status:', status);
    }
}, 'myTag', 0, '/wsman', 'action');

// Cancel all queued requests on shutdown
comm.CancelAllQueries(503);
```

> **Runtime note:** This module requires the [Duktape](https://duktape.org/) JS engine and its `http` / `http-digest` native modules. It is **not** compatible with Node.js without a compatibility shim. For the Node.js equivalent, see [`amt-wsman.js`](https://github.com/flamingo-stack/meshcentral/blob/main/amt-wsman.js).
