RFB (Remote Framebuffer) protocol client implementation — the core class that establishes and manages VNC connections over WebSockets or WebRTC data channels, handling authentication, input events, display rendering, and clipboard operations.

## Key Components

- **`RFB` class** (default export) — Main VNC client extending `EventTargetMixin`, managing the full RFB protocol lifecycle
- **Security type constants** — Supports `None`, `VNCAuth`, `RA2ne`, `Tight`, `VeNCrypt`, `XVP`, `ARD`, `MSLogonII`, and `UnixLogon`
- **Frame buffer decoders** — Instantiates `Raw`, `CopyRect`, `RRE`, `Hextile`, `Tight`, `TightPNG`, `ZRLE`, and `JPEG` decoders
- **Input handling** — Integrates `Keyboard`, `GestureHandler`, and mouse event processing with viewport drag support
- **Extended clipboard** — Implements extended clipboard pseudo-encoding with `Caps`, `Request`, `Peek`, `Notify`, and `Provide` actions
- **Key properties** — `viewOnly`, `clipViewport`, `scaleViewport`, `dragViewport`, `focusOnClick`, `capabilities`, `clippingViewport`

## Usage Example

```javascript
import RFB from './rfb.js';

const target = document.getElementById('vnc-container');

const rfb = new RFB(target, 'wss://my-vnc-host:6080', {
  credentials: { password: 'secret' },
  shared: true,
  wsProtocols: ['binary'],
});

// Listen for connection events
rfb.addEventListener('connect', () => console.log('Connected'));
rfb.addEventListener('disconnect', (e) => console.log('Disconnected', e.detail));
rfb.addEventListener('credentialsrequired', (e) => {
  rfb.sendCredentials({ password: prompt('Password:') });
});

// Configure display behavior
rfb.scaleViewport = true;
rfb.clipViewport = false;
rfb.viewOnly = false;
```
