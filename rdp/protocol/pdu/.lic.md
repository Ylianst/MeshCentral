Implements the RDP licensing protocol layer, defining message structures and binary encodings for the RDP license negotiation handshake as specified by Microsoft's MS-RDPBCGR protocol.

## Key Components

**Constants**
- `MessageType` — Enum of license PDU message types (e.g., `LICENSE_REQUEST`, `PLATFORM_CHALLENGE`, `ERROR_ALERT`)
- `ErrorCode` — License error codes per [MS-RDPBCGR §2.2.1.12](http://msdn.microsoft.com/en-us/library/cc240482.aspx), including `STATUS_VALID_CLIENT` and `ERR_NO_LICENSE`
- `StateTransition` — Automata state transitions for the license negotiation flow
- `BinaryBlobType` — Blob type tags for license binary payloads
- `Preambule` — Protocol version flags (`PREAMBLE_VERSION_2_0`, `PREAMBLE_VERSION_3_0`)

**Functions**
- `licenseBinaryBlob(blobType)` — Builds a typed binary blob component with self-describing length
- `licensingErrorMessage(opt)` — Constructs an `ERROR_ALERT` PDU component
- `productInformation()` — Encodes server product info (company name, product ID) in UCS-2
- `scope()` / `scopeList()` — Builds scope and scope list components for license negotiation
- `serverLicenseRequest(opt)` — Parses/builds the server's initial `LICENSE_REQUEST` PDU
- `clientNewLicenseRequest(opt)` — Builds the client `NEW_LICENSE_REQUEST` PDU
- `serverPlatformChallenge(opt)` — Parses the server's `PLATFORM_CHALLENGE` PDU
- `clientPLatformChallengeResponse(opt)` — Builds the client's challenge response PDU
- `licensePacket(message)` — Top-level dispatcher that reads/writes any license PDU, routing by `bMsgtype`

## Usage Example

```javascript
var lic = require('./lic');

// Build a client new license request
var request = lic.clientNewLicenseRequest();

// Wrap any license message in a packet for sending over the wire
var packet = lic.licensePacket(request);

// Parse an incoming license packet (reads from stream)
var inbound = lic.licensePacket(); // Factory auto-dispatches by message type
```
