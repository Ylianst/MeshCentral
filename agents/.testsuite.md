A test suite for validating core MeshCentral utility functions and runtime module integrations, including SHA256 hashing and filesystem operations.

## Key Components

### Utility Functions
- **`toNumberIfNumber(x)`** — Converts numeric strings to integers
- **`char2hex(i)`** / **`rstr2hex(input)`** / **`hex2rstr(d)`** — Decimal/raw string to hex conversion helpers
- **`buf2rstr(buf)`** — Converts a Buffer to a raw string
- **`objToString(x, p, ret)`** — Recursively serializes objects (including functions) to a readable string
- **`splitArgs(str)`** / **`parseArgs(argv)`** — CLI argument parsing utilities
- **`parseUrl(url)`** — Parses a URL string into a structured options object
- **`addPad(p, ret)`** — Pads strings with repeating characters

### Test Cases
- **Test 1** — SHA256 hashing via `SHA256Stream`; validates the hash of `"bob"` equals the expected hex digest
- **Test 2** *(commented out)* — `SimpleDataStore` database round-trip with SHA256 keying and compaction
- **Test 3** — Filesystem operations via Node's `fs` module: `mkdirSync`, `renameSync`, and `unlinkSync`

## Usage Example

```javascript
// Run the test suite directly with Node.js or MeshCentral's JS runtime
// node testsuite.js

// Utility function examples extracted from the suite:

// Parse a CLI-style argument string
const args = parseArgs(['node', 'script.js', '--host', 'localhost', '--port', '8080']);
// → { _: [], host: 'localhost', port: 8080 }

// Parse a URL into connection options
const opts = parseUrl('https://example.com/api/v1');
// → { protocol: 'https:', hostname: 'example.com', port: 443, path: '/api/v1' }

// Convert a buffer to a hex string
const hex = rstr2hex(buf2rstr(Buffer.from('hello')));
// → '68656C6C6F'
```

> **Note:** This file exits with code `2` via `process.exit(2)` after all tests complete. It is intended as a standalone diagnostic script, not a framework-integrated test runner.
