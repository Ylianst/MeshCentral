Minimal WebRTC data channel wrapper for KVM (Keyboard/Video/Mouse) remote control sessions in MeshCentral, bridging binary and string message handling between an RTC channel and a protocol module.

## Key Components

- **`CreateKvmDataChannel(e, t, n)`** — Factory function returning a channel object (`a`) that manages:
  - `a.Start()` — Attaches message listener to the WebRTC channel and starts a 30-second keep-alive interval
  - `a.Stop()` — Clears the keep-alive timer and resets state to `0`
  - `a.send(e)` — Sends binary data (converts string → `Uint8Array` before transmitting)
  - `a.sendCtrlMsg(e)` — Sends string control messages and triggers an optional external keep-alive
  - `a.xxOnMessage(e)` — Handles incoming messages; routes binary blobs through `FileReader`, plain strings to `onControlMsg`
  - `a.xxOnSocketData(e)` — Normalizes binary (`ArrayBuffer`) or string data and forwards to `t.ProcessData()`
  - `a.xxStateChange(e)` — Updates state and notifies both the protocol module and optional `onStateChanged` callback
  - `a.xxSendRtcKeepAlive()` — Sends `{"action":"ping"}` on the control channel every 30 seconds

## Usage Example

```javascript
// Assumes an open RTCDataChannel (webChannel) and a protocol module (kvmModule)
const keepAlive = { sendKeepAlive: () => console.log('keepalive sent') };

const channel = CreateKvmDataChannel(webChannel, kvmModule, keepAlive);

// Hook state/control callbacks before starting
channel.onStateChanged = (ch, state) => console.log('State:', state);
channel.onControlMsg  = (msg) => console.log('Control message:', msg);

channel.Start(); // Connects message handlers, begins 30s ping interval

// Send binary KVM data
channel.send('\x01\x02\x03');

// Send a JSON control message
channel.sendCtrlMsg(JSON.stringify({ action: 'resize', w: 1280, h: 720 }));

channel.Stop(); // Cleans up interval, resets state
```

## Notes

- **`FileReader` queue** (`l`, `o`) serializes blob reads to avoid concurrent async reads — blobs are queued and processed one at a time.
- Falls back from `readAsBinaryString` → `readAsArrayBuffer` → manual `Uint8Array` iteration for broad browser compatibility.
