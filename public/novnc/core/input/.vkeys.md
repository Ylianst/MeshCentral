Maps Microsoft Windows Virtual-Key (VK) codes to their corresponding HTML `KeyboardEvent.code` string values, used by the noVNC HTML5 VNC client for cross-platform keyboard input handling.

## Key Components

**Default Export** — A plain object literal where:
- **Keys** are hexadecimal Windows Virtual-Key codes (e.g., `0x08`, `0x70`)
- **Values** are W3C `KeyboardEvent.code` strings (e.g., `'Backspace'`, `'F1'`)

**Key groups covered:**

| Range | Keys |
|---|---|
| `0x08–0x1d` | Control keys (Backspace, Tab, Enter, Shift, Ctrl, Alt, Escape, etc.) |
| `0x20–0x2f` | Navigation (Arrow keys, Page Up/Down, Home, End, Insert, Delete) |
| `0x30–0x39` | Digit row (`Digit0`–`Digit9`) |
| `0x5b–0x5f` | Meta/Windows keys, ContextMenu, Sleep |
| `0x60–0x6f` | Numpad (0–9, arithmetic operators) |
| `0x70–0x87` | Function keys (`F1`–`F24`) |
| `0x90–0x91` | NumLock, ScrollLock |
| `0xa6–0xb7` | Browser controls, media keys, volume, launch shortcuts |
| `0xe1` | AltGraph (mapped as `'AltRight'`) |

> **Note:** `0x6e` (`NumpadDecimal`) is intentionally duplicated due to a known Windows bug.

## Usage Example

```javascript
import vkeys from './vkeys.js';

function translateVirtualKey(vkCode) {
    const htmlKey = vkeys[vkCode];
    if (!htmlKey) {
        return null; // Unmapped key
    }
    return htmlKey;
}

// Translate a Windows VK_F5 (0x74) to its HTML key code
console.log(translateVirtualKey(0x74)); // → 'F5'

// Translate VK_RETURN (0x0d)
console.log(translateVirtualKey(0x0d)); // → 'Enter'

// Handle unknown key
console.log(translateVirtualKey(0x99)); // → null
```
