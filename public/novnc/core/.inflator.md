Wrapper class around the pako zlib `inflate` functions, providing a stateful zlib decompression interface used within the noVNC client for decoding compressed VNC data streams.

## Key Components

### `Inflate` (default export)
A stateful zlib decompressor backed by a single reusable `ZStream` instance.

| Method | Description |
|--------|-------------|
| `constructor()` | Initializes a `ZStream` with a 100 KB output buffer and calls `inflateInit`. |
| `setInput(data)` | Sets the compressed input bytes (`Uint8Array`) on the stream. Pass `null`/falsy to clear input. |
| `inflate(expected)` | Decompresses exactly `expected` bytes. Resizes the output buffer if needed. Returns a `Uint8Array` slice of the result. Throws on zlib error or incomplete block. |
| `reset()` | Resets the zlib stream state via `inflateReset`, allowing reuse without re-initialization. |

## Usage Example

```javascript
import Inflate from './inflator.js';

const inflator = new Inflate();

// Feed compressed data
inflator.setInput(compressedUint8Array);

// Decompress, providing the expected output byte count
const decompressed = inflator.inflate(expectedByteCount);

// Reuse the same instance for the next compressed block
inflator.reset();
inflator.setInput(nextCompressedChunk);
const next = inflator.inflate(nextExpectedSize);
```

## Notes

- The output buffer auto-grows when `expected` exceeds the current `chunkSize` (default: 100 KB), avoiding repeated small allocations.
- Throws `Error("zlib inflate failed")` if pako returns a negative status code.
- Throws `Error("Incomplete zlib block")` if fewer bytes than `expected` are produced.
