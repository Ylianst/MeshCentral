Parses and handles Intel AMT (Active Management Technology) events from WSMAN XML messages, converting raw XML payloads into structured JavaScript objects.

## Key Components

- **`CreateAmtEventsHandler(parent)`** — Factory function that returns an event handler object bound to a parent MeshCentral context
- **`ParseWsman(xml)`** — Private method that parses WSMAN XML envelopes, extracting `Header` and `Body` fields into a structured object
- **`_ParseWsmanRec(node)`** — Private recursive helper that walks XML child nodes, converting text content and attributes into a nested JS object; handles boolean coercion and array deduplication
- **`handleAmtEvent(data, nodeid, amthost)`** — Public method that accepts a raw WSMAN XML string/document, parses it, and logs the originating host/node (dispatch logic is stubbed with a TODO)
- **`_turnToXml(text)`** / **`_turnToXmlRec(text)`** — Lightweight XML parser that replaces a full XML parser dependency, building a DOM-like tree with `getElementsByTagName`, `childNodes`, and attribute support
- **`_treeBuilder`** — Internal stack-based helper used by `_turnToXmlRec` to manage element nesting and XML namespace resolution during parsing

## Usage Example

```javascript
const amtevents = require('./amtevents');

const handler = amtevents.CreateAmtEventsHandler(parentObj);

// Process a raw WSMAN XML event string from an AMT device
const rawXml = '<?xml version="1.0"?>...<a:Envelope>...</a:Envelope>';
const parsed = handler.handleAmtEvent(rawXml, 'node-id-abcdef', '192.168.1.100');

// parsed => { Header: { Action: '...', ResourceURI: '...' }, Body: { AlertType: '8', ... } }
```

## Notes

- The built-in `_turnToXml` parser handles namespace prefixes (e.g., `a:Header`, `g:CIM_AlertIndication`) without requiring an external XML library
- Event dispatching in `handleAmtEvent` is currently incomplete (marked TODO); the method returns the parsed object for upstream use
