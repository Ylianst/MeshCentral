Mini DHCP client module for Linux that fetches network configuration data via UDP broadcast. It bundles a `promise2` polyfill and implements the DHCP Discover/Offer handshake to retrieve IP configuration from a DHCP server.

## Key Components

- **`promise2` module** — Embedded Base64-encoded Promise polyfill (`addModule`) used internally for async DHCP operations
- **`_hide` global utility** — Lightweight helper for managing hidden/internal object references across the module
- **`Function.prototype.internal`** — Property shim ensuring compatibility with the internal event-switcher pattern used by `promise2`
- **DHCP client logic** — Sends a DHCPDISCOVER broadcast over UDP and parses the DHCPOFFER response to extract options (IP, subnet mask, gateway, DNS, etc.)

## Usage Example

```javascript
// Typical invocation from a MeshAgent context on Linux
var dhcp = require('linux-dhcp');

dhcp.getInfo('eth0').then(function(info) {
    console.log('Assigned IP:', info.ip);
    console.log('Subnet mask:', info.subnet);
    console.log('Gateway:',     info.gateway);
    console.log('DNS servers:', info.dns);
}).catch(function(err) {
    console.error('DHCP discovery failed:', err);
});
```

> **Note:** The module requires raw UDP socket access (typically `SOCK_DGRAM` on port 68/67) and is intended to run as root or with appropriate Linux capabilities on the target device.
