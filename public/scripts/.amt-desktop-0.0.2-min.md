Minified JavaScript module implementing an AMT (Intel Active Management Technology) Remote Desktop client using the RFB/VNC protocol over a canvas element.

## Key Components

- **`CreateAmtRemoteDesktop(canvasId, scrollDiv)`** — Factory function that initializes and returns a remote desktop session object bound to an HTML canvas
- **Pixel rendering functions** — `s()` (8bpp), `c()` (16bpp), `h()`/`d()` (run-length fill) handle color format conversions including grayscale and low-color modes
- **`o()`** — Tile decoder supporting RFB encoding types: raw, solid fill, color palettes (2–16 colors), RLE (type 128), and mixed palette+RLE
- **`i()`** — `putImageData` wrapper that applies rotation transforms before committing pixels to the canvas
- **`ProcessBinaryData()`** — Core RFB state machine (states 0–4, 100+) that handles protocol handshake, server init, framebuffer updates, and zlib-compressed tile data
- **`hold()`** / **`setRotation()`** — Session control helpers for pausing rendering and rotating the canvas 0°/90°/180°/270°
- **Key map (`m`)** — Maps browser `KeyboardEvent.code` values to RFB keysym codes for keyboard input forwarding
- **`f()`** — Sends framebuffer update requests, with optional focus-region mode

## Usage Example

```javascript
// Create a remote desktop session bound to a canvas element
const rd = CreateAmtRemoteDesktop("myCanvas", "myScrollDiv");

// Attach to a parent transport (WebSocket wrapper)
rd.parent = myWebSocketTransport;

// Start the session
rd.Start();

// Feed incoming binary data from the WebSocket
websocket.onmessage = (event) => {
  rd.ProcessBinaryData(event.data);
};

// Rotate the display (0=normal, 1=90°, 2=180°, 3=270°)
rd.setRotation(1);

// Pause/resume rendering (e.g. on tab visibility change)
rd.hold(true);  // pause
rd.hold(false); // resume
```

## Notes

- Requires `ZLIB.inflateInit` and helper functions (`ShortToStr`, `IntToStr`, `Q`, `QS`) to be available in scope
- Supports 8bpp and 16bpp color depths, grayscale, low-color, and optional zlib tile compression
