MeshCentral Intel AMT Manager — orchestrates lifecycle management of Intel Active Management Technology (AMT) devices, handling device registration, connection tracking, 802.1x/Wi-Fi profile validation, and WSMAN stack interactions across CIRA, Relay, LMS, and Local connection types.

## Key Components

- **`CreateAmtManager(parent)`** — Factory function that initializes the AMT manager singleton, configuring domain admin accounts, environment detection, 802.1x wired profiles, and Wi-Fi profiles from the server config.

- **`obj.amtDevices`** — Registry mapping node IDs to active AMT device sessions.

- **`obj.activeLocalConnections`** — Tracks active local (LAN) AMT connections by host.

- **`obj.amtAdminAccounts`** — Per-domain administrator credential store loaded from config.

- **`isAmtDeviceValid(dev)`** — Checks whether a given device object is currently managed.

- **`addAmtDevice(dev)`** — Registers a new AMT device session for management.

- **`removeAmtDevice(dev, tag)`** — Tears down a single AMT device session: cancels WSMAN queries, clears poll timers, releases task limiter slots, and notifies LMS connections of closure.

- **`removeDevice(nodeid)`** — Removes all AMT sessions for a given node ID, including 802.1x satellite notification dispatch.

- **WSMAN Stack** — Integrates `amt-wsman-comm`, `amt-wsman`, and `amt` modules for AMT protocol communication.

## Usage Example

```javascript
const amtManager = require('./amtmanager').CreateAmtManager(parent);

// Check if a device is actively managed
if (isAmtDeviceValid(dev)) {
    console.log('Device is managed:', dev.nodeid);
}

// Add a new AMT device for management
const added = addAmtDevice(dev);
if (added) {
    console.log('Started managing:', dev.nodeid);
}

// Remove a specific device session
removeAmtDevice(dev, 'connection-lost');

// Remove all sessions for a node
removeDevice('node//domain//abc123');
```
