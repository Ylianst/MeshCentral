Handles theme initialization and Select2 widget setup on page load by reading persisted theme preferences from `localStorage` and applying the corresponding Bootstrap CSS stylesheet.

## Key Components

- **Theme restoration** — Reads `theme` from `localStorage` and dynamically updates the `#theme-stylesheet` `<link>` element's `href` to load the matching Bootstrap theme CSS. The `default` theme resolves to the parent `..` directory as a safe path fallback.
- **Select2 initialization** — Configures all `.select2` elements using the `bootstrap-5` theme, with responsive width logic derived from element data attributes or CSS classes.

## Usage Example

```javascript
// Assumes the following elements exist in the DOM:
// <link id="theme-stylesheet" href="styles/themes/../bootstrap-min.css" rel="stylesheet">
// <select class="select2 w-100" data-placeholder="Choose an option">...</select>

// Set a theme before the page loads to have it applied automatically:
localStorage.setItem("theme", "dark");

// On DOMContentLoaded, the stylesheet href becomes:
// styles/themes/dark/bootstrap-min.css

// For the default theme:
localStorage.setItem("theme", "default");
// Resolves to: styles/themes/../bootstrap-min.css
```

## Notes

- Requires **jQuery**, **Select2**, and a `#theme-stylesheet` `<link>` element to be present.
- Theme names are sanitized with `encodeURIComponent` to prevent path traversal; `default` is intentionally mapped to `..` to fall back to the base stylesheet directory.
- Select2 width is resolved in priority order: `data-width` attribute → `w-100` class → `"style"` (inherits from CSS).
