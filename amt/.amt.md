Intel AMT (Active Management Technology) communication stack service that wraps WSMAN protocol operations for managing Intel AMT-enabled devices. Provides both individual and batch operations for ENUMERATE, GET, PUT, CREATE, DELETE, and method execution.

## Key Components

- **`AmtStackCreateService(wsmanStack)`** — Factory function that creates the AMT stack service object wrapping a WSMAN stack instance
- **`Get / Put / Create / Delete`** — Individual WSMAN CRUD operations with callback-based responses
- **`Exec / ExecWithXml`** — WSMAN method invocation with standard or XML-formatted arguments
- **`Subscribe / UnSubscribe`** — WSMAN event subscription management
- **`Enum`** — WSMAN ENUMERATE + PULL operation with concurrency limiting via `MaxActiveEnumsCount`
- **`BatchEnum`** — Executes multiple ENUM (or GET with `*` prefix) operations sequentially, aggregating results
- **`BatchGet`** — Executes multiple GET operations sequentially
- **`CompleteName`** — Resolves short class names (`AMT_`, `CIM_`, `IPS_` prefixes) to full schema URIs
- **`RequestPowerStateChange / RequestOSPowerStateChange`** — Convenience wrappers for power management operations
- **`onProcessChanged`** — Optional callback fired when the number of pending operations changes, useful for progress tracking

## Usage Example

```javascript
const wsmanStack = createWsmanStack(/* connection config */);
const amt = AmtStackCreateService(wsmanStack);

// Track progress
amt.onProcessChanged = (current, max) => {
  console.log(`Progress: ${current}/${max}`);
};

// Single GET
amt.Get('AMT_GeneralSettings', (stack, name, response, status) => {
  if (status === 200) console.log(response.Body);
});

// Batch enumeration (mix of ENUM and GET using * prefix)
amt.BatchEnum('setup', ['AMT_EthernetPortSettings', '*AMT_GeneralSettings'], (stack, name, results, status) => {
  console.log(results['AMT_GeneralSettings']);
  console.log(results['AMT_EthernetPortSettings']);
});

// Power management
amt.RequestPowerStateChange(5 /* cycle */, (stack, name, response, status) => {
  console.log('Power state changed:', status);
});
```
