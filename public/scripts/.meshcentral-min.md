Minimal WebSocket control client factory for establishing and managing a real-time connection to the MeshCentral server's `control.ashx` endpoint.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `MeshServerCreateControl` | Factory Function | Creates and returns a WebSocket control object (`n`) managing connection lifecycle, messaging, and state |
| `n.Start()` | Method | Opens the WebSocket connection, handles auth cookie injection, and starts a 29-second ping interval |
| `n.Stop(code)` | Method | Closes the WebSocket, clears the ping timer, and resets connection state |
| `n.send(data)` | Method | Serializes and transmits a JSON message; suppresses ping messages from trace logging |
| `n.xxOnMessage(event)` | Internal Handler | Parses incoming messages, handles `ping`/`pong` keepalive, `close` actions, and dispatches to `n.onMessage` |
| `n.xxStateChange(state, cause)` | Internal Handler | Updates `n.State` and fires the `onStateChanged` callback when state transitions occur |

**State values:** `0` = disconnected, `1` = connecting, `2` = connected

## Usage Example

```javascript
// Create a control connection to the MeshCentral server
const control = MeshServerCreateControl('/path/', 'optional-auth-cookie');

// Listen for state changes (0=disconnected, 1=connecting, 2=connected)
control.onStateChanged = function(ctrl, newState, oldState, cause) {
  console.log(`State changed: ${oldState} → ${newState}`);
};

// Listen for incoming server messages
control.onMessage = function(ctrl, message) {
  console.log('Server message:', message);
};

// Optional: enable trace logging (1=object, 2=JSON string)
control.trace = 1;

// Start the WebSocket connection
control.Start();

// Send a custom action to the server
control.send({ action: 'myAction', data: 'value' });

// Gracefully disconnect
control.Stop();
```

## Notes

- The factory appends `?key=` from `urlargs.key` if present in the page URL
- Auth cookies are sent post-connect via a `urlargs` action rather than in the URL query string
- Ping/pong keepalive runs every **29 seconds** to prevent idle connection timeouts
