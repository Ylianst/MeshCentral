Shared utility library for MeshCentral providing binary encoding/decoding, string manipulation, cryptographic helpers, HTML escaping, and database field name escaping used throughout the platform.

## Key Components

| Export | Description |
|--------|-------------|
| `ReadShort` / `ReadInt` | Big-endian binary integer readers from character strings |
| `ReadShortX` / `ReadIntX` | Little-endian variants of the binary readers |
| `ShortToStr` / `IntToStr` | Convert integers to binary character strings (big/little-endian) |
| `hex2rstr` / `rstr2hex` | Convert between hex strings and raw binary strings |
| `ComputeDigesthash` | MD5 digest authentication hash (RFC 2617) |
| `escapeHtml` / `escapeHtmlBreaks` | HTML entity escaping for safe output |
| `escapeFieldName` / `unEscapeFieldName` | Percent-encode field names for MongoDB/NeDB compatibility |
| `escapeLinksFieldName` / `unEscapeLinksFieldName` | Escape `links`, `ssh`, and `rdp` document fields for database storage |
| `aceEscapeFieldNames` / `aceUnEscapeFieldNames` | URI-encode field names for AceBase compatibility |
| `objKeysToLower` | Recursively lowercase all object keys with exception support |
| `random` | Unbiased cryptographic random number generator |
| `quoteSplit` | Split comma-separated strings respecting quoted values |
| `IsFilenameValid` | Validate filenames against reserved names and invalid characters |
| `format` | `{0}`, `{1}` style string formatting |
| `zeroPad` | Zero-pad numbers to a given width |

## Usage Example

```javascript
const common = require('./common');

// Binary encoding
const buf = common.IntToStr(0xDEADBEEF);
const val = common.ReadInt(buf, 0); // 0xDEADBEEF

// Digest authentication
const hash = common.ComputeDigesthash(
  'admin', 'password', 'MeshCentral',
  'GET', '/api/v1/resource',
  'auth', 'abc123nonce', '00000001', 'clientnonce'
);

// Safe HTML output
const safe = common.escapeHtml('<script>alert("xss")</script>');

// Database field escaping (NeDB/MongoDB)
const doc = { links: { 'user@domain.com': { rights: 1 } } };
const escaped = common.escapeLinksFieldName(doc);
// { links: { 'user@domain%2Ecom': { rights: 1 } } }
const restored = common.unEscapeLinksFieldName(escaped);

// Unbiased random number [0, 99]
const n = common.random(99);

// String formatting
const msg = common.format('Hello {0}, you have {1} messages', 'Alice', 5);
```
