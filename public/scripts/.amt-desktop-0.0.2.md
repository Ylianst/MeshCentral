Remote Desktop client implementation for Intel AMT KVM sessions using the RFB/VNC protocol over WebSockets. Handles connection handshake, pixel encoding negotiation, framebuffer updates, and user input (mouse/keyboard) events.

## Key Components

- **`CreateAmtRemoteDesktop(divid, scrolldiv)`** — Factory function that constructs and returns a remote desktop session object bound to a canvas element
- **State Machine** (`obj.state`) — Drives the RFB handshake sequence: version exchange (0) → security negotiation (1→2) → security response (3) → server init (4) → active session (100+)
- **`obj.ProcessBinaryData(data)`** — Core ingestion loop; appends incoming WebSocket binary frames to an accumulator buffer and dispatches state-machine transitions
- **Pixel Format Negotiation** — Supports RGB565 (16-bit, default), RGB332 (8-bit), and grayscale/low-color modes via `obj.bpp` and `obj.graymode`/`obj.lowcolor` flags
- **Encoding Support** — Advertises RAW (0), RLE (16), Desktop Size (-223), and optionally KVM in-band extension (1092) encodings to the AMT server
- **Rotation & Focus modules** (`###BEGIN###/{DesktopRotation}`, `###BEGIN###/{DesktopFocus}`) — Conditional compilation blocks for screen rotation and mouse focus tracking
- **In-band KVM data** (`###BEGIN###/{DesktopInband}`) — Supports `kvmExt` extensions including ZLib compression and decimation mode control
- **ZLIB inflate** (`###BEGIN###/{Inflate}`) — Uses `ZLIB.inflateInit(-15)` for raw deflate stream decompression

## Usage Example

```javascript
// Create a remote desktop session bound to a canvas
var desktop = CreateAmtRemoteDesktop('myCanvas', 'myScrollDiv');

// Configure display options before connecting
desktop.bpp = 2;          // 16-bit color (RGB565)
desktop.useRLE = true;    // Enable RLE compression
desktop.graymode = false; // Full color

// Hook into screen size changes
desktop.onScreenSizeChange = function (obj, w, h) {
    console.log('Remote screen:', w, 'x', h);
};

// Feed incoming WebSocket binary frames
websocket.onmessage = function (evt) {
    desktop.ProcessBinaryData(evt.data);
};
```
