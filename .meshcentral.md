Main entry point for the MeshCentral server. Initializes and orchestrates all server subsystems including the web server, database, Intel AMT management, agent handling, certificates, and multi-server support.

## Key Components

- **`CreateMeshCentralServer(config, args)`** — Factory function that constructs the central server object with all subsystem references (`webserver`, `mpsserver`, `mqttbroker`, `letsencrypt`, etc.)
- **`obj.Start()`** — Bootstraps the server: validates CLI arguments, merges environment variables (prefixed `meshcentral_`), connects to the database, and starts all services
- **`obj.taskLimiter`** — A task limiter queue (max 50 tasks, 20s timeout) to smooth server workload via `common.createTaskLimiterQueue`
- **`obj.connectivityByNode`** — Tracks live agent/CIRA/AMT connections per node ID
- **`obj.peerConnectivityByNode`** — Tracks peer server connectivity by server ID and node ID
- **`obj.meshAgentBinaries`** / **`obj.meshToolsBinaries`** — Registries of agent and tool binaries with SHA-384 hashes and paths
- **`getCurrentVersion()`** — Reads server version from `package.json`
- **Path setup** — Automatically resolves `datapath`, `filespath`, `backuppath`, `recordpath`, and web asset paths depending on whether MeshCentral is installed as an npm module or standalone

## Usage Example

```javascript
const config = require('./config.json');
const args = require('minimist')(process.argv.slice(2));

const meshServer = CreateMeshCentralServer(config, args);
meshServer.Start();
```

## Notes

- Supports `MESHCENTRAL_*` environment variables as CLI argument overrides
- Windows-specific: integrates `node-windows` for service and event log management
- Temporary files in `meshcentral-files/tmp` older than 30 minutes are cleaned on startup
