Remote Desktop agent implementation for MeshCentral providing KVM (keyboard, video, mouse) control over remote desktop sessions via canvas rendering.

## Key Components

### `CreateAgentRemoteDesktop(canvasid, scrolldiv)`
Factory function that constructs and returns a remote desktop session object with the following core members:

- **`obj.Start()`** — Initializes session state and resets the accumulator
- **`obj.Stop()`** — Tears down the session, clears canvas, releases input grabs
- **`obj.ProcessPictureMsg(data, X, Y)`** — Decodes incoming JPEG tile data and queues it for rendering on the canvas
- **`obj.DoPendingOperations()`** — Processes the ordered tile draw queue, ensuring frames render in sequence
- **`obj.ProcessCopyRectMsg(str)`** — Handles rectangle copy operations for efficient screen updates
- **`obj.ProcessScreenMsg(width, height)`** — Handles remote screen resize events and resets rendering state
- **`obj.ProcessBinaryCommand(cmd, cmdsize, view)`** — Dispatches incoming binary protocol commands (tiles, screen size, display info, touch init)
- **`obj.SendCompressionLevel(type, level, scaling, frametimer)`** — Configures image type (JPEG/PNG/TIFF/WebP), compression, scaling, and frame rate
- **`obj.SendRefresh()`** / **`obj.SendPause()`** / **`obj.SendUnPause()`** — Session flow control commands
- **`obj.xxStateChange(newstate)`** — Manages connection state transitions

### Key Properties
| Property | Description |
|---|---|
| `connectmode` | Transport type: `0` = HTTP, `1` = WebSocket, `2` = WebRTC |
| `ImageType` | `1` = JPEG, `2` = PNG, `3` = TIFF, `4` = WebP |
| `rotation` | Canvas rotation state |
| `RemoteInputLock` | Remote user input lock state |
| `KeyboardState` | Bitmask: `1` = NumLock, `2` = ScrollLock, `4` = CapsLock |

## Usage Example

```javascript
// Initialize remote desktop on a canvas element
var rd = CreateAgentRemoteDesktop('myCanvas', document.getElementById('scrollDiv'));

// Hook into screen resize events
rd.onScreenSizeChange = function(obj, width, height, canvas) {
    console.log('Remote screen resized to', width, 'x', height);
};

// Attach to a transport parent (e.g. WebSocket wrapper)
rd.parent = myWebSocketConnection;

// Start the session and configure compression
rd.Start();
rd.SendCompressionLevel(1, 50, 1024, 100); // JPEG, 50% quality, 1024 scaling, 100ms frame timer
rd.SendUnPause();
```
