Cross-platform module that draws animated colored borders around all connected monitors to visually identify displays during remote support sessions, with separate implementations for Windows and Linux.

## Key Components

### `windows_monitorborder`
Windows implementation using Win32 GDI APIs via `user32.dll` and `gdi32.dll`. Draws red/yellow animated borders that cycle through 8 states (segments illuminated clockwise) at 450ms intervals using `FillRect` on the desktop device context.

- **`Start()`** — Fetches monitor info, acquires the desktop DC, and begins the animation interval
- **`Stop()`** — Clears the interval and invalidates the screen regions to restore original display

### `linux_monitorborder`
Linux implementation using X11 APIs. Detects Unity desktop and branches behavior:

- **Non-Unity:** Draws directly on the root window using `XDrawLine` with XOR graphics context
- **Unity:** Creates four borderless overlay windows (top, right, left, bottom) positioned at screen edges since direct root window drawing is blocked

- **`Start()`** — Retrieves display/monitor info and sets up borders per display
- **`Stop()`** — Clears drawn lines or destroys overlay windows

## Usage Example

```javascript
// Windows
var border = new windows_monitorborder();
border.Start(); // Begins animated red/yellow border on all monitors
// ... later ...
border.Stop();  // Removes borders and repaints affected regions

// Linux
var border = new linux_monitorborder();
border.Start(); // Draws X11 borders or Unity overlay windows
border.Stop();  // Clears all borders
```

## Notes

- Both constructors extend `EventEmitter` and automatically call `Stop()` on object destruction (`~` event)
- The Windows animation cycles through 8 states, highlighting border segments in yellow sequentially against a red background
