Bootstrap v5.3.3 bundled library — provides the complete UI component framework including DOM utilities, event handling, and interactive components (modals, dropdowns, tooltips, etc.) for web applications.

## Key Components

| Component | Description |
|-----------|-------------|
| `Data` | Element-instance registry using a `Map` for storing component state |
| `EventHandler` | Custom event system with namespacing, delegation, and jQuery compatibility |
| `Manipulator` | DOM attribute/style manipulation utilities |
| `BaseComponent` | Abstract base class for all Bootstrap components |
| `Alert`, `Button`, `Carousel` | Interactive UI components |
| `Collapse`, `Dropdown`, `Modal` | Overlay and toggle components |
| `Offcanvas`, `Popover`, `ScrollSpy` | Advanced positioning components |
| `Tab`, `Toast`, `Tooltip` | Notification and navigation components |

**Utility functions include:** `getUID`, `getElement`, `isVisible`, `isDisabled`, `executeAfterTransition`, `getNextActiveElement`, `defineJQueryPlugin`

## Usage Example

```javascript
// Via CDN script tag — components available on window.bootstrap
const modal = new bootstrap.Modal(document.getElementById('myModal'), {
  backdrop: 'static',
  keyboard: false
});
modal.show();

// Event delegation via EventHandler
bootstrap.EventHandler.on(document, 'click', '.btn', event => {
  console.log('Button clicked', event.delegateTarget);
});

// Retrieve an existing component instance
const instance = bootstrap.Modal.getInstance(document.getElementById('myModal'));
instance?.hide();

// jQuery plugin interface (if jQuery is present)
$('#myModal').modal('show');
```

## Notes

- Supports UMD (CommonJS, AMD, global) module formats
- jQuery integration is opt-in; suppressed via `data-bs-no-jquery` on `<body>`
- One component instance per element is enforced — duplicate instantiation logs a console error
- Source: [bootstrap.js](https://github.com/flamingo-stack/meshcentral/blob/main/bootstrap.js)
