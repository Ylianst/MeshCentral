Implements RSA-PKCS1-v1_5 encryption and decryption using BigInt arithmetic, providing a Web Crypto API-compatible interface for key generation, import, export, and message encryption/decryption.

## Key Components

- **`RSACipher`** — Main class implementing RSA operations with PKCS#1 v1.5 padding
  - `generateKey(algorithm, extractable, keyUsages)` — Static factory; generates an RSA key pair via Web Crypto API and stores the JWK components
  - `importKey(key, algorithm, extractable, keyUsages)` — Static factory; imports a raw public key `{ n, e }` (encrypt-only)
  - `encrypt(algorithm, message)` — Applies PKCS#1 v1.5 padding and performs modular exponentiation with the public exponent
  - `decrypt(algorithm, message)` — Reverses PKCS#1 v1.5 padding after modular exponentiation with the private exponent
  - `exportKey()` — Returns raw `{ n, e, d }` byte arrays if the key was marked extractable
  - `algorithm` — Getter returning `{ name: "RSA-PKCS1-v1_5" }`

## Usage Example

```javascript
import { RSACipher } from "./rsa.js";

// Generate a new RSA key pair
const { privateKey } = await RSACipher.generateKey(
  { modulusLength: 2048, publicExponent: new Uint8Array([1, 0, 1]) },
  true,
  ["encrypt", "decrypt"]
);

// Encrypt a message
const message = new TextEncoder().encode("hello");
const ciphertext = await privateKey.encrypt({}, message);

// Decrypt the message
const plaintext = await privateKey.decrypt({}, ciphertext);
console.log(new TextDecoder().decode(plaintext)); // "hello"

// Import a raw public key (encrypt only)
const exported = await privateKey.exportKey();
const publicKey = await RSACipher.importKey(
  { n: exported.n, e: exported.e },
  {},
  false,
  ["encrypt"]
);
```

## Notes

- Internally uses `modPow` and BigInt conversion utilities from [`bigint.js`](https://github.com/flamingo-stack/meshcentral/blob/main/core/crypto/bigint.js) rather than the Web Crypto API for RSA math, making it usable in environments where RSA-PKCS1-v1_5 signing/decryption is unavailable
- Key generation delegates to the browser's `crypto.subtle` with RSA-OAEP, then re-exports the JWK to extract raw components
- PKCS#1 v1.5 padding enforces a non-zero random padding string; messages exceeding `keyBytes - 11` bytes are rejected
