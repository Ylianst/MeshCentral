Minified bundle of the xterm.js terminal emulator library, providing a full-featured browser-based terminal implementation with accessibility, rendering, input handling, and link detection capabilities.

## Key Components

| Export / Class | Description |
|---|---|
| `AccessibilityManager` | Manages ARIA accessibility tree, live regions, and screen reader announcements for terminal rows |
| `Linkifier` | Detects and highlights clickable links in terminal output using pluggable link providers |
| `ColorContrastCache` | Two-key map cache for color contrast calculations used by the renderer |
| `addDisposableDomListener` | Utility that attaches a DOM event listener and returns a disposable for cleanup |
| Clipboard helpers | `copyHandler`, `handlePasteEvent`, `paste`, `bracketTextForPaste`, `rightClickHandler`, `moveTextAreaUnderMouseCursor` |

## Usage Example

```javascript
// Load the minified bundle (UMD / CommonJS / ESM compatible)
const { Terminal } = require('./xterm-min');

// Create and mount a terminal
const term = new Terminal({ rows: 24, cols: 80 });
term.open(document.getElementById('terminal'));

// Write output
term.write('Hello from xterm!\r\n');

// Accessibility is managed internally; the AccessibilityManager
// attaches an ARIA list to the terminal element automatically.

// Clean up all disposables when done
term.dispose();
```

## Notes

- The file is a **self-contained UMD bundle** — it works as a CommonJS module (`require`), an AMD module (`define`), or a global script.
- `AccessibilityManager` inserts an `.xterm-accessibility` container with `role="list"` rows and an `aria-live="assertive"` region for screen reader output.
- Clipboard utilities handle bracketed paste mode (`[200~`/`[201~`) automatically.
- All event listeners use the internal `Disposable` pattern; call `.dispose()` on any registered component to prevent memory leaks.
