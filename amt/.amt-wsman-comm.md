Handles HTTP/WSMAN communication with Intel AMT devices over TCP sockets, supporting Digest authentication, Kerberos auth, TLS, and MPS (CIRA/Relay/LMS) tunnel connections.

## Key Components

- **`CreateWsmanComm(host, port, user, pass, tls, tlsoptions, mpsConnection)`** — Factory function that returns a WSMAN communication object configured for a specific AMT device endpoint.
- **`obj.PerformAjax(postdata, callback, tag, pri, url, action)`** — Queues an AMT WSMAN request, supporting priority ordering and concurrent call limits.
- **`obj.PerformAjaxEx / PerformAjaxExNodeJS2`** — Internal execution layer with retry logic (default 5 retries) and error propagation.
- **`obj.sendRequest(postdata, url, action)`** — Builds and sends the raw HTTP/1.1 request with Digest or Kerberos `Authorization` headers.
- **`obj.xxConnectHttpSocket()`** — Establishes the underlying TCP or TLS socket, either directly or through an MPS tunnel via `SerialTunnel`.
- **`obj.parseDigest / renderDigest`** — Parses incoming `WWW-Authenticate: Digest` challenges and constructs the `Authorization` response header.
- **`SerialTunnel`** — Internal `Duplex` stream adapter used to layer TLS over an MPS channel connection.

## Usage Example

```javascript
var CreateWsmanComm = require('./amt-wsman-comm');

// Direct TCP connection (no TLS, no MPS tunnel)
var comm = CreateWsmanComm('192.168.1.100', 16992, 'admin', 'Password123!', 0, null, null);

// Send a WSMAN enumerate request
var wsmanBody = '<body>...</body>';
comm.PerformAjax(wsmanBody, function (response, tag) {
    if (response) {
        console.log('Response received:', response);
    }
}, 'myTag', 0, '/wsman', 'POST');

// High-priority request (inserted at front of queue)
comm.PerformAjax(wsmanBody, callback, 'urgent', 1, '/wsman', 'POST');

// Via MPS tunnel (CIRA/Relay/LMS)
var comm = CreateWsmanComm('192.168.1.100', 16993, 'admin', 'Password123!', 1, tlsOptions, mpsConn);
```

## Notes

- Only one active AJAX call is allowed by default (`MaxActiveAjaxCount = 1`); additional calls are queued in `PendingAjax`.
- Set `obj.FailAllError = 999` to silently cancel all pending requests.
- Digest realm can be pinned via `obj.digestRealmMatch` to guard against MITM attacks (error code `997` on mismatch).
