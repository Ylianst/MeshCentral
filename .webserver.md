MeshCentral's core HTTP/HTTPS web server module that bootstraps the Express application, configures TLS, manages user/mesh/agent sessions, and wires up all route handlers for the management platform.

## Key Components

- **`CreateWebServer(parent, db, args, certificates, doneFunc)`** — Primary factory function that constructs and returns the web server object with all subsystems initialized
- **`SerialTunnel`** — Duplex stream wrapper used to embed TLS within existing connections (e.g., for AMT relay)
- **Mesh Rights Constants** (`MESHRIGHT_*`) — Bitmask flags controlling per-user permissions on device groups (remote control, file access, desktop, etc.)
- **Site Rights Constants** (`SITERIGHT_*`) — Bitmask flags for server-level administrative privileges (backup, user management, recordings, etc.)
- **Web Relay Sessions** (`webRelaySessions`) — Tracks active browser-based relay tunnels with lifecycle management and cleanup
- **Certificate Hashing** — Computes and caches SHA hashes of web/agent TLS certificates per domain for agent authentication
- **SSPI Integration** — Optional Windows SSPI/Kerberos authentication wired per domain configuration
- **WebAuthn/FIDO2** — Initialized via `webauthn.js` for hardware key authentication support
- **`resolveSafeUploadTempPath`** — Security utility that validates upload temp paths are confined to allowed roots (prevents path traversal)

## Usage Example

```javascript
// Instantiated internally by MeshCentral's main server process
const webserver = require('./webserver.js');

webserver.CreateWebServer(
  parent,       // MeshCentral parent object
  db,           // Database handle
  args,         // CLI/config arguments
  certificates, // TLS certificate bundle
  function(webObj) {
    // webObj.app    → Express app
    // webObj.tlsServer → HTTPS server instance
    // webObj.users  → loaded user map
    // webObj.meshes → loaded device group map
    console.log('Web server ready');
  }
);
```
