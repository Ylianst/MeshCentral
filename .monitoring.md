MeshCentral monitoring module that exposes server metrics via a Prometheus-compatible HTTP endpoint, tracking agent sessions, relay errors, device groups, Intel AMT connections, and security events.

## Key Components

- **`CreateMonitoring(parent, args)`** — Factory function that initializes the monitoring module and returns a monitoring object
- **`counterMetrics`** — Monotonically increasing metrics (e.g., `RelayErrors`, `InvalidPKCSsignature`, `DuplicateAgent`, `blockedUsers`)
- **`gaugeMetrics`** — Bidirectional metrics (e.g., `AgentSessions`, `ConnectedUsers`, `DeviceGroups`, `ConnectedIntelAMT`)
- **`/metrics` endpoint** — Async Express route that samples live MeshCentral state and returns Prometheus-formatted output
- **`prom-client`** — Optional dependency; only loaded when `config.settings.prometheus` is configured

## Configuration

Add to MeshCentral's `config.json` under `settings`:

```json
{
  "settings": {
    "prometheus": 9464
  }
}
```

Port must be a valid number between `1`–`65535`. Omitting the field disables the endpoint entirely.

## Usage Example

```javascript
// Internal MeshCentral bootstrap (simplified)
const monitoring = require('./monitoring');

const monitoringObj = monitoring.CreateMonitoring(parent, args);
// Prometheus metrics now available at http://host:9464/metrics
```

Scrape target for `prometheus.yml`:

```yaml
scrape_configs:
  - job_name: meshcentral
    static_configs:
      - targets: ["localhost:9464"]
```

## Metric Reference

| Metric | Type | Description |
|---|---|---|
| `meshcentral_agentsessions` | Gauge | Active WebSocket agent connections |
| `meshcentral_connectedusers` | Gauge | Connected user sessions |
| `meshcentral_connectedintelamt` | Gauge | Nodes with Intel AMT connectivity |
| `meshcentral_relayerrors` | Counter | Cumulative relay session errors |
| `meshcentral_badsignature` | Counter | Combined agent signature failures |
| `meshcentral_duplicateagent` | Counter | Duplicate agent connection attempts |
