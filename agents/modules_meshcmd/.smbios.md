Parses raw SMBIOS (System Management BIOS) firmware table data on Windows and Linux platforms, extracting structured hardware information including processor, memory, system, and Intel AMT details.

## Key Components

- **`SMBiosTables`** — Main constructor that initializes platform-specific native bindings (`Kernel32.dll` on Windows, `dmidecode` on Linux)
- **`get(callback)`** — Retrieves raw SMBIOS firmware table bytes; uses `GetSystemFirmwareTable` on Windows and spawns `dmidecode -u` on Linux
- **`_parse(SMData)`** — Internal parser that decodes raw SMBIOS byte buffers into typed structure arrays with associated string tables
- **`parse(data)`** — High-level aggregator that calls all sub-parsers and returns a combined result object
- **`processorInfo(data)`** — Extracts CPU type, speed, core/thread count, socket, manufacturer, and status (SMBIOS type 4)
- **`memoryInfo(data)`** — Reads physical memory array location and max capacity (SMBIOS type 16)
- **`systemInfo(data)`** — Decodes system UUID (mixed-endian format) and wake reason (SMBIOS type 1)
- **`systemSlots(data)`** — Lists system expansion slot names (SMBIOS type 9)
- **`amtInfo(data)`** — Detects Intel AMT presence and capabilities including KVM, SOL, TXT, VMX, and ME/MEBX versions (SMBIOS types 130/131)

## Usage Example

```javascript
var SMBios = require('./smbios');
var tables = new SMBios.SMBiosTables();

// Async usage (works on both Windows and Linux)
tables.get(function(rawData) {
    if (!rawData) {
        console.log('SMBIOS data unavailable');
        return;
    }
    var info = tables.parse(rawData);
    console.log('System UUID:', info.systemInfo.uuid);
    console.log('Processors:', info.processorInfo);
    console.log('AMT Enabled:', info.amtInfo.AMT);
});

// Synchronous usage (Windows only)
var rawData = tables.get();
var parsed = tables.parse(rawData);
console.log('Max Memory (KB):', parsed.memoryInfo.maxCapacityKb);
```

> **Note:** On Linux, `dmidecode` must be installed and the process requires elevated privileges (`sudo`) to read SMBIOS tables. If insufficient data is returned, the callback receives an empty result.
