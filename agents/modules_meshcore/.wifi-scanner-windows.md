Windows Wi-Fi scanning module that interfaces with the Windows WLAN API (`wlanapi.dll`) via native marshaling to enumerate wireless interfaces, trigger network scans, and retrieve BSS (Basic Service Set) network information.

## Key Components

- **`Wireless`** — Main singleton class (exported via `module.exports`) that initializes the WLAN API handle, registers scan notifications, and exposes scanning methods as an EventEmitter.
- **`AccessPoint`** — Data model representing a discovered Wi-Fi access point with `ssid`, `bssid`, `rssi`, and `lq` (link quality) properties.
- **`_Scan()`** — Enumerates WLAN interfaces and invokes `WlanScan` to trigger an active network scan.
- **`OnNotify()`** — Native callback invoked when a scan completes (`WlanNotificationSource == 8, code == 7`); retrieves the BSS list and emits a `Scan` event for each discovered access point.
- **`GetConnectedNetwork()`** — Queries the currently associated network, returning an `AccessPoint` if connected, or throwing if not associated.

## Usage Example

```javascript
const wifi = require('./wifi-scanner-windows');

// Listen for discovered access points
wifi.on('Scan', function (ap) {
    console.log(`Found: ${ap.ssid} [${ap.bssid}] RSSI: ${ap.rssi} LQ: ${ap.lq}`);
});

// Trigger a Wi-Fi scan
const started = wifi.Scan();
console.log('Scan initiated:', started);

// Get the currently connected network
try {
    const connected = wifi.GetConnectedNetwork();
    console.log('Connected to:', connected.toString());
} catch (err) {
    console.error(err);
}
```

> **Platform:** Windows only — depends on `wlanapi.dll` and the internal `_GenericMarshal` native proxy module available in the MeshCentral agent runtime.
