Standalone Node.js migration script that runs once at container startup (via `entrypoint.sh`) to initialize MeshCentral's MongoDB database and generate agent configuration files.

## Key Components

| Function | Description |
|---|---|
| `computeServerIdFromCert(datapath)` | Reads the agent certificate, computes SHA-384 public key fingerprint as the server ID |
| `buildParentShim(config, datapath)` | Constructs a minimal MeshCentral parent object shim required to initialize `db.js` |
| `loadConfig(configfile)` | Loads and parses `config.json`, substituting any unresolved `${VAR}` placeholders from environment |
| `ensureAdminUser(db, domain, cb)` | Idempotent admin user creation; rotates password if `MESH_PASS` differs from stored hash |
| `ensureDeviceGroup(db, domain, userid, cb)` | Idempotent device group (mesh) creation with full admin rights |
| `writeMeshIdFiles(meshid, serverIdHex)` | Writes `mesh_id`, `mesh_device_group_id`, and `mesh_server_id` to `MESH_DIR` |
| `generateMshFile(meshIdHex, serverIdHex)` | Builds the `meshagent.msh` agent config and copies it to `public/` for static serving |

## Usage Example

```bash
# Invoked automatically by entrypoint.sh — not typically called manually
MESH_DIR=/data/mesh \
MESH_USER=admin \
MESH_PASS=secret \
MESH_DEVICE_GROUP=OpenFrame \
OPENFRAME_MODE=true \
OPENFRAME_GATEWAY_URL=gw.example.com \
node migrate.js --datapath /data/meshcentral-data --configfile /data/config.json
```

Required environment variables:

| Variable | Required | Description |
|---|---|---|
| `MESH_DIR` | ✅ | Directory for output files (`mesh_id`, `meshagent.msh`, etc.) |
| `MESH_USER` | ✅ | Admin username |
| `MESH_PASS` | ✅ | Admin password |
| `MESH_DEVICE_GROUP` | — | Device group name (default: `OpenFrame`) |
| `OPENFRAME_MODE` | — | Set `true` to route agents via OpenFrame Gateway |
| `OPENFRAME_GATEWAY_URL` | — | Gateway hostname when OpenFrame mode is enabled |
| `MESH_PROTOCOL` / `MESH_NGINX_NAT_HOST` / `MESH_EXTERNAL_PORT` | — | Standard mode WebSocket URL components |
