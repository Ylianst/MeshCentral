X11 keysym constants map exported as a default object, providing symbolic key names to their corresponding hexadecimal code point values for use in remote desktop and keyboard input handling.

## Key Components

**Default Export — `keysym` object**

A flat key-value map where each property is an X11 keysym name (prefixed with `XK_`) and its value is the corresponding hexadecimal code point. Categories include:

| Category | Examples |
|---|---|
| Control keys | `XK_BackSpace`, `XK_Tab`, `XK_Escape`, `XK_Delete` |
| Cursor / navigation | `XK_Home`, `XK_End`, `XK_Page_Up`, `XK_Arrow*` |
| Keypad (numpad) | `XK_KP_0`–`XK_KP_9`, `XK_KP_Enter`, `XK_KP_Add` |
| Function keys | `XK_F1`–`XK_F35`, with Sun keyboard aliases (`XK_L1`–`XK_R15`) |
| Modifiers | `XK_Shift_L/R`, `XK_Control_L/R`, `XK_Alt_L/R`, `XK_Super_L/R` |
| Japanese input | `XK_Kanji`, `XK_Hiragana`, `XK_Katakana`, `XK_Henkan` |
| Latin-1 printable | `XK_space` through `XK_9`, standard punctuation |
| XKB extensions | `XK_ISO_Level3_Shift` (AltGr), group navigation keys |

Some keys share the same code point via aliases (e.g. `XK_Henkan` = `XK_Henkan_Mode`, `XK_Page_Up` = `XK_Prior`).

## Usage Example

```javascript
import keysym from './keysym.js';

// Look up the code for a key by name
const escCode = keysym.XK_Escape;         // 0xff1b
const ctrlL   = keysym.XK_Control_L;     // 0xffe3
const enterKP = keysym.XK_KP_Enter;      // 0xff8d

// Send a key event over a VNC/RFB connection
function sendKey(rfbClient, keyName, isDown) {
    const code = keysym[keyName];
    if (code !== undefined) {
        rfbClient.sendKeyEvent(code, isDown);
    }
}

sendKey(client, 'XK_Return', true);
sendKey(client, 'XK_Return', false);
```

## Notes

- Source: [keysym.js](https://github.com/flamingo-stack/meshcentral/blob/main/keysym.js)
- Values mirror the X11 `keysymdef.h` standard, making this compatible with VNC/RFB protocol implementations.
- Aliases are intentional — both names resolve to the same code point.
