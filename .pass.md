Password hashing utility providing PBKDF2-based password hashing with salt generation and IIS-compatible hashing support.

## Key Components

- **`exports.hash(pwd, salt, fn, tag)`** — Hashes a password using PBKDF2 with SHA-384. If called with 3 arguments `(pwd, fn, tag)`, auto-generates a random salt; if called with 4 arguments, uses the provided salt. Passes `(err, salt, hash, tag)` to the callback. Falls back to the default digest if SHA-384 is unsupported (older Node.js).

- **`exports.iishash(type, pwd, salt, fn)`** — IIS-compatible password hashing. Supports two modes:
  - `type = 0`: Returns the plaintext password (no hashing)
  - `type = 1`: SHA-1 hash of `base64(salt) + UTF-16LE(password)`, mimicking IIS password storage format

## Configuration

| Constant | Value | Purpose |
|---|---|---|
| `len` | `128` | Salt/hash byte length |
| `iterations` | `12000` | PBKDF2 iterations (~300ms) |

## Usage Example

```javascript
const pass = require('./pass');

// Generate a new salt + hash (3-argument form)
pass.hash('myPassword', function(err, salt, hash) {
  if (err) throw err;
  console.log('Salt:', salt);
  console.log('Hash:', hash);
});

// Verify against an existing salt (4-argument form)
pass.hash('myPassword', storedSalt, function(err, hash, tag) {
  if (err) throw err;
  const isValid = (hash === storedHash);
}, 'optionalTag');

// IIS-compatible SHA-1 hash
pass.iishash(1, 'myPassword', base64Salt, function(err, hash) {
  if (err) throw err;
  console.log('IIS Hash:', hash);
});
```
