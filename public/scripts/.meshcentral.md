Brief description: Provides a WebSocket-based control channel factory for MeshCentral, managing connection lifecycle, authentication, keep-alive pings, and message routing between the browser client and the MeshCentral server.

## Key Components

**`MeshServerCreateControl(domain, authCookie)`** — Factory function returning a control object with:

| Member | Type | Description |
|--------|------|-------------|
| `State` | `number` | Public connection state (`0` = disconnected, `1` = connecting, `2` = connected) |
| `connectstate` | `number` | Internal WebSocket readiness flag |
| `pingTimer` | `timer` | Interval handle for keep-alive pings (every 29 seconds) |
| `Start()` | `function` | Opens the WebSocket to `control.ashx`, wires event handlers, starts ping timer |
| `Stop(errCode)` | `function` | Closes the WebSocket, clears the ping timer, fires state change |
| `send(x)` | `function` | Serializes and sends a JSON message if the socket is open |
| `xxStateChange(newstate, errCode)` | `function` | Internal state machine; fires `onStateChanged` callback on transitions |
| `xxOnMessage(e)` | `function` | Parses inbound JSON; handles `ping`/`pong`, `close`, and delegated `onMessage` |
| `onStateChanged` | `callback` | User-assigned: `fn(obj, newState, prevState, errCode)` |
| `onMessage` | `callback` | User-assigned: `fn(obj, message)` |
| `trace` | `number` | `1` = object logging, `2` = JSON string logging |

## Usage Example

```javascript
// Initialize the control channel
var ctrl = MeshServerCreateControl('/myDomain/', 'myAuthCookieValue');

// Listen for state changes
ctrl.onStateChanged = function(obj, newState, prevState, errCode) {
    console.log('State changed from', prevState, 'to', newState, 'errCode:', errCode);
};

// Listen for inbound server messages
ctrl.onMessage = function(obj, message) {
    if (message.action === 'meshes') {
        console.log('Received mesh list:', message.meshes);
    }
};

// Enable debug logging (optional)
ctrl.trace = 1;

// Open the WebSocket connection
ctrl.Start();

// Send a custom message
ctrl.send({ action: 'getMeshes', type: 3 });

// Gracefully disconnect
ctrl.Stop(0);
```

## Notes

- The WebSocket URL is derived from the current page's `window.location`, automatically switching `http` → `ws` and `https` → `wss`.
- If `authCookie` is present, it is sent as a `urlargs` action immediately after the socket opens, supporting cookie-less auth flows.
- The 29-second ping interval is intentionally below typical corporate proxy idle timeouts to prevent forced disconnections.
