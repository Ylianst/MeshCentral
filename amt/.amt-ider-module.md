Intel AMT IDE Redirection (IDER) module that enables remote boot of managed devices by redirecting floppy and CD-ROM disk images over an AMT connection.

## Key Components

- **`CreateAmtRemoteIder(webserver, meshcentral)`** — Factory function returning the IDER session object
- **`obj.diskSetup(floppyPath, cdromPath)`** — Opens and validates local disk image files (floppy/ISO), returns error codes 1–7
- **`obj.Start()`** — Initiates the IDER session by sending `OPEN_SESSION` (0x40) and initializing sequence counters
- **`obj.Stop()`** — Tears down the IDER session and calls parent stop
- **`obj.ProcessData(data)`** — Receives raw binary data from AMT, accumulates it, and dispatches commands in sequence order
- **`obj.SendCommand(cmdid, data, completed, dma)`** — Low-level framer that wraps outgoing IDER protocol packets with sequence numbers and attributes
- **`obj.SendCommandEndResponse(error, sense, device, asc, asq)`** — Sends SCSI sense/status response (command `0x51`)
- **`obj.SendDataToHost(device, completed, data, dma)`** — Sends SCSI read data back to the AMT host (command `0x54`)
- **`obj.SendGetDataFromHost(device, chunksize)`** — Requests a data chunk write from the host (command `0x52`)
- **`obj.xxStateChange(newstate)`** — Called by the parent transport when connection state changes (0 = stop, 3 = start)

Pre-defined `Buffer` constants encode SCSI Mode Sense responses for floppy (LS-120, 1.44MB) and CD-ROM media types.

## Usage Example

```javascript
const iderModule = require('./amt-ider-module');

const ider = iderModule.CreateAmtRemoteIder(webserver, meshcentral);

// Attach disk images
const result = ider.diskSetup('/path/to/floppy.img', '/path/to/boot.iso');
if (result !== 0) {
    console.error('Disk setup failed with error code:', result);
    // 1=floppy missing, 4=cdrom missing, 2/5=bad size, 3/6=open error, 7=no images
    return;
}

// Wire up to parent AMT transport
ider.parent = amtTransport;

// Track sector-level transfer stats
ider.sectorStats = (transferred, device, total) => {
    console.log(`Device ${device}: ${transferred}/${total} sectors`);
};

ider.debug = true; // Enable verbose logging
ider.Start();
```
