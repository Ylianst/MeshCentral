Windows desktop utility module that exposes Windows desktop features including wallpaper management, mouse trail accessibility settings, and user idle time detection via Windows API calls (`user32.dll`, `kernel32.dll`).

## Key Components

| Export | Method | Description |
|--------|--------|-------------|
| `background` | `get(tsid)` | Retrieves the current desktop wallpaper path |
| `background` | `set(path, tsid)` | Sets the desktop wallpaper to the given path |
| `mouse` | `getTrails(tsid)` | Returns mouse trail cursor count (0/1 = disabled) |
| `mouse` | `setTrails(value, tsid)` | Sets mouse trail cursor count |
| `idle` | `getSeconds(tsid)` | Returns seconds since last keyboard/mouse input |
| `idle` | `getSecondsAllSessions()` | Returns minimum idle seconds across all active sessions, or `-1` if no users logged in |
| `dispatch(parent, method, args)` | — | Internal helper used by child processes spawned via `sessionDispatch` |

All functions accept an optional `tsid` (Terminal Session ID) parameter. When provided (including explicit `null`), the call is dispatched to the appropriate user session via a child process.

## Usage Example

```javascript
var deskutils = require('win-deskutils');

// Get/set desktop wallpaper for current session
var wallpaper = deskutils.background.get();
deskutils.background.set('C:\\Wallpapers\\bg.jpg');

// Get/set mouse trails
var trails = deskutils.mouse.getTrails();  // 0 or 1 = disabled
deskutils.mouse.setTrails(5);             // Enable with 5 cursors

// Get idle time for current session (in seconds)
var idleSeconds = deskutils.idle.getSeconds();

// Get minimum idle time across all active RDP/console sessions
deskutils.idle.getSecondsAllSessions().then(function(minIdle) {
    if (minIdle === -1) {
        console.log('No users logged in');
    } else {
        console.log('Least-idle user: ' + minIdle + 's');
    }
});

// Target a specific user session
var wallpaper = deskutils.background.get(2); // Session ID 2
```
