Intel AMT Communication Stack service that wraps WSMAN protocol operations (GET, PUT, CREATE, DELETE, ENUMERATE, SUBSCRIBE) for interacting with Intel Active Management Technology endpoints.

## Key Components

- **`AmtStackCreateService(wsmanStack)`** — Factory function returning the AMT stack object bound to a WSMAN transport layer
- **`obj.Get / Put / Create / Delete`** — Single-resource WSMAN operations with callback-based responses
- **`obj.Exec / ExecWithXml`** — WSMAN method invocations with optional XML argument serialization
- **`obj.Enum`** — WSMAN ENUMERATE + PULL sequence with concurrency throttling (`MaxActiveEnumsCount`)
- **`obj.BatchEnum`** — Sequentially enumerates a list of resource names, collecting results into a single callback
- **`obj.BatchGet`** — Sequentially fetches a list of resources, aggregating responses
- **`obj.Subscribe / UnSubscribe`** — WSMAN event subscription management
- **`obj.CompleteName(name)`** — Resolves `AMT_`, `CIM_`, or `IPS_` prefixes to their full WBEM schema URIs
- **`obj.GetPendingActions()`** — Returns the total count of in-flight and queued operations
- **`obj.RequestPowerStateChange(PowerState, cb)`** — Sends a CIM power state change command to the managed system
- **`obj.SetBootConfigRole(Role, cb)`** — Configures the AMT boot configuration role

## Usage Example

```javascript
var amtStack = AmtStackCreateService(wsmanStackInstance);

// Single GET
amtStack.Get('AMT_GeneralSettings', function(stack, name, response, status) {
    if (status === 200) console.log(response.Body);
});

// Batch ENUM across multiple AMT/CIM resources
amtStack.BatchEnum('myBatch', ['AMT_GeneralSettings', 'CIM_ComputerSystem'], function(stack, name, results, status) {
    console.log(results['AMT_GeneralSettings'].response);
}, null, true);

// Power state change (e.g., reboot = 10)
amtStack.RequestPowerStateChange(10, function(stack, name, response, status) {
    console.log('Power change status:', status);
});
```
