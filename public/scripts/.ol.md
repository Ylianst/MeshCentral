Bundled build of OpenLayers v4.2.0, a full-featured JavaScript mapping library for displaying interactive maps in web browsers.

## Key Components

- **Projection System** (`Bb`, `Cb`, `Kb`) — Coordinate reference system definitions supporting EPSG:3857 (Web Mercator) and EPSG:4326 (WGS84), with proj4 integration for custom projections
- **Extent Utilities** (`Na`, `Qa`, `sb`, etc.) — Bounding box operations: intersection, union, transformation, and containment checks
- **Spherical Math** (`xb`, `yb`) — Great-circle distance calculations and geodesy formulae for area and offset computations
- **Tile Grid** (`lc`) — Resolution/zoom level management for tiled map layers
- **Coordinate Transforms** (`Hb`, `Ib`, `Vb`) — Forward/inverse projection transforms between coordinate systems
- **Assertion Helpers** (`wa`, `xa`) — Developer-friendly error reporting with links to the OpenLayers error documentation

## Usage Example

This file is the UMD bundle — consume it via CommonJS, AMD, or as a global:

```javascript
// CommonJS (Node.js / bundlers)
const ol = require('./ol.js');

// AMD
define(['ol'], function(ol) {
  const map = new ol.Map({ /* ... */ });
});

// Browser global
<script src="ol.js"></script>
<script>
  const view = new ol.View({
    center: ol.proj.fromLonLat([-74.006, 40.7128]),
    zoom: 12
  });

  const map = new ol.Map({
    target: 'map',
    layers: [new ol.layer.Tile({ source: new ol.source.OSM() })],
    view: view
  });
</script>
```
