Cross-platform system information utility that collects CPU utilization, memory usage, and thermal data for Windows, Linux, and macOS environments.

## Key Components

| Export | Platform | Description |
|--------|----------|-------------|
| `cpuUtilization()` | All | Returns a Promise resolving to `{ total, cpus[] }` with per-CPU and aggregate utilization percentages |
| `memUtilization()` | All | Returns memory stats including `MemTotal`, `MemFree`, `percentFree`, and `percentConsumed` |
| `thermals()` | All | Returns an array of temperature readings in Celsius |

**Platform implementations:**
- **Windows** — Uses `pdh.dll` (Performance Data Helper) via `_GenericMarshal` for CPU, `kernel32.GlobalMemoryStatusEx` for memory, and WMI (`MSAcpi_ThermalZoneTemperature`) for thermals
- **Linux** — Reads `/proc/stat` for CPU deltas and `/proc/meminfo` for memory; thermal data from `/sys/class/thermal/thermal_zone*/temp`
- **macOS** — Shells out to `top -l 1` for CPU/memory and `powermetrics -s smc` for thermals

## Usage Example

```javascript
const sysinfo = require('./sysinfo');

// CPU utilization (async)
sysinfo.cpuUtilization().then(function (data) {
    console.log('Total CPU:', data.total.toFixed(2) + '%');
    data.cpus.forEach(function (util, i) {
        console.log('CPU ' + i + ':', util.toFixed(2) + '%');
    });
});

// Memory utilization (sync on Linux/macOS)
const mem = sysinfo.memUtilization();
console.log('Memory consumed:', mem.percentConsumed.toFixed(2) + '%');

// Thermal readings
const temps = sysinfo.thermals();
console.log('Temperatures:', temps);
```

> **Note:** The module exports `undefined` on unsupported platforms. Always verify `module.exports` is defined before use. Windows support requires the `_GenericMarshal` and `win-wmi` native modules.
