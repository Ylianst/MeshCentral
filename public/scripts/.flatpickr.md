Flatpickr v4.6.13 — a lightweight, zero-dependency JavaScript datetime picker library bundled as a UMD module compatible with CommonJS, AMD, and global browser environments.

## Key Components

- **Default Config (`a`)** — Comprehensive options object covering date formats, time settings, display modes (`single`, `multiple`, `range`), locale, plugins, and event hooks
- **Locale (`i`)** — English locale with weekday/month names, ordinals, and AM/PM labels
- **Format Tokens (`w`)** — Date formatting functions supporting tokens like `Y`, `m`, `d`, `H`, `i`, `s`, `Z`
- **Parse Tokens (`v` / `D`)** — Reverse mapping for parsing formatted date strings back to `Date` objects
- **`b` (formatDate)** — Factory returning a date-to-string formatter using the token maps
- **`C` (parseDate)** — Factory returning a string-to-`Date` parser supporting ISO, Unix timestamps, and custom formats
- **`M` (compareDates)** — Day-level or millisecond-level date comparison utility
- **`E` (resolveTimeFields)** — Clamps default hour/minute/second values against configured `minDate`/`maxDate`
- **Event hooks** — `onChange`, `onOpen`, `onClose`, `onMonthChange`, `onYearChange`, `onReady`, and more
- **`k` (core instance factory)** — Main picker constructor binding config, locale, DOM, and interaction logic

## Usage Example

```javascript
// Basic date picker
const picker = flatpickr("#myInput", {
  dateFormat: "Y-m-d",
  defaultDate: "today",
  onChange: (selectedDates, dateStr) => {
    console.log("Selected:", dateStr);
  }
});

// Date + time picker with range mode
flatpickr("#rangeInput", {
  mode: "range",
  enableTime: true,
  time_24hr: true,
  minDate: "2024-01-01",
  maxDate: "2024-12-31",
  onClose: (dates) => {
    console.log("From:", dates[0], "To:", dates[1]);
  }
});

// Programmatic control
picker.setDate("2024-06-15");
picker.open();
picker.destroy();
```

## Configuration Highlights

| Option | Default | Description |
|---|---|---|
| `dateFormat` | `"Y-m-d"` | Output format string |
| `mode` | `"single"` | `single`, `multiple`, or `range` |
| `enableTime` | `false` | Show time picker |
| `inline` | `false` | Always-visible calendar |
| `showMonths` | `1` | Number of months displayed |
