Browser utility module for the noVNC HTML5 VNC client, providing helpers for URL parameter parsing, cookie management, and persistent settings storage with support for Chrome extension sync storage and `localStorage`.

## Key Components

| Export | Description |
|--------|-------------|
| `initLogging(level?)` | Initializes log level from argument or `logging=` URL parameter |
| `getQueryVar(name, defVal?)` | Reads a value from the URL query string (`?key=value`) |
| `getHashVar(name, defVal?)` | Reads a value from the URL hash fragment (`#key=value`) |
| `getConfigVar(name, defVal?)` | Reads from hash or query string; hash takes precedence |
| `createCookie(name, value, days?)` | Creates a cookie; session-only if `days` is omitted; adds `secure` flag on HTTPS |
| `readCookie(name, defaultValue?)` | Reads a cookie by name, returning `defaultValue` if not found |
| `eraseCookie(name)` | Deletes a cookie by setting it expired |
| `initSettings()` | Loads settings from Chrome sync storage or falls back to an in-memory cache |
| `writeSetting(name, value)` | Persists a setting to Chrome sync storage or `localStorage` |
| `readSetting(name, defaultValue?)` | Reads a setting from cache, Chrome storage, or `localStorage` |
| `setSetting(name, value)` | Updates the in-memory settings cache without writing to storage |
| `eraseSetting(name)` | Removes a setting from all storage backends |

## Usage Example

```javascript
import {
  initLogging,
  getConfigVar,
  createCookie,
  readSetting,
  writeSetting,
  initSettings
} from './webutil.js';

// Initialize logging (reads ?logging=debug from URL if no arg passed)
initLogging();

// Read VNC host from hash or query string, defaulting to localhost
const host = getConfigVar('host', 'localhost');
const port = getConfigVar('port', '5900');

// Persist user preference
await initSettings();
writeSetting('view_only', false);
const viewOnly = readSetting('view_only', false);

// Store a session cookie
createCookie('novnc_token', 'abc123');
```

## Notes

- `getConfigVar` supports privacy-friendly hash parameters (e.g. `https://example.com#password=secret`) that are never sent to the server.
- Settings fall back gracefully: Chrome sync storage → `localStorage` → in-memory object.
- `localStorage` errors (e.g. cookies disabled) are caught and logged once via `logOnce` to avoid log spam.
