Minified xterm.js addon that automatically resizes a terminal instance to fill its parent container by calculating optimal column and row dimensions based on available space.

## Key Components

**`FitAddon` class**
- `activate(terminal)` — Binds the addon to an xterm.js `Terminal` instance
- `dispose()` — Cleanup hook (no-op in this implementation)
- `fit()` — Resizes the terminal to fill its parent element; skips resize if dimensions are unchanged
- `proposeDimensions()` — Calculates and returns `{ cols, rows }` based on parent container size, computed padding, cell dimensions, and scrollbar width

## Usage Example

```javascript
import { Terminal } from 'xterm';
import { FitAddon } from './xterm-addon-fit';

const terminal = new Terminal();
const fitAddon = new FitAddon();

terminal.loadAddon(fitAddon);
terminal.open(document.getElementById('terminal-container'));

// Fit terminal to container immediately
fitAddon.fit();

// Re-fit on window resize
window.addEventListener('resize', () => fitAddon.fit());

// Inspect proposed dimensions without resizing
const dims = fitAddon.proposeDimensions();
console.log(`Would resize to ${dims.cols} cols × ${dims.rows} rows`);
```

## Notes

- Requires an xterm.js `Terminal` with a mounted DOM element and a valid parent container
- Accounts for CSS `padding` on the terminal element and scrollbar width (when `scrollback > 0`)
- Enforces minimum dimensions: 2 columns, 1 row
- Source map references `addon-fit.js.map`
