Mesh Agent Transport Module that establishes WebSocket relay connections between a browser client and a remote mesh agent, supporting protocol tunneling for terminal, desktop, file transfer, and other session types.

## Key Components

- **`CreateAgentRedirect(meshserver, module, serverPublicNamePort, authCookie, rauthCookie, domainUrl)`** — Factory function that constructs and returns an agent redirect object (`obj`) managing the full lifecycle of a relay session.

- **`obj.Start(nodeid)`** — Initiates the WebSocket connection to `meshrelay.ashx`, sends a tunnel request to the mesh server, and generates a random `tunnelid` to correlate client and agent sides of the relay.

- **`obj.xxOnSocketConnected()`** — Handles socket open events; starts a 10-second RTT latency ping interval using control channel `102938`.

- **`obj.xxOnControlCommand(msg)`** — Dispatches control-channel JSON messages including `console`, `metadata`, `rtt`, WebRTC signaling (`answer`, `webrtc0/1/2`), and `ping/pong`.

- **`obj.xxOnMessage(e)`** — Core message handler for both WebSocket and WebRTC data channels; routes binary commands to the inner module and handles connection state transitions (`c`/`cr` handshake).

- **`obj.sendCtrlMsg(x)`** — Sends a control message over the WebSocket with optional trace logging.

- **`performWebRtcSwitch()`** — Internal function that coordinates the traffic switchover from WebSocket to WebRTC once both sides signal readiness.

- **`obj.setConsoleMessage(str, id, args, timeout)`** — Updates the console message state and fires `onConsoleMessageChange` if the message has changed.

## Usage Example

```javascript
var redirect = CreateAgentRedirect(
  meshserver,       // MeshServer WebSocket object
  terminalModule,   // Inner module (e.g., Terminal with protocol = 1)
  null,             // serverPublicNamePort (optional)
  'auth-cookie',    // authCookie
  'rauth-cookie',   // rauthCookie
  '/domain/'        // domainUrl
);

redirect.onStateChanged = function(obj, state) {
  console.log('Connection state:', state);
  // 0 = Disconnected, 1 = Connecting, 2 = Server connected, 3 = End-to-end
};

redirect.latency.callback = function(ms) {
  console.log('Round-trip latency:', ms, 'ms');
};

redirect.Start('node/domain/abcdef1234567890');
```
