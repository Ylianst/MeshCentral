Scans the local filesystem for MeshCentral agent binaries, computes their SHA384 hashes, and outputs a JSON manifest mapping each agent's numeric platform ID to its file metadata.

## Key Components

- **`agents`** — A static map of agent binary filenames to their numeric platform IDs (e.g., `'MeshService.exe': 3`, `'meshagent_arm64': 26`).
- **`getAgentInfo(filename, id)`** — Checks if a binary exists, reads its file stats, computes its SHA384 hash, and returns an object containing `filename`, `hash`, `size`, and `mtime`. Returns `null` if the file is not found.
- **`agentinfo`** — The accumulated result object, keyed by platform ID, built by iterating over all entries in `agents`.

## Usage Example

Run directly from the command line in the directory containing the agent binaries:

```bash
node hashagents.js
```

Example output:

```json
{
  "3": {
    "filename": "MeshService.exe",
    "hash": "a1b2c3d4...",
    "size": 2048576,
    "mtime": "2024-01-15T10:30:00.000Z"
  },
  "6": {
    "filename": "meshagent_x86-64",
    "hash": "e5f6a7b8...",
    "size": 1924096,
    "mtime": "2024-01-15T10:30:00.000Z"
  }
}
```

> **Note:** This script depends on a `getSHA384FileHash()` function that must be available in scope (not defined in this file). It exits via `process.exit()` after printing results, making it suitable for use as a one-shot CLI utility.
