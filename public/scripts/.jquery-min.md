Minified build of **jQuery v3.7.1** with AJAX, effects, and several deprecated modules excluded, bundled for use in browser or CommonJS environments.

## Key Components

| Export / Symbol | Description |
|---|---|
| `ce` / `jQuery` / `$` | Core jQuery constructor — wraps DOM elements into a jQuery object |
| `ce.fn` / `ce.prototype` | Prototype shared by all jQuery instances; defines chainable DOM methods |
| `ce.extend` | Deep/shallow object merger; also used to attach static utility methods |
| `ce.each` / `ce.map` / `ce.grep` | Iteration and filtering utilities for arrays and objects |
| `ce.isPlainObject` / `ce.isEmptyObject` | Type-checking helpers |
| `ce.contains` | Tests whether one DOM node contains another |
| `ce.escapeSelector` | CSS selector escaping per the WICG spec |
| `ce.globalEval` | Evaluates a script string in the global scope |
| `I` (Sizzle-like engine) | Internal CSS selector engine with caching, pseudo-class support, and `querySelectorAll` fallback |
| `W` / `B` / `F` | Internal cache factory, mark-as-cached helper, and feature-detection helper |
| `le` (`support`) | Browser capability flags populated at runtime |

## Usage Example

```javascript
// Browser global usage (after including the script)
const $divs = $('div.my-class');

// Iterate over matched elements
$divs.each(function (index, el) {
  console.log(index, el.textContent);
});

// Extend a target object (deep merge)
const merged = $.extend(true, {}, defaults, overrides);

// Check plain object
if ($.isPlainObject(value)) {
  console.log('Got a plain object');
}

// CommonJS / Node.js (DOM required, e.g. via jsdom)
const { JSDOM } = require('jsdom');
const { window } = new JSDOM('');
const $ = require('./jquery-min.js')(window);
console.log($('body').length); // 1
```
