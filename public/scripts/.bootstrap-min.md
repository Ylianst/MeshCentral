Minified production build of Bootstrap v5.3.3, the popular open-source CSS framework's JavaScript bundle, providing interactive UI component behaviors for the MeshCentral web interface.

## Key Components

| Component | Description |
|-----------|-------------|
| `Alert` | Dismissible alert component with fade animation |
| `Button` | Toggle button with `aria-pressed` state management |
| `Swipe` | Touch/pointer gesture detection for left/right swipe callbacks |
| `BaseComponent` (`W`) | Abstract base class for all Bootstrap components with instance management |
| `Config` (`H`) | Configuration parsing, merging, and type validation base class |
| `EventHandler` (`N`) | Custom event system with delegation, namespacing, and jQuery interop |
| `Data` (`e`) | Per-element instance registry backed by a `Map` |
| `SelectorEngine` (`z`) | DOM query utilities including `find`, `findOne`, `focusableChildren`, and selector resolution |
| `Manipulator` (`F`) | `data-bs-*` attribute get/set/remove helpers |

## Usage Example

Bootstrap components are instantiated via static factory methods or jQuery-style interfaces:

```javascript
// Get or create a component instance
const alertEl = document.querySelector('.alert');
const alert = bootstrap.Alert.getOrCreateInstance(alertEl);
alert.close();

// jQuery plugin interface (if jQuery is present)
$('.alert').alert('close');

// Button toggle
const btn = document.querySelector('[data-bs-toggle="button"]');
bootstrap.Button.getOrCreateInstance(btn).toggle();

// Swipe gesture support
const swipe = new bootstrap.Swipe(element, {
  leftCallback: () => console.log('swiped left'),
  rightCallback: () => console.log('swiped right'),
  endCallback: () => console.log('swipe ended')
});
```
