BER (Basic Encoding Rules) TLV codec for ASN.1 data structures used in RDP protocol communication. Handles encoding and decoding of Tag-Length-Value tuples per the BER specification.

## Key Components

| Function | Description |
|---|---|
| `decode(s, tag)` | Decodes a BER TLV tuple from a stream, validating the tag and returning the value as a `BinaryString` |
| `encode(tag, buffer)` | Encodes data into a BER TLV structure by combining tag, length, and value components |
| `decodeTag(s, tag)` | Internal — parses and validates the Tag field, supporting tag numbers above 30 via multi-byte encoding |
| `decodeLength(s)` | Internal — parses the Length field, handling short form (1 byte) and long form (1–2 byte) encodings |
| `encodeTag(tag)` | Internal — serializes a tag, using multi-byte form for tag numbers above 30 |
| `encodeLength(length)` | Internal — serializes length in short form (`≤ 0x7F`) or long form (`0x82` + UInt16BE) |

## Usage Example

```javascript
var ber = require('./ber');
var type = require('../core').type;

// Define an ASN.1 tag (e.g., UNIVERSAL, PRIMITIVE, INTEGER = 2)
var tag = { tagClass: 0x00, tagFormat: 0x00, tagNumber: 2 };

// Encode a value into BER TLV
var buffer = new type.BinaryString(someData);
var encoded = ber.encode(tag, buffer);

// Decode a BER TLV from a stream
var stream = new type.Stream(rawBytes);
try {
    var value = ber.decode(stream, tag);
} catch (e) {
    // Throws ProtocolError on tag mismatch or invalid length
    console.error('BER decode failed:', e.message);
}
```

## Error Handling

Throws `ProtocolError` with codes:
- `NODE_RDP_ASN1_BER_INVALID_TAG` — decoded tag does not match expected
- `NODE_RDP_ASN1_BER_INVALID_LENGTH` — long-form length uses unsupported byte count (not 1 or 2)
