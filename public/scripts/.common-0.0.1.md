A lightweight utility library providing common DOM manipulation helpers, binary encoding/decoding functions, string utilities, and data conversion methods for browser-based JavaScript.

## Key Components

### DOM Helpers (`Q*` functions)
| Function | Description |
|----------|-------------|
| `Q(id)` | Shorthand for `document.getElementById` |
| `QS(id)` | Get element's style object |
| `QE(id, bool)` | Enable/disable an element |
| `QV(id, bool)` | Show/hide element via `display` |
| `QH(id, html)` | Set element's `innerHTML` |
| `QA(id, html)` | Append to element's `innerHTML` |
| `QC(id)` | Get element's `classList` |
| `QVH(id, bool)` | Toggle `visually-hidden` CSS class |

### Binary Encoding
- `ReadShort` / `ReadShortX` — Read big/little-endian 16-bit integers from a string
- `ReadInt` / `ReadIntX` / `ReadSInt` — Read 32-bit integers (signed/unsigned, big/little-endian)
- `ShortToStr` / `IntToStr` — Encode integers to binary strings (big-endian)
- `ShortToStrX` / `IntToStrX` — Encode integers to binary strings (little-endian)

### String & Data Utilities
- `EscapeHtml` / `EscapeHtmlBreaks` — Sanitize HTML special characters
- `hex2rstr` / `rstr2hex` — Hex ↔ raw string conversion
- `encode_utf8` / `decode_utf8` — UTF-8 encode/decode
- `data2blob` / `utf2blob` — Convert strings to `Blob` objects
- `isAlphaNumeric` / `isSafeString` — Input validation
- `parseUriArgs` — Parse and sanitize URL query parameters
- `jsonToCamel` — Convert object keys to camelCase
- `joinPaths` — Join path segments with `/`
- `zeroPad` — Left-pad numbers with zeros
- `check_webp_feature` — Async WebP format support detection

## Usage Example

```javascript
// DOM manipulation
QV('loading-spinner', false);   // hide element
QH('status-msg', 'Connected'); // set inner HTML
QE('submit-btn', true);        // enable button

// Binary encoding
const packet = ShortToStr(0x0102) + IntToStr(0xDEADBEEF);
const value  = ReadInt(packet, 2);

// String safety
if (isSafeString(userInput)) {
  QH('output', EscapeHtml(userInput));
}

// URL args
const args = parseUriArgs(true);
console.log(args.sessionId);

// Path joining
const url = joinPaths('/api', 'v1/', 'devices/');
// → '/api/v1/devices'
```
