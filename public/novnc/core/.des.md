DES (Data Encryption Standard) cipher implementation for VNC authentication, ported from the Flashlight VNC ActionScript implementation and adapted for JavaScript ES6 module use.

## Key Components

- **`DES` class** — Main export; encapsulates key scheduling and encryption logic
  - **`constructor(password)`** — Accepts an 8-byte array and generates 32 round subkeys using PC1 permutation, rotation schedule (`totrot`), and PC2 selection
  - **`enc8(text)`** — Encrypts a single 8-byte block using 8 rounds of the Feistel network with initial/final permutations and S-box lookups (SP1–SP8)
  - **`encrypt(t)`** — Encrypts a 16-byte input by calling `enc8` on each 8-byte half and concatenating the results

- **Lookup Tables** — Pre-computed constants for performance:
  - `PC2`, `totrot` — Key schedule permutation and rotation tables
  - `SP1`–`SP8` — Combined S-box and P-box permutation tables for the Feistel rounds

## Usage Example

```javascript
import DES from './des.js';

// Password must be an 8-byte array (e.g., from a VNC authentication challenge)
const password = [0x01, 0x23, 0x45, 0x67, 0x89, 0xab, 0xcd, 0xef];
const des = new DES(password);

// Encrypt a 16-byte plaintext block
const plaintext = new Array(16).fill(0x41); // 16 x 'A'
const ciphertext = des.encrypt(plaintext);

// Encrypt a single 8-byte block
const block = [0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x07, 0x08];
const encryptedBlock = des.enc8(block);
```

> **Note:** This is a legacy DES implementation used specifically for VNC RFB protocol authentication (DES challenge-response). It is not suitable for general-purpose cryptography. All inputs and outputs are plain JavaScript arrays of integers (0–255).
