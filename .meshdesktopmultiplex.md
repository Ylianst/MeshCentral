Remote desktop session multiplexor that manages shared KVM/desktop connections between a single agent and multiple browser viewers in MeshCentral.

## Key Components

### `CreateDesktopMultiplexor(parent, domain, nodeid, id, func)`
Factory function that creates a multiplexor session object managing:

- **`obj.agent`** — The single agent connection (remote device)
- **`obj.viewers[]`** — Array of browser viewer connections
- **`obj.images{}`** — Tile-based image cache for screen state reconstruction
- **`obj.screen`** — Tile map tracking which image covers each screen tile

### Core Methods

- **`obj.addPeer(peer)`** — Registers either an agent or viewer connection, initializes per-peer state, triggers session recording checks, and synchronizes existing screen state to new viewers
- **`obj.sendToViewer(peer, data)`** — Queues and sends data to a specific viewer with overflow protection
- **`obj.sendToAgent(data)`** — Forwards viewer commands (keyboard, mouse, touch events) to the agent
- **`obj.sendSessionMetadata()`** — Broadcasts connected peer list to all viewers

### State Management
- Tile-based screen cache (`obj.screen`, `obj.images`) allows late-joining viewers to receive the full current desktop state
- Compression/scaling/framerate negotiated as highest/lowest values across all viewers (`imageCompression`, `imageScaling`, `imageFrameRate`)
- Session recording support via `obj.recordingFile`

## Usage Example

```javascript
// Instantiated internally by the MeshCentral relay server
const mux = CreateDesktopMultiplexor(webserver, domain, 'node//dev//123', 'session-id-456', callback);

// Agent connects first
mux.addPeer(agentWebSocket);

// Viewers join later; existing screen state is replayed to each new viewer
mux.addPeer(viewerWebSocket1);
mux.addPeer(viewerWebSocket2);
```
