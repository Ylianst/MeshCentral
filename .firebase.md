MeshCentral Firebase communication module that provides push notification delivery to Android devices via either direct Firebase Admin SDK integration or a relay connection (WebSocket or HTTPS).

## Key Components

### `CreateFirebase(parent, serviceAccount)`
Initializes a direct Firebase Admin SDK connection for sending push notifications.

- **`sendToDevice(node, payload, options, func)`** — Resolves a node by ID or object, then sends a push notification
- **`sendToDeviceEx(node, payload, options, func)`** — Sends a Firebase Cloud Message directly using `admin.messaging().send()`
- **`setupRelay(ws)`** — Establishes a two-way WebSocket relay for bidirectional push notification routing
- **`stats`** — Tracks sent, sendError, received, receivedNoRoute, and receivedBadArgs counters

### `CreateFirebaseRelay(parent, url, key)`
Initializes a relay-mode Firebase connection, forwarding notifications through an external service.

- **WebSocket mode (`wss:`)** — Maintains a persistent WebSocket with exponential backoff reconnection; supports bidirectional message routing back to agents
- **HTTPS mode (`https:`)** — Push-only mode using HTTPS POST to an external relay endpoint
- **`tokenToNodeMap`** — Maps device push tokens to `{ nid, mid, did }` for inbound message routing

## Usage Example

```javascript
// Direct Firebase (using service account credentials)
const firebase = require('./firebase');
const fb = firebase.CreateFirebase(parent, serviceAccountJson);

fb.sendToDevice(nodeId, {
  notification: { title: 'Alert', body: 'Device needs attention' },
  data: { action: 'connect' }
}, { priority: 'high', timeToLive: 60 }, function(response, err) {
  if (err) console.error('Send failed:', err);
  else console.log('Sent:', response);
});

// Relay mode (via external WebSocket relay)
const relay = firebase.CreateFirebaseRelay(parent, 'wss://relay.example.com/firebase', 'mykey');
relay.sendToDevice(node, payload, options, callback);
```
