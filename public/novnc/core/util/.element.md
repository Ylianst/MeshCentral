Utility module for HTML element coordinate calculations, part of the noVNC HTML5 VNC client library.

## Key Components

### `clientToElement(x, y, elem)`
Converts client (viewport) coordinates to element-local coordinates, clamping the result to the element's bounding box if the point falls outside it.

**Parameters:**
- `x` — Client X coordinate (e.g., from a mouse event)
- `y` — Client Y coordinate
- `elem` — Target DOM element

**Returns:** `{ x, y }` — Position relative to the element's top-left corner, clipped to `[0, width-1]` and `[0, height-1]`

## Usage Example

```javascript
import { clientToElement } from './core/util/element.js';

canvas.addEventListener('mousemove', (e) => {
    const pos = clientToElement(e.clientX, e.clientY, canvas);
    console.log(`Element-relative position: ${pos.x}, ${pos.y}`);
});
```

This is particularly useful when handling mouse or touch events on the VNC canvas, ensuring pointer coordinates stay within the element boundary even when the cursor moves outside it rapidly.
