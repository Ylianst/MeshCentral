Decodes JPEG-encoded rectangles from a VNC data stream, with support for RealVNC's table reuse pattern by caching Huffman and quantization tables across frames.

## Key Components

**`JPEGDecoder`** — Main class with the following members:

- `_cachedQuantTables` / `_cachedHuffmanTables` — Persisted JPEG tables reused across frames when RealVNC omits them from subsequent images
- `_segments` — Accumulator for raw JPEG segment byte arrays during a single rect decode
- `decodeRect(x, y, width, height, sock, display, depth)` — Reads all JPEG segments from the socket queue until End-of-Image (`0xD9`), splices in cached tables if the frame omits them, assembles the final `Uint8Array`, and calls `display.imageRect()` to render
- `_readSegment(sock)` — Reads one JPEG marker segment from the socket, handling variable-length payloads and the special Start-of-Scan (`0xDA`) case where entropy-coded data must be consumed past the declared length

## Usage Example

```javascript
import JPEGDecoder from './jpeg.js';

const decoder = new JPEGDecoder();

// Called per incoming VNC JPEG-encoded rectangle
const complete = decoder.decodeRect(
    x, y, width, height,
    sock,    // RQ-buffered WebSocket wrapper
    display, // noVNC Display object
    depth    // color depth (unused by JPEG path)
);

if (!complete) {
    // Insufficient data in buffer — retry when more arrives
}
```

> **Note:** `decodeRect` returns `false` if the socket buffer lacks enough data, allowing the caller to defer processing until more bytes arrive. The decoder is stateful between calls — do not share instances across concurrent connections.
