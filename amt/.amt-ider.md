Handles server-side Intel AMT IDE Redirection (IDER) sessions, enabling remote boot of AMT-managed devices from disk images (`.img`/`.iso`) stored in user file storage.

## Key Components

### `CreateAmtIderSession(parent, db, ws, req, args, domain, user)`
Factory function that creates and returns an IDER session object managing the full lifecycle of an AMT remote boot session over WebSocket.

**Session Object Methods:**
- `obj.close(arg)` — Closes the session; `1` for soft WebSocket close, `2` for hard TCP socket close

**Internal Functions:**
- `processWebSocketData(msg)` — Dispatches incoming WebSocket commands (`ping`, `start`, `dialogResponse`)
- `onIderStateChange(sender, state)` — Handles IDER state transitions; cleans up and closes on state `0`
- `iderSectorStats(mode, dev, total, start, len)` — Emits disk I/O statistics back to the browser client
- `readFsRec(dir, func)` — Recursively enumerates all files under a directory
- `addHtmlValue(t, v)` — Builds an HTML label/value row for the selection dialog

## Usage Example

```javascript
// Instantiated by the MeshCentral server on WebSocket upgrade
const amtIder = require('./amt-ider.js');

const session = amtIder.CreateAmtIderSession(
    parent, db, ws, req, args, domain, user
);

// To forcibly terminate the session:
session.close(1); // Soft disconnect
session.close(2); // Hard disconnect
```

**WebSocket command flow:**

```text
Browser → "start"          → Server scans user files, returns dialog with .img/.iso lists
Browser → "dialogResponse" → Server validates paths, sets up and starts AMT IDER session
Server  → "state"          → Broadcasts session state changes
Server  → "stats"          → Streams sector-level I/O statistics
```

## Notes

- Disk images must be uploaded to the user's "My Files" folder on the MeshCentral server
- Path traversal is blocked by rejecting any path containing `..`
- Delegates actual AMT protocol handling to [`amt-redir-mesh.js`](https://github.com/flamingo-stack/meshcentral/blob/main/amt-redir-mesh.js) and [`amt-ider-module.js`](https://github.com/flamingo-stack/meshcentral/blob/main/amt-ider-module.js)
