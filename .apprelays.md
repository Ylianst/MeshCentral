Manages web relay sessions for browser-based remote access protocols (RDP, SSH, VNC, SFTP) in MeshCentral, creating and multiplexing tunnels between HTTP/WebSocket clients and remote devices.

## Key Components

### Protocol Constants
Numeric identifiers for supported relay protocols:
- `PROTOCOL_WEBRDP` (201), `PROTOCOL_WEBSSH` (202), `PROTOCOL_WEBSFTP` (203), `PROTOCOL_WEBVNC` (204)
- `PROTOCOL_TERMINAL` (1), `PROTOCOL_DESKTOP` (2), `PROTOCOL_FILES` (5)

### Mesh Rights Flags
Bitmask constants controlling user permissions (e.g., `MESHRIGHT_REMOTECONTROL`, `MESHRIGHT_RELAY`, `MESHRIGHT_ADMIN`).

### `SerialTunnel(options)`
A duplex stream wrapper used to embed TLS within an existing connection by forwarding writes through a configurable `forwardwrite` handler.

### `CreateWebRelaySession(parent, db, req, args, domain, userid, nodeid, addr, port, appid, sessionid, expire, mtype)`
Creates a session that manages multiple tunnels to a single remote device. Handles:
- `handleRequest(req, res)` — queues an HTTP request for relay
- `handleWebSocket(ws, req)` — queues a WebSocket request for relay
- `checkTimeout()` — cleans up idle non-WebSocket tunnels older than 5 minutes
- `close()` — tears down all tunnels and pending requests, fires `onclose`

### `CreateWebRelay(parent, db, args, domain, mtype)`
Creates an individual tunnel to a remote device. Exposes:
- `processRequest(req, res)` — forwards an HTTP request through the tunnel
- Events: `onclose`, `onconnect`, `oncompleted`, `onNextRequest`

## Usage Example

```javascript
const apprelays = require('./apprelays');

// Create a session managing tunnels to a device's web interface
const session = apprelays.CreateWebRelaySession(
    parent, db, req, args, domain,
    'user//domain/admin',
    'node//domain/abc123',
    '192.168.1.10', 8080,
    appid, sessionid, expire, mtype
);

// Route incoming HTTP requests through the session
session.handleRequest(req, res);

// Route incoming WebSocket upgrades through the session
session.handleWebSocket(ws, req);

// Clean up when done
session.close();
```
