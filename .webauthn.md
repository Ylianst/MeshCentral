MeshCentral WebAuthn module providing FIDO2/WebAuthn registration and assertion verification for authenticator-based multi-factor authentication.

## Key Components

| Export/Function | Description |
|---|---|
| `CreateWebAuthnModule()` | Factory function returning the WebAuthn module object |
| `obj.generateRegistrationChallenge()` | Generates a FIDO2 credential creation options object with a random 64-byte challenge |
| `obj.verifyAuthenticatorAttestationResponse()` | Verifies attestation responses for `none`, `fido-u2f`, and `packed` formats during registration |
| `obj.verifyAuthenticatorAssertionResponse()` | Verifies assertion signatures during authentication login |
| `parseMakeCredAuthData()` | Internal parser for CTAP2 authenticator data during credential creation |
| `parseGetAssertAuthData()` | Internal parser for authenticator data during assertion |
| `COSEECDHAtoPKCS()` | Converts COSE-encoded ECDH public key to uncompressed PKCS format |
| `ASN1toPEM()` | Converts raw ASN.1/DER buffer to PEM-encoded certificate string |

## Usage Example

```javascript
const { CreateWebAuthnModule } = require('./webauthn');

const webauthn = CreateWebAuthnModule();

// --- Registration ---
// 1. Generate challenge and send to client
const challenge = webauthn.generateRegistrationChallenge('MyApp', {
    id: 'user-123',
    name: 'alice',
    displayName: 'Alice'
});
// Send challenge to browser navigator.credentials.create()

// 2. Verify the authenticator's attestation response from the browser
const attestationResponse = {
    attestationObject: '<base64-encoded-attestation-object>',
    clientDataJSON: '<base64-encoded-client-data>'
};
const regResult = webauthn.verifyAuthenticatorAttestationResponse(attestationResponse);
if (regResult.verified) {
    // Store regResult.authrInfo: { fmt, publicKey, counter, keyId }
    console.log('Registered key:', regResult.authrInfo.keyId);
}

// --- Authentication ---
// Verify assertion response against stored authenticator info
const assertionResponse = {
    authenticatorData: Buffer.from('<...>'),
    clientDataJSON: Buffer.from('<...>'),
    signature: Buffer.from('<...>')
};
const storedAuthr = { fmt: 'fido-u2f', publicKey: '<PEM>', counter: 0 };
const authResult = webauthn.verifyAuthenticatorAssertionResponse(assertionResponse, storedAuthr);
if (authResult.verified) {
    // Update stored counter to authResult.counter to prevent replay attacks
}
```

> **Note:** This module currently supports `none`, `fido-u2f`, and `packed` (self-signed) attestation formats. Android SafetyNet and full certificate-chain packed attestation are stubbed out and commented in the source.
