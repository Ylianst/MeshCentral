MeshCentral Intel AMT HTTP interceptor that sits between a browser and Intel AMT device, parsing HTTP traffic in both directions, managing authentication state, and injecting Digest authentication credentials into browser requests.

## Key Components

- **`CreateHttpInterceptor(args)`** — Factory function returning an HTTP interceptor instance configured with host/port/credentials
- **`processAmtData(data)`** — Parses raw HTTP responses from Intel AMT (headers, content-length bodies, chunked transfer, until-close mode)
- **`processBrowserData(data)`** — Parses browser HTTP requests and injects Digest authentication headers before forwarding to AMT
- **`processAmtDataEx()` / `processBrowserDataEx()`** — Internal accumulators that drive a state machine through four HTTP parsing modes:
  - `0` = Header parsing
  - `1` = Content-Length body
  - `2` = Chunked transfer encoding
  - `3` = Stream until connection close
- **`GetAuthArgs(authheader)`** — Parses `WWW-Authenticate` Digest challenge headers into key/value pairs
- **`ComputeDigesthash(...)`** — Computes MD5-based Digest authentication response hash (RFC 2617)
- **`HttpInterceptorAuthentications`** — Module-level cache storing `WWW-Authenticate` challenges keyed by `host:port`

## Usage Example

```javascript
const interceptor = require('./interceptor.js');

const http = interceptor.CreateHttpInterceptor({
    host: '192.168.1.100',
    port: 16992,
    user: 'admin',
    pass: 'Password123!'
});

// Forward AMT response to browser
socket.on('data', (data) => {
    const processed = http.processAmtData(data);
    browserSocket.write(processed);
});

// Forward browser request to AMT (auth injected automatically)
browserSocket.on('data', (data) => {
    const processed = http.processBrowserData(data);
    socket.write(processed);
});
```

## Notes

- Authentication challenges are cached globally across interceptor instances per `host:port`
- `blockAmtStorage` flag redirects `/amt-storage` requests to `/amt-dummy-storage` when CIRA doesn't support web storage
