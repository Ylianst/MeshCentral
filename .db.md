MeshCentral database abstraction module that provides a unified interface for multiple database backends (NeDB, MongoDB, MariaDB, MySQL, PostgreSQL, AceBase, SQLite) used to persist devices, events, power states, and server statistics.

## Key Components

- **`CreateDB(parent, func)`** — Main factory function that initializes the database object, configures bulk operation state, and wires up all database methods
- **`deriveTenantDomain(domains)`** — Derives the active tenant domain key from server config for per-tenant database identifier isolation in OpenFrame/multi-tenant mode
- **`SetupDatabase(func)`** — Bootstraps the DB by resolving or generating a `DatabaseIdentifier`, checking and migrating `SchemaVersion`, then invoking the callback
- **`maintenance()`** — Periodic cleanup routine that purges expired events, power events, server stats, and SMBIOS records across all supported backends
- **`removeInactiveDevices(showall, cb)`** — Removes stale device records based on per-domain and per-mesh-group `autoremoveinactivedevices` thresholds
- **`obj.sqliteConfig`** — SQLite-specific tuning options (vacuum mode, journal mode, synchronous level)
- **`obj.dbCounters`** — Tracks file set/remove/power/event operation counts, extended with bulk-operation pending counters when `mongodbbulkoperations` is enabled
- **`obj.backupStatus`** — Bitmask tracking backup failure states (`BACKUPFAIL_ZIPCREATE`, `BACKUPFAIL_ZIPMODULE`, `BACKUPFAIL_DBDUMP`)

## Usage Example

```javascript
const db = require('./db.js');

// Initialize the database (NeDB by default, or pass --mongodb, --mariadb, etc.)
db.CreateDB(parent, function (dbVer) {
    db.SetupDatabase(function (schemaVersion) {
        console.log('DB ready, schema version:', schemaVersion);

        // Retrieve a record by key
        db.Get('DatabaseIdentifier', function (err, docs) {
            if (!err && docs.length > 0) {
                console.log('Server ID:', docs[0].value);
            }
        });

        // Derive tenant domain in OpenFrame multi-tenant mode
        const tenantDomain = db.deriveTenantDomain(parent.config.domains);
        console.log('Tenant domain:', tenantDomain || '(default)');
    });
});
```

## Supported Backends

| Constant | Backend |
|---|---|
| `DB_NEDB` | NeDB (default, file-based) |
| `DB_MONGODB` | MongoDB |
| `DB_MARIADB` | MariaDB |
| `DB_MYSQL` | MySQL |
| `DB_POSTGRESQL` | PostgreSQL |
| `DB_ACEBASE` | AceBase |
| `DB_SQLITE` | SQLite3 |
