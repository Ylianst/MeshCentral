Utility module from the noVNC HTML5 VNC client that provides helper functions for converting JavaScript numbers to 32-bit integer representations.

## Key Components

- **`toUnsigned32bit(toConvert)`** — Converts a number to an unsigned 32-bit integer using the zero-fill right shift operator (`>>> 0`).
- **`toSigned32bit(toConvert)`** — Converts a number to a signed 32-bit integer using the bitwise OR operator (`| 0`).

## Usage Example

```javascript
import { toUnsigned32bit, toSigned32bit } from './int.js';

// Unsigned 32-bit conversion
toUnsigned32bit(-1);        // → 4294967295
toUnsigned32bit(4294967296) // → 0 (overflow wraps)

// Signed 32-bit conversion
toSigned32bit(2147483648);  // → -2147483648
toSigned32bit(0xFFFFFFFF);  // → -1
```

## Notes

These utilities ensure consistent integer handling across VNC protocol data parsing, where precise 32-bit signed/unsigned boundaries matter for correct byte-level interpretation of network data.
