MeshCentral multi-server peer communication module that establishes and manages encrypted WebSocket connections between MeshCentral server instances for cluster/peer synchronization.

## Key Components

### `CreateMultiServer(parent, args)`
Factory function that initializes the multi-server manager, maintaining two server registries:
- `outPeerServers` — outgoing peer connections initiated by this server
- `peerServers` — all fully authenticated peer connections (inbound and outbound)

### `CreatePeerOutServer(parent, serverid, url)`
Constructs an outgoing peer connection object with:
- **`connect()`** — Establishes a WebSocket connection using mutual TLS certificate authentication (SHA-384 fingerprinting via `node-forge`)
- **`disconnect()`** — Tears down the connection and schedules exponential-backoff reconnection
- **`getConnectRetryTime()`** — Returns a randomized backoff delay (capped near 30s) to avoid thundering-herd reconnects
- **`send(msg)`** — Serializes and transmits JSON messages to the peer; no-ops if connection is not fully established (`connectionState != 15`)
- **`stop()`** — Permanently halts reconnection attempts

### Authentication Flow (4-bit state machine via `connectionState`)
| Bit | Meaning |
|-----|---------|
| `1` | Connection initiated |
| `2` | WebSocket open |
| `4` | Peer certificate/signature verified |
| `8` | Peer confirmed our authentication |

All 4 bits set (`15`) means the peer is fully authenticated and ready for data exchange.

## Usage Example

```javascript
const multiserver = require('./multiserver.js');

// Initialize multi-server support
const ms = multiserver.CreateMultiServer(parent, args);

// Connect to a peer MeshCentral instance
const peer = ms.CreatePeerOutServer(ms, 'peer-1', 'wss://peer.example.com/');

// Send a message once authenticated (connectionState === 15)
peer.send({ action: 'info', serverid: ms.serverid });

// Stop and clean up the peer connection
peer.stop();
```
