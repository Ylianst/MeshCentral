Implements the Intel AMT IDE Redirection (IDER) protocol over WebSocket, enabling remote boot of managed systems from virtual floppy or CD-ROM images.

## Key Components

- **`CreateAmtRemoteIder()`** — Factory function that constructs and returns the IDER session object with all state and methods.
- **`obj.Start()`** — Initializes byte counters and sequence numbers, then sends the `OPEN_SESSION` (0x40) command to begin the IDER handshake.
- **`obj.Stop()`** — Clears the ping timer and delegates to the parent transport to tear down the connection.
- **`obj.ProcessData(data)`** — Accumulates incoming bytes and dispatches complete frames via `ProcessDataEx()`, enforcing sequence number integrity.
- **`obj.ProcessDataEx()`** — Core state machine; parses command IDs from the 8-byte frame header and handles:
  - `0x41` OPEN\_SESSION — reads firmware/buffer info, selects boot mode (OnReboot/Graceful/Now)
  - `0x43` CLOSE — tears down the session
  - `0x44/0x45` KEEPALIVEPING/PONG — heartbeat exchange
  - `0x46` RESETOCCURED — responds once pending media operations complete
- **`obj.SendCommand(cmdid, data, completed, dma)`** — Frames and dispatches a command packet, incrementing `outSequence`.
- **`obj.SendCommandEndResponse()`** — Sends SCSI sense data (`0x51`) to report command success or error.
- **`obj.SendDataToHost()`** — Sends a SCSI READ response (`0x54`) with optional DMA flag.
- **`obj.SendGetDataFromHost()`** — Requests a data chunk from the host (`0x52`) for write operations.
- **`obj.SendDisableEnableFeatures()`** — Sends a features toggle command (`0x48`), used to set the IDER boot trigger mode.
- **Static mode-sense arrays** — Pre-encoded SCSI Mode Sense response buffers for floppy (LS-120, standard), CD-ROM, and combined (0x3F) page modes.

## Usage Example

```javascript
// Create and wire up an IDER session
var ider = CreateAmtRemoteIder();

// Attach a CD-ROM image (File or Blob)
ider.cdrom = cdromImageFile;
ider.cdromReady = true;

// Set boot mode: 0 = OnReboot, 1 = Graceful, 2 = Now
ider.iderStart = 0;

// Connect to parent transport (e.g. AMT WebSocket relay)
ider.parent = amtTransport;

// Transport calls this when the connection reaches state 3 (connected)
ider.xxStateChange(3); // triggers ider.Start()

// Transport pipes incoming bytes here
ider.ProcessData(rawBinaryString);
```
