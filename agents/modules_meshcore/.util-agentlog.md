Parses and reads MeshCentral agent log files, handling both standard log entries and crash reports across Windows and Linux platforms.

## Key Components

- **`parseLine(entry)`** — Internal function that parses a single log line, detecting:
  - Standard timestamped log entries (with optional hash and file/line metadata)
  - Windows crash stack entries (`[fn => file:line]` format)
  - Linux crash stack entries (symbol addresses, file references, crash IDs)
- **`readLog_data(buffer)`** — Stream data handler that buffers incomplete lines and feeds complete lines to `parseLine`
- **`readLogEx(path)`** — Reads a log file by path using a Node.js read stream, returning an array of all parsed log objects
- **`readLog(criteria, path)`** — Primary export; filters parsed log entries by a date string, numeric timestamp (Unix seconds), or count of last N entries (if `criteria < 1000`)

## Usage Example

```javascript
const agentLog = require('./util-agentlog');

// Read all entries from the default log path
const allEntries = agentLog.readEx('/path/to/agent.log');

// Get the last 50 log entries
const recent = agentLog.read(50);

// Get entries newer than a specific date
const sinceDate = agentLog.read('2024-01-15');

// Get entries newer than a Unix timestamp, from a custom path
const filtered = agentLog.read(1705276800, '/custom/agent.log');

// Parsed entry structure
// { t: 1705276800, m: "message text", h: "abc123", f: "source.js", l: "42" }
```

## Exports

| Export | Description |
|--------|-------------|
| `read(criteria, path)` | Filtered log reader; supports count, timestamp, or date string |
| `readEx(path)` | Raw log reader returning all parsed entries as an array |
