MD4 cryptographic hash function implementation (js-md4 v0.3.2), supporting multiple output formats and input types across browser and Node.js environments.

## Key Components

| Export/Method | Description |
|---|---|
| `md4(message)` | Default export — computes MD4 hash, returns hex string |
| `md4.hex(message)` | Returns hash as lowercase hex string |
| `md4.digest(message)` | Returns hash as byte array |
| `md4.array(message)` | Alias for `digest` — returns byte array |
| `md4.buffer(message)` | Returns hash as `ArrayBuffer` |
| `md4.arrayBuffer(message)` | Returns hash as `ArrayBuffer` |
| `md4.create()` | Creates a new `Md4` instance for incremental hashing |
| `md4.update(message)` | Creates instance and calls `.update()` in one step |
| `Md4.prototype.update(message)` | Feeds data into an existing hash instance |
| `Md4.prototype.finalize()` | Applies MD4 padding and finalizes the digest |

Accepts `String`, `Array`, `Uint8Array`, or `ArrayBuffer` as input. Uses shared `ArrayBuffer`/`Uint32Array` memory for performance when available, and delegates to Node.js `crypto.createHash('md4')` in Node environments.

## Usage Example

```javascript
// One-shot hex hash
md4('The quick brown fox jumps over the lazy dog');
// => '1bee69a46ba811185c194762abaeae90'

// Specific output formats
md4.hex('hello');
md4.array('hello');    // byte array
md4.buffer('hello');  // ArrayBuffer

// Incremental / streaming hashing
var hash = md4.create();
hash.update('The quick brown ');
hash.update('fox jumps over the lazy dog');
hash.hex(); // => '1bee69a46ba811185c194762abaeae90'

// Hash binary data
var bytes = new Uint8Array([0x00, 0xff, 0x10]);
md4.hex(bytes);
```

> **Note:** MD4 is a legacy algorithm considered cryptographically broken. Use only for compatibility with older protocols (e.g., NTLM). See source at [`md4.js`](https://github.com/flamingo-stack/meshcentral/blob/main/md4.js).
