Minified implementation of the Adler-32 checksum algorithm, extending the global `ZLIB` object with checksum computation and combination utilities.

## Key Components

- **`ZLIB.adler32(adler, buf, offset, len)`** — Computes an Adler-32 checksum over a buffer segment. Accepts either a `string` or a byte array (`Uint8Array`/array-like). Uses loop-unrolling in blocks of 5552 bytes (the largest block before modular reduction is required) for performance.
- **`ZLIB.adler32_combine(adler1, adler2, len2)`** — Combines two independent Adler-32 checksums into a single checksum, as if the two data streams were concatenated.

### Internal Constants

| Constant | Value | Purpose |
|---|---|---|
| `r` | `65521` | Largest prime ≤ 2¹⁶ (Adler-32 modulus) |
| `e` | `5552` | Max block size before overflow-safe mod reduction |

## Usage Example

```javascript
// Ensure zlib.js is loaded before this file
// <script src="zlib.js"></script>
// <script src="zlib-adler32-min.js"></script>

// Compute checksum over a byte array
const data = new Uint8Array([72, 101, 108, 108, 111]); // "Hello"
const checksum = ZLIB.adler32(1, data, 0, data.length);
console.log(checksum.toString(16)); // e.g., "077e0205"

// Compute checksum over a string
const strChecksum = ZLIB.adler32(1, "Hello", 0, 5);

// Combine two checksums (useful for parallel/chunked processing)
const part1 = ZLIB.adler32(1, data.slice(0, 3), 0, 3);
const part2 = ZLIB.adler32(1, data.slice(3), 0, 2);
const combined = ZLIB.adler32_combine(part1, part2, 2);
```

> **Dependency:** `zlib.js` must be loaded first. The script will `alert` and abort if the global `ZLIB` object is not found.
