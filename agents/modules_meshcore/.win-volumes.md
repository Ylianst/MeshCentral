Retrieves Windows volume and disk information using WMI queries, including filesystem details, BitLocker encryption status, and recovery passwords.

## Key Components

### `trimObject(j)`
Sanitizes a WMI result object by removing null values, empty strings, and internal `__`-prefixed properties. Also converts negative serial numbers to unsigned 32-bit integers.

### `getVolumes()`
Queries `Win32_Volume` for detailed volume metadata and merges BitLocker encryption data from `Win32_EncryptableVolume` (when available), keyed by `DeviceID`.

### `windows_volumes()`
Returns a Promise resolving to a map of logical drives (keyed by drive letter without colon). Each entry includes:
- `name`, `type`, `size`, `sizeremaining`, `removable`, `cdrom` — from `Win32_LogicalDisk`
- `volumeStatus`, `protectionStatus` — from `Win32_EncryptableVolume`
- `identifier`, `recoveryPassword` — parsed from `manage-bde` CLI output (multilingual: English, German, French)

### Module Exports
| Export | Description |
|---|---|
| `getVolumes` | Synchronous; returns raw volume map or `{}` on error |
| `volumes_promise` | Async; returns a Promise resolving to logical drive map with encryption info |

## Usage Example

```javascript
const winVolumes = require('./win-volumes');

// Synchronous: raw WMI volume data
const volumes = winVolumes.getVolumes();
console.log(volumes); // { '\\\\?\\Volume{abc...}\\': { DeviceID, Label, ... } }

// Async: logical drives with BitLocker status
winVolumes.volumes_promise().then(function (drives) {
    for (var letter in drives) {
        const d = drives[letter];
        console.log(`${letter}: ${d.name} [${d.type}] ${d.volumeStatus || 'N/A'} - Recovery: ${d.recoveryPassword || 'None'}`);
    }
});
```

> **Note:** Requires a Windows environment with `win-wmi` and `child_process` available. BitLocker data retrieval requires administrative privileges and `manage-bde` access.
