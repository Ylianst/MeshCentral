Manages custom cursor rendering for the noVNC HTML5 VNC client, handling both native CSS cursor URIs and a canvas-based fallback for touch devices or browsers that don't support cursor URIs.

## Key Components

**Class: `Cursor`**

| Member | Description |
|--------|-------------|
| `attach(target)` | Binds the cursor to a DOM element, sets up mouse event listeners in fallback mode |
| `detach()` | Removes event listeners and cleans up the canvas from the DOM |
| `change(rgba, hotx, hoty, w, h)` | Updates cursor appearance from raw RGBA pixel data with a hotspot offset |
| `clear()` | Resets cursor to `cursor: none` and clears the canvas |
| `move(clientX, clientY)` | Manually repositions the fallback canvas cursor (for emulated mouse events) |
| `_updateVisibility(target)` | Shows/hides the fallback canvas based on whether the pointer is over the target |
| `_captureIsActive()` | Detects active pointer capture via `document.captureElement` |

**`useFallback` (module-level constant)**  
Determined at load time — `true` when the browser lacks cursor URI support or is a touch device. Switches between CSS `url()` cursor injection and a fixed-position canvas overlay.

## Usage Example

```javascript
import Cursor from './cursor.js';

const cursor = new Cursor();
const canvas = document.getElementById('vnc-canvas');

// Attach to target element
cursor.attach(canvas);

// Update cursor image from RGBA data (e.g., received from VNC server)
const rgba = new Uint8Array(16 * 16 * 4); // 16x16 cursor pixel data
cursor.change(rgba, 0, 0, 16, 16);        // hotspot at (0,0)

// Move fallback cursor manually (for touch/emulated mouse events)
cursor.move(clientX, clientY);

// Remove cursor and clean up
cursor.clear();
cursor.detach();
```

## Fallback Mode

When `useFallback` is `true`, a fixed-position `<canvas>` element is appended to `<body>` and tracked via mouse events. Key behaviors:
- Visibility is toggled based on whether the pointer is within the target element
- Pointer capture state is respected via `document.captureElement`
- Compensates for visual vs. layout viewport offset (`window.visualViewport`)
