RDP PDU type constants and packet structure definitions for the node-rdpjs RDP protocol implementation, covering share control headers, data PDU types, input events, and error codes.

## Key Components

### Enumerations

| Constant | Description |
|----------|-------------|
| `PDUType` | Primary PDU types (demand/confirm active, data, redirect) |
| `PDUType2` | Secondary PDU subtypes (update, control, input, font, etc.) |
| `StreamId` | Stream priority levels (undefined, low, medium, high) |
| `CompressionOrder` / `CompressionType` | Compression flags and algorithm identifiers |
| `Action` | Control action types (request, granted, detach, cooperate) |
| `UpdateType` | Bitmap/palette/order update categories |
| `InputMessageType` | Input event types (scancode, unicode, mouse) |
| `PointerFlag` | Mouse button and wheel flags |
| `KeyboardFlag` | Key state flags (extended, down, release) |
| `FastPathUpdateType` | Fast-path output update types |
| `ErrorInfo` | Comprehensive RDP session error codes |
| `ToogleFlag` | Keyboard lock state flags (scroll, num, caps, kana) |

### Functions

- **`shareControlHeader(length, pduType, userId, opt)`** — Builds a share control header `type.Component` with total length, PDU type, and optional PDU source fields.

## Usage Example

```javascript
var data = require('./data');

// Build a share control header for a data PDU
var header = data.shareControlHeader(
    128,                          // total packet length
    data.PDUType.PDUTYPE_DATAPDU, // PDU type
    1001,                         // user ID
    {}                            // options
);

// Check input event type
function handleInput(eventType) {
    if (eventType === data.InputMessageType.INPUT_EVENT_MOUSE) {
        // handle mouse input
    } else if (eventType === data.InputMessageType.INPUT_EVENT_SCANCODE) {
        // handle keyboard input
    }
}

// Inspect keyboard flags
var isKeyRelease = (flags & data.KeyboardFlag.KBDFLAGS_RELEASE) !== 0;
```

## References

All constants follow the [MS-RDPBCGR](http://msdn.microsoft.com/en-us/library/cc240576.aspx) specification. Each enum maps directly to MSDN-documented protocol values for use in parsing and constructing RDP protocol packets.
