Minified UMD bundle that bridges [Moment.js](https://momentjs.com/) date parsing/formatting with [Chart.js](https://www.chartjs.org/) time scale adapters (v1.0.1).

## Key Components

| Export / Symbol | Description |
|---|---|
| `_adapters._date.override(...)` | Registers the Moment.js adapter with Chart.js's internal date adapter registry |
| `formats` | Default display format map for Chart.js time units (`datetime`, `millisecond` → `year`) |
| `parse(value, format?)` | Parses strings, Moment instances, or timestamps into milliseconds via `moment().valueOf()` |
| `format(ms, fmt)` | Formats a millisecond timestamp using a Moment.js format string |
| `add(ms, amount, unit)` | Returns a new timestamp after adding a Moment.js duration |
| `diff(a, b, unit)` | Returns the difference between two timestamps in the given unit |
| `startOf(ms, unit, weekday?)` | Snaps a timestamp to the start of the given time unit; handles `isoWeek` with an optional weekday offset |
| `endOf(ms, unit)` | Returns the end-of-unit timestamp |

## Usage Example

Include after both `moment` and `chart.js` are loaded. No explicit calls needed — the adapter self-registers.

```javascript
// Browser (UMD globals already loaded via <script> tags)
// Just include chartjs-adapter-moment-min.js and Chart.js uses Moment automatically.

// Node.js / bundler
const moment = require('moment');
const { Chart } = require('chart.js');
require('./chartjs-adapter-moment-min.js'); // registers adapter

const chart = new Chart(ctx, {
  type: 'line',
  data: { datasets: [{ data: timeSeriesData }] },
  options: {
    scales: {
      x: {
        type: 'time',
        time: {
          unit: 'day',          // uses formats.day → 'MMM D'
          tooltipFormat: 'MMM D, YYYY, h:mm:ss a'
        }
      }
    }
  }
});
```

## Notes

- The adapter only registers when `moment` is available as a function; otherwise it passes an empty object (safe no-op).
