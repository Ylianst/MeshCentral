Handles RFB CopyRect encoding by reading a source position from the socket buffer and blitting an existing screen region to a new location, avoiding retransmission of unchanged pixel data.

## Key Components

- **`CopyRectDecoder`** — Default export class implementing the CopyRect RFB decoder
- **`decodeRect(x, y, width, height, sock, display, depth)`** — Decodes a single CopyRect rectangle by:
  - Waiting for 4 bytes (`deltaX`, `deltaY`) from the receive queue
  - Extracting the source coordinates via `rQshift16()`
  - Invoking `display.copyImage()` to blit the source region to the target position

## Usage Example

```javascript
import CopyRectDecoder from './copyrect.js';

const decoder = new CopyRectDecoder();

// Called by the RFB protocol handler when a CopyRect-encoded rect is received
const complete = decoder.decodeRect(
    destX, destY,       // target position on screen
    width, height,      // rectangle dimensions
    sock,               // WebSocket receive queue
    display,            // noVNC Display object
    depth               // color depth (unused by CopyRect)
);

if (!complete) {
    // Insufficient data buffered — retry on next data event
}
```

## Notes

- Returns `false` if fewer than 4 bytes are available in the socket buffer (signals the caller to retry)
- Returns `true` early (no-op) if `width` or `height` is zero
- The `depth` parameter is accepted for interface consistency but is not used by this encoding
