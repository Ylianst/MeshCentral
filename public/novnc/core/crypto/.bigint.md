Utility module providing BigInt cryptographic and conversion helpers for modular exponentiation and binary data interop.

## Key Components

| Export | Signature | Description |
|--------|-----------|-------------|
| `modPow` | `(b, e, m) → BigInt` | Fast modular exponentiation using square-and-multiply |
| `bigIntToU8Array` | `(bigint, padLength?) → Uint8Array` | Converts a BigInt to a big-endian byte array |
| `u8ArrayToBigInt` | `(arr) → BigInt` | Converts a big-endian `Uint8Array` back to a BigInt |

## Usage Example

```javascript
import { modPow, bigIntToU8Array, u8ArrayToBigInt } from './bigint.js';

// Modular exponentiation: 2^10 mod 1000
const result = modPow(2n, 10n, 1000n);
console.log(result); // 24n

// BigInt → Uint8Array (padded to 4 bytes)
const bytes = bigIntToU8Array(255n, 4);
console.log(bytes); // Uint8Array [ 0, 0, 0, 255 ]

// Uint8Array → BigInt (round-trip)
const restored = u8ArrayToBigInt(bytes);
console.log(restored); // 255n
```

## Notes

- `modPow` uses the **binary method** (right-to-left), running in O(log e) multiplications — suitable for RSA/DH key operations.
- `bigIntToU8Array` pads output to the nearest byte boundary by default; pass an explicit `padLength` to enforce a fixed buffer size.
- All three functions operate on native BigInt (`n` suffix literals), requiring ES2020+.
