Handles multi-provider user messaging for MeshCentral, enabling outbound notifications via Telegram, Discord, XMPP, CallMeBot, Pushover, ntfy, Zulip, and Slack Webhook.

## Key Components

- **`CreateServer(parent)`** — Factory function that initializes the messaging module and all configured providers, returning a unified `obj` with active clients and a bitmask `obj.providers` tracking enabled services
- **`obj.providers`** — Bitmask integer indicating active providers: `1`=Telegram, `4`=Discord, `8`=XMPP, `16`=CallMeBot, `32`=Pushover, `64`=ntfy, `128`=Zulip, `256`=Slack
- **`setupTelegram()`** — Async initializer supporting both user session and bot token authentication, with optional proxy and WSS configuration
- **`discordSendMsg(userId, message)`** — Sends a direct message to a Discord user by their numeric user ID
- **`discordFindUserByTag(userTag, func)`** — Resolves a `username#discriminator` tag to a Discord user ID by searching all guild members

## Usage Example

```javascript
// In config.json, enable one or more providers:
{
  "messaging": {
    "telegram": {
      "apiid": 12345678,
      "apihash": "abc123...",
      "bottoken": "123456:ABC-abc..."
    },
    "discord": {
      "token": "your-discord-bot-token"
    }
  }
}

// The server instantiates the messaging module via MeshCentral core:
const messaging = require('./meshmessaging').CreateServer(parent);

// Check which providers are active (bitmask):
if (messaging.providers & 1) { /* Telegram active */ }
if (messaging.providers & 4) { /* Discord active */ }

// Send a Discord DM (internal async helper):
discordSendMsg('123456789012345678', 'Alert: Device offline');
```

## Supported Providers

| Provider | Bitmask | Auth Method |
|---|---|---|
| Telegram | `1` | User session or bot token |
| Discord | `4` | Bot token |
| XMPP | `8` | Username/password |
| CallMeBot | `16` | Signal API (no token) |
| Pushover | `32` | API token |
| ntfy | `64` | No auth |
| Zulip | `128` | Email + API key |
| Slack | `256` | Webhook |
