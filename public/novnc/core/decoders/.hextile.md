Implements the Hextile RFB encoding decoder for noVNC, processing rectangular screen regions divided into 16×16 pixel tiles with support for multiple sub-encodings (Raw, Background, Foreground, AnySubrects, SubrectsColoured).

## Key Components

**`HextileDecoder` class**

- **`constructor()`** — Initializes tile state, last sub-encoding tracker, and a reusable 16×16 RGBA pixel buffer (`_tileBuffer`).
- **`decodeRect(x, y, width, height, sock, display, depth)`** — Main decode loop. Iterates over all tiles in a rectangle, reads sub-encoding flags from the socket queue, validates data availability, and dispatches to raw blit or subrect rendering. Returns `false` if more data is needed (partial frame), `true` when the full rectangle is decoded.
- **`_startTile(x, y, width, height, color)`** — Fills the internal tile buffer with a solid background color to begin compositing a tile.
- **`_subTile(x, y, w, h, color)`** — Paints a sub-rectangle within the current tile buffer with the given color.
- **`_finishTile(display)`** — Blits the completed tile buffer to the display at the tile's screen coordinates.

## Usage Example

```javascript
import HextileDecoder from './hextile.js';

const decoder = new HextileDecoder();

// Called per RFB rectangle update with Hextile encoding
function onRectUpdate(rect, sock, display) {
    const { x, y, width, height } = rect;

    const done = decoder.decodeRect(x, y, width, height, sock, display, 24);

    if (!done) {
        // Socket buffer incomplete — wait for more data
        return false;
    }

    // Rectangle fully rendered to display
    return true;
}
```
