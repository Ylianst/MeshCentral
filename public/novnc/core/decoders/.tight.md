Implements the Tight encoding decoder for the noVNC HTML5 VNC client, handling compressed rectangle data using zlib streams, fill colors, JPEG/PNG images, and palette-based pixel formats.

## Key Components

- **`TightDecoder`** — Main decoder class managing state across partial data reads
  - `_ctl` — Compression control byte parsed from stream
  - `_filter` — Active filter type (Copy, Palette, Gradient)
  - `_palette` — 1KB buffer for up to 256 palette entries
  - `_zlibs` — Array of 4 independent `Inflator` (zlib) stream instances

### Methods

| Method | Description |
|---|---|
| `decodeRect()` | Entry point; dispatches to fill, JPEG, PNG, or basic rect handlers |
| `_fillRect()` | Renders a solid-color rectangle from a 3-byte pixel |
| `_jpegRect()` | Decodes a JPEG-encoded rectangle via `display.imageRect()` |
| `_basicRect()` | Reads filter type and dispatches to Copy, Palette, or Gradient sub-decoders |
| `_copyFilter()` | Raw RGB pixel data, zlib-inflated when ≥12 bytes |
| `_paletteFilter()` | Indexed color image; delegates to `_monoRect()` (1-bit) or `_paletteRect()` (8-bit) |
| `_gradientFilter()` | Delta-prediction decompression applied per row/channel |
| `_readData()` | Reads a compact 1–3 byte length prefix then shifts that many bytes from the socket |
| `_getScratchBuffer()` | Returns a reused `Uint8Array`, reallocating only when the requested size grows |

## Usage Example

```javascript
import TightDecoder from './decoders/tight.js';

const decoder = new TightDecoder();

// Called per rectangle update received from the VNC server
const complete = decoder.decodeRect(
    x, y, width, height,
    sock,     // RFB socket with rQ read-queue methods
    display,  // noVNC Display instance
    depth     // Pixel depth
);

if (!complete) {
    // Insufficient data buffered yet; retry on next data event
}
```

> **Note:** `decodeRect()` returns `false` when the socket buffer lacks enough data, enabling incremental/stateful decoding across multiple network chunks.
