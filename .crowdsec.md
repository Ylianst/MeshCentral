Integrates CrowdSec threat intelligence into MeshCentral's HTTP layer, providing IP-based remediation (ban or CAPTCHA) for incoming web requests using the `@crowdsec/express-bouncer` library.

## Key Components

- **`CreateCrowdSecBouncer(parent, config)`** — Factory function that initializes and returns a bouncer instance with the following methods:
  - **`obj.testConnectivity()`** — Async method that verifies connectivity to the CrowdSec LAPI endpoint.
  - **`obj.process(domain, req, res, next)`** — Async middleware handler that fetches the remediation decision for a client IP and either serves a ban wall (HTTP 403), redirects to a CAPTCHA page, or allows the request through.
  - **`obj.applyCaptcha(req, res, next)`** — Async handler for CAPTCHA challenge/response flow, delegating to the internal `applyCaptchaEx` function.
- **`applyCaptchaEx(...)`** — Internal async function managing the full CAPTCHA lifecycle: generation, phrase validation, resolution caching, and error display.
- **`generateCaptcha(ip, duration)`** — Creates an SVG CAPTCHA via `svg-captcha`, stores it in `currentCaptchaIpList`, and schedules automatic expiry.

## Usage Example

```javascript
const crowdSec = require('./crowdsec');

const bouncer = crowdSec.CreateCrowdSecBouncer(parent, {
  url: 'http://localhost:8080',
  apikey: 'your-crowdsec-api-key',
  fallbackremediation: 'ban',
  captchagenerationcacheduration: 60000,   // 60 seconds
  captcharesolutioncacheduration: 1800000  // 30 minutes
});

// Test LAPI connectivity on startup
const ok = await bouncer.testConnectivity();

// Use in an Express-style request handler
app.use(async (req, res, next) => {
  const blocked = await bouncer.process(domain, req, res, next);
  if (!blocked) next();
});

// Mount the CAPTCHA endpoint
app.all('/captcha.ashx', async (req, res, next) => {
  await bouncer.applyCaptcha(req, res, next);
});
```

## Configuration Defaults

| Key | Default | Description |
|-----|---------|-------------|
| `useragent` | `CrowdSec Express-NodeJS bouncer/v0.0.1` | HTTP User-Agent sent to LAPI |
| `timeout` | `2000` ms | Request timeout |
| `fallbackremediation` | `ban` | Action when LAPI is unreachable |
| `captchagenerationcacheduration` | `60000` ms | CAPTCHA TTL before regeneration |
| `captcharesolutioncacheduration` | `1800000` ms | Solved CAPTCHA TTL |
