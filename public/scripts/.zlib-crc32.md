JavaScript implementation of the zlib CRC-32 checksum algorithm, extending the `ZLIB` global namespace with CRC-32 computation and combination functions.

## Key Components

- **`ZLIB.crc32(crc, buf, offset, len)`** — Computes or updates a running CRC-32 checksum. Accepts either a `string` or byte array as `buf`. Pass `null` for `buf` to get the initial CRC value (`0`). Pre- and post-conditioning (one's complement) is handled internally.
- **`ZLIB.crc32_combine(crc1, crc2, len2)`** — Combines two independently computed CRC-32 values into a single checksum representing the concatenation of both sequences, using GF(2) matrix operations.
- **`crc32_string(crc, buf, offset, len)`** *(internal)* — CRC-32 implementation for string input using `charCodeAt`.
- **`crc32_array(crc, buf, offset, len)`** *(internal)* — CRC-32 implementation for array/byte input.
- **`crc_table`** *(internal)* — Precomputed 256-entry lookup table for the CRC-32 polynomial (`0xEDB88320`), enabling an 8-bytes-at-a-time unrolled loop for performance.

## Usage Example

```javascript
// Initialize CRC
var crc = ZLIB.crc32(0, null, 0, 0);

// Update with a string buffer
crc = ZLIB.crc32(crc, "hello world", 0, 11);

// Update with a byte array
var bytes = [0x68, 0x65, 0x6c, 0x6c, 0x6f];
crc = ZLIB.crc32(crc, bytes, 0, bytes.length);

// Combine two separately computed CRC-32 values
var crc1 = ZLIB.crc32(ZLIB.crc32(0, null, 0, 0), "hello", 0, 5);
var crc2 = ZLIB.crc32(ZLIB.crc32(0, null, 0, 0), " world", 0, 6);
var combined = ZLIB.crc32_combine(crc1, crc2, 6);
```

> **Dependency:** `zlib.js` must be loaded before this file to define the `ZLIB` global namespace.
