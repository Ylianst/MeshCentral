Implements the RA2 (RSA-AES) authentication protocol for VNC connections, providing encrypted session negotiation using RSA key exchange and AES-EAX symmetric encryption.

## Key Components

### `RA2Cipher` (internal class)
AES-EAX symmetric cipher wrapper with an incrementing counter (CTR mode):
- `setKey(key)` — Imports a raw AES-EAX key via the legacy crypto abstraction
- `makeMessage(message)` — Encrypts and frames a message with a 2-byte length header + 16-byte tag
- `receiveMessage(length, encrypted)` — Decrypts and authenticates an incoming encrypted frame

### `RSAAESAuthenticationState` (default export)
Stateful async authentication handler extending `EventTargetMixin`:

| Method | Description |
|---|---|
| `negotiateRA2neAuthAsync()` | Full 7-step RA2 handshake (RSA key exchange → session keys → credential exchange) |
| `checkInternalEvents()` | Polls pending socket/credential checks (call on each data-received event) |
| `approveServer()` | Resolves the server key verification promise (call after user/UI approves the server key) |
| `disconnect()` | Rejects all pending async waits with a normal-disconnect error |

**Events dispatched:**
- `serververification` — fired with `{ type: "RSA", publickey }` for server key approval
- `credentialsrequired` — fired with `{ types: ["username","password"] }` or `{ types: ["password"] }` depending on subtype

## Usage Example

```javascript
import RSAAESAuthenticationState from './ra2.js';

const auth = new RSAAESAuthenticationState(sock, () => credentials);

// Handle server key verification (e.g., show fingerprint to user)
auth.addEventListener('serververification', (e) => {
    console.log('Server RSA key received:', e.detail.publickey);
    auth.approveServer(); // Call after user approval
});

// Handle credential requests
auth.addEventListener('credentialsrequired', (e) => {
    credentials = { username: 'admin', password: 'secret' };
    auth.checkInternalEvents(); // Trigger re-check after setting credentials
});

// On incoming socket data
sock.on('data', () => auth.checkInternalEvents());

// Start authentication
await auth.negotiateRA2neAuthAsync();
```
