Performs local network discovery of MeshCentral mesh agents by broadcasting UDP multicast packets over IPv4 and IPv6, enabling agents on the local network to locate and connect to the MeshCentral server.

## Key Components

- **`CreateMeshScanner(parent)`** — Factory function that constructs and returns the scanner object
- **`encryptPacket(plainPacket)`** / **`decryptPacket(packet)`** — AES-256-CBC encryption/decryption for UDP multicast packets using a configurable discovery key
- **`getInterfaceList()`** — Enumerates all non-loopback network interfaces, returning IPv4 and IPv6 address lists
- **`setupServers()`** / **`clearServers()`** — Manages UDP socket lifecycle for all detected interfaces on port `16989`
- **`obj.start()`** — Initializes multicast packets (including server name, cert hash, and WebSocket URL) and begins periodic scanning every 20 minutes
- **`obj.stop()`** — Tears down timers and closes all UDP sockets
- **`obj.performScan(server)`** — Sends encrypted multicast discovery packets to `239.255.255.235` (IPv4) and `FF02::FE` (IPv6) on port `16990`
- **`onUdpPacket(msg, info, socket)`** — Handles incoming UDP responses from agents

## Usage Example

```javascript
const meshScanner = require('./meshscanner');

// Initialize and start the scanner (called internally by MeshCentral)
const scanner = meshScanner.CreateMeshScanner(parent);
scanner.start();

// Trigger an immediate scan on all sockets
scanner.performScan();

// Stop scanning and release all sockets
scanner.stop();
```

## Configuration

| Option | Description |
|---|---|
| `localdiscovery.key` | Shared key for AES-256 packet encryption |
| `localdiscovery.name` | Custom server name broadcast in discovery packets |
| `localdiscovery.info` | Additional info string included in discovery packets |
| `args.aliasport` / `args.port` | WebSocket port included in agent connection URLs |
