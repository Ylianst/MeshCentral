MeshCentral web relay server that creates an HTTP/HTTPS relay server for routing web traffic through multi-tunnel sessions to managed devices.

## Key Components

- **`CreateWebRelayServer(parent, db, args, certificates, func)`** — Factory function that constructs and returns the relay server object
- **`serverStart()`** — Initializes Express middleware, TLS configuration, session handling, and registers HTTP/WebSocket routes
- **`relaySessions`** — In-memory map of `RelayID → WebMultiTunnel` objects managing active relay sessions
- **`HandleEvent`** — Listens for `server-shareremove` events to close sessions when device shares are revoked
- **`/control-redirect.ashx`** route — Magic URL that bootstraps a new relay session from a signed relay cookie
- **WebSocket handler (`/*`)** — Forwards WebSocket connections to the matched `relaySession.handleWebSocket()`
- **HTTP middleware** — Validates session cookies, resolves client IP (including CloudFlare/reverse-proxy headers), and dispatches requests to `relaySession.handleRequest()`

## Usage Example

```javascript
const webRelayServer = require('./webrelayserver');

webRelayServer.CreateWebRelayServer(
  parent,        // MeshCentral parent object
  db,            // Database instance
  args,          // Server arguments (port, TLS offload, trusted proxy, etc.)
  certificates,  // TLS certificates { web: { cert, key, ca } }
  function(port) {
    console.log(`Web relay server listening on port ${port}`);
  }
);
```

**Session flow:**

```text
Client → GET /control-redirect.ashx?c=<signed-cookie>
       → Session validated, relaySession created in relaySessions map
       → Subsequent requests/WebSockets matched via session cookie
       → Forwarded to relaySession.handleRequest() / handleWebSocket()
```

## Security Features

- TLS 1.2+ enforced with PFS cipher suites when not offloaded
- HTTP security headers (`HSTS`, `CSP`, `X-Frame-Options`, `X-XSS-Protection`)
- Cookie sessions signed with SHA-384 via `keygrip`
- `SameSite`, `httpOnly`, and `secure` cookie flags
- Trusted reverse-proxy IP resolution (supports CloudFlare, `X-Forwarded-For`)
- Optional [CrowdSec](https://www.crowdsec.net/) bouncer middleware integration
