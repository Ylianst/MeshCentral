Handles Intel AMT ACM (Admin Control Mode) certificate operations for MeshCentral, including certificate generation, chain building, ACM activation request signing, and activation logging.

## Key Components

- **`getAcmCertChain(domain, fqdn, hash)`** — Builds the TLS certificate chain for ACM activation by matching a cert hash to a configured signing certificate. Dynamically issues a leaf cert for wildcard entries.
- **`signAcmRequest(domain, request, user, pass, ...)`** — Signs an Intel AMT ACM activation request using the matched signing cert; returns signature, nonce, cert chain, and MD5 password hash.
- **`logAmtActivation(domain, x)`** — Appends activation events to a domain-specific log file and maintains a rolling list (max 3) of known AMT passwords per device UUID.
- **`loadIntelAmtAcmCerts(amtacmactivation)`** — Loads and validates ACM activation certificates from configuration.
- **`IssueWebServerCertificate(...)`** *(referenced)* — Issues leaf TLS certificates signed by a root cert (defined elsewhere in the module).
- **`checkAcmActivationCertName(commonName, trustedFqdn)`** — Validates wildcard or exact FQDN matches against certificate common names.
- **`TopLevelDomainExtendedSupport`** — Lookup table defining subdomain depth rules for supported TLDs.

## Usage Example

```javascript
const certOps = require('./certoperations').CertificateOperations(parent);

// Build ACM certificate chain for a device
const chain = certOps.getAcmCertChain(domain, 'device.example.com', sha256Hash);
if (chain.error) {
  console.error(chain.errorText);
} else {
  console.log('Cert chain ready:', chain.certs.length, 'certs');
}

// Sign an ACM activation request from an AMT device
const result = certOps.signAcmRequest(
  domain, { nonce, realm, fqdn, hash, uuid },
  'admin', 'password', '192.168.1.10:16992',
  nodeId, meshId, 'MyPC', agentId
);
if (!result.error) {
  sendToDevice({ signature: result.signature, nonce: result.nonce });
}
```
