Minified JavaScript service layer that wraps Intel AMT (Active Management Technology) WS-Management operations, providing a high-level API for querying and controlling AMT-enabled hardware via WSMAN protocol.

## Key Components

- **`AmtStackCreateService(wsman)`** — Factory function that creates and returns an AMT service object bound to a WSMAN transport instance
- **Namespace prefixes (`pfx`)** — Maps `AMT_`, `CIM_`, and `IPS_` class prefixes to their full Intel/DMTF schema URIs
- **Enumeration queue** — Manages concurrent WSMAN Enumerate/Pull operations via `PendingEnums`, `ActiveEnumsCount`, and `MaxActiveEnumsCount`
- **Progress tracking** — `GetPendingActions()` and `onProcessChanged` callback for monitoring in-flight requests
- **Core CRUD operations** — `Get`, `Put`, `Create`, `Delete`, `Exec`, `Enum`, `Subscribe`, `UnSubscribe`
- **Batch helpers** — `BatchEnum` and `BatchGet` for issuing multiple queries in a single logical operation
- **AMT-specific methods** — Hundreds of pre-wired calls covering:
  - Agent Presence Watchdog (`AMT_AgentPresenceWatchdog_*`)
  - Audit Log (`AMT_AuditLog_*`)
  - Authorization Service (`AMT_AuthorizationService_*`)
  - Endpoint Access Control (`AMT_EndpointAccessControlService_*`)
  - Power management (`RequestPowerStateChange`, `SetBootConfigRole`)
  - Message Log parsing with IPMI event decoding

## Usage Example

```javascript
// Initialize with a WSMAN transport
const amt = AmtStackCreateService(wsmanInstance);

// Monitor progress
amt.onProcessChanged = (pending, max) => {
  console.log(`Progress: ${pending}/${max}`);
};

// Fetch a single AMT resource
amt.Get('AMT_GeneralSettings', (stack, name, response, status, tag) => {
  if (status === 200) console.log(response.Body);
});

// Batch enumerate multiple classes
amt.BatchEnum('myQuery', ['AMT_EthernetPortSettings', 'CIM_NetworkPort'], (stack, name, responses, status) => {
  console.log(responses);
}, null, {});

// Execute a power state change (e.g., power off = 8)
amt.RequestPowerStateChange(8, (stack, name, response, status) => {
  console.log('Power state changed:', status);
});

// Read AMT audit/message log events
amt.AMT_AuditLog_ReadRecords(1, (stack, name, response, status) => {
  if (status === 200) console.log(response);
}, myTag);
```

## Notes

- Requires a WSMAN communication object (`wsman`) with `ExecGet`, `ExecPut`, `ExecEnum`, `ExecPull`, `ExecMethod`, and `ExecSubscribe` methods
- Class names are auto-resolved to full URIs via `CompleteName()` based on `AMT_`, `CIM_`, or `IPS_` prefix
- Source: [`amt-0.2.0-min.js`](https://github.com/flamingo-stack/meshcentral/blob/main/amt-0.2.0-min.js)
