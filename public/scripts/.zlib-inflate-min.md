Minified JavaScript implementation of the DEFLATE inflation (decompression) algorithm, providing the core inflate functionality for the ZLIB library used in MeshCentral.

## Key Components

| Component | Description |
|-----------|-------------|
| `b(t, a)` | Internal Huffman code table builder — constructs length/distance decode tables |
| `e(i, s)` | Core inflate inner loop — decodes compressed bitstream using Huffman tables |
| `d()` | Inflate state constructor — initializes all decompression state fields |
| `ZLIB.inflateInit(t)` | Creates and initializes a new inflate stream with window bits |
| `ZLIB.inflateReset(t, a)` | Resets inflate stream, optionally reconfiguring window bits and checksum function |
| `ZLIB.inflateResetKeep(t)` | Resets stream counters/state while preserving window allocation |
| `ZLIB.inflatePrime(t, a, i)` | Inserts raw bits into the inflate bit buffer (used for multi-part streams) |

## Usage Example

```javascript
// Initialize a zlib inflate stream (window bits = 15, zlib format)
var stream = ZLIB.inflateInit(15);

// Set input compressed data
stream.input_data = compressedString;
stream.next_in = 0;
stream.avail_in = compressedString.length;
stream.next_out = 0;
stream.avail_out = expectedOutputSize;

// Run inflation
var result = ZLIB.inflate(stream, ZLIB.Z_NO_FLUSH);

if (result === ZLIB.Z_OK || result === ZLIB.Z_STREAM_END) {
  console.log(stream.output_data); // decompressed string
}
```

## Dependencies

- **Requires `zlib.js`** to be loaded first — `ZLIB` global must exist before this file or an `alert()` is triggered.
- Optionally uses `ZLIB.adler32` or `ZLIB.crc32` for checksum validation when available.
