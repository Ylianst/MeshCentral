Keyboard event handler for the noVNC HTML5 VNC client that translates browser keyboard events into VNC-compatible keysym events, with platform-specific workarounds for macOS, iOS, and Windows.

## Key Components

**Class: `Keyboard`**

- **`constructor(target)`** — Initializes the keyboard handler on a DOM target element, setting up internal key tracking state and event handler bindings.
- **`onkeyevent`** — Callback fired on key press/release: `(keysym, code, down, numlock, capslock) => {}`
- **`grab()`** — Attaches `keydown`, `keyup`, and `blur` listeners to the target element.
- **`ungrab()`** — Removes all listeners and releases any currently held-down keys.

**Private Methods**

| Method | Purpose |
|--------|---------|
| `_sendKeyEvent()` | Tracks key state and fires `onkeyevent`; ignores releases for keys not tracked as down |
| `_getKeyCode()` | Resolves a stable key code with fallbacks for legacy browser APIs |
| `_handleKeyDown()` | Processes keydown with platform fixes (AltGr, macOS meta, CapsLock, JP IM keys) |
| `_handleKeyUp()` | Processes keyup with Windows Shift bug workaround |
| `_handleAltGrTimeout()` | Finalizes Windows AltGr detection after 100ms timeout |
| `_allKeysUp()` | Sends release events for all currently tracked keys |

## Usage Example

```javascript
import Keyboard from './core/input/keyboard.js';

const canvas = document.getElementById('vnc-canvas');
const keyboard = new Keyboard(canvas);

keyboard.onkeyevent = (keysym, code, down, numlock, capslock) => {
    if (down) {
        console.log(`Key pressed: keysym=${keysym}, code=${code}`);
    }
    // Forward event to VNC server
    rfb.sendKeyEvent(keysym, code, down);
};

// Start capturing keyboard input
keyboard.grab();

// Stop capturing (e.g., on disconnect)
keyboard.ungrab();
```
