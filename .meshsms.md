MeshCentral SMS gateway communication module that abstracts multiple SMS provider integrations (Twilio, Plivo, Telnyx, and generic URL-based) behind a unified send interface.

## Key Components

- **`CreateMeshSMS(parent)`** — Factory function that initializes and returns an SMS gateway object based on the provider configured in `config.json`
- **`obj.sendSMS(to, msg, func)`** — Dispatches an SMS through the configured provider; `func(success, error, result)` callback
- **`getTemplate(templateNumber, domain, lang)`** — Internal helper that resolves localized SMS message templates from `.txt` files, with fallback to English
- **`obj.sendPhoneCheck(domain, phoneNumber, verificationCode, language, func)`** — Sends phone number verification SMS using template index `0`
- **`obj.sendToken(domain, phoneNumber, verificationCode, language, func)`** — Sends two-factor authentication token SMS (template index `1`)

## Usage Example

```javascript
// config.json (Twilio example)
{
  "sms": {
    "provider": "twilio",
    "sid": "ACxxxxxxxxx",
    "auth": "xxxxxxx",
    "from": "+15555555555"
  }
}

// Initialize the SMS module
const meshSMS = require('./meshsms').CreateMeshSMS(parent);

// Send a raw SMS
meshSMS.sendSMS('+14155552671', 'Hello from MeshCentral', function (success, err, result) {
  if (success) console.log('SMS sent');
  else console.error('SMS failed:', err);
});

// Send a phone verification code
meshSMS.sendPhoneCheck(domain, '+14155552671', '123456', 'en', function (success, err) {
  if (!success) console.error('Verification SMS failed:', err);
});
```

## Supported Providers

| Provider | Required Config Keys |
|----------|---------------------|
| `twilio` | `sid`, `auth`, `from` |
| `plivo`  | `id`, `token`, `from` |
| `telnyx` | `apikey`, `from` |
| `url`    | `url` (must include `{{phone}}` and `{{message}}`) |

> **Debug mode:** Set `url` to `"console"` to log SMS output without sending — useful for local development.
