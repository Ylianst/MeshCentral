Intel AMT (Active Management Technology) manager module that provides an interface for communicating with Intel ME (Management Engine) hardware via MEI and LMS interfaces.

## Key Components

- **`AmtManager(agent, db, isdebug)`** — Main constructor. Initializes the AMT stack, sets up event emitters, and binds to the MEI module.
- **`obj.reset()`** — Loads the `amt-mei` module and establishes a MEI connection with up to 10 retry attempts (10s intervals).
- **`obj.getMeiState(flags, func)`** — Queries MEI hardware state with selective data fetching controlled by bitflags:
  - `1` = Firmware versions
  - `2` = OS admin credentials
  - `4` = Certificate hashes
  - `8` = Network interface settings
- **`obj.lmsreset()`** — Initializes the Local Manageability Service (LMS) via the `amt-lme` module and binds port mappings.
- **`obj.startConfigurationHBased()`** — Initiates host-based ACM (Admin Control Mode) activation with TLS.
- **`handleAmtNotification()`** — Internal handler for AMT user notifications (SOL/KVM connect/disconnect events).

## Usage Example

```javascript
var AmtManager = require('./amt-manage');

var manager = new AmtManager(agent, db, true);

// Listen for LMS state changes
manager.on('stateChange_LMS', function (state) {
    console.log('LMS state changed:', state);
});

// Reset and connect to MEI
manager.reset();

// Query MEI state: versions (1) + network (8)
manager.getMeiState(1 | 8, function (state) {
    if (state == null) { console.log('MEI unavailable'); return; }
    console.log('AMT UUID:', state.UUID);
    console.log('Provisioning state:', state.ProvisioningState);
    console.log('Network (eth0):', state.net0);
});
```
