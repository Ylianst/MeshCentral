Implements the ZRLE (Zlib Run-Length Encoding) decoding algorithm for the noVNC HTML5 VNC client, decompressing and rendering tiled rectangular regions of the remote framebuffer.

## Key Components

- **`ZRLEDecoder`** — Main export class that handles ZRLE-encoded VNC framebuffer rectangles using a zlib inflator and two pre-allocated `Uint8Array` pixel buffers (64×64 tiles).
- **`decodeRect(x, y, width, height, sock, display, depth)`** — Primary method; reads the zlib-compressed data length, decompresses the stream, and iterates over 64×64 tiles dispatching to the appropriate subencoding handler.
- **`_readPixels(pixels)`** — Inflates raw 24-bit RGB pixel data and expands it to RGBA (alpha fixed at 255).
- **`_decodePaletteTile(paletteSize, tileSize, tilew, tileh)`** — Handles palette subencodings (2–16 colors) using 1-, 2-, or 4-bits-per-pixel packed indexing.
- **`_decodeRLETile(tileSize)`** — Handles plain RLE subencoding (type 128); expands pixel runs.
- **`_decodeRLEPaletteTile(paletteSize, tileSize)`** — Handles RLE + palette subencodings (130–255); supports both single pixels and run-length palette indices.
- **`_readRLELength()`** — Reads a variable-length RLE run count using the ZRLE multi-byte accumulation scheme (sum of 255-valued bytes + 1).

## Usage Example

```javascript
import ZRLEDecoder from './zrle.js';

const decoder = new ZRLEDecoder();

// Called by the VNC client when a ZRLE-encoded rectangle arrives
const complete = decoder.decodeRect(
    x, y,           // top-left position on the remote desktop
    width, height,  // rectangle dimensions
    sock,           // WebSocket receive queue (rQshift32, rQshiftBytes, etc.)
    display,        // noVNC Display object (blitImage, fillRect)
    depth           // colour depth (unused internally, passed by protocol layer)
);

if (!complete) {
    // Insufficient data buffered; will be retried when more arrives
}
```

## Subencoding Dispatch

| Value | Type |
|---|---|
| `0` | Raw RGBA pixels |
| `1` | Solid fill colour |
| `2–16` | Packed palette |
| `128` | Plain RLE |
| `130–255` | RLE + palette |
