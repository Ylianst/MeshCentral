A minimal MeshAgent core module that handles basic console commands and server communication for the MeshCentral agent framework.

## Key Components

- **`splitArgs(str)`** — Parses a command string into an array, respecting quoted substrings
- **`parseArgs(argv)`** — Converts a split argument array into a named key-value object (similar to minimist)
- **`sendConsoleText(msg, sessionid)`** — Sends a console message back to the MeshAgent server, optionally scoped to a session
- **`processConsoleCommand(cmd, args, rights, sessionid)`** — Dispatches built-in console commands: `help`, `versions`, `eval`, `setdebug`, `osinfo`
- **`handleServerCommand(data)`** — Receives and routes incoming server command objects
- **`handleServerConnection(state)`** — Responds to server connect/disconnect events; sends `coreinfo` on connect
- **`obj.start()`** — Registers command and connection handlers with the MeshAgent and announces the core
- **`obj.stop()`** — Deregisters all handlers

## Usage Example

### Embedded in MeshCentral (NodeJS export mode)

```javascript
const tinyCore = require('./tinycore');
const core = tinyCore.createMeshCore(agent); // agent exposes getMeshApi()
core.start();
```

### Standalone (runs directly on MeshAgent without NodeJS)

```javascript
// No export available; the module auto-starts when loaded by the MeshAgent runtime
// Output: "TinyCore Started..."
```

### Console command dispatch

```javascript
// Incoming server message triggers command processing:
handleServerCommand({
  action: 'msg',
  type: 'console',
  value: 'osinfo',
  sessionid: 'abc123',
  rights: 0xFFFF
});
// → Sends OS name back to session "abc123"
```

## Notes

- Runs in two modes: **standalone** (direct MeshAgent runtime) and **embedded** (NodeJS `module.exports`)
- `eval` command requires trusted administrator rights — passes raw JS to `MeshAgent.eval()`
- Source: [`tinycore.js`](https://github.com/flamingo-stack/meshcentral/blob/main/tinycore.js)
