Auto-generated lookup table mapping HTML key names (Web KeyboardEvent codes) to their corresponding AT Set 1 (XT) scan codes for keyboard input translation in remote desktop and KVM contexts.

## Key Components

- **Default Export** — A single ES module default export: a plain JavaScript object (`Record<string, number>`) mapping HTML key code strings to hexadecimal AT Set 1 scan codes.

## Mapping Structure

Each entry follows the pattern:

```text
"HTMLKeyCode": 0xSCANCODE  /* html:Name -> linux:LinuxKeycode (LINUX_KEY_NAME) -> atset1:DecimalValue */
```

Key categories covered:

| Category | Examples |
|---|---|
| Alphanumeric keys | `KeyA`–`KeyZ`, `Digit0`–`Digit9` |
| Modifier keys | `AltLeft`, `ControlRight`, `ShiftLeft`, `MetaLeft` |
| Function keys | `F1`–`F24` |
| Numpad keys | `Numpad0`–`Numpad9`, `NumpadEnter`, `NumpadDivide` |
| Navigation keys | `ArrowUp/Down/Left/Right`, `Home`, `End`, `Insert`, `Delete` |
| Media keys | `MediaPlayPause`, `MediaTrackNext`, `AudioVolumeUp`, `Eject` |
| Browser keys | `BrowserBack`, `BrowserForward`, `BrowserSearch` |
| IME/Language keys | `KanaMode`, `Hiragana`, `Katakana`, `Lang1`–`Lang5` |

Extended keys (e.g., `AltRight`, `ArrowDown`) use the `0xe0xx` prefix indicating a two-byte XT scan code sequence.

## Usage Example

```javascript
import xtScanCodes from './xtscancodes.js';

// Translate a browser KeyboardEvent code to an XT scan code
document.addEventListener('keydown', (event) => {
  const scanCode = xtScanCodes[event.code];
  if (scanCode !== undefined) {
    sendScanCodeToRemoteSession(scanCode);
  }
});

// Direct lookup
const enterScanCode = xtScanCodes['Enter']; // 0x1c (28)
const altRightCode  = xtScanCodes['AltRight']; // 0xe038 (extended key)
```
