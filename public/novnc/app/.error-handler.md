Global error handler for the noVNC HTML5 VNC client that intercepts uncaught exceptions and unhandled promise rejections, displaying them in a fallback UI overlay while disabling keyboard interaction.

## Key Components

- **`handleError(event, err)`** — Core error handler that:
  - Suppresses a known Firefox `ResizeObserver` loop bug
  - Renders only the first error (ignores subsequent errors)
  - Populates `#noVNC_fallback_errormsg` with error message, source location (`filename:line:col`), and stack trace
  - Opens the `#noVNC_fallback_error` overlay via CSS class
  - Disables keyboard focus on all interactive elements after a fatal error
- **Window event listeners** — Registers handlers for:
  - `error` — catches synchronous uncaught exceptions
  - `unhandledrejection` — catches unhandled `Promise` rejections

## Usage Example

```javascript
// This module self-registers on load; no explicit call needed.
// Ensure the following elements exist in your HTML:

/*
<div id="noVNC_fallback_error">
  <div id="noVNC_fallback_errormsg"></div>
</div>
*/

// On any uncaught error, the overlay opens automatically:
// - #noVNC_fallback_error receives class "noVNC_open"
// - #noVNC_fallback_errormsg is populated with:
//   .noVNC_message  → error.message
//   .noVNC_location → filename:lineno:colno
//   .noVNC_stack    → err.stack (if available)

// Triggering manually (for testing):
window.dispatchEvent(new ErrorEvent('error', {
    message: 'Test error',
    filename: 'app.js',
    lineno: 42,
    colno: 7,
    error: new Error('Test error')
}));
```

## Notes

- Returns `false` intentionally to preserve browser console error output
- Fails silently via `document.write` if DOM manipulation itself throws
