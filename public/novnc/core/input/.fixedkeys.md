A static lookup table used by the noVNC client to map layout-independent HTML key codes (`event.code`) to their corresponding HTML key values (`event.key`) as a fallback when the browser cannot determine the key value from the layout.

## Key Components

- **Default export** — A plain object mapping W3C UI Events `code` strings to `key` strings, organized into six sections:
  - **Writing System Keys** — `Backspace`
  - **Functional Keys** — Modifier/control keys (`Alt`, `Control`, `Shift`, `Meta`, `Enter`, `Tab`, `CapsLock`, etc.)
  - **Control Pad** — Navigation keys (`Delete`, `End`, `Home`, `Insert`, `PageUp`, `PageDown`)
  - **Arrow Pad** — Directional keys (`ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`)
  - **Numpad** — `NumLock`, `NumpadBackspace`, `NumpadClear`
  - **Function Section** — `Escape`, `F1`–`F35`, `PrintScreen`, `ScrollLock`, `Pause`
  - **Media Keys** — Browser navigation, audio/volume, and media playback controls

## Usage Example

```javascript
import fixedkeys from './fixedkeys.js';

function resolveKeyValue(event) {
    // Use browser-provided key value if available
    if (event.key && event.key !== 'Unidentified') {
        return event.key;
    }

    // Fall back to the fixed mapping using the physical key code
    return fixedkeys[event.code] ?? null;
}

// Example: physical key 'ShiftLeft' → resolved value 'Shift'
console.log(fixedkeys['ShiftLeft']);     // 'Shift'
console.log(fixedkeys['F5']);            // 'F5'
console.log(fixedkeys['AudioVolumeUp']); // 'AudioVolumeUp'
```

> **Note:** Keys omitted from this map (e.g., letter/digit keys) are handled via their Unicode representation or browser-native `event.key` values. `AltRight` maps to `'Alt'` but may represent `'AltGraph'` on some keyboard layouts.
