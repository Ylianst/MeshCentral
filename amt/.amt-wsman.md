Intel AMT WSMAN (Web Services Management) stack implementation that constructs and sends WS-Management protocol messages to Intel Active Management Technology (AMT) endpoints over HTTP.

## Key Components

| Export/Function | Description |
|---|---|
| `WsmanStackCreateService(comm)` | Factory function that creates a WSMAN stack object bound to a communication layer |
| `obj.PerformAjax` | Core method that wraps outgoing SOAP envelopes and parses XML responses via `amt-xml.js` |
| `obj.ExecGet` | Executes a WS-Transfer GET request for a resource URI |
| `obj.ExecPut` | Executes a WS-Transfer PUT (update) request with a payload object |
| `obj.ExecCreate` | Executes a WS-Transfer CREATE request |
| `obj.ExecDelete` | Executes a WS-Transfer DELETE request |
| `obj.ExecEnum` | Initiates a WS-Enumeration Enumerate operation |
| `obj.ExecPull` | Pulls results from an active enumeration context |
| `obj.ExecMethod` | Executes a WSMAN method call with key/value argument pairs |
| `obj.ExecMethodXml` | Executes a WSMAN method call with pre-formatted XML arguments |
| `obj.ExecSubscribe` | Subscribes to WS-Eventing events with optional push/push-with-ack delivery |
| `obj.ExecUnSubscribe` | Unsubscribes from a WS-Eventing subscription |
| `obj.CancelAllQueries` | Cancels all pending requests via the communication layer |

## Usage Example

```javascript
const comm = require('./amt-comm'); // communication transport layer
const WsmanStack = require('./amt-wsman');

const wsman = WsmanStackCreateService(comm);

// GET a resource
const resourceUri = 'http://intel.com/wbem/wscim/1/amt-schema/1/AMT_GeneralSettings';
wsman.ExecGet(resourceUri, function(stack, name, response, status) {
    if (status === 200) {
        console.log('Response:', response.Body);
    }
}, 'myTag', 0);

// Call a method with arguments
wsman.ExecMethod(
    'http://intel.com/wbem/wscim/1/amt-schema/1/AMT_SetupAndConfigurationService',
    'Unprovision',
    { ProvisioningMode: 1 },
    function(stack, name, response, status) {
        console.log('Method result:', status);
    }
);
```
