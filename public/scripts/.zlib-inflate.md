JavaScript implementation of the zlib inflate (decompression) algorithm, ported from the original C zlib 1.2.6 library by Mark Adler. It provides stream-based DEFLATE decompression supporting raw, zlib, and gzip formats.

## Key Components

- **`ZLIB.inflateInit([windowBits])`** — Initializes and returns a decompression stream object. `windowBits` controls the window size and format detection (raw, zlib, or gzip).
- **`z_stream.inflate(encoded_string, [options])`** — Decompresses an encoded string, returning the decoded output. Accepts optional parameters (`next_in`, `avail_in`, `avail_out`, `flush`) mirroring the zlib C API.
- **`z_stream.inflateReset()`** — Resets the stream state for reuse without reinitializing.
- **`inflate_table(state, type)`** — Internal function that builds canonical Huffman decode tables for `CODES`, `LENS`, or `DISTS` symbol types.
- **Inflate state machine** — Processes input through named states (`HEAD`, `FLAGS`, `TYPE`, `STORED`, `LEN`, `DIST`, `MATCH`, `CHECK`, `DONE`, `BAD`, etc.) to handle all DEFLATE block types.
- **`ZLIB.inflate_copyright`** — Copyright string from the original zlib library, preserved per license requirements.

## Usage Example

```javascript
// Initialize a decompression stream (default windowBits = 15)
var zStream = ZLIB.inflateInit();

// Decompress a zlib-encoded string
var decoded = zStream.inflate(encodedString);

// Decompress with explicit options
var decoded = zStream.inflate(encodedString, {
  next_in: 0,
  avail_in: encodedString.length,
  avail_out: 1024,
  flush: ZLIB.Z_NO_FLUSH
});

// Reset the stream for reuse
zStream.inflateReset();

// For gzip format, use negative windowBits
var gzStream = ZLIB.inflateInit(-15);
var decoded = gzStream.inflate(gzipEncodedString);
```

> **Dependency:** Requires `zlib.js` to be loaded before this file, as it depends on the `ZLIB` global namespace and constants like `ZLIB.Z_NO_FLUSH`.
