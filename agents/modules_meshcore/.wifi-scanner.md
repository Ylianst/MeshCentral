Cross-platform WiFi scanner module that detects nearby wireless access points on Windows and Linux, emitting structured `accessPoint` events for each discovered network.

## Key Components

### `AccessPoint(ssid, bssid, lq)`
Constructor representing a discovered wireless network with:
- `ssid` — Network name
- `bssid` — MAC address identifier
- `lq` — Link quality/signal level
- `toString()` — Formats as `[bssid]: ssid (lq)`

### `WiFiScanner`
EventEmitter-based scanner class exposing:

| Member | Description |
|---|---|
| `accessPoint` event | Emitted for each discovered AP |
| `hasWireless()` | Returns `true` if a wireless interface exists |
| `Scan()` | Initiates platform-specific scan |

**Platform strategies:**
- **Windows** — Spawns a sandboxed `ScriptContainer` running `wifi-scanner-windows`
- **Linux** — Executes `/sbin/iwlist <interface> scan` and parses stdout output

## Usage Example

```javascript
var WiFiScanner = require('wifi-scanner');

var scanner = new WiFiScanner();

if (scanner.hasWireless()) {
    scanner.on('accessPoint', function (ap) {
        console.log(ap.toString());
        // Output: [AA:BB:CC:DD:EE:FF]: MyNetwork (70)
        console.log('SSID:', ap.ssid);
        console.log('BSSID:', ap.bssid);
        console.log('Signal:', ap.lq);
    });

    scanner.Scan();
} else {
    console.log('No wireless interfaces found.');
}
```

## Notes

- Linux parsing relies on `iwlist` output format; the detected interface is the first `wireless` type found via `os.networkInterfaces()`
- Hidden SSIDs (`<hidden>`) are normalized to an empty string
- Source: [`wifi-scanner.js`](https://github.com/flamingo-stack/meshcentral/blob/main/wifi-scanner.js)
