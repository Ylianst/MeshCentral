Provides a browser-side RDP (Remote Desktop Protocol) client that connects to a MeshCentral relay endpoint via WebSocket, rendering remote desktop bitmap frames on an HTML5 canvas and forwarding user input events.

## Key Components

| Export / Symbol | Description |
|---|---|
| `CreateRDPDesktop(canvasid, domainUrl)` | Factory function that constructs and returns an RDP desktop controller object |
| `obj.Start(nodeid, port, credentials)` | Initiates WebSocket connection to `mstscrelay.ashx` and begins RDP session |
| `obj.Stop()` | Closes the WebSocket and clears the canvas |
| `obj.m.mousemove/mousedown/mouseup/mousewheel` | Mouse event handlers with Nagle-style batching for move events |
| `obj.m.handleKeyDown/handleKeyUp` | Keyboard handlers that translate browser key events to RDP scan codes |
| `obj.m.sendcad()` | Sends Ctrl+Alt+Del scan code sequence |
| `obj.m.setClipboard(content)` / `obj.m.getClipboard()` | Bidirectional clipboard sync over the WebSocket |
| `obj.m.SendStringUnicode(txt)` | Sends a Unicode string for remote text input |
| `changeState(newstate)` | Internal state machine: `0`=disconnected, `1`=connecting, `2`=setup, `3`=active |

## Usage Example

```javascript
// Initialize and start an RDP session
var rdp = CreateRDPDesktop('myCanvas', '/meshrelay/');

rdp.onStateChanged = function (obj, state) {
    console.log('RDP state changed to:', state);
};

rdp.Start('node//abc123', 3389, {
    username: 'Administrator',
    password: 's3cr3t',
    domain: 'CORP',
    width: 1280,
    height: 1024,
    savecred: false,
    servercred: false
});

// Wire up input events from the canvas element
var canvas = document.getElementById('myCanvas');
canvas.addEventListener('mousemove', rdp.m.mousemove);
canvas.addEventListener('mousedown', rdp.m.mousedown);
canvas.addEventListener('mouseup',   rdp.m.mouseup);
document.addEventListener('keydown', rdp.m.handleKeyDown);
document.addEventListener('keyup',   rdp.m.handleKeyUp);

// Send Ctrl+Alt+Del
rdp.m.sendcad();

// Clipboard sync
rdp.m.onClipboardChanged = function (text) {
    console.log('Remote clipboard:', text);
};
rdp.m.setClipboard('Hello from local!');
```

> **Note:** Depends on `Mstsc` (the FreeRDP/MSTSC JS library) for canvas rendering (`Mstsc.Canvas.create`) and scan code translation (`Mstsc.scancode`). Source: [`agent-rdp-0.0.1.js`](https://github.com/flamingo-stack/meshcentral/blob/main/agent-rdp-0.0.1.js)
