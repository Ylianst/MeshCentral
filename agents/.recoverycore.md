Recovery core module for the MeshCentral agent that provides fallback/recovery capabilities when the primary agent core is unavailable, handling tunnels, console messaging, service management, and agent self-restart via `execv`.

## Key Components

- **`meshCoreObj`** — Declares the core identity (`"MeshCore Recovery"`) with capability bitmask (caps: 14 = Terminal + Files + Console)
- **`sendConsoleText(msg, sessionid)`** — Sends console messages back to the MeshCentral server, optionally scoped to a session
- **`sendAgentMessage(msg, icon)`** — Broadcasts agent-level UI messages with icon identifiers to connected sessions
- **`MeshServerLog(msg, state)` / `MeshServerLogEx(id, args, msg, state)`** — Appends events to the server-side audit log, with optional i18n support
- **`getOpenDescriptors()`** — Returns open file descriptors for the current process (Linux via `/proc`, FreeBSD via `procstat`)
- **`closeDescriptors(libc, descriptors)`** — Closes all non-standard file descriptors using a native libc proxy
- **`linux_execv(name, agentfilename, sessionid)`** — Restarts the agent in-place using `execv()` via `_GenericMarshal`; falls back to the service manager if libc is unavailable
- **`_getPotentialServiceNames()` / `_verifyServiceName(names)`** — Windows-only helpers that inspect the registry and service manager to identify the running agent's service name
- **`windows_getCommandLine()`** — Retrieves the parsed command-line arguments on Windows via `kernel32` / `shell32`
- **`pathjoin(...args)`** — Cross-platform path joining utility that normalises slashes
- **Array polyfills** — Safe `find` / `findIndex` polyfills for older MeshAgent runtimes

## Usage Example

```javascript
// Send a status message to a specific management session
sendConsoleText('Recovery core loaded successfully', sessionid);

// Log an event to the MeshCentral server with user context
MeshServerLog('Agent recovery initiated', {
  userid: 'user//admin',
  username: 'admin',
  sessionid: sessionid
});

// Restart the agent process on Linux using execv
linux_execv(serviceName, process.execPath, sessionid);
```
