MPS (Management Presence Server) implementation for MeshCentral that handles Intel AMT CIRA (Client Initiated Remote Access) connections over TLS or plain TCP, implementing the APF (AMT Port Forwarding) protocol.

## Key Components

- **`CreateMpsServer(parent, db, args, certificates)`** — Factory function that constructs and starts the MPS server instance
- **`obj.ciraConnections`** — Registry mapping Node IDs to active CIRA socket connections
- **`addCiraConnection(socket)`** — Registers a new CIRA/Relay/LMS connection and updates device connectivity state after a 300ms hold
- **`removeCiraConnection(socket)`** — Deregisters a connection and clears connectivity state if no same-type connections remain
- **`obj.getStats()`** — Returns runtime statistics including connection counts, auth attempts, and protocol-level event counters
- **`APFProtocol`** — Enum of APF protocol message type constants (channel open/close, keepalive, auth, JSON control, etc.)
- **TLS session caching** — In-memory store (`tlsSessionStore`) for TLS session resumption, capped at 1000 entries
- **Dual security modes** — High-security (TLS 1.2/1.3 only) or legacy mode (TLS 1.0+) configurable via `args.mpshighsecurity`

## Usage Example

```javascript
const mpsServer = require('./mpsserver.js');

const server = mpsServer.CreateMpsServer(
  parent,       // MeshCentral parent object
  db,           // Database instance
  {
    mpsport: 4433,
    mpstlsoffload: false,
    mpshighsecurity: true,
    lanonly: false
  },
  certificates  // { mps: { key, cert }, AmtMpsName }
);

// Check active CIRA connections for a device
const connections = server.ciraConnections[nodeId];

// Get server statistics
const stats = server.getStats();
console.log(`Active CIRA connections: ${stats.ciraConnections}`);
```

## Notes

- Supports three connection types: CIRA (connType 0), Relay (connType 1), and LMS (connType 2)
- LMS connections are silently managed without broadcasting connectivity state changes
- The server also acts as a minimal HTTPS server, serving a status page at `/`
