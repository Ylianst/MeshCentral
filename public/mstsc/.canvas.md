Provides an HTML5 Canvas renderer for RDP bitmap data, handling both RLE-compressed and uncompressed bitmap formats received from node-rdpjs.

## Key Components

- **`decompress(bitmap)`** — Decompresses RLE-encoded bitmap data using Emscripten-compiled C functions (`bitmap_decompress_15/16/24/32`) via `Module.ccall`. Supports 15, 16, 24, and 32 bits-per-pixel formats.
- **`reverse(bitmap)`** — Handles uncompressed bitmaps by wrapping raw data in a `Uint8ClampedArray` for canvas compatibility.
- **`Canvas(canvas)`** — Constructor that wraps an HTML `<canvas>` element and its 2D rendering context.
- **`Canvas.prototype.update(bitmap)`** — Renders a bitmap to the canvas using `createImageData` and `putImageData`, dispatching to `decompress` or `reverse` based on `bitmap.isCompress`.
- **`Mstsc.Canvas.create(canvas)`** — Public factory method exported to the global `Mstsc` namespace.

## Usage Example

```javascript
// Get a reference to your canvas element
const canvasEl = document.getElementById('rdp-screen');

// Create a Canvas renderer instance
const renderer = Mstsc.Canvas.create(canvasEl);

// Handle incoming bitmap events from node-rdpjs
rdpClient.on('bitmap', function(bitmap) {
  renderer.update(bitmap);
  // bitmap shape: { bitsPerPixel, data, width, height,
  //                 destLeft, destTop, destRight, destBottom, isCompress }
});
```

> **Note:** The `decompress` function depends on an Emscripten `Module` global with `_malloc`, `_free`, `HEAPU8`, and `ccall` available. Ensure the compiled WASM/asm.js module is loaded before calling `update` on compressed bitmaps.
