Minified WebSocket client module that implements the Intel AMT IDE-Redirect (IDER) protocol, enabling remote boot of AMT-managed devices from virtual floppy or CD-ROM images over a WebSocket connection.

## Key Components

- **`CreateAmtRemoteIder()`** — Factory function returning the IDER session object (`e`) with all protocol state and methods
- **`e.Start()`** — Initializes the IDER session, resets counters, and sends the opening negotiation command
- **`e.Stop()`** — Tears down the session, clears the heartbeat/ping timer, and delegates to the parent transport
- **`e.ProcessData(n)`** — Accumulates incoming WebSocket binary data and dispatches packets via `ProcessDataEx`
- **`e.ProcessDataEx()`** — Core packet dispatcher: handles IDER protocol commands (`65`=open, `67`=close, `68/69`=ping/pong, `70`=reset, `80`=SCSI command, `83`=SCSI write, etc.)
- **SCSI command handler** (inline closure on case `80`) — Handles SCSI commands issued by AMT: `TEST_UNIT_READY`, `READ_6/10`, `MODE_SENSE_6/10`, `READ_CAPACITY`, `READ_TOC`, `GET_CONFIGURATION`, `GET_EVENT_STATUS_NOTIFICATION`, etc.
- **`_(r)` (file read loop)** — Reads chunks from a `File` object via `FileReader`, respecting `readbfr` limits, and streams data back to AMT
- **`e.SendCommand/SendCommandEndResponse/SendDataToHost/SendGetDataFromHost/SendDisableEnableFeatures`** — Low-level packet builders that write to the parent WebSocket transport

### Key State Properties

| Property | Purpose |
|---|---|
| `e.floppy` / `e.cdrom` | `File` objects for virtual media |
| `e.floppyReady` / `e.cdromReady` | Media-ready latch flags |
| `e.inSequence` / `e.outSequence` | Packet sequence counters |
| `y`, `b`, `A`, `T`, `D` | Active read-operation context (file, device, offset, length, reset-pending) |

## Usage Example

```javascript
// Attach IDER to a parent WebSocket transport
const ider = CreateAmtRemoteIder();
ider.parent = wsTransport;         // must expose xxSend() and Stop()
ider.floppy = floppyFileObject;    // File | null
ider.cdrom  = cdromFileObject;     // File | null
ider.iderStart = 1;                // 0=floppy, 1=CD-ROM, 2=both

// Wire into WebSocket transport state/data callbacks
wsTransport.onStateChange = ider.xxStateChange;
wsTransport.onData        = ider.ProcessData;
```
