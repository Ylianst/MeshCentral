JavaScript implementation of the Adler-32 checksum algorithm for the `ZLIB` global namespace, ported from zlib's `adler32.c`. It supports both string and typed array buffers with performance optimizations including loop unrolling in NMAX-sized blocks.

## Key Components

- **`ZLIB.adler32(adler, buf, offset, len)`** — Updates a running Adler-32 checksum over `buf[offset..offset+len-1]`. Accepts either a `string` or array-like buffer. Pass `null` as `buf` to get the required initial value (`1`).
- **`ZLIB.adler32_combine(adler1, adler2, len2)`** — Combines two independently computed Adler-32 checksums into one, as if the two byte sequences were concatenated. Returns `0xffffffff` for negative `len2`.
- **`adler32_string` / `adler32_array`** (internal) — Separate optimized implementations for string vs. array buffers, each using 16-iteration unrolled inner loops and modulo-deferred arithmetic for performance.

## Usage Example

```javascript
// Initialize checksum
var adler = ZLIB.adler32(0, null, 0, 0);

// Stream data in chunks
while ((length = read_buffer(buffer)) !== EOF) {
  adler = ZLIB.adler32(adler, buffer, 0, length);
}

// Validate
if (adler !== original_adler) throw new Error('Checksum mismatch');

// Combine two independent checksums
var combined = ZLIB.adler32_combine(adler1, adler2, len2);
```

> **Dependency:** `zlib.js` must be loaded before this file so the `ZLIB` global is defined.
