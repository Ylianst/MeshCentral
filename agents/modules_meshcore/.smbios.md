Parses and interprets SMBIOS (System Management BIOS) firmware tables on Windows and Linux platforms, extracting structured hardware information such as processor details, memory configuration, system identifiers, expansion slots, and Intel AMT capabilities.

## Key Components

| Export / Function | Description |
|---|---|
| `SMBiosTables()` | Constructor — sets up platform-specific native bindings (Win32 via `Kernel32.dll`) or `dmidecode` invocation (Linux) |
| `get(callback)` | Reads raw SMBIOS data from the OS; supports async callback or synchronous return |
| `_parse(SMData)` | Low-level parser that walks the raw SMBIOS byte stream and indexes structures by type |
| `parse(data)` | High-level parser that calls all info extractors and returns a combined result object |
| `processorInfo(data)` | Extracts CPU socket, speed, cores, threads, manufacturer, and status (SMBIOS Type 4) |
| `memoryInfo(data)` | Extracts memory location and max capacity (SMBIOS Type 16) |
| `systemInfo(data)` | Extracts system UUID and wake reason (SMBIOS Type 1) |
| `systemSlots(data)` | Lists expansion slot names (SMBIOS Type 9) |
| `amtInfo(data)` | Detects Intel AMT presence and capabilities including KVM, SOL, TXT, VMX, ME version (SMBIOS Types 130/131) |

## Usage Example

```javascript
var SMBiosTables = require('./smbios');
var smbios = new SMBiosTables();

// Async usage (Linux & Windows)
smbios.get(function (rawData) {
    if (!rawData) {
        console.log('Unable to read SMBIOS data');
        return;
    }
    var info = this.parse(rawData);
    console.log('System UUID:', info.systemInfo.uuid);
    console.log('Wake Reason:', info.systemInfo.wakeReason);
    console.log('Processors:', info.processorInfo);
    console.log('AMT Enabled:', info.amtInfo && info.amtInfo.enabled);
});

// Synchronous usage (Windows only)
var rawData = smbios.get();
var parsed = smbios.parse(rawData);
console.log('Max Memory (KB):', parsed.memoryInfo.maxCapacityKb);
```

> **Platform Notes:** On Windows, raw SMBIOS data is read via `GetSystemFirmwareTable` from `Kernel32.dll`. On Linux, `/usr/sbin/dmidecode -u` is invoked and its output is canonicalized before parsing. Root/admin privileges are typically required.
