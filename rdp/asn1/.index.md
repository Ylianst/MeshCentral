Barrel/entry-point module for the ASN.1 library, re-exporting the BER encoding, universal types, and specification sub-modules as a unified API.

## Key Components

| Export | Module | Description |
|--------|--------|-------------|
| `ber` | `./ber` | BER (Basic Encoding Rules) encoding/decoding logic |
| `univ` | `./univ` | ASN.1 universal primitive and constructed types |
| `spec` | `./spec` | ASN.1 specification/schema definitions |

## Usage Example

```javascript
const asn1 = require('./asn1');

// Access BER encoding utilities
const encoded = asn1.ber.encode(someData);

// Use universal ASN.1 types
const integer = new asn1.univ.Integer(42);

// Reference specification definitions
const schema = asn1.spec.SomeSchema;
```
