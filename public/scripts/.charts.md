Chart.js v4.3.3 minified library bundle — the complete charting library packaged for browser and Node.js environments, providing all core chart types, plugins, scales, and rendering utilities.

## Key Components

| Export | Description |
|--------|-------------|
| `Chart` | Main class — create and manage chart instances |
| `Colors` | Built-in color palette plugin |
| `Decimation` | Data decimation plugin for performance |
| `Filler` | Area fill plugin for line/radar charts |
| `Legend` | Legend rendering plugin |
| `SubTitle` / `Title` | Chart title/subtitle plugins |
| `Tooltip` | Interactive tooltip plugin |

## Usage Example

```javascript
// CommonJS
const Chart = require('./charts.js');

// ESM / browser (via <script> tag, exposes window.Chart)
const ctx = document.getElementById('myChart').getContext('2d');

const chart = new Chart(ctx, {
  type: 'bar',
  data: {
    labels: ['Jan', 'Feb', 'Mar'],
    datasets: [{
      label: 'Sales',
      data: [120, 95, 140],
      backgroundColor: 'rgba(75, 192, 192, 0.4)'
    }]
  },
  options: {
    responsive: true,
    plugins: {
      legend: { position: 'top' },
      title:  { display: true, text: 'Monthly Sales' }
    }
  }
});

// Programmatic update
chart.data.datasets[0].data.push(180);
chart.update();

// Clean up
chart.destroy();
```
