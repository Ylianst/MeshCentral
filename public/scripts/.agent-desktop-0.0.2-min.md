Minified JavaScript module providing remote desktop client functionality for MeshCentral, handling canvas rendering, input encoding, and binary protocol communication between a browser and a remote desktop agent.

## Key Components

| Export / Symbol | Description |
|---|---|
| `CreateAgentRemoteDesktop(canvasId, scrollDiv)` | Factory function returning a remote desktop session object (`n`) bound to a canvas element |
| `n.Start / n.Stop` | Lifecycle methods to initialize or tear down a session |
| `n.ProcessBinaryCommand` | Routes incoming binary protocol frames (images, screen size, touch, keyboard state, cursor, etc.) |
| `n.ProcessPictureMsg` | Decodes JPEG tile data, queues it for ordered canvas drawing |
| `n.DoPendingOperations` | Flush ordered draw queue to the canvas, preserving tile sequence |
| `n.SendKeyMsg / n.SendKeyMsgKC` | Keyboard event encoding with extended key flag and AltGr detection |
| `n.SendMouseMsg` | Mouse position and button state encoding |
| `n.SendTouchMsg1 / n.SendTouchMsg2` | Multi-touch event encoding |
| `n.SendCtrlAltDelMsg / n.SendEscKey` | Special key sequence helpers |
| `n.SendCompressionLevel` | Configure image type, compression, scaling, and frame rate |
| `n.checkAltGr` | Detects Windows AltGr key combination from synthetic Ctrl+Alt events |
| `n.setRotation / n.rotX / n.rotY` | Canvas rotation support for display orientation |
| Callbacks: `onScreenSizeChange`, `onMessage`, `onDisplayinfo`, `onRemoteInputLockChanged`, `onKeyboardStateChanged`, `onTouchEnabledChanged` | Extension points for UI integration |

## Usage Example

```javascript
// Attach to a canvas element and a scroll container
const desktop = CreateAgentRemoteDesktop('myCanvas', document.getElementById('scroll'));

// Wire up a WebSocket transport
desktop.parent = { send: (data) => ws.send(data) };

// Handle incoming binary frames from the agent
ws.onmessage = (event) => {
  const buf = new Uint8Array(event.data);
  const cmd  = buf[1];          // command byte
  const len  = (buf[2] << 8) + buf[3];
  desktop.ProcessBinaryCommand(cmd, len, buf);
};

// React to screen size changes
desktop.onScreenSizeChange = (ctx, w, h, canvas) => {
  canvas.width  = w;
  canvas.height = h;
};

// Start the session and request a full refresh
desktop.Start();
desktop.SendRefresh();
```
