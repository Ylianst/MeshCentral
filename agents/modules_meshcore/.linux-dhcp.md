A lightweight DHCP client module for Linux that sends DHCP DISCOVER packets over raw UDP sockets to retrieve network configuration data (IP address, subnet mask, gateway, DNS servers, etc.).

## Key Components

- **`CreateDHCPClient(options)`** — Factory function that creates a DHCP client instance. Accepts an `options` object with network interface details.
- **DHCP packet builder** — Constructs RFC 2131-compliant DHCP DISCOVER packets with option fields (magic cookie, message type, parameter request list).
- **Raw UDP socket** — Binds to port 68, broadcasts to 255.255.255.255:67, and listens for DHCP OFFER responses.
- **Embedded `promise2` module** — A bundled base64-encoded Promise polyfill used internally for async flow control.
- **`_hide` / `internal` globals** — Utility helpers for internal module encapsulation patterns.

## Usage Example

```javascript
var dhcp = require('linux-dhcp');

var client = dhcp.CreateDHCPClient({
    interface: 'eth0',
    mac: Buffer.from([0x00, 0x11, 0x22, 0x33, 0x44, 0x55])
});

client.then(function(config) {
    console.log('IP Address:', config.ip);
    console.log('Subnet Mask:', config.subnet);
    console.log('Gateway:', config.gateway);
    console.log('DNS Servers:', config.dns);
}).catch(function(err) {
    console.error('DHCP discovery failed:', err);
});
```

## Notes

- Designed for Linux environments using raw socket access; not intended for use on Windows or macOS.
- The module is self-contained — the `promise2` dependency is embedded as a base64 Buffer and loaded via `addModule()`, a MeshAgent-specific runtime function.
- Source: [`linux-dhcp.js`](https://github.com/flamingo-stack/meshcentral/blob/main/linux-dhcp.js)
