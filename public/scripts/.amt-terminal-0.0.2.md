Remote terminal emulator for Intel AMT (Active Management Technology) that renders VT100/xterm escape sequences in a browser `div` element, supporting SOL (Serial over LAN) and PowerShell protocols.

## Key Components

- **`CreateAmtRemoteTerminal(divid, options)`** — Factory function that constructs and returns a terminal emulator object bound to a DOM element
- **`obj.Init(width, height)`** — Initializes the terminal screen buffer (`_tscreen`) and attribute buffer (`_scratt`) with configurable dimensions (default 80×25)
- **`obj.ProcessData(str)`** — Entry point for incoming data; handles UTF-8 decoding and delegates to the VT100 parser
- **`_ProcessVt100EscString(str)`** — Iterates characters and routes each through the escape-sequence state machine
- **`_ProcessVt100EscChar(b, c)`** — State machine core; handles ESC sequences, CSI (`[`), xterm strings (`]`), and normal characters across 7 states
- **`_ProcessEscapeHandler(code, args, argslen, mode)`** — Dispatches CSI sequences: cursor movement (`A/B/C/D`), erase (`J/K`), SGR attributes (`m`), scroll regions (`r`), and more
- **`_ProcessXTermHandler(escNumber)`** — Handles xterm OSC sequences (e.g., window title changes via `onTitleChange` callback)
- **`obj.TermDraw()`** — Re-renders the terminal grid to the DOM div using color attributes from `_TermColors`

**Internal state:** 16-color palette, cursor position (`_termx`/`_termy`), scroll region, reverse/underline attributes, cursor visibility, scroll-back buffer, and alt-keypad mode.

## Usage Example

```javascript
// Create a terminal bound to a div with id "termDiv"
var terminal = CreateAmtRemoteTerminal('termDiv', {
    protocol: 1 // 1 = SOL, 6 = PowerShell
});

// Initialize with 80 columns, 25 rows
terminal.Init(80, 25);

// Hook title changes (e.g., from xterm OSC sequences)
terminal.onTitleChange = function(term, newTitle) {
    document.title = newTitle;
};

// Feed incoming data from a WebSocket or AMT connection
socket.onmessage = function(event) {
    terminal.ProcessData(event.data);
};

// Send keystrokes back to the remote session
terminal.TermSendKeys('\r'); // Enter key
```
