Minified bundle combining Font Awesome Free 6.7.2 icons with the Font Awesome JavaScript runtime, enabling SVG icon rendering and style management in web applications.

## Key Components

- **Icon Style Maps** — Mappings between CSS class prefixes (`fas`, `far`, `fab`, etc.) and style names (`solid`, `regular`, `brands`) across four families: `classic`, `duotone`, `sharp`, and `sharp-duotone`
- **Global Registry** (`___FONT_AWESOME___`) — Window-level namespace storing icon styles, hooks, and shims for cross-script coordination
- **`u()` (addPack)** — Registers icon packs into the global style registry, with optional hook bypass via `skipHooks`
- **`d()` (normalizeIcons)** — Normalizes icon definitions, unwrapping nested `icon` properties to flat `iconName` keys
- **Icon Data** (`v`) — Inline SVG path data for bundled icons (e.g., `monero`, `hooli`, `yelp`, `cc-visa`, `lastfm`, etc.)
- **Proxy-wrapped lookups** — `o()` wraps style maps in a `Proxy` to fall back to the `classic` family when a requested key is absent

## Usage Example

```javascript
// Font Awesome auto-initializes on load; reference icons via CSS classes in HTML
// <i class="fas fa-check"></i>
// <i class="far fa-circle"></i>
// <i class="fab fa-aws"></i>

// Programmatically register a custom icon pack
window[i].hooks.addPack("fas", {
  "custom-icon": {
    iconName: "custom-icon",
    icon: [512, 512, [], "e001", "M256 ...svgPath..."]
  }
});

// Check registered styles
console.log(window["___FONT_AWESOME___"].styles);
```
