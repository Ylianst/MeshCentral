Provides a `BufferLayer` class that wraps a TCP socket to buffer incoming data into well-formed packets and supports TLS upgrades for RDP protocol communication.

## Key Components

### `BufferLayer(socket)`
Constructor that wraps a TCP socket, wiring up `data`, `close`, and `error` event forwarding. Maintains an internal buffer queue and tracks expected packet sizes.

**Methods:**

| Method | Description |
|--------|-------------|
| `recv(data)` | Accumulates incoming TCP chunks and emits complete `data` events when `expectedSize` bytes are available |
| `send(data)` | Serializes a `type.Type` packet and writes it to the active socket (plain or TLS) |
| `sendBuffer(buffer)` | Writes a raw `Buffer` directly to the active socket |
| `expect(expectedSize)` | Sets the byte threshold before the next `data` event is emitted |
| `startTLS(callback)` | Upgrades the connection to a TLS client socket |
| `listenTLS(keyFilePath, crtFilePath, callback)` | Upgrades the connection to a TLS server socket using the provided key/cert files |
| `close()` | Gracefully ends the underlying TCP socket |

## Usage Example

```javascript
const net = require('net');
const { BufferLayer } = require('./layer');

const socket = net.connect(3389, 'rdp-host.example.com', () => {
  const layer = new BufferLayer(socket);

  // Listen for fully assembled packets
  layer.on('data', (stream) => {
    console.log('Received complete packet:', stream);
    // Signal next expected packet size
    layer.expect(4);
  });

  layer.on('error', (err) => console.error('Layer error:', err));
  layer.on('close', () => console.log('Connection closed'));

  // Expect the first 4-byte header
  layer.expect(4);

  // Upgrade to TLS when needed
  layer.startTLS((err) => {
    if (!err) console.log('TLS handshake complete');
  });
});
```

## Notes

- `expect(0)` halts delivery — `recv` will buffer data but not emit until a non-zero size is set.
- TLS is handled via Node's built-in `tls` module with `rejectUnauthorized: false`; certificate validation is disabled by design for RDP compatibility.
