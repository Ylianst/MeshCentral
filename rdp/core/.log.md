Lightweight logging utility for the `node-rdpjs` RDP client library, providing level-based log filtering with five severity tiers.

## Key Components

- **`Levels`** — Enum-style object mapping severity names (`DEBUG`, `INFO`, `WARN`, `ERROR`, `NONE`) to numeric priority values (1–5).
- **`log(level, message)`** — Internal function that filters output against the current module level and writes to `console.log` with a `[node-rdpjs]` prefix.
- **`module.exports.level`** — Configurable threshold (defaults to `Levels.INFO`); messages below this level are suppressed.
- **`debug / info / warn / error`** — Exported logging methods (currently stubbed/no-op; active logging logic is commented out pending a Bunyan integration).

> **Note:** All exported log methods (`debug`, `info`, `warn`, `error`) are currently no-ops. The `log()` internal function and `Levels` filtering logic are wired up but the output calls within the exported methods are commented out.

## Usage Example

```javascript
var log = require('./log');

// Change the minimum log level
log.level = log.Levels.DEBUG;

// Use exported log methods (currently no-op stubs)
log.debug('Connection attempt started');
log.info('Session established');
log.warn('Unexpected packet received');
log.error('Connection failed');

// Check available levels
console.log(log.Levels.ERROR); // 4
```
