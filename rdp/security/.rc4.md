RC4 stream cipher implementation for encrypting and decrypting text using the RC4 algorithm with ES6 generator-based keystream production.

## Key Components

- **`RC4(key)`** — Constructor that initializes the cipher with a key, running key setup and creating a byte stream generator
- **`convert(text)`** — Helper that converts a string into an array of Unicode character codes
- **`keySetup(key)`** — Performs the RC4 Key Scheduling Algorithm (KSA), producing a permuted 256-byte state array
- **`byteStreamGenerator(K)`** — ES6 generator implementing the RC4 Pseudo-Random Generation Algorithm (PRGA), yielding keystream bytes on demand
- **`RC4.prototype.encrypt(input)`** — Encrypts a plaintext string, returning a hex-encoded ciphertext
- **`RC4.prototype.decrypt(input)`** — Decrypts a hex-encoded ciphertext string back to plaintext

## Usage Example

```javascript
const RC4 = require('./rc4');

// Initialize with a secret key
const cipher = new RC4('mySecretKey');

// Encrypt plaintext
const encrypted = cipher.encrypt('Hello, World!');
console.log(encrypted); // e.g. "a3f1c9..."

// To decrypt, initialize a new instance with the same key
// Note: the generator is stateful, so a fresh instance is needed per operation
const cipher2 = new RC4('mySecretKey');
const decrypted = cipher2.decrypt(encrypted);
console.log(decrypted); // "Hello, World!"
```

> **⚠️ Security Notice:** RC4 is a cryptographically broken cipher and should **not** be used for security-sensitive applications. Use modern algorithms (AES-GCM via the [Web Crypto API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Crypto_API)) for any production encryption needs.

## Notes

- The byte stream generator is **stateful** — encrypt and decrypt operations consume keystream bytes sequentially. Create a fresh `RC4` instance with the same key for each independent operation.
- There is a bug in `decrypt`: `byteStream` is referenced without `this.`, which will cause a `ReferenceError` at runtime.
