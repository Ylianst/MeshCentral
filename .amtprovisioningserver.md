Implements the Intel AMT bare-metal provisioning server (Setup and Configuration Application/SCA) for MeshCentral, handling device hello notifications on the local LAN and orchestrating AMT activation.

## Key Components

- **`CreateAmtProvisioningServer(parent, config)`** — Factory function that instantiates the provisioning server. Accepts a parent MeshCentral instance and a configuration object with device group, passwords, and optional port.
- **TCP Server (`obj.server`)** — Listens on port `9971` (configurable) for incoming AMT hello packets and HTTP GET requests. Serves an informational HTML page to browser connections.
- **`parseHelloData(data, addr)`** — Decodes binary AMT hello packets (version 3 only). Extracts admin credential status, retry count, device GUID, and a list of certificate hashes (SHA1/SHA256/SHA384).
- **`processHelloData(data, addr)`** — Entry point for handling parsed hello data. Validates the device group, deduplicates in-flight activations via `obj.devices`, and initiates the activation workflow.
- **`guidToStr(g)` / `strToGuid(s)`** — Utility functions for converting between raw hex GUIDs and standard hyphenated UUID string format.
- **`checkAmtPassword(password)`** — Validates MEBx password complexity (uppercase, lowercase, numeric, non-alpha, minimum 8 characters).

## Usage Example

```javascript
// In MeshCentral server configuration (config.json)
{
  "amtprovisioning": {
    "devicegroup": "mesh//XXXXXX",
    "newmebxpassword": "P@ssw0rd!",
    "trustedfqdn": "meshcentral.example.com",
    "port": 9971
  }
}

// Instantiation (handled internally by MeshCentral)
const { CreateAmtProvisioningServer } = require('./amtprovisioningserver');
const server = CreateAmtProvisioningServer(parent, config.amtprovisioning);
// Returns null if MEBx password is invalid
```

Intel AMT devices on the local LAN send a binary hello packet to port `9971`; the server parses the packet, validates the certificate hashes against trusted roots, and activates the device into the configured MeshCentral device group.
