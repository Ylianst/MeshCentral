Handles embedding JavaScript content or MSH (Mesh Policy) data into Windows and Linux executable binaries by streaming modified binary output, and parses Windows PE (Portable Executable) headers to support signed/unsigned binary detection.

## Key Components

### Constants
- `exeJavaScriptGuid` — GUID marker appended when embedding JavaScript content
- `exeMeshPolicyGuid` — GUID marker for mesh policy data
- `exeNullPolicyGuid` — GUID marker used when the MSH contains random/null policy data

### Exported Functions

- **`streamExeWithJavaScript(options)`** — Pipes a source binary to a destination stream, appending JS content, its length (4-byte big-endian), and the JavaScript GUID. Only supports unsigned binaries.

- **`streamExeWithMeshPolicy(options)`** — Pipes a source binary with embedded MSH policy data. Handles both unsigned binaries (append at end) and signed Windows PE binaries (injects into the authenticode certificate table with quad-alignment padding).

- **`parseWindowsExecutable(exePath)`** — Reads and parses the DOS and NT PE headers of a Windows executable, returning certificate table addresses, binary format (`x86`/`x64`), checksum position, and RVA data.

## Usage Example

```javascript
const exeHandler = require('./exeHandler');
const fs = require('fs');

// Embed JavaScript into an unsigned Windows executable
const dest = fs.createWriteStream('./output-agent.exe');
exeHandler.streamExeWithJavaScript({
    platform: 'win32',
    sourceFileName: './agent.exe',
    destinationStream: dest,
    js: Buffer.from('console.log("hello");')
});

// Parse a Windows PE binary
const info = exeHandler.parseWindowsExecutable('./agent.exe');
console.log(info.format); // 'x86' or 'x64'
console.log(info.CertificateTableAddress); // 0 if unsigned

// Embed a mesh policy into a signed Windows binary
exeHandler.streamExeWithMeshPolicy({
    platform: 'win32',
    sourceFileName: './agent.exe',
    destinationStream: fs.createWriteStream('./agent-policy.exe'),
    msh: 'MeshID=abc123\nServerID=xyz'
});
```

> **Note:** `streamExeWithJavaScript` will throw if called on a signed Windows binary. Use `parseWindowsExecutable` first to check `CertificateTableAddress` before streaming.
