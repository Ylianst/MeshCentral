Implements a WebSocket-based redirect client for Intel AMT (Active Management Technology) remote management protocols, handling connection setup, authentication (Digest/MD5), and binary data framing for KVM, SOL, and IDER sessions.

## Key Components

| Export/Symbol | Type | Description |
|---|---|---|
| `CreateAmtRedirect(m, authCookie)` | Factory Function | Creates and returns an AMT redirect instance bound to a module `m` and optional auth cookie |
| `n.Start(host, port, user, pass, tls)` | Method | Initiates WebSocket connection to `webrelay.ashx` with AMT host/port/TLS parameters |
| `n.Send` / `n.send` | Method | Sends data over the established AMT session; wraps payload with protocol-specific framing |
| `n.Stop(reason)` | Method | Tears down the connection, clears timers, resets state |
| `n.xxOnMessage` | Internal Handler | Parses incoming binary AMT protocol frames (command bytes 17–240), dispatches auth and data callbacks |
| `n.xxSendAmtKeepAlive` | Internal Timer | Sends periodic keepalive packets (every 2s) for SOL protocol sessions |
| `n.State` / `n.onStateChanged` | Property / Callback | Tracks connection state (0–3); fires `onStateChanged(instance, state)` on transitions |

**Protocols supported** (via `n.protocol`):
- `1` — SOL (Serial Over LAN)
- `2` — KVM (Keyboard/Video/Mouse)  
- `3` — IDER (IDE Redirection)

## Usage Example

```javascript
// Create an AMT redirect instance attached to a display module
const amtRedir = CreateAmtRedirect(myDisplayModule, "optional-auth-cookie");

// Listen for state changes (0=disconnected, 1=connecting, 2=socket open, 3=ready)
amtRedir.onStateChanged = function(instance, state) {
  console.log("AMT state:", state);
  if (state === 3) {
    // Session ready — send data
    amtRedir.Send("some-payload");
  }
};

// Start a KVM session (protocol=2) over TLS
amtRedir.m.protocol = 2;
amtRedir.Start("192.168.1.100", 16994, "admin", "password", 1);

// Disconnect
amtRedir.Stop();
```

> **Note:** Requires `hex_md5`, `IntToStrX`, and `ShortToStrX` helpers to be available globally for Digest authentication. The module callback (`m.ProcessBinaryData` or `m.ProcessData`) receives decapsulated AMT payload data.
