Implements the X.224 Transport Protocol Data Unit (TPDU) layer for RDP connections, handling connection negotiation, protocol selection (RDP/SSL/NLA/Hybrid), and data framing between the transport and presentation layers.

## Key Components

- **`MessageType`** — Enum of X.224 TPDU codes (connection request/confirm, disconnect, data, error)
- **`NegotiationType`** — Enum for RDP negotiation packet types (request, response, failure)
- **`Protocols`** — Enum of supported security protocols (RDP, SSL, Hybrid, Hybrid-EX)
- **`negotiation(opt)`** — Builds the security negotiation sub-structure used in connection PDUs
- **`clientConnectionRequestPDU(opt, cookie)`** — Constructs the client connection request packet, including optional routing token/cookie and protocol negotiation
- **`serverConnectionConfirm(opt)`** — Constructs the server connection confirm packet
- **`x224DataHeader()`** — Builds the 3-byte header prepended to all data messages
- **`X224(transport)`** — Base class (EventEmitter); handles data forwarding and wraps outgoing messages with the X.224 data header
- **`Client(transport, config)`** — Client automata; drives the connect handshake, handles SSL/TLS upgrade, and delegates NLA to the `nla` module
- **`Server(transport, keyFilePath, crtFilePath)`** — Server automata; receives connection requests and initiates SSL via `listenTLS`

## Usage Example

```javascript
const x224 = require('./x224');

// Client usage
const client = new x224.Client(transport, {
  domain: 'CORP',
  userName: 'admin',
  password: 's3cr3t'
});

client.on('connect', function(selectedProtocol) {
  console.log('X.224 connected, protocol:', selectedProtocol);
  client.send(myRdpMessage);
});

client.on('error', function(err) {
  console.error('X.224 error:', err);
});

client.connect();

// Server usage
const server = new x224.Server(transport, '/path/to/server.key', '/path/to/server.crt');

server.on('connect', function(requestedProtocol) {
  console.log('Client connected with protocol:', requestedProtocol);
});
```
