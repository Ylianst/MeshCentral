JavaScript implementation of the zlib compression library's common definitions and data structures, establishing the `ZLIB` namespace with standard constants, return codes, and core constructors.

## Key Components

- **`ZLIB` namespace** — Top-level object containing all zlib constants and constructors, initialized once via `common_initialized` guard
- **Flush constants** — `Z_NO_FLUSH`, `Z_PARTIAL_FLUSH`, `Z_SYNC_FLUSH`, `Z_FULL_FLUSH`, `Z_FINISH`, `Z_BLOCK`, `Z_TREES`
- **Return code constants** — `Z_OK`, `Z_STREAM_END`, `Z_NEED_DICT`, `Z_ERRNO`, `Z_STREAM_ERROR`, `Z_DATA_ERROR`, `Z_MEM_ERROR`, `Z_BUF_ERROR`, `Z_VERSION_ERROR`
- **`ZLIB.z_stream`** — Core stream constructor holding input/output buffers, byte counters, error state, and checksum function reference
- **`ZLIB.gz_header`** — gzip header constructor storing metadata including modification time, OS flag, filename, comment, and CRC flag

## Usage Example

```javascript
// Initialize a z_stream for compression/decompression
var stream = new ZLIB.z_stream();
stream.input_data = myCompressedString;
stream.avail_in = stream.input_data.length;

// Initialize a gz_header for gzip metadata
var header = new ZLIB.gz_header();
header.name = "example.txt";
header.time = Math.floor(Date.now() / 1000);

// Check return codes after operations
var result = ZLIB.inflate(stream, ZLIB.Z_FINISH);
if (result === ZLIB.Z_OK) {
    console.log("Success:", stream.output_data);
} else if (result === ZLIB.Z_STREAM_END) {
    console.log("Stream complete");
} else {
    console.error("Error:", stream.msg);
}
```

## Notes

This file implements the zlib specification ([RFC 1950](https://tools.ietf.org/html/rfc1950)/[1951](https://tools.ietf.org/html/rfc1951)/[1952](https://tools.ietf.org/html/rfc1952)) in pure JavaScript. Only the deflate compression method (`Z_DEFLATED = 8`) is supported. Source: [`zlib.js`](https://github.com/flamingo-stack/meshcentral/blob/main/zlib.js)
