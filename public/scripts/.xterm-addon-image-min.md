Minified bundle of the `xterm-addon-image` library, providing sixel and image rendering support for xterm.js terminals. This is the production-optimized build of the image addon.

## Key Components

- **`ImageAddon`** — Main export; the xterm.js addon class that enables in-terminal image rendering
- **`Decoder` / `DecoderAsync`** — Sixel image decoder backed by a WebAssembly module for high-performance pixel processing
- **`decode` / `decodeAsync`** — Convenience functions for one-shot sixel decoding
- **Color utilities** — `toRGBA8888`, `fromRGBA8888`, `nearestColorIndex`, `normalizeRGB`, `normalizeHLS`, plus built-in palettes (`PALETTE_VT340_COLOR`, `PALETTE_VT340_GREY`, `PALETTE_ANSI_256`)
- **`LIMITS`** — Constants defining max canvas width (16384px), chunk size (16384 bytes), and palette size (4096 entries)
- **InWasm helper** — Inline WebAssembly loader that handles sync/async module instantiation

## Usage Example

```javascript
import { Terminal } from 'xterm';
import { ImageAddon } from './xterm-addon-image-min.js';

const terminal = new Terminal();
const imageAddon = new ImageAddon({
  memoryLimit: 128 * 1024 * 1024, // 128 MB
  sixelScrolling: true,
  pixelLimit: 16 * 1024 * 1024
});

terminal.loadAddon(imageAddon);
terminal.open(document.getElementById('terminal'));

// Standalone sixel decoding
import { decode } from './xterm-addon-image-min.js';

const result = decode(sixelData, { paletteLimit: 256 });
console.log(result.width, result.height); // pixel dimensions
// result.data8 → Uint8ClampedArray (RGBA), result.data32 → Uint32Array
```

## Notes

- The WebAssembly binary is embedded as a base64 string; no separate `.wasm` file is needed.
- Supports UMD, AMD, and CommonJS module formats.
