MD5 hashing utility for the noVNC HTML5 VNC client, implementing the MD5 message-digest algorithm to hash a binary string and return a `Uint8Array` of bytes.

## Key Components

| Export/Function | Description |
|---|---|
| `MD5(d)` | **Public export.** Entry point — hashes a binary string and returns a `Uint8Array` |
| `Y(d, g)` | Core MD5 compression loop — pads input, processes 512-bit blocks across four rounds (FF, GG, HH, II) |
| `X(d)` | Converts a binary string into a 32-bit word array |
| `V(d)` | Converts a 32-bit word array back into a binary string |
| `M(d)` | Converts a binary string into a `Uint8Array` of char codes |
| `ff/gg/hh/ii` | MD5 round functions implementing the four auxiliary bitwise operations |
| `cmn(d,g,m,f,r,i)` | Shared helper called by each round function — applies rotate-left and accumulates |
| `add(d, g)` | 32-bit unsigned addition using 16-bit limbs to avoid JavaScript integer overflow |
| `rol(d, g)` | Bitwise left rotation used in each round step |

## Usage Example

```javascript
import { MD5 } from './md5.js';

// Input must be a binary string (e.g., from a challenge/response auth handshake)
const binaryInput = "\x48\x65\x6c\x6c\x6f"; // "Hello" as binary chars

const hashBytes = MD5(binaryInput); // Returns Uint8Array (16 bytes)

// Convert to hex string for display
const hexHash = Array.from(hashBytes)
    .map(b => b.toString(16).padStart(2, '0'))
    .join('');

console.log(hexHash);
// → "8b1a9953c4611296a827abf8c47804d7"
```

> **Note:** This implementation operates on raw binary strings, not UTF-8 text. It is used internally within noVNC for VNC authentication protocols (e.g., ARD authentication) and is not intended as a general-purpose cryptographic utility.
