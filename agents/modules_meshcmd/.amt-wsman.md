Implements the Intel AMT (Active Management Technology) WS-Management (WSMAN) protocol stack, providing a service object that constructs and sends SOAP/XML WSMAN requests over HTTP to AMT-capable devices.

## Key Components

- **`WsmanStackCreateService()`** — Factory function that creates and returns a WSMAN service object. Accepts either a config object (`{ transport, ... }`) or positional arguments (`CreateWsmanComm, host, port, user, pass, tls, extra`).
- **`obj.PerformAjax()`** — Core method that wraps outgoing data in a SOAP envelope and dispatches it via the transport layer (`obj.comm`), then parses the XML response using `amt-xml`.
- **`obj.ExecGet()`** — Sends a WSMAN GET request for a given resource URI.
- **`obj.ExecPut()`** — Sends a WSMAN PUT (update) request with a payload object.
- **`obj.ExecCreate()`** — Sends a WSMAN CREATE request to instantiate a new resource.
- **`obj.ExecDelete()`** — Sends a WSMAN DELETE request.
- **`obj.ExecEnum()` / `obj.ExecPull()`** — Implements WS-Enumeration (enumerate + pull) for iterating resource collections.
- **`obj.ExecMethod()` / `obj.ExecMethodXml()`** — Invokes a WSMAN method call, accepting arguments as a JS object or pre-formatted XML.
- **`obj.ExecSubscribe()` / `obj.ExecUnSubscribe()`** — Manages WS-Eventing subscriptions (Push/PushWithAck delivery modes) with optional digest authentication.
- **`obj.CancelAllQueries()`** — Cancels all pending transport requests.
- **`_PutObjToBodyXml()`** *(private)* — Serializes a JS object into WSMAN-compliant XML body content.

## Usage Example

```javascript
const WsmanStack = require('./amt-wsman');
const WsmanComm  = require('./amt-wsman-comm');

const wsman = WsmanStackCreateService(WsmanComm, '192.168.1.100', 16992, 'admin', 'Password1!', false);

// GET a resource
wsman.ExecGet(
  'http://intel.com/wbem/wscim/1/amt-schema/1/AMT_GeneralSettings',
  function(stack, resUri, response, status, tag) {
    if (status === 200) console.log(response);
  }
);

// Enumerate all instances of a class
wsman.ExecEnum(
  'http://intel.com/wbem/wscim/1/amt-schema/1/AMT_EthernetPortSettings',
  function(stack, resUri, response, status, tag) {
    if (status === 200) {
      const ctx = response.Body.EnumerateResponse.EnumerationContext;
      wsman.ExecPull(resUri, ctx, pullCallback);
    }
  }
);
```
