UDP-based scanner for discovering Intel AMT (Active Management Technology) devices on a local network by sending RMCP ping packets and parsing responses.

## Key Components

- **`AMTScanner`** — Main constructor that extends Node.js `EventEmitter`, emitting a `found` event with discovered devices
- **`buildRmcpPing(tag)`** — Constructs a raw RMCP ping UDP packet used to probe AMT endpoints on port 623
- **`parseRmcpPacket(server, data, rinfo, func)`** — Parses RMCP UDP responses, extracting AMT version, provisioning state, and open ports (16992/16993)
- **`parseIPv4Range(range)`** — Accepts IP ranges in `start-end`, CIDR (`/mask`), or single IP formats; returns `{ min, max }` integer bounds
- **`parseIpv4Addr(addr)`** / **`IPv4NumToStr(num)`** — Utility functions for converting between dotted-decimal strings and 32-bit integers
- **`scan(rangestr, timeout, callback)`** — Orchestrates the full scan: creates a UDP socket, sends RMCP pings to all IPs in range, collects responses, and fires the callback/event after `timeout` ms

## Usage Example

```javascript
const AMTScanner = require('./amt-scanner');

const scanner = new AMTScanner();

// Listen for the 'found' event
scanner.on('found', function (results) {
    results.forEach(device => {
        console.log(`AMT device at ${device.address}, version ${device.majorVersion}.${device.minorVersion}`);
        console.log(`  Provisioning state: ${device.provisioningState}`);
        console.log(`  Open ports: ${device.openPorts.join(', ')}`);
    });
});

// Scan a CIDR range with a 5-second timeout
scanner.scan('192.168.1.0/24', 5000, function (results) {
    console.log(`Scan complete. Found ${results.length} AMT device(s).`);
});

// Or scan an explicit range
scanner.scan('10.0.0.1-10.0.0.254', 3000, (results) => {
    console.log(results);
});
```

> **Note:** Requires UDP socket access (port 623). Run with appropriate network permissions. Excludes network/broadcast addresses from CIDR scans to prevent unrecoverable socket errors.
