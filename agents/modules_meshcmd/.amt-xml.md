Lightweight XML/WSMAN parser and serialization utilities for Intel AMT (Active Management Technology) communication, converting XML responses to JSON objects and building XML request bodies.

## Key Components

| Export / Function | Description |
|---|---|
| `ParseWsman(xml)` | Parses a WSMAN XML envelope into a structured `{ Header, Body }` JSON object |
| `_ParseWsmanRec(node)` | Recursive helper that converts XML child nodes to nested JSON, with type coercion for booleans and integers |
| `_PutObjToBodyXml(resuri, putObj)` | Serializes a JS object into a WSMAN PUT request XML body string |
| `_turnToXml(text)` | Dependency-free XML string parser; returns a DOM-like tree with `getElementsByTagName` support |
| `_turnToXmlRec(text)` | Recursive tokenizer that builds the DOM-like node tree from raw XML text |
| `_treeBuilder` | Stack-based internal class managing element nesting and namespace resolution during parsing |

## Usage Example

```javascript
const amtXml = require('./amt-xml');

// Parse a raw WSMAN XML response string
const rawXml = `<Envelope>
  <Header>
    <a:Action>http://intel.com/wbem/wscim/1/amt-schema/1/AMT_GeneralSettings/Get</a:Action>
  </Header>
  <Body>
    <g:AMT_GeneralSettings_OUTPUT>
      <g:HostName>my-device</g:HostName>
      <g:NetworkInterfaceEnabled>true</g:NetworkInterfaceEnabled>
      <g:PingResponseEnabled>false</g:PingResponseEnabled>
    </g:AMT_GeneralSettings_OUTPUT>
  </Body>
</Envelope>`;

const parsed = amtXml.ParseWsman(rawXml);
// Result:
// {
//   Header: { Action: 'http://...Get', Method: 'AMT_GeneralSettings' },
//   Body: {
//     HostName: 'my-device',
//     NetworkInterfaceEnabled: true,   // coerced from string
//     PingResponseEnabled: false        // coerced from string
//   }
// }

console.log(parsed.Body.HostName); // 'my-device'
console.log(parsed.Header.Method);  // 'AMT_GeneralSettings'
```

> **Note:** `ParseWsman` accepts either a raw XML string or a pre-parsed DOM object. Type coercion automatically converts `"true"`/`"false"` to booleans and numeric strings to integers.
