DOMPurify 3.2.6 — a battle-tested XSS sanitization library that cleans untrusted HTML, SVG, and MathML strings before they are inserted into the DOM.

## Key Components

- **`DOMPurify.sanitize(dirty, config?)`** — Core method. Parses and sanitizes an HTML/SVG/MathML string or node, returning a clean string or DOM node.
- **`DOMPurify.addHook(entryPoint, hookFn)`** — Registers a lifecycle hook (e.g., `beforeSanitizeElements`, `afterSanitizeAttributes`) to customize sanitization behavior.
- **`DOMPurify.removeHook(entryPoint)`** / **`removeHooks(entryPoint)`** / **`removeAllHooks()`** — Removes registered hooks.
- **`DOMPurify.isValidAttribute(tag, attr, value)`** — Validates a single attribute against current config.
- **`DOMPurify.setConfig(config)`** / **`clearConfig()`** — Persists a default configuration across multiple `sanitize` calls.
- **Allow-lists** — Frozen arrays for permitted HTML tags (`html`), SVG tags (`svg`), MathML tags (`mathMl`), SVG filters (`svgFilters`), and their corresponding safe attributes.
- **`unapply` / `unconstruct`** — Internal prototype-hardened wrappers around native methods, guarding against prototype pollution.
- **`addToSet`** — Utility that populates a null-prototype lookup object from an array, used to build allow-list hash maps.

## Usage Example

```javascript
import DOMPurify from './purify.js';

// Basic sanitization — strips scripts and event handlers
const clean = DOMPurify.sanitize('<img src=x onerror=alert(1)><b>Hello</b>');
// → <b>Hello</b>

// Allow only specific tags and attributes
const restricted = DOMPurify.sanitize(userInput, {
  ALLOWED_TAGS: ['b', 'i', 'em', 'strong', 'a'],
  ALLOWED_ATTR: ['href', 'title'],
});

// Return a DOM DocumentFragment instead of a string
const fragment = DOMPurify.sanitize(userInput, { RETURN_DOM_FRAGMENT: true });
document.getElementById('output').appendChild(fragment);

// Lifecycle hook — log every removed element
DOMPurify.addHook('uponSanitizeElement', (node, data) => {
  if (data.allowedTags[data.tagName] === undefined) {
    console.warn('Removed element:', data.tagName);
  }
});
```
