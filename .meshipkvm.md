Manages IP KVM (Keyboard, Video, Mouse) devices within MeshCentral, handling lifecycle events for device groups and synchronizing port/node state with the database.

## Key Components

- **`CreateIPKVMManager(parent)`** — Factory function that returns the manager object, subscribes to mesh events, and bootstraps management of all existing IP KVM device groups (mesh type 4)
- **`startManagement(mesh)`** — Instantiates a device-model-specific manager (Raritan KX III or WebPowerSwitch 7) for a given mesh and registers it in `obj.managedGroups`
- **`stopManagement(meshid)`** — Tears down a managed group, clears all tracked port connectivity states, and calls `manager.stop()`
- **`changeManagementRelayId(meshid, relayid)`** — Updates the relay target if a mesh's `relayid` changes at runtime
- **`onStateChanged(sender, state)`** — Handles KVM device connect/disconnect events; clears MeshCentral connectivity state for all ports on disconnection
- **`onPortsChanged(sender, updatedPorts)`** — Syncs KVM (port class `KVM`) and PDU (port class `PDU`) ports to the database, creating or updating device nodes and setting connectivity state accordingly
- **`obj.managedGroups`** — Map of `meshid → manager` for active KVM device groups
- **`obj.managedPorts`** — Map of `nodeid → PortInfo` for all currently tracked ports

## Usage Example

```javascript
const ipKvmManager = CreateIPKVMManager(parent);

// Manager auto-subscribes to mesh events:
// 'server-createmesh', 'server-deletemesh', 'server-editmesh', 'devport-operation'

// Manually trigger a power operation (normally driven by events)
const manager = ipKvmManager.managedGroups['mesh/domain/meshid'];
if (manager && manager.powerOperation) {
    manager.powerOperation({ action: 'turnon', meshid: 'mesh/domain/meshid' });
}

// Inspect currently tracked ports
console.log(ipKvmManager.managedPorts);
// { 'node/domain/portId': { name: 'Port 1', meshid: '...', portid: '...', ... } }
```

## Supported Device Models

| Model ID | Type |
|---|---|
| `1` | Raritan KX III (`CreateRaritanKX3Manager`) |
| `2` | WebPowerSwitch 7 (`CreateWebPowerSwitch`) |
