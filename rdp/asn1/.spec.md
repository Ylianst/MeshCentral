Provides the foundational ASN.1 type system for the RDP protocol implementation, defining tag classes, tag formats, and base specification objects used for encoding and decoding ASN.1 structures.

## Key Components

- **`TagClass`** — Enum-like object defining ASN.1 tag classes: `Universal` (`0x00`), `Application` (`0x40`), `Context` (`0x80`), `Private` (`0xC0`)
- **`TagFormat`** — Enum-like object defining encoding formats: `Primitive` (`0x00`), `Constructed` (`0x20`)
- **`Asn1Tag`** — Constructor combining `tagClass`, `tagFormat`, and `tagNumber` into a single tag descriptor
- **`Asn1Spec`** — Base specification class holding a tag and optional flag; provides chainable methods:
  - `.implicitTag(tag)` — Overrides the current tag with an implicit tag
  - `.optional()` — Marks the spec as optional
  - `.explicitTag(tag)` — Wraps the spec in an explicit tag, returning an `Asn1SpecExplicitTag`
  - `.decode(s, decoder)` — Abstract; must be implemented by subclasses
  - `.encode(encoder)` — Abstract; must be implemented by subclasses
- **`Asn1SpecExplicitTag`** — Subclass of `Asn1Spec` that wraps an inner spec with an explicit outer tag, decoding the outer header first before delegating to the inner spec

## Usage Example

```javascript
var spec = require('./spec');

// Define a tag
var myTag = new spec.Asn1Tag(
  spec.TagClass.Context,
  spec.TagFormat.Primitive,
  0x01
);

// Create a base spec and mark it optional with an implicit tag
var mySpec = new spec.Asn1Spec(myTag)
  .implicitTag(new spec.Asn1Tag(spec.TagClass.Universal, spec.TagFormat.Primitive, 0x02))
  .optional();

// Wrap with an explicit tag
var explicitSpec = mySpec.explicitTag(
  new spec.Asn1Tag(spec.TagClass.Context, spec.TagFormat.Constructed, 0x00)
);
```
