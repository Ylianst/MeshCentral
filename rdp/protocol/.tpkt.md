Implements the TPKT (Transport Protocol Data Unit) layer of the RDP protocol stack, handling both standard X224 and FastPath packet framing over a transport connection.

## Key Components

| Export/Method | Description |
|---|---|
| `TPKT(transport)` | Constructor — wraps a transport, sets up initial 2-byte read and event forwarding (`close`, `error`) |
| `Action` | Enum — `FASTPATH_ACTION_FASTPATH (0x0)` and `FASTPATH_ACTION_X224 (0x3)` packet type constants |
| `recvHeader(s)` | Parses the first 2 bytes to determine X224 vs. FastPath routing |
| `recvExtendedHeader(s)` | Reads the 2-byte X224 payload length and schedules full packet read |
| `recvData(s)` | Emits `data` event with the decoded payload stream; resets for next header |
| `recvExtendedFastPathHeader(s, length)` | Decodes two-byte FastPath length encoding and schedules payload read |
| `recvFastPath(s)` | Emits `fastPathData` event with security flags and payload; resets for next header |
| `send(message)` | Wraps a message in a TPKT X224 frame (`version + reserved + uint16 length + payload`) |
| `close()` | Delegates close to the underlying transport |

## Usage Example

```javascript
var TPKT = require('./tpkt');

// Assume `transport` is a lower-level socket/stream wrapper
var tpkt = new TPKT(transport);

// Standard RDP data
tpkt.on('data', function(stream) {
  console.log('Received X224 payload:', stream);
});

// FastPath input/graphics data
tpkt.on('fastPathData', function(secFlag, stream) {
  console.log('FastPath secFlag:', secFlag, 'payload:', stream);
});

tpkt.on('close', function() { console.log('Connection closed'); });
tpkt.on('error', function(err) { console.error('TPKT error:', err); });

// Send an RDP message wrapped in TPKT
tpkt.send(someRdpMessage);
```
