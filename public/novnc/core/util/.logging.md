Configures and exports a tiered logging utility for the noVNC HTML5 VNC client, binding log functions to the browser console at the specified verbosity level.

## Key Components

- **`initLogging(level)`** — Initializes logging at the given level (`'debug'`, `'info'`, `'warn'`, `'error'`, `'none'`). Uses fall-through switch logic so each level also enables all levels above it in severity. Defaults to `'warn'` if no level is provided.
- **`getLogging()`** — Returns the currently active log level string.
- **`Debug`, `Info`, `Warn`, `Error`** — Exported log functions bound to their respective `console` methods. Each is a no-op until `initLogging()` activates it based on the current level.

## Usage Example

```javascript
import { initLogging, getLogging, Debug, Info, Warn, Error } from './logging.js';

// Set log level to debug (enables all levels)
initLogging('debug');

Debug('Connecting to VNC server...');   // console.debug
Info('Connection established');          // console.info
Warn('Frame buffer update delayed');     // console.warn
Error('Connection lost unexpectedly');   // console.error

// Check current level
console.log(getLogging()); // 'debug'

// Suppress all output
initLogging('none');
```

> **Note:** Log levels follow a cascade — setting `'warn'` enables `Warn` and `Error` but silences `Debug` and `Info`. The module auto-initializes at `'warn'` on load.
