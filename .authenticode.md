Parses and manipulates Windows PE (Portable Executable) file Authenticode signatures, supporting reading, writing, signing, and verifying code signing information in `.exe` and `.dll` files.

## Key Components

- **`createAuthenticodeHandler(path)`** — Main factory function returning a handler object for reading/modifying PE file Authenticode signatures, including methods for:
  - `openFile()` — Parses DOS/COFF/PE optional headers
  - `close()` — Releases the file descriptor
  - `obj.Oids` — Authenticode-specific OID constants (SPC_INDIRECT_DATA, SPC_PE_IMAGE_DATA, etc.)

- **`createSelfSignedCert(args)`** — Generates a 2048-bit RSA self-signed certificate with code signing extensions (valid 10 years)

- **`loadCertificates(pemFileNames)`** — Loads X.509 certificates and RSA private keys from PEM files

- **`loadIcon(iconFile)`** — Parses `.ico` files into an icon group resource object

- **`loadBitmap(bitmapFile)`** — Reads a `.bmp` file, returning raw bitmap data (strips 14-byte header)

- **`hashObject(obj)`** — Computes a SHA-384 hex digest of a buffer or JSON-serializable object

- **`createOutFile(args, filename)`** — Derives a default output filename by appending `-out` to the input stem

## Usage Example

```javascript
const authenticode = require('./authenticode');

// Open a PE file for inspection
const handler = authenticode.createAuthenticodeHandler('./myapp.exe');

// Generate a self-signed code-signing certificate
const certInfo = authenticode.createSelfSignedCert({
    cn: 'My Company',
    org: 'My Org',
    country: 'US',
    serial: '01ABCDEF'
});

// Load existing PEM cert + key for signing
const signingCreds = authenticode.loadCertificates(['cert.pem', 'key.pem']);

// Load an icon for embedding
const icon = authenticode.loadIcon('./app.ico');

handler.close();
```
