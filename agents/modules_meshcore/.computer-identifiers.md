Collects hardware identifiers (BIOS, CPU, GPU, storage, memory, USB) from Linux, Windows, and macOS systems for device inventory and management within MeshCentral.

## Key Components

- **`linux_identifiers()`** — Reads DMI data from `/sys/class/dmi/id`, with Raspberry Pi fallback via devicetree; gathers CPU, GPU, storage, memory (via `dmidecode`), and USB devices
- **`trimIdentifiers(val)`** — Strips whitespace and removes null/empty/`'None'` fields from identifier objects
- **`trimResults(val)`** — Removes private (`_`-prefixed), null, or zero-valued fields from result arrays
- **`brief(headers, obj)`** — Filters result objects to only include specified header keys
- **`dataHandler(c)`** — Accumulates stdout/stderr chunks into a string buffer for child process output collection

## Usage Example

```javascript
// Require the module and retrieve identifiers for the current platform
var computerIdentifiers = require('./computer-identifiers');

computerIdentifiers(function(err, identifiers) {
    if (err) {
        console.error('Failed to retrieve identifiers:', err);
        return;
    }

    // identifiers contains platform-specific hardware info
    console.log('Board:', identifiers.identifiers.board_name);
    console.log('CPU:', identifiers.identifiers.cpu_name);
    console.log('BIOS Mode:', identifiers.identifiers.bios_mode);
    console.log('Storage:', identifiers.identifiers.storage_devices);
});
```

## Platform Support

| Platform | Data Sources |
|----------|-------------|
| Linux | `/sys/class/dmi/id`, `/proc/cpuinfo`, `lspci`, `lshw`, `dmidecode`, `df` |
| Linux (Raspberry Pi) | `/sys/firmware/devicetree`, `vcgencmd` |
| Windows | WMI queries via `wmic` |
| macOS | `system_profiler` |
