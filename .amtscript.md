Compiles, decompiles, and runs AMT (Intel Active Management Technology) binary scripts, providing a script engine with variable management, instruction execution, and WebSocket-based AMT operations.

## Key Components

- **`CreateAmtScriptEngine()`** — Factory function that creates and returns a script engine object (`o`)
- **`script_functionTable1`** — Core opcodes: `nop`, `jump`, `set`, `print`, `getitem`, `substr`, `split`, `jsonparse`, `wsbatchenum`, `wsput`, `wscreate`, `wsdelete`, etc.
- **`script_functionTable2`** — Assignment-style functions: `encodeuri`, `atob`, `btoa`, `hex2str`, `md5`, `readint`, `inttostr`, etc.
- **`script_functionTable3`** — Optional pull/diagnostic functions: `pullsystemstatus`, `pulleventlog`, `pullcertificates`, `disconnect`, `getsidstring`, etc.

The engine exposes per-script instance methods:
- **`reset()`** / **`start()`** / **`stop()`** — Lifecycle control with optional step timing
- **`getVar(name)`** / **`setVar(name, val)`** — Dot-notation variable access with nested path resolution
- **`step()`** — Executes one instruction: reads opcode, decodes arguments, interpolates `{var}` placeholders, and dispatches to the appropriate handler

## Usage Example

```javascript
const { CreateAmtScriptEngine } = require('./amtscript');

const engine = CreateAmtScriptEngine();

// Load a compiled binary script
const scriptObj = engine.script_setup(binaryBuffer, { myVar: 'hello' });

if (scriptObj) {
  scriptObj.onConsole = (msg) => console.log('[Script]', msg);
  scriptObj.amtstack = myAmtStack; // Provide AMT WS-Management stack

  scriptObj.start(100); // Step every 100ms
}
```
