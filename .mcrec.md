MeshCentral recording file indexer (`mcrec.js`) that parses `.mcrec` session recording files and appends searchable time-based index metadata to enable efficient seeking within remote desktop session recordings.

## Key Components

- **`indexFile(infile)`** — Entry point that opens a recording file, validates it, and initiates the sequential block-reading/indexing pipeline
- **`readNextBlock(state, func)`** — Reads the next 16-byte block header + payload from the file stream, advancing the internal file pointer
- **`readLastBlock(state, func)`** — Reads the final 32-byte block to detect whether the file already contains index metadata (`MeshCentralMCNDX` magic)
- **`processBlock(state, block, err)`** — Core state machine that interprets block types (metadata, network data, end) and tracks screen tile positions for remote desktop (protocol 2) sessions
- **`createIndex(state, ptr)`** — Snapshots the current screen tile map into a compact index entry at configurable time intervals (default 10 s)
- **`writeIndex(state, func)`** — Serializes collected indexes as extra metadata and appends two blocks (`type 4` extra metadata + `type 3` end marker) to the file
- **`recordingEntry(fd, type, flags, time, data, func, tag, position)`** — Low-level block writer that formats the 16-byte header and writes string or binary payloads at an optional absolute file position

## Usage Example

```javascript
// Run directly from the command line to index a recording file:
// node mcrec.js session.mcrec

// Or require and call programmatically:
const { indexFile } = require('./mcrec');
indexFile('/recordings/session.mcrec');
// Appends index blocks in-place; logs "Done." on success
// Skips files already indexed (contain MeshCentralMCNDX marker)
```

## Notes

- Supports **protocol 2** (MeshCentral Remote Desktop) indexing; terminal (protocol 1) and Intel AMT KVM (protocol 101) stubs are present but unimplemented
- Tile tracking uses 16×16 pixel grid cells; screen size changes (`command 7`) reset the tile map
- Can run as a standalone CLI script or be invoked from a Node.js worker thread
- Source: [`mcrec.js`](https://github.com/flamingo-stack/meshcentral/blob/main/mcrec.js)
