Minified WebSocket-based agent redirection module that establishes a relay tunnel between a browser client and a MeshCentral node, with optional WebRTC upgrade for peer-to-peer communication.

## Key Components

| Export / Symbol | Description |
|---|---|
| `CreateAgentRedirect(e, t, n, a, o, c)` | Factory function returning a redirect session object. Parameters: mesh server, protocol module, unused, auth cookie, relay auth cookie, base path |
| `r.Start(nodeid)` | Opens WebSocket to `meshrelay.ashx` and signals the mesh server to create the matching tunnel |
| `r.send(data)` | Sends binary or string data over the active transport (WebSocket or WebRTC data channel) |
| `r.sendText(data)` | UTF-8 encodes and sends text via `r.send` |
| `r.Stop()` | Tears down WebRTC and WebSocket, resets state |
| `r.xxOnMessage(event)` | Dispatches incoming messages: control commands, binary frames (with reassembly), and raw text |
| `r.xxOnControlCommand(msg)` | Handles `ctrlChannel:"102938"` messages: RTT latency, WebRTC signaling, console messages, metadata, ping/pong |
| `r.sendCtrlMsg(msg)` | Sends a JSON control-channel message when allowed |
| `r.latency` | Tracks round-trip time via periodic RTT pings every 10 seconds |
| `r.attemptWebRTC` | Flag enabling optional WebRTC upgrade after tunnel is established |

## Usage Example

```javascript
// Initialize a redirect session
const redirect = CreateAgentRedirect(
  meshServerSocket,   // MeshCentral WebSocket connection
  protocolModule,     // Module implementing ProcessData / ProcessBinaryData
  null,               // unused
  "authCookieValue",  // browser auth cookie
  "rauthCookieValue", // relay auth cookie
  "/"                 // base path
);

// React to connection state changes (0=disconnected, 1=connecting, 2=connected, 3=ready)
redirect.onStateChanged = (session, state) => {
  console.log("Redirect state:", state);
};

// Optionally enable WebRTC upgrade
redirect.attemptWebRTC = true;
redirect.webrtcconfig = { iceServers: [{ urls: "stun:stun.example.com" }] };

// Connect to a specific node
redirect.Start("nodeid~0$abc123");

// Send data over the tunnel
redirect.send(new Uint8Array([0x01, 0x02, 0x03]));
redirect.sendText({ action: "ping" });

// Disconnect
redirect.Stop();
```

## Notes

- Binary frames support multi-chunk reassembly via an internal buffer (`s`, `i`, `d`, `g`).
- Large binary payloads (≥16 KB) without a `ProcessBinaryData` handler are decoded via `FileReader`/`Blob` to avoid `String.fromCharCode` stack limits.
