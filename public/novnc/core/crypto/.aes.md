Implements two AES cipher modes — ECB (Electronic Codebook) and EAX (authenticated encryption) — built on top of the Web Crypto API (`window.crypto.subtle`), polyfilling modes not natively supported by browsers.

## Key Components

### `AESECBCipher`
A polyfill for AES-ECB mode using AES-CBC with a zero IV, processing each 16-byte block independently.

| Member | Description |
|--------|-------------|
| `importKey(key, algorithm, extractable, keyUsages)` | Static factory; imports a raw key and returns a ready cipher instance |
| `encrypt(algorithm, plaintext)` | Encrypts plaintext block-by-block (must be a multiple of 16 bytes) |
| `algorithm` | Returns `{ name: "AES-ECB" }` |

### `AESEAXCipher`
A full AES-EAX authenticated encryption implementation using AES-CTR for encryption and CMAC (via AES-CBC) for authentication.

| Member | Description |
|--------|-------------|
| `importKey(key, ...)` | Static factory; imports raw key into CTR and CBC sub-keys, initializes CMAC subkeys |
| `encrypt(algorithm, message)` | Encrypts message and appends a 16-byte authentication tag; `algorithm` requires `iv` and `additionalData` |
| `decrypt(algorithm, data)` | Verifies the authentication tag, then decrypts; returns `null` on MAC mismatch |
| `_computeCMAC(data, prefixBlock)` | Internal CMAC computation used for nonce, additional data, and ciphertext authentication |

## Usage Example

```javascript
// AES-ECB encryption
const rawKey = crypto.getRandomValues(new Uint8Array(16));
const ecbCipher = await AESECBCipher.importKey(rawKey, null, false, ["encrypt"]);
const plaintext = new Uint8Array(16); // Must be multiple of 16 bytes
const ciphertext = await ecbCipher.encrypt(null, plaintext);

// AES-EAX authenticated encryption
const eaxCipher = await AESEAXCipher.importKey(rawKey, null, false, []);
const nonce = crypto.getRandomValues(new Uint8Array(16));
const additionalData = new Uint8Array([1, 2, 3]);
const message = new TextEncoder().encode("hello");

const encrypted = await eaxCipher.encrypt({ iv: nonce, additionalData }, message);
const decrypted = await eaxCipher.decrypt({ iv: nonce, additionalData }, encrypted);
// decrypted === null if authentication tag is invalid
```

> **Note:** `AESECBCipher` is generally not recommended for new protocols due to ECB's lack of semantic security. Prefer `AESEAXCipher` for authenticated encryption where integrity verification is required.
