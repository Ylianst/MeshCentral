jQuery v3.7.1 (custom build) — a slim DOM manipulation and utility library with AJAX, effects, and some deprecated modules excluded. This build supports CommonJS/Node.js environments as well as standard browser globals.

## Key Components

| Export / API | Description |
|---|---|
| `jQuery` / `$` | Core factory function; wraps DOM elements in a jQuery object |
| `jQuery.fn` | Prototype shared by all jQuery instances; chainable traversal/manipulation methods |
| `jQuery.extend` | Deep/shallow object merging; also used to attach static utilities to `jQuery` |
| `jQuery.each` | Iterates arrays and plain objects with a callback |
| `jQuery.map` | Maps over elements, returning a new jQuery-wrapped set |
| `jQuery.isPlainObject` | Detects plain `{}` objects vs host objects |
| `jQuery.isEmptyObject` | Checks whether an object has no own enumerable keys |
| `jQuery.makeArray` | Converts array-like values to real arrays |
| `jQuery.merge` | Appends the contents of a second array-like into the first |
| `jQuery.inArray` | Wraps `Array.prototype.indexOf` |
| `jQuery.globalEval` | Evaluates a script string in the global scope via `DOMEval` |
| `jQuery.text` | Extracts the combined text content of DOM nodes |
| `DOMEval` | Internal helper; injects a `<script>` element to execute code |
| `toType` | Internal type detection utility |

**Excluded modules** (stripped from this build): `ajax`, `effects`, `manipulation/_evalUrl`, deprecated ajax-event aliases, and animation helpers.

## Usage Example

```javascript
// Browser global
const $divs = $("div.container");

// Iterate matched elements
$divs.each(function(index, el) {
  console.log(index, el.textContent);
});

// Deep-merge configuration objects
const defaults = { timeout: 30, retries: 3 };
const config = jQuery.extend(true, {}, defaults, { timeout: 60 });

// CommonJS / Node.js (requires a window shim)
const jsdom = require("jsdom");
const { window } = new jsdom.JSDOM("");
const $ = require("./jquery.js")(window);

// Utility helpers
jQuery.isPlainObject({});          // true
jQuery.isEmptyObject({});          // true
jQuery.inArray(2, [1, 2, 3]);      // 1
jQuery.makeArray(document.querySelectorAll("p")); // real Array
```

> **Note:** Because AJAX and effects modules are excluded, calling `$.ajax()`, `$.getJSON()`, `.animate()`, or `.fadeIn()` will throw. Use the full jQuery build if those APIs are needed.
