Minified/bundled browser build of the **xterm.js** terminal emulator library, exposing the full xterm API as a self-contained UMD module (supports CommonJS, AMD, and global script inclusion).

## Key Components

| Export / Class | Description |
|---|---|
| `AccessibilityManager` | Builds and maintains an ARIA-accessible DOM tree (role="list") mirroring terminal rows; handles screen-reader announcements, boundary focus scrolling, and selection sync |
| `Linkifier` | Detects and underlines links on mouse hover using pluggable `ILinkProvider` instances; fires `onShowLinkUnderline` / `onHideLinkUnderline` events |
| `ColorContrastCache` | Two-key cache for computed CSS color strings and resolved color objects to avoid redundant contrast calculations |
| `addDisposableDomListener` | Helper that wraps `addEventListener` and returns a `{ dispose() }` object for leak-free cleanup |
| Clipboard helpers | `prepareTextForTerminal`, `bracketTextForPaste`, `copyHandler`, `handlePasteEvent`, `paste`, `moveTextAreaUnderMouseCursor`, `rightClickHandler` |

## Usage Example

```javascript
// CommonJS (Node/bundler)
const { Terminal } = require('./xterm.js');

const term = new Terminal({ rows: 24, cols: 80 });
term.open(document.getElementById('terminal'));

// Write data to the terminal
term.write('Hello, \x1B[1;3;31mxterm.js\x1B[0m\r\n');

// Listen for user input
term.onData(data => {
  // Forward data to your backend / pty
  socket.send(data);
});

// Resize handler
term.onResize(({ cols, rows }) => {
  console.log(`Terminal resized to ${cols}x${rows}`);
});
```

## Notes

- This is the **compiled bundle** — source lives in the `src/` tree and is built via webpack.
- Accessibility and link-detection features are auto-registered when `Terminal.open()` is called.
- All internal classes use a `Disposable` base pattern; call `term.dispose()` to release all resources.
