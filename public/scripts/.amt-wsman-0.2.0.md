Intel AMT WSMAN Stack client that constructs and sends SOAP-based WS-Management protocol messages to Intel Active Management Technology (AMT) endpoints, handling request building, response parsing, and communication lifecycle management.

## Key Components

- **`WsmanStackCreateService(host, port, user, pass, tls, extra)`** — Factory function that creates a WSMAN stack instance configured for a specific AMT host
- **`PerformAjax(postdata, callback, tag, pri, namespaces)`** — Core method wrapping all SOAP envelope construction and HTTP communication
- **`ExecGet(resuri, callback, tag, pri)`** — Executes a WS-Transfer GET operation
- **`ExecPut(resuri, putobj, callback, tag, pri, selectors)`** — Executes a WS-Transfer PUT operation
- **`ExecCreate(resuri, putobj, callback, tag, pri, selectors)`** — Executes a WS-Transfer CREATE operation
- **`ExecDelete(resuri, putobj, callback, tag, pri)`** — Executes a WS-Transfer DELETE operation
- **`ExecEnum(resuri, callback, tag, pri)`** — Executes a WS-Enumeration Enumerate operation
- **`ExecPull(resuri, enumctx, callback, tag, pri)`** — Executes a WS-Enumeration Pull operation to retrieve enumerated items
- **`ExecMethod(resuri, method, args, callback, tag, pri, selectors)`** — Executes a CIM method call with object arguments
- **`ExecMethodXml(resuri, method, argsxml, callback, tag, pri, selectors)`** — Executes a CIM method call with pre-formatted XML arguments
- **`ExecSubscribe / ExecUnSubscribe`** — Manages WS-Eventing subscriptions with optional digest authentication
- **`ParseWsman(xml)`** — Parses WSMAN SOAP responses into structured JavaScript objects
- **`CancelAllQueries(s)`** — Cancels all pending requests with a given status code

## Usage Example

```javascript
// Create a WSMAN stack instance targeting an AMT device
var stack = WsmanStackCreateService('192.168.1.100', 16992, 'admin', 'password', false);

// GET a resource
stack.ExecGet(
  'http://intel.com/wbem/wscim/1/amt-schema/1/AMT_GeneralSettings',
  function (stack, name, response, status, tag) {
    if (status === 200) {
      console.log('Settings:', response.Body);
    } else {
      console.error('Error:', status);
    }
  },
  'myTag',
  0 // priority
);

// Enumerate instances of a CIM class
stack.ExecEnum(
  'http://schemas.dmtf.org/wbem/wscim/1/cim-schema/2/CIM_SoftwareIdentity',
  function (stack, name, response, status, tag) {
    if (status === 200) {
      var ctx = response.Body.EnumerationContext;
      // Pull results using ctx
      stack.ExecPull(
        'http://schemas.dmtf.org/wbem/wscim/1/cim-schema/2/CIM_SoftwareIdentity',
        ctx, myCallback, tag, 0
      );
    }
  },
  null, 0
);

// Call an AMT method with arguments
stack.ExecMethod(
  'http://intel.com/wbem/wscim/1/amt-schema/1/AMT_SetupAndConfigurationService',
  'CommitChanges',
  {},
  function (stack, name, response, status, tag) {
    console.log('Method result:', response.Body.ReturnValue);
  },
  null, 0
);
```

## Notes

- Depends on `CreateWsmanComm` for the underlying HTTP/TLS transport layer
- Message IDs are auto-incremented via `NextMessageId` to uniquely label each WSMAN call
- All callbacks follow the signature: `callback(stack, resourceURI, response, httpStatus, tag)`
- Source: [`amt-wsman-0.2.0.js`](https://github.com/flamingo-stack/meshcentral/blob/main/amt-wsman-0.2.0.js)
