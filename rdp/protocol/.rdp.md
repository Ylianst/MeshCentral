RDP client and server implementation for the node-rdpjs library, providing full RDP protocol support including bitmap rendering, input events, clipboard integration, and connection management.

## Key Components

- **`RdpClient`** — Main RDP client class (EventEmitter) that orchestrates the full protocol stack (TPKT → X224 → MCS → PDU layers). Handles credentials, screen config, keyboard layout, and emits events: `connect`, `session`, `close`, `bitmap`, `pointer`, `clipboard`, `error`.
- **`RdpServer`** — Basic RDP server-side implementation requiring TLS key/cert configuration.
- **`decompress(bitmap)`** — Decompresses RLE-encoded bitmap data for 15/16/24/32-bit color depths using the native `rle` module.
- **`createClient(config)`** — Factory function returning a new `RdpClient` instance.
- **`createServer(config, next)`** — Factory function returning a TCP server that spawns `RdpServer` instances per connection.

### `RdpClient` Methods

| Method | Description |
|---|---|
| `connect(host, port)` | Initiates TCP + RDP handshake |
| `close()` | Gracefully closes an active session |
| `sendPointerEvent(x, y, button, isPressed)` | Sends mouse click/move events |
| `sendWheelEvent(x, y, step, isNegative, isHorizontal)` | Sends scroll wheel events |
| `sendKeyEventScancode(code, isPressed, extended)` | Sends raw scancode key events |
| `sendKeyEventUnicode(code, isPressed)` | Sends Unicode key events |
| `setClipboardData(content)` | Pushes clipboard content to the remote session |

## Usage Example

```javascript
const rdp = require('./rdp');

const client = rdp.createClient({
    domain: 'WORKGROUP',
    userName: 'admin',
    password: 's3cr3t',
    screen: { width: 1280, height: 720 },
    locale: 'en',
    enablePerf: true,
    decompress: true,
    logLevel: 'WARN'
});

client
    .on('connect', () => console.log('RDP connected'))
    .on('bitmap', (bitmap) => {
        // Render bitmap region to canvas
        const { destLeft, destTop, width, height, data } = bitmap;
    })
    .on('close', () => console.log('Session closed'))
    .on('error', (err) => console.error(err));

client.connect('192.168.1.100', 3389);

// Send input
client.sendPointerEvent(100, 200, 1, true);   // left click down
client.sendKeyEventScancode(0x1C, true);       // Enter key down
```
