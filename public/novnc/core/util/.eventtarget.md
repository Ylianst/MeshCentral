A mixin class from the noVNC library that provides `EventTarget`-compatible event handling functionality for classes that cannot extend the native `EventTarget` directly.

## Key Components

- **`EventTargetMixin`** *(default export)* — A mixin class implementing the standard browser `EventTarget` interface using a `Map` of `Set`s for listener storage.
  - `addEventListener(type, callback)` — Registers a callback for the given event type; duplicate callbacks are ignored (Set semantics).
  - `removeEventListener(type, callback)` — Removes a previously registered callback.
  - `dispatchEvent(event)` — Invokes all listeners for `event.type` and returns `false` if `preventDefault()` was called, `true` otherwise.

## Usage Example

```javascript
import EventTargetMixin from './eventtarget.js';

class MyConnection extends EventTargetMixin {
    connect(host) {
        // ... connection logic ...
        this.dispatchEvent(new CustomEvent('connect', { detail: { host } }));
    }
}

const conn = new MyConnection();

conn.addEventListener('connect', (e) => {
    console.log('Connected to:', e.detail.host);
});

conn.connect('vnc.example.com');

// Remove listener when no longer needed
const handler = (e) => console.log(e);
conn.addEventListener('disconnect', handler);
conn.removeEventListener('disconnect', handler);
```

## Notes

- Listener uniqueness per event type is enforced via `Set`, preventing duplicate registrations for the same callback reference.
- Compatible with standard [`Event`](https://developer.mozilla.org/en-US/docs/Web/API/Event) and [`CustomEvent`](https://developer.mozilla.org/en-US/docs/Web/API/CustomEvent) objects.
- Source: [`core/eventtarget.js`](https://github.com/flamingo-stack/meshcentral/blob/main/node_modules/noVNC/core/eventtarget.js)
