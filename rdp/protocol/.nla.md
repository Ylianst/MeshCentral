Implements the Network Level Authentication (NLA) layer for the RDP stack, handling NTLM authentication and secure credential exchange over a TLS-wrapped transport using ASN.1/DER encoding.

## Key Components

- **`NLA(transport, nlaCompletedFunc, domain, user, password)`** — Constructor that initializes the NTLM context, hooks into the transport layer, and begins the authentication handshake
- **`NLA.prototype.recvHeader`** — Parses the DER-encoded ASN.1 header bytes to determine payload length
- **`NLA.prototype.recvHeaderSize`** — Handles multi-byte DER length fields (1–2 bytes)
- **`NLA.prototype.recvData`** — Processes complete ASN.1 blocks; drives the two-phase NTLM state machine (challenge response → credential submission)
- **`NLA.prototype.sendNegotiateMessage`** — Builds and sends the initial NTLM Negotiate message wrapped in a `TSRequest` ASN.1 structure
- **`NLA.prototype.send`** / **`NLA.prototype.close`** — Passthrough helpers for the underlying transport
- **`NegotiateFlags`** — Bitmask constants for NTLM capability negotiation
- **`ntowfv2` / `lmowfv2`** — NTLMv2 key derivation functions (HMAC-MD5 over MD4 password hash)
- **`compute_response_v2`** — Generates NTLMv2 challenge/response blobs and session base key
- **`createRC4`** — RC4 cipher factory with a fallback to a pure-JS implementation for Node.js v17+
- **`md4`** — MD4 hash helper with fallback for Node.js v17+ (which dropped MD4 support)

## Usage Example

```javascript
const NLA = require('./nla');

// Called after TLS is established on the transport socket
const nlaLayer = new NLA(
  tlsTransport,
  function onNlaComplete() {
    console.log('NLA authentication succeeded, RDP session starting');
  },
  'CORP',       // domain
  'jdoe',       // username
  'P@ssw0rd'    // password
);

// Kick off the handshake
nlaLayer.sendNegotiateMessage();
```

The `NLA` instance temporarily hijacks the transport's `data`/`close`/`error` listeners, restoring them upon successful authentication so the RDP protocol layer resumes normally.
