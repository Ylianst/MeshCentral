Intel AMT Communication Stack service layer that wraps WSMAN protocol operations (GET, PUT, CREATE, DELETE, ENUMERATE, SUBSCRIBE) for managing Intel Active Management Technology devices.

## Key Components

- **`AmtStackCreateService(wsmanStack)`** — Factory constructor returning the AMT stack object bound to a WSMAN transport layer
- **Core WSMAN Operations** — `Get`, `Put`, `Create`, `Delete`, `Exec`, `ExecWithXml`, `Subscribe`, `UnSubscribe` — thin wrappers that resolve AMT/CIM/IPS namespace prefixes and invoke the underlying WSMAN stack
- **`Enum(name, callback, tag, pri)`** — Throttled WSMAN ENUMERATE with pull-continuation; queues requests beyond `MaxActiveEnumsCount` (default: 1)
- **`BatchEnum(batchname, names, callback, ...)`** — Sequentially enumerates a list of resource names, collecting results into a single callback; names prefixed with `*` perform GET instead of ENUM
- **`BatchGet(batchname, names, callback, ...)`** — Sequential GET operations across multiple resource URIs
- **`CompleteName(name)`** — Resolves short names (`AMT_*`, `CIM_*`, `IPS_*`) to full WBEM URIs
- **`GetPendingActions()`** — Returns total in-flight + queued operation count
- **`RequestPowerStateChange(PowerState, callback)`** / **`SetBootConfigRole(Role, callback)`** — Convenience wrappers for common AMT power and boot operations
- **`CancelAllQueries(status)`** — Propagates cancellation to the underlying WSMAN transport

## Usage Example

```javascript
// Initialize the stack with a WSMAN transport
var amtStack = AmtStackCreateService(wsmanStack);

// Track progress
amtStack.onProcessChanged = function(current, max) {
    console.log(`Progress: ${current}/${max}`);
};

// GET a single AMT resource
amtStack.Get("AMT_GeneralSettings", function(stack, name, response, status, tag) {
    if (status === 200) console.log(response.Body);
});

// Batch enumerate multiple resources
amtStack.BatchEnum("audit", ["AMT_AuditLog", "*AMT_GeneralSettings"], function(stack, name, results, status) {
    console.log(results["AMT_AuditLog"].response);
    console.log(results["AMT_GeneralSettings"].response);
});

// Request power state change (e.g., power cycle = 10)
amtStack.RequestPowerStateChange(10, function(stack, name, response, status) {
    console.log("Power state changed:", status);
});
```
