Implements PER (Packed Encoding Rules) encoding and decoding primitives for the T.125 protocol layer used in RDP connections.

## Key Components

| Function | Description |
|---|---|
| `readLength` / `writeLength` | Decode/encode variable-length PER length fields (1 or 2 bytes, MSB flag) |
| `readChoice` / `writeChoice` | Read/write PER choice values as `UInt8` |
| `readSelection` / `writeSelection` | Read/write PER selection fields as `UInt8` |
| `readNumberOfSet` / `writeNumberOfSet` | Read/write set count fields as `UInt8` |
| `readEnumerates` / `writeEnumerates` | Read/write enumeration values as `UInt8` |
| `readInteger` / `writeInteger` | Variable-width integer decode/encode (1, 2, or 4 bytes, length-prefixed) |
| `readInteger16` / `writeInteger16` | Fixed 16-bit integer with optional minimum offset |
| `readObjectIdentifier` / `writeObjectIdentifier` | Validate/write ASN.1 OID in PER format (5-byte, packed first two arcs) |
| `readNumericString` / `writeNumericString` | Read/write BCD-packed numeric strings with minimum offset |
| `readOctetStream` / `writeOctetStream` | Read/write raw byte sequences with length prefix and minimum offset |
| `readPadding` / `writePadding` | Skip/produce null-byte padding |

## Usage Example

```javascript
const per = require('./per');
const type = require('../../core').type;

// Encoding
const lengthField = per.writeLength(300);       // 2-byte: 0x812C
const intField    = per.writeInteger(1000);     // length-prefixed UInt16Be
const oidField    = per.writeObjectIdentifier([0, 0, 20, 124, 0, 1]);

// Decoding
const stream = new type.Stream(buffer);
const length = per.readLength(stream);          // e.g. 300
const value  = per.readInteger(stream);         // e.g. 1000
const valid  = per.readObjectIdentifier(stream, [0, 0, 20, 124, 0, 1]); // true/false

// Octet stream round-trip
const encoded = per.writeOctetStream("RDP", 0);
const matches = per.readOctetStream(stream, "RDP", 0); // true if bytes match
```
