GCC (Generic Conference Control) conference data block builder and parser for the RDP protocol, handling client/server capability negotiation during connection setup.

## Key Components

### Constants / Enums
| Export | Description |
|--------|-------------|
| `MessageType` | Block type identifiers for client↔server data blocks (e.g., `CS_CORE`, `SC_SECURITY`) |
| `ColorDepth` / `HighColor` / `Support` | Color depth and display capability flags |
| `CapabilityFlag` | Client capability bits (error info PDU, monitor layout, etc.) |
| `EncryptionMethod` / `EncryptionLevel` | RDP encryption negotiation values |
| `ChannelOptions` | Virtual channel behavior flags |
| `KeyboardType` / `KeyboardLayout` | Keyboard hardware and locale identifiers |
| `CertificateType` | Server certificate chain version constants |

### Functions
| Function | Description |
|----------|-------------|
| `block(data)` | Wraps a GCC data block with type/length header; auto-dispatches to the correct parser on read |
| `clientCoreData(opt)` | Client→server core capabilities (resolution, color depth, keyboard, RDP version) |
| `serverCoreData(opt)` | Server→client core response (RDP version, protocol flags) |
| `clientSecurityData(opt)` | Client encryption method flags |
| `serverSecurityData(opt)` | Server encryption method and level |
| `clientNetworkData(channelDefArray, opt)` | Client virtual channel requests |
| `serverNetworkData(channelIds, opt)` | Server channel ID assignments |
| `channelDef(opt)` | Single channel definition (name + options flags) |

## Usage Example

```javascript
var gcc = require('./gcc');

// Build a client core data block with default 1280×800, French keyboard
var coreBlock = gcc.block(gcc.clientCoreData());

// Build a client network data block requesting two channels
var channels = new type.Component([
    gcc.channelDef({ name: 'rdpdr', options: gcc.ChannelOptions.CHANNEL_OPTION_INITIALIZED }),
    gcc.channelDef({ name: 'cliprdr', options: gcc.ChannelOptions.CHANNEL_OPTION_INITIALIZED })
]);
var netBlock = gcc.block(gcc.clientNetworkData(channels));

// Parse an incoming server security block from a stream
var secBlock = gcc.block();
secBlock.read(stream); // auto-detects MessageType.SC_SECURITY and parses accordingly
```
