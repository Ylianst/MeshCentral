Implements the MD5 hashing algorithm for use in the noVNC HTML5 VNC client, converting an input byte array into an MD5 digest returned as a `Uint8Array`.

## Key Components

| Export/Function | Description |
|---|---|
| `MD5(d)` | **Exported async function.** Entry point — accepts a byte array, returns a `Uint8Array` MD5 hash |
| `Y(d, g)` | Core MD5 compression — applies the four round functions (`ff`, `gg`, `hh`, `ii`) across 512-bit blocks |
| `X(d)` | Converts a string to a little-endian 32-bit word array |
| `V(d)` | Converts a 32-bit word array back to a string |
| `M(d)` | Converts a string of char codes into a `Uint8Array` |
| `cmn(d, g, m, f, r, i)` | Shared core operation used by all four round functions |
| `ff` / `gg` / `hh` / `ii` | MD5 round functions implementing F, G, H, and I auxiliary operations |
| `add(d, g)` | 32-bit modular addition |
| `rol(d, g)` | Bitwise left rotate |

## Usage Example

```javascript
import { MD5 } from './md5.js';

// Hash a byte array (e.g. a UTF-8 encoded password)
const input = new TextEncoder().encode("password");
const hash = await MD5(Array.from(input));

// Convert result to hex string
const hex = Array.from(hash)
  .map(b => b.toString(16).padStart(2, '0'))
  .join('');

console.log(hex); // 5f4dcc3b5aa765d61d8327deb882cf99
```

> **Note:** This implementation is part of the [noVNC integration](https://github.com/flamingo-stack/meshcentral/blob/main/main/md5.js) and is intended for internal protocol use (e.g., VNC authentication challenges), not general-purpose cryptography.
