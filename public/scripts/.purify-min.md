Minified build of **DOMPurify 3.2.6** — a battle-tested XSS sanitization library that cleans untrusted HTML, SVG, and MathML before inserting it into the DOM.

## Key Components

- **`DOMPurify.sanitize(dirty, config)`** — Core method; strips dangerous tags/attributes from an HTML string or DOM node
- **`DOMPurify.addHook(hookName, fn)`** — Registers lifecycle hooks for custom sanitization logic
- **`DOMPurify.removeHook(hookName)`** / **`DOMPurify.removeHooks(hookName)`** — Removes registered hooks
- **`DOMPurify.isValidAttribute(tag, attr, value)`** — Checks whether a given attribute is safe for a tag
- **Allowlists** — Pre-frozen sets for safe HTML tags (`L`/`C`/`M`), safe SVG/MathML attributes (`P`/`H`), and safe URI schemes (`IS_ALLOWED_URI`)
- **Regex guards** — Blocks Mustache (`{{...}}`), ERB (`<%...%>`), template literal (`${...}`), and `javascript:`/`data:` URI patterns

## Usage Example

```javascript
// UMD: works in Node.js, AMD, and browser globals
const DOMPurify = require('./purify-min');

// Basic sanitization
const clean = DOMPurify.sanitize('<img src=x onerror=alert(1)>');
// → '<img src="x">'

// Allow only specific tags
const strict = DOMPurify.sanitize(dirtyHTML, {
  ALLOWED_TAGS: ['b', 'i', 'em', 'strong', 'a'],
  ALLOWED_ATTR: ['href']
});

// Custom hook — strip data attributes
DOMPurify.addHook('uponSanitizeAttribute', (node, data) => {
  if (data.attrName.startsWith('data-')) {
    data.forceKeepAttr = false;
  }
});

// Trusted Types integration (browser)
const clean = DOMPurify.sanitize(dirty, { RETURN_TRUSTED_TYPE: true });
document.body.innerHTML = clean; // safe with Trusted Types policy
```
