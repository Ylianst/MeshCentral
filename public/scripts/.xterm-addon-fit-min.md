Minified build of the [xterm.js FitAddon](https://github.com/xtermjs/xterm.js/tree/master/addons/addon-fit), which automatically resizes an xterm.js terminal to fill its parent container element.

## Key Components

**`FitAddon` class**

| Method | Description |
|---|---|
| `activate(terminal)` | Binds the addon to an xterm.js `Terminal` instance |
| `dispose()` | Cleanup hook (no-op in this build) |
| `fit()` | Resizes the terminal to match the proposed dimensions |
| `proposeDimensions()` | Calculates optimal `cols`/`rows` based on parent container size, cell dimensions, padding, and scrollbar width |

## Usage Example

```javascript
import { Terminal } from 'xterm';
import { FitAddon } from './xterm-addon-fit-min.js';

const terminal = new Terminal();
const fitAddon = new FitAddon();

terminal.loadAddon(fitAddon);
terminal.open(document.getElementById('terminal-container'));

// Initial fit
fitAddon.fit();

// Re-fit on window resize
window.addEventListener('resize', () => fitAddon.fit());
```

## Notes

- `proposeDimensions()` accounts for parent container padding, computed styles, and scrollbar width to avoid overflow
- Returns `undefined` (no-op) if the terminal or its parent element is not yet mounted in the DOM, or if cell dimensions are zero
- Enforces minimum dimensions: **2 columns**, **1 row**
- This is the **minified/bundled** version; source lives upstream at [xtermjs/xterm.js](https://github.com/xtermjs/xterm.js). For issues specific to this deployment, see the [flamingo-stack/meshcentral](https://github.com/flamingo-stack/meshcentral) repository
