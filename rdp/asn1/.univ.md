Implements ASN.1 Universal type definitions for BER encoding/decoding in the node-rdpjs RDP protocol library, mapping standard ASN.1 data types to JavaScript constructors with `encode`/`decode` methods.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `UniversalTag` | Enum | ASN.1 universal tag number constants (e.g., `Boolean=1`, `Integer=2`, `Sequence=16`) |
| `Boolean` | Class | ASN.1 Boolean — encodes as `0xff`/`0x00`, decodes to JS boolean |
| `Integer` | Class | ASN.1 Integer — handles values up to 32-bit; falls back to raw Buffer for bignums |
| `Sequence` | Class | ASN.1 Sequence (constructed) — ordered list of typed fields with optional-field error recovery |
| `Enumerate` | Class | ASN.1 Enumerated — single-byte integer value |
| `OctetString` | Class | ASN.1 OctetString — raw Buffer value |
| `ObjectIdentifier` | Class | ASN.1 OID — raw Buffer, decode only |
| `Null` | Class | ASN.1 Null — no value, consumes tag on decode |
| `Choice` | Class | ASN.1 Choice — tries each alternative in order, resets stream offset on failure |
| `SetOf` / `SequenceOf` | Class | Repeated-element collections driven by a factory function |
| `BitString` | Class | ASN.1 BitString — decodes to an array of `0`/`1` values; `toBuffer()` converts back |
| `T61String`, `PrintableString`, `UniversalString`, `UTF8String` | Class | String variants — raw Buffer storage, decode only |

All classes extend `spec.Asn1Spec` and carry a typed `Asn1Tag` for BER tag matching.

## Usage Example

```javascript
var univ = require('./univ');
var ber  = require('./ber');   // BER encoder/decoder

// --- Encoding ---
var seq = new univ.Sequence([
  new univ.Integer(42),
  new univ.OctetString(Buffer.from('hello'))
]);
var encoded = seq.encode(ber.encoder);

// --- Decoding ---
var decoded = new univ.Sequence([
  new univ.Integer(),
  new univ.OctetString()
]);
decoded.decode(stream, ber.decoder);
console.log(decoded.value[0].value); // 42
console.log(decoded.value[1].value); // <Buffer 68 65 6c 6c 6f>

// --- Choice (tries Integer first, falls back to OctetString) ---
var choice = new univ.Choice([
  new univ.Integer(),
  new univ.OctetString()
]);
choice.decode(stream, ber.decoder);

// --- BitString to Buffer ---
var bs = new univ.BitString();
bs.decode(stream, ber.decoder);
var buf = bs.toBuffer();
```

> **Note:** `Integer.decode` accumulates bytes via bit-shifting for values ≤ 4 bytes; larger values are returned as a raw `Buffer` (bignum path).
