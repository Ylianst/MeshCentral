A JavaScript implementation of Big Number (BN) arithmetic, providing a subset of operations optimized for RSA encryption. Based on Tom Wu's classic jsbn library with added Node.js Buffer support.

## Key Components

- **`BigInteger(a, b)`** — Constructor supporting initialization from numbers, Buffers, byte arrays, or strings with a radix
- **`nbi()`** — Factory function returning a new uninitialized `BigInteger`
- **`nbv(i)`** — Factory function returning a `BigInteger` initialized to integer value `i`
- **Multiply accumulate functions** — `am1`, `am2`, `am3`: platform-optimized inner-loop helpers for digit multiplication; Node.js uses `am3` with 28-bit digits
- **Arithmetic methods** (on prototype):
  - `bnNegate` / `bnAbs` — Negation and absolute value
  - `bnCompareTo` — Three-way comparison
  - `bnBitLength` — Returns number of bits in the integer
  - `bnpSubTo` / `bnpMultiplyTo` — In-place subtraction and multiplication
  - `bnpLShiftTo` / `bnpRShiftTo` / `bnpDLShiftTo` / `bnpDRShiftTo` — Bit and digit shifting
  - `bnToString` — Converts to string in a given radix (2, 4, 8, 16, 32)
- **`bnpFromString` / `bnpFromBuffer` / `bnpFromByteArray`** — Multiple input parsers
- **`bnpClamp`** — Removes excess high-order zero digits

## Usage Example

```javascript
var BigInteger = require('./jsbn');

// Create from hex string
var a = new BigInteger('deadbeef', 16);

// Create from integer
var b = new BigInteger(255, null);

// Create from Node.js Buffer
var buf = Buffer.from([0x01, 0x02, 0x03]);
var c = new BigInteger(buf);

// Arithmetic
var neg = a.negate();
var bits = a.bitLength();
var str = a.toString(16); // back to hex
```

## Notes

- Node.js-specific: uses `am3` multiply accumulator with `dbits = 28` for optimal performance
- Digit base is 2²⁸; internal digits stored as array elements on the `BigInteger` instance
- Primarily used as a dependency for RSA key operations within MeshCentral
