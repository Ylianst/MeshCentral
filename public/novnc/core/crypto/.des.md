DES (Data Encryption Standard) cipher implementation providing ECB and CBC mode encryption, ported from the Flashlight VNC ActionScript implementation for use in VNC authentication.

## Key Components

- **`DES`** (internal class) — Core DES cipher. Constructor accepts a password byte array and precomputes the 16 subkeys. The `enc8(text)` method encrypts exactly 8 bytes using the standard DES Feistel network with SP-box lookup tables.
- **`DESECBCipher`** (exported) — Electronic Codebook mode wrapper. Exposes a Web Crypto-compatible API (`importKey`, `encrypt`) for encrypting arbitrary-length data in independent 8-byte blocks.
- **`DESCBCCipher`** (exported, appears truncated) — Cipher Block Chaining mode wrapper with the same Web Crypto-compatible interface.
- **SP1–SP8** — Precomputed S-box / permutation lookup tables combining the DES S-boxes with P-permutation for optimized single-pass computation.
- **`PC2` / `totrot`** — Key schedule constants used during subkey generation in the `DES` constructor.

## Usage Example

```javascript
import { DESECBCipher } from './des.js';

// Import a DES key (8-byte Uint8Array)
const keyBytes = new Uint8Array([0x01, 0x23, 0x45, 0x67, 0x89, 0xab, 0xcd, 0xef]);
const cipher = DESECBCipher.importKey(keyBytes, null, false, []);

// Encrypt 8-byte aligned plaintext
const plaintext = new Uint8Array(16).fill(0x41); // 16 bytes of 'A'
const ciphertext = cipher.encrypt(null, plaintext);
// ciphertext is a Uint8Array of the encrypted result
```

> **Note:** This is a legacy DES implementation (56-bit key) used for VNC authentication (RFB protocol challenge-response). DES is cryptographically weak and should not be used for general-purpose encryption. See the [source file](https://github.com/flamingo-stack/meshcentral/blob/main/des.js) for full licensing details.
