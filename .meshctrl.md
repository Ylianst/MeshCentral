MeshCentral command-line control tool (`meshctrl.js`) that connects to a MeshCentral server via WebSocket and performs administrative operations including user management, device management, remote shell access, file transfer, and real-time event monitoring.

## Key Components

### Command Dispatcher
The main entry point parses CLI arguments using `minimist` and routes to the appropriate action handler. Supports 50+ commands covering the full MeshCentral API surface.

### Authentication
Connects to MeshCentral via WebSocket (`ws`) supporting:
- Username/password login
- Login key (hex or file-based)
- 2FA token support
- HTTP proxy via `https-proxy-agent`

### Command Categories

| Category | Commands |
|---|---|
| **User Management** | `adduser`, `edituser`, `removeuser`, `listusers`, `listusersessions` |
| **Device Management** | `listdevices`, `deviceinfo`, `editdevice`, `removedevice`, `addlocaldevice`, `addamtdevice` |
| **Group Management** | `adddevicegroup`, `editdevicegroup`, `removedevicegroup`, `addusergroup`, `listusergroups` |
| **Remote Operations** | `shell`, `runcommand`, `upload`, `download`, `devicepower`, `webrelay` |
| **Notifications** | `devicetoast`, `devicemessage`, `grouptoast`, `groupmessage`, `broadcast` |
| **Reporting** | `report`, `listevents`, `showevents`, `agentdownload` |

## Usage Example

```bash
# List all devices on a MeshCentral server
node meshctrl.js listdevices \
  --url wss://meshcentral.example.com:443 \
  --loginuser admin \
  --loginpass secret

# Run a remote shell command on a device
node meshctrl.js runcommand \
  --url wss://meshcentral.example.com:443 \
  --loginuser admin \
  --loginpass secret \
  --id '//domain/device/nodeid' \
  --run "uptime"

# Upload a file to a remote device
node meshctrl.js upload \
  --url wss://meshcentral.example.com:443 \
  --loginuser admin \
  --loginpass secret \
  --id '//domain/device/nodeid' \
  --localfile ./agent.zip \
  --remotefile /tmp/agent.zip
```

## Dependencies

| Module | Purpose |
|---|---|
| `minimist` | CLI argument parsing |
| `ws` | WebSocket client for server communication |
| `https-proxy-agent` | Optional HTTP proxy support (required only when `--proxy` is set) |
| `crypto` | Built-in Node.js module for key operations |
