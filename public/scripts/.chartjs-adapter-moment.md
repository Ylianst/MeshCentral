Moment.js date adapter for Chart.js, overriding the default `_adapters._date` interface to enable moment-powered date parsing, formatting, and arithmetic on time-scale charts.

## Key Components

- **`FORMATS`** — Map of time unit keys (`datetime`, `millisecond` → `year`) to moment.js display format strings used by Chart.js time axes.
- **`_id`** — Adapter identifier string (`'moment'`) for debug identification.
- **`formats()`** — Returns the `FORMATS` map to Chart.js.
- **`parse(value, format)`** — Converts a string, timestamp, or moment object to a Unix ms timestamp; returns `null` if invalid.
- **`format(time, format)`** — Formats a Unix ms timestamp into a display string using a moment format token.
- **`add(time, amount, unit)`** — Adds a duration to a timestamp and returns a new Unix ms timestamp.
- **`diff(max, min, unit)`** — Returns the difference between two timestamps in the specified unit.
- **`startOf(time, unit, weekday)`** — Returns the start of a time unit (supports `isoWeek` with configurable weekday offset).
- **`endOf(time, unit)`** — Returns the end of a time unit as a Unix ms timestamp.

## Usage Example

```javascript
// Include both dependencies before this adapter
import moment from 'moment';
import { Chart } from 'chart.js';
import 'chartjs-adapter-moment';

const chart = new Chart(ctx, {
  type: 'line',
  data: { datasets: [{ data: [{ x: '2024-01-15', y: 42 }] }] },
  options: {
    scales: {
      x: {
        type: 'time',
        time: {
          unit: 'day',         // Uses FORMATS.day → 'MMM D'
          tooltipFormat: 'MMM D, YYYY, h:mm:ss a'
        }
      }
    }
  }
});
```

> **Note:** The adapter only registers if `moment` is available as a function at load time; otherwise an empty override is applied. Works with CommonJS, AMD, and browser globals.
