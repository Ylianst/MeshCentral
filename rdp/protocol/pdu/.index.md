Entry point for the RDP (Remote Desktop Protocol) PDU layer, aggregating and re-exporting core protocol sub-modules for licensing, security, global channel, data handling, and clipboard redirection.

## Key Components

| Export | Module | Description |
|--------|--------|-------------|
| `lic` | `./lic` | RDP licensing protocol handling |
| `sec` | `./sec` | Security layer (encryption, authentication) |
| `global` | `./global` | Global channel protocol definitions |
| `data` | `./data` | RDP data PDU structures |
| `cliprdr` | `./cliprdr` | Clipboard redirection channel protocol |

## Usage Example

```javascript
const pdu = require('./path/to/pdu');

// Access licensing module
const licHandler = pdu.lic;

// Access security module
const secLayer = pdu.sec;

// Access clipboard redirection
const clipboard = pdu.cliprdr;

// Access global channel definitions
const globalChannel = pdu.global;

// Access data PDU structures
const dataStructures = pdu.data;
```
