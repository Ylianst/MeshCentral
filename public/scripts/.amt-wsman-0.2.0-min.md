Minified WS-Management (WSMAN) client stack factory for Intel AMT (Active Management Technology) communication, providing SOAP envelope construction and XML parsing for AMT device management operations.

## Key Components

- **`WsmanStackCreateService()`** — Factory function that creates a WSMAN stack instance bound to a communication backend via `CreateWsmanComm()`
- **`n.ExecGet`** — Sends a WS-Transfer `Get` request for a resource URI
- **`n.ExecPut`** — Sends a WS-Transfer `Put` request to update a resource, serializing JS objects to XML
- **`n.ExecCreate` / `n.ExecCreateXml`** — Sends WS-Transfer `Create` requests (object or raw XML body variants)
- **`n.ExecDelete`** — Sends a WS-Transfer `Delete` request with selector-based targeting
- **`n.ExecMethod` / `n.ExecMethodXml`** — Invokes a CIM method on a resource (object or raw XML parameter variants)
- **`n.ExecEnum` / `n.ExecPull`** — WS-Enumeration `Enumerate` and `Pull` operations for iterating resource collections
- **`n.ExecSubscribe` / `n.ExecUnSubscribe`** — WS-Eventing subscription management with optional digest auth token support
- **`n.ParseWsman`** — Parses SOAP response XML into a plain JS object (`{ Header, Body }`)
- **`n.PerformAjax`** — Core SOAP envelope sender; delegates to the underlying comm layer
- **`n.CancelAllQueries`** — Cancels pending requests via the comm layer

## Usage Example

```javascript
// Create a WSMAN stack targeting an AMT device
const stack = WsmanStackCreateService(
  "192.168.1.100", // host
  16992,           // port
  "admin",         // user
  "P@ssword1",     // password
  false,           // TLS
  null             // extra options
);

// Get a CIM resource
const resourceURI = "http://intel.com/wbem/wscim/1/amt-schema/1/AMT_GeneralSettings";
stack.ExecGet(resourceURI, (stack, uri, response, status) => {
  console.log("Status:", status);
  console.log("Body:", response.Body);
}, null, null);

// Enumerate instances of a class
stack.ExecEnum(resourceURI, (stack, uri, response, status) => {
  const ctx = response.Body.EnumerationContext;
  stack.ExecPull(resourceURI, ctx, (s, u, r) => console.log(r.Body), null, null);
}, null, null);
```

## Notes

- All SOAP messages use `NextMessageId` (auto-incremented) for `a:MessageID` uniqueness
- The `ParseWsman` method handles both pre-parsed DOM nodes and raw XML strings, with IE (`ActiveXObject`) fallback
- Selector sets support nested `EndpointReference` structures for EPR-based addressing
