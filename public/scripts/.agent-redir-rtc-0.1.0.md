Provides a WebRTC data channel transport layer for MeshCentral agent redirection, bridging binary and control messages between a WebSocket relay channel and inner protocol modules (KVM, Terminal, etc.).

## Key Components

| Export / Symbol | Description |
|---|---|
| `CreateKvmDataChannel(webchannel, module, keepalive)` | Factory function that constructs the transport object wrapping a WebRTC data channel |
| `obj.Start()` | Activates the channel, wires up message handlers, and starts a 30-second keep-alive interval |
| `obj.Stop()` | Tears down the channel, clears the keep-alive timer, and resets state |
| `obj.send(x)` | Sends binary data over the WebRTC channel, converting strings to `Uint8Array` first |
| `obj.sendCtrlMsg(x)` | Sends a string control message over the WebRTC channel |
| `obj.xxOnMessage(e)` | Internal handler that routes incoming data — strings to `onControlMsg`, blobs/buffers through `FileReader` then to `xxOnSocketData` |
| `obj.xxOnSocketData(data)` | Normalizes incoming binary data to a string and delegates to the inner module's `ProcessData` |
| `obj.xxStateChange(newstate)` | Updates connection state and propagates it to the inner module and any registered `onStateChanged` listener |
| `obj.xxSendRtcKeepAlive()` | Sends a `{"action":"ping"}` JSON control message to keep the channel alive |

## Usage Example

```javascript
// inner module must implement ProcessData(data) and xxStateChange(state)
var desktopModule = CreateDesktopModule();

var channel = CreateKvmDataChannel(
  rtcDataChannel,   // WebRTC RTCDataChannel or WebSocket relay
  desktopModule,    // inner protocol module (KVM/Terminal/Files)
  keepaliveHelper   // optional keepalive object with sendKeepAlive()
);

// Listen for state changes
channel.onStateChanged = function (sender, state) {
  console.log('Channel state changed to', state);
};

// Listen for control messages from the remote peer
channel.onControlMsg = function (msg) {
  console.log('Control message received:', msg);
};

// Start the channel (sets state → 3 and enables message handling)
channel.Start();

// Send binary data to the agent
channel.send(someUint8Array);

// Send a JSON control message
channel.sendCtrlMsg(JSON.stringify({ action: 'hello' }));

// Cleanly shut down
channel.Stop();
```

## Notes

- **`FileReader` compatibility**: Uses `readAsBinaryString` (Chrome/Firefox draft) with a fallback to `readAsArrayBuffer` (spec), and a final IE10 fallback using `Uint8Array` manual conversion. A shared, queued `FileReader` instance prevents parallel read conflicts.
- **Protocol field** (`obj.protocol`): Inherited from the inner module — `1`=SOL, `2`=KVM, `3`=IDER, `4`=Files, `5`=FileTransfer.
