Manages the HTML5 canvas rendering pipeline for the noVNC client, handling a dual-buffer (backbuffer + visible canvas) drawing architecture with an ordered render queue.

## Key Components

- **`Display` class** — Main export; wraps two canvas elements (backbuffer for rendering, target for display) with viewport and scaling support
- **`scale` / `clipViewport`** — Properties controlling zoom level and viewport clipping behavior
- **`viewportChangePos(deltaX, deltaY)`** — Moves the visible viewport within the framebuffer bounds
- **`viewportChangeSize(width, height)`** — Resizes the visible viewport and underlying canvas element
- **`resize(width, height)`** — Resizes the full framebuffer, preserving existing pixel data
- **`fillRect()`** — Draws a solid-color rectangle, queued or immediate
- **`copyImage()`** — Copies a region within the backbuffer (image-smoothing disabled to prevent blur)
- **`imageRect()`** — Decodes a base64-encoded image and queues it for rendering
- **`blitImage()`** — Blits raw RGBA pixel data onto the backbuffer
- **`flip(fromQueue)`** — Transfers damaged regions from the backbuffer to the visible canvas
- **`flush()`** — Returns a Promise that resolves when the render queue is empty
- **`absX(x)` / `absY(y)`** — Converts scaled viewport-relative coordinates to absolute framebuffer coordinates
- **`_damage(x, y, w, h)`** — Tracks the bounding box of modified regions for efficient flipping

## Usage Example

```javascript
import Display from './display.js';

const canvas = document.getElementById('vnc-canvas');
const display = new Display(canvas);

// Set framebuffer size
display.resize(1920, 1080);

// Configure viewport
display.scale = 0.75;
display.clipViewport = true;
display.viewportChangeSize(1280, 720);

// Draw operations (queued automatically)
display.fillRect(0, 0, 100, 100, [255, 0, 0], false);
display.blitImage(10, 10, 64, 64, pixelData, 0, false);

// Wait for all pending draws to complete
await display.flush();

// Convert to PNG for snapshot
const dataUrl = display.toDataURL('image/png');
```
