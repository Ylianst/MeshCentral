Entry point for the `node-rdpjs` library, exposing the RDP (Remote Desktop Protocol) client and server factory functions.

## Key Components

| Export | Source | Description |
|--------|--------|-------------|
| `createClient` | `protocol.rdp.createClient` | Factory function to create an RDP client connection |
| `createServer` | `protocol.rdp.createServer` | Factory function to create an RDP server instance |

## Usage Example

```javascript
const rdp = require('./index');

// Create an RDP client
const client = rdp.createClient({
  domain: '',
  userName: 'admin',
  password: 'secret'
});

client.connect('192.168.1.100', 3389);

// Create an RDP server
const server = rdp.createServer({
  // server options
});

server.listen(3389);
```
