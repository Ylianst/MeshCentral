Defines RDP capability set structures and constants for the node-rdpjs RDP protocol implementation, mapping to Microsoft's RDP capability exchange specification ([MS-RDPBCGR]).

## Key Components

### Enumerations

| Constant | Description |
|----------|-------------|
| `CapsType` | Capability set type identifiers (general, bitmap, order, input, etc.) |
| `MajorType` / `MinorType` | OS major/minor type identifiers for client platform identification |
| `GeneralExtraFlag` | Flags for general capability negotiation (fastpath, autoreconnect, etc.) |
| `OrderFlag` / `Order` / `OrderEx` | Drawing order negotiation flags and indices |
| `InputFlags` | Input capability flags (scancode, mouse, Unicode, fastpath) |
| `BrushSupport` | Brush rendering support levels |
| `GlyphSupport` | Glyph cache support levels |
| `VirtualChannelCompressionFlag` | Virtual channel compression capabilities |
| `SoundFlag` | Sound capability flags |

### Capability Factory Functions

| Function | Cap Type | Description |
|----------|----------|-------------|
| `generalCapability(opt)` | `CAPSTYPE_GENERAL` | OS type, protocol version, compression, and feature flags |
| `bitmapCapability(opt)` | `CAPSTYPE_BITMAP` | Color depth, resolution, compression settings |
| `orderCapability(orders, opt)` | `CAPSTYPE_ORDER` | Drawing order support with optional order list |
| `bitmapCacheCapability(opt)` | `CAPSTYPE_BITMAPCACHE` | Bitmap cache entry counts and cell sizes |
| `pointerCapability(isServer, opt)` | `CAPSTYPE_POINTER` | Pointer/cursor cache settings, server-mode conditional |
| `inputCapability(opt)` | `CAPSTYPE_INPUT` | Keyboard layout, type, subtype, and IME filename |
| `brushCapability(opt)` | `CAPSTYPE_BRUSH` | Brush rendering support level |
| `cacheEntry(opt)` | — | Reusable glyph cache entry structure |

## Usage Example

```javascript
var caps = require('./caps');

// Build a general capability set for a Windows client
var generalCap = caps.generalCapability();
generalCap.osMajorType.value = caps.MajorType.OSMAJORTYPE_WINDOWS;
generalCap.osMinorType.value = caps.MinorType.OSMINORTYPE_WINDOWS_NT;
generalCap.extraFlags.value = caps.GeneralExtraFlag.FASTPATH_OUTPUT_SUPPORTED
                            | caps.GeneralExtraFlag.AUTORECONNECT_SUPPORTED;

// Build a bitmap capability for a 1024x768 24-bit session
var bitmapCap = caps.bitmapCapability();
bitmapCap.preferredBitsPerPixel.value = 24;
bitmapCap.desktopWidth.value  = 1024;
bitmapCap.desktopHeight.value = 768;

// Build input capability referencing keyboard settings from GCC core data
var inputCap = caps.inputCapability();
inputCap.inputFlags.value = caps.InputFlags.INPUT_FLAG_SCANCODES
                          | caps.InputFlags.INPUT_FLAG_MOUSEX;

// Pointer capability — include pointerCacheSize only when in server mode
var ptrCap = caps.pointerCapability(true /* isServer */);
```
