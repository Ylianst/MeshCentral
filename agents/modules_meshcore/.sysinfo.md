Cross-platform system information module that collects CPU utilization, memory utilization, and thermal sensor data for Windows, Linux, and macOS platforms.

## Key Components

| Export | Description |
|--------|-------------|
| `cpuUtilization()` | Returns a Promise resolving to CPU usage percentages per core and total |
| `memUtilization()` | Returns memory stats including total, free, and percent consumed/free |
| `thermals()` | Returns an array of thermal zone readings with `CurrentTemperature` and `InstanceName` |

**Platform implementations:**

- **Windows** — Uses PDH (Performance Data Helper) API via `_GenericMarshal` for CPU, `GlobalMemoryStatusEx` for memory, and WMI `MSAcpi_ThermalZoneTemperature` for thermals
- **Linux** — Reads `/proc/stat` for CPU deltas and `/proc/meminfo` for memory; uses `/sys/class/thermal` and `/sys/class/hwmon` for thermals
- **macOS** — Shells out to `top` for CPU/memory and `powermetrics` for SMC thermal data

## Usage Example

```javascript
var sysinfo = require('./sysinfo');

// CPU utilization (async, returns Promise)
sysinfo.cpuUtilization().then(function(cpu) {
    console.log('Total CPU:', cpu.total.toFixed(2) + '%');
    console.log('Per-core:', cpu.cpus);
});

// Memory utilization (synchronous on Linux/macOS)
var mem = sysinfo.memUtilization();
console.log('Memory used:', mem.percentConsumed.toFixed(2) + '%');
console.log('Memory free:', mem.percentFree.toFixed(2) + '%');

// Thermal sensors
var temps = sysinfo.thermals();
temps.forEach(function(zone) {
    console.log(zone.InstanceName + ':', zone.CurrentTemperature + '°C');
});
```

> **Note:** On Linux, `cpuUtilization()` computes utilization as a delta between two reads. The first call will return `0%` or unreliable values since no prior baseline exists. Call it at an interval (e.g., every second) for accurate readings.
