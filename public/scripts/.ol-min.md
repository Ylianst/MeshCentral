Minified build of OpenLayers v4.2.0, a high-performance web mapping library. This file bundles the complete OpenLayers library into a single distributable module, supporting UMD (CommonJS, AMD, and global) module formats.

## Key Components

- **Projection System** (`Bb`, `Cb`, `Kb`) — EPSG:3857 (Web Mercator) and EPSG:4326 (WGS84) coordinate reference systems with proj4 integration
- **Extent Utilities** (`Na`, `Qa`, `pb`, `sb`, etc.) — Bounding box creation, intersection, transformation, and spatial query helpers
- **Spherical Geodesy** (`xb`, `yb`) — Great-circle distance calculation and area computation using the Haversine formula
- **Tile Grid** (`lc`) — Resolution array management for tiled map layers with zoom-level support
- **Coordinate Transform Pipeline** (`Vb`, `ec`, `gc`) — Lazy transform lookup with proj4 fallback for arbitrary CRS pairs
- **Assertion Helpers** (`wa`, `xa`) — Developer-friendly error codes linked to the OpenLayers error docs

## Usage Example

```javascript
// CommonJS
const ol = require('./ol-min.js');

// AMD
define(['ol-min'], function(ol) { /* ... */ });

// Browser global
// <script src="ol-min.js"></script> → window.ol

// Project coordinates from WGS84 → Web Mercator
const lonLat = [-122.4194, 37.7749]; // San Francisco
const webMercator = ol.proj.fromLonLat(lonLat);

// Create a bounding extent
const extent = ol.extent.boundingExtent([
  [-180, -90],
  [180, 90]
]);

// Check if a coordinate is inside an extent
const inside = ol.extent.containsCoordinate(extent, lonLat);
```
