Windows PseudoConsole (ConPTY) wrapper that creates and manages virtual terminal sessions on Windows, exposing them as Node.js Duplex streams for bidirectional I/O.

## Key Components

| Export/Method | Description |
|---|---|
| `supported` | Boolean property indicating if `CreatePseudoConsole` is available (Windows 10 1809+) |
| `Create(path, width, height)` | Spawns any executable inside a PseudoConsole; returns a Duplex stream |
| `Start(width, height)` | Convenience method to launch `cmd.exe` |
| `StartPowerShell(width, height)` | Launches PowerShell (handles x64/x86 path resolution) |
| `PowerShellCapable()` | Checks if PowerShell is installed on the system |
| `ds.resizeTerminal(w, h)` | Resizes the active PseudoConsole via `ResizePseudoConsole` |

## Usage Example

```javascript
const vt = require('./win-virtual-terminal');

// Check platform support
if (!vt.supported) {
  throw new Error('PseudoConsole requires Windows 10 1809 or later');
}

// Launch cmd.exe at 80x25
const terminal = vt.Start(80, 25);

// Read output from the terminal
terminal.on('data', (chunk) => {
  process.stdout.write(chunk);
});

// Write input to the terminal
terminal.write('dir\r\n');

// Launch PowerShell instead
const ps = vt.StartPowerShell(120, 40);
ps.on('data', (data) => console.log(data.toString()));
ps.write('Get-Process\r\n');

// Resize the terminal window
ps.resizeTerminal(160, 50);

// Spawn an arbitrary executable
const custom = vt.Create('C:\\Windows\\System32\\wsl.exe', 100, 30);
```

> **Note:** This module only exports on `win32` platforms. Importing on Linux/macOS returns `undefined`. The underlying Win32 APIs (`CreatePseudoConsole`, `ResizePseudoConsole`) require Windows 10 version 1809 (build 17763) or later.
