Minified runtime engine for executing, compiling, and decompiling binary AMT (Intel Active Management Technology) scripts version 0.2.0. Provides a bytecode interpreter that supports variable management, WSMAN operations, and extensible function tables.

## Key Components

### `script_setup(e, t)`
Initializes a script runtime instance from a binary script buffer. Validates the magic number (`612182341`) and version header, then returns a controller object with:
- `reset()` / `start(speed)` / `stop()` — lifecycle controls
- `step()` — executes one instruction per tick, dispatching opcodes 0–25 plus extended function tables
- `getVar(path)` / `setVar(path, value)` — dot-notation variable access
- `xxWsmanReturn` / `xxSignWithDummyCaReturn` — async callbacks for WSMAN and cert operations

### `script_compile(source, errCallback)`
Compiles a human-readable AMT script (newline-delimited text) into binary bytecode. Resolves labels, encodes literals (strings, integers, label references), and prepends the magic header.

### `script_decompile(binary, offset)`
Reverses binary bytecode back into readable source, reconstructing labels and argument types.

### Function Tables
- `script_functionTable1` / `script_functionTableX2` — built-in opcodes (NOP, jump, set, print, JSON ops, WSMAN calls, etc.)
- `script_functionTable2` / `script_functionTableX2` — extended string/encoding utilities (URI encode, MD5, hex, atob/btoa)
- `script_functionTable3` / `script_functionTableX3` — AMT-specific pulls (system status, event log, audit log, certificates, hardware info)

## Usage Example

```javascript
// Compile a script from source text
const binary = script_compile(sourceText, (err) => console.error(err));

// Set up and run the script at 100ms/step
const ctx = script_setup(binary, { myVar: "hello" });
ctx.amtstack = myAmtStackInstance;
ctx.onConsole = (msg) => console.log("[Script]", msg);
ctx.start(100); // step every 100ms

// Or step manually
ctx.reset();
ctx.step();

// Decompile binary back to source
const source = script_decompile(binary, -1);
console.log(source);
```
