Manages automated TLS certificate acquisition and renewal using the ACME protocol (Let's Encrypt, ZeroSSL, or custom ACME providers) via the `acme-client` library.

## Key Components

- **`CreateLetsEncrypt(parent)`** — Factory function that initializes the Let's Encrypt module and returns the `obj` instance
- **`obj.getCertificate(certs, func)`** — Loads existing certificates from disk, applies them to domains, and schedules renewal checks
- **`obj.checkRenewCertificate()`** — Evaluates certificate validity; returns status codes: `0` (OK), `1` (no cert), `2` (expiring <45 days), `3` (missing domains), `4` (request pending)
- **`obj.requestCertificate()`** — Generates a private key and initiates an ACME certificate order; supports Let's Encrypt, ZeroSSL, and custom ACME servers with EAB
- **`challengeCreateFn / challengeRemoveFn`** — Handles HTTP-01 challenge token lifecycle
- **`obj.challenge(token, hostname, func)`** — Responds to HTTP-01 challenge lookups from the redirect web server
- **`obj.log(str)`** — Debug logger that appends timestamped entries to `obj.events` (capped at 200)

## Usage Example

```javascript
// Initialized internally by MeshCentral when letsencrypt config is present
const letsEncrypt = require('./letsencrypt').CreateLetsEncrypt(parent);

// Load and apply certificates at startup
letsEncrypt.getCertificate(certs, function(updatedCerts) {
    // updatedCerts.web.cert and updatedCerts.web.key are populated
    // if a valid LE cert exists for the common name
    startWebServer(updatedCerts);
});

// Serve HTTP-01 challenge responses on port 80
app.get('/.well-known/acme-challenge/:token', function(req, res) {
    letsEncrypt.challenge(req.params.token, req.hostname, function(keyAuth) {
        if (keyAuth) res.send(keyAuth);
        else res.status(404).send('Not found');
    });
});
```

## Configuration (`config.json`)

```json
{
  "letsencrypt": {
    "email": "admin@example.com",
    "production": true,
    "rsakeysize": 2048,
    "names": ["example.com", "mesh.example.com"],
    "zerossl": { "kid": "...", "hmackey": "..." }
  }
}
```

**Requirements:** A redirect server must be active on port 80. Certificates are stored in `<datapath>/letsencrypt-certs/`. Renewal is checked every 24 hours; certificates are renewed when fewer than 45 days remain.

**Source:** [`letsencrypt.js`](https://github.com/flamingo-stack/meshcentral/blob/main/letsencrypt.js)
