Implements the APF (Active Platform Framework) / CIRA (Client Initiated Remote Access) client protocol for connecting Intel AMT devices to a Management Presence Server (MPS) over a secure WebSocket connection.

## Key Components

- **`CreateAPFClient(parent, args)`** — Factory function that creates and returns an APF client object. Requires a valid 36-character `clientuuid` in `args`.
- **`CIRASTATE`** — State machine enum tracking the CIRA handshake lifecycle (`INITIAL` → `PROTOCOL_VERSION_SENT` → `AUTH_SERVICE_REQUEST_SENT` → `AUTH_REQUEST_SENT` → `PFWD_SERVICE_REQUEST_SENT` → `GLOBAL_REQUEST_SENT`).
- **`APFProtocol`** — Enum of APF protocol message type codes including `PROTOCOLVERSION`, `SERVICE_REQUEST`, `USERAUTH_REQUEST`, `CHANNEL_OPEN`, `KEEPALIVE_REQUEST`, and `JSON_CONTROL` (Mesh-specific extension).
- **`onSecureConnect(resp, ws, head)`** — WebSocket connection handler that initializes data accumulation, wires up event listeners, and begins the APF handshake sequence.
- **Send\* functions** — Low-level protocol message builders: `SendProtocolVersion`, `SendServiceRequest`, `SendUserAuthRequest`, `SendGlobalRequestPfwd`, `SendKeepAliveRequest`, `SendKeepAliveReply`, `SendJsonControl`.
- **`ProcessData(socket)`** — Parses and dispatches incoming APF protocol messages from the accumulator buffer.
- **State helpers** — `updateMeiState`, `sendMeiDeactivationState`, `sendStartTlsHostConfigResponse`, `sendStopConfigurationResponse` send JSON control messages to the MPS.

## Usage Example

```javascript
var apfClient = CreateAPFClient(parentModule, {
    clientuuid: '12345678-1234-1234-1234-123456789abc',
    clientname:  'amt-device.local',
    mpsuser:     'admin',
    mpspass:     'Password1!',
    conntype:    1 // optional connection type flag
});

apfClient.onChannelClosed = function(client) {
    console.log('APF channel closed');
};

// After WebSocket upgrade is established:
apfClient.onSecureConnect(response, webSocket, head);

// Send MEI state update at runtime:
apfClient.updateMeiState({ state: 'provisioned' });
```
