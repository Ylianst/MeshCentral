Entry point for the RDP (Remote Desktop Protocol) connection layer, aggregating the MCS (Multipoint Communication Service) and GCC (Generic Conference Control) protocol modules.

## Key Components

| Export | Module | Description |
|--------|--------|-------------|
| `mcs` | `./mcs` | Multipoint Communication Service protocol implementation |
| `gcc` | `./gcc` | Generic Conference Control protocol implementation |

## Usage Example

```javascript
const rdpCore = require('./index');

// Access MCS protocol layer
const mcs = rdpCore.mcs;

// Access GCC protocol layer
const gcc = rdpCore.gcc;
```

## Notes

- Part of the `node-rdpjs` library (GPL v3)
- MCS handles the multi-channel communication layer used in RDP sessions
- GCC manages conference negotiation during the RDP connection handshake
- Source: [`index.js`](https://github.com/flamingo-stack/meshcentral/blob/main/index.js)
