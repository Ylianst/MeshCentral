Implements the Raw encoding decoder for the noVNC VNC client, converting raw pixel data received over a WebSocket into display output line by line.

## Key Components

### `RawDecoder` (default export)
A stateful decoder class for VNC Raw rectangle encoding.

- **`constructor()`** — Initializes `_lines` counter to track remaining scanlines to decode.
- **`decodeRect(x, y, width, height, sock, display, depth)`** — Decodes a raw-encoded rectangle from the socket buffer and blits it to the display. Supports 8-bit (3-bit RGB packed) and 32-bit pixel depths. Returns `true` when the rectangle is fully decoded, or `false` if more socket data is needed (allowing incremental/resumable decoding).

## Usage Example

```javascript
import RawDecoder from './decoders/raw.js';

const decoder = new RawDecoder();

// Called when a Raw-encoded rect arrives from the VNC server
function handleRawRect(x, y, width, height, sock, display, depth) {
    const done = decoder.decodeRect(x, y, width, height, sock, display, depth);

    if (!done) {
        // Insufficient data in buffer; retry when more arrives
        return false;
    }

    // Rectangle fully decoded and blitted to display
    return true;
}
```

## Notes

- **8-bit depth** — Each byte encodes RGB as 2-bit channels (`RR GG BB`), expanded to full 8-bit RGBA.
- **32-bit depth** — Data is used directly; alpha channel is forced to `255` (fully opaque) for all pixels.
- Decoding is **incremental**: `_lines` persists across calls so partial socket reads resume correctly on the next invocation.
