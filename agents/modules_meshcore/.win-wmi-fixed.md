A Windows WMI (Windows Management Instrumentation) query module that wraps the native COM-based WbemLocator and IWbemServices interfaces using generic marshaling, enabling synchronous and asynchronous WQL queries from JavaScript.

## Key Components

- **`CLSID_WbemAdministrativeLocator` / `IID_WbemLocator`** — COM class and interface identifiers for connecting to the WMI service
- **`LocatorFunctions` / `ServiceFunctions` / `ResultsFunctions` / `ResultFunctions`** — COM vtable function name arrays for `IWbemLocator`, `IWbemServices`, `IEnumWbemClassObject`, and `IWbemClassObject` interfaces
- **`QueryAsyncHandler`** — COM callback sink implementing `IWbemObjectSink` (`QueryInterface`, `AddRef`, `Release`, `Indicate`, `SetStatus`) for async WQL query results
- **`enumerateProperties(j, fields)`** — Extracts WMI class object properties by marshaling `IWbemClassObject::Get()` results, handling both scalar VARIANT types and `VT_ARRAY` SafeArray types (integers, booleans, BSTRs, etc.)
- **`OleAut32.SafeArrayAccessData`** — Native proxy call used to access COM SafeArray data for both property name enumeration and array-typed property values
- **`wmi_handlers`** — Registry for tracking active WMI query state

## Usage Example

```javascript
// Internal usage pattern (module is used by higher-level WMI wrappers)
var wmi = require('win-wmi-fixed');

// Query specific WMI class with optional field filtering
wmi.query('root\\cimv2', 'SELECT * FROM Win32_OperatingSystem', ['Caption', 'Version'])
  .then(function(results) {
    results.forEach(function(item) {
      console.log(item.Caption, item.Version);
    });
  })
  .catch(function(err) {
    console.error('WMI query failed:', err);
  });
```
