RRE (Rise-and-Run Encoding) decoder for the noVNC HTML5 VNC client. Handles decoding of RRE-encoded rectangles, which consist of a solid background fill followed by a series of colored sub-rectangles.

## Key Components

### `RREDecoder` Class

- **`constructor()`** — Initializes the decoder with `_subrects` state counter set to `0`, used to track remaining sub-rectangles across partial data reads.
- **`decodeRect(x, y, width, height, sock, display, depth)`** — Decodes a single RRE-encoded rectangle from the socket buffer and renders it to the display. Returns `false` if insufficient data is available (allowing resumption when more data arrives), or `true` on successful completion.

## Decoding Flow

1. **Header phase** — Reads a 4-byte sub-rectangle count and a 4-byte background color, then fills the full rectangle with the background color.
2. **Sub-rectangle phase** — Iterates over each sub-rectangle, reading a 4-byte color and four 2-byte values (`sx`, `sy`, `swidth`, `sheight`), then fills each sub-region offset relative to the parent rectangle's origin.

## Usage Example

```javascript
import RREDecoder from './rre.js';

const decoder = new RREDecoder();

// Called by the VNC client's rect handler
const done = decoder.decodeRect(
    rectX, rectY,       // Rectangle origin
    rectWidth,          // Rectangle dimensions
    rectHeight,
    sock,               // noVNC WebSocket queue
    display,            // noVNC Display instance
    depth               // Color depth
);

if (!done) {
    // Insufficient data; retry when more arrives
}
```
