Provides Base64 encoding and decoding utilities for converting between byte arrays and Base64 strings, derived from Mozilla's SunSpider benchmark suite.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `default` | Object | Namespace object containing encoding/decoding methods and lookup tables |
| `encode(data)` | Method | Converts an array of integers (bytes) to a Base64 string |
| `decode(data, offset)` | Method | Converts a Base64 string back to an array of integers |
| `toBase64Table` | Property | Character lookup table for encoding (64 characters + pad) |
| `toBinaryTable` | Property | Reverse lookup table mapping ASCII codes to 6-bit values |
| `base64Pad` | Property | Padding character (`=`) used for alignment |

## Usage Example

```javascript
import Base64 from './base64.js';

// Encode a byte array to a Base64 string
const bytes = [72, 101, 108, 108, 111]; // "Hello"
const encoded = Base64.encode(bytes);
console.log(encoded); // "SGVsbG8="

// Decode a Base64 string back to a byte array
const decoded = Base64.decode('SGVsbG8=');
console.log(decoded); // [72, 101, 108, 108, 111]

// Decode with an offset to skip leading characters
const withOffset = Base64.decode('xxSGVsbG8=', 2);
console.log(withOffset); // [72, 101, 108, 108, 111]
```

> **Note:** `decode` throws a `Base64-Error` if the input string is corrupted (leftover bits after processing). Illegal characters are logged via the `Log.Error` utility and skipped rather than throwing immediately.
