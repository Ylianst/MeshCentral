Minified JavaScript port of the zlib compression library, providing the foundational constants, error codes, and data structures required by the zlib inflate/deflate modules.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ZLIB.Z_*` flush constants | `number` | Flush modes: `Z_NO_FLUSH`, `Z_PARTIAL_FLUSH`, `Z_SYNC_FLUSH`, `Z_FULL_FLUSH`, `Z_FINISH`, `Z_BLOCK`, `Z_TREES` |
| `ZLIB.Z_*` return codes | `number` | Status codes: `Z_OK (0)`, `Z_STREAM_END (1)`, `Z_NEED_DICT (2)` and errors `-1` through `-6` |
| `ZLIB.Z_DEFLATED` | `number` | Compression method identifier (`8`) |
| `ZLIB.z_stream` | `constructor` | Stream state object holding I/O buffers, byte counts, checksum, and error state |
| `ZLIB.gz_header` | `constructor` | gzip header metadata object (timestamps, OS flags, filename, comments, CRC flag) |
| `ZLIB.common_initialized` | `boolean` | Guard flag preventing re-initialization when the script is loaded multiple times |

## Usage Example

```javascript
// Initialize a zlib stream
var stream = new ZLIB.z_stream();
stream.input_data  = compressedBytes;
stream.avail_in    = compressedBytes.length;
stream.avail_out   = 65536;

// Check return codes from inflate/deflate operations
var result = ZLIB.inflate(stream, ZLIB.Z_FINISH);

if (result === ZLIB.Z_STREAM_END) {
  console.log("Decompression complete:", stream.output_data);
} else if (result === ZLIB.Z_DATA_ERROR) {
  console.error("Corrupt or invalid data");
} else if (result !== ZLIB.Z_OK) {
  console.error("zlib error:", stream.msg);
}

// Inspect a gzip header
var header = new ZLIB.gz_header();
console.log("OS byte:", header.os);   // 255 = unknown
```

> **Note:** This file is an initialization stub. It only sets up the `ZLIB` namespace once (guarded by `common_initialized`). Actual compress/decompress logic is provided by companion modules (e.g., `inflate-min.js`, `deflate-min.js`).
