Queries Windows Security Center (WSC) via the `Wscapi.dll` native API to retrieve and monitor the health status of the system's firewall, antivirus, and auto-update providers.

## Key Components

| Export / Symbol | Description |
|---|---|
| `module.exports` | EventEmitter object exposing security status and change events (Windows only) |
| `getStatus()` | Returns an object with `firewall`, `antiVirus`, and `autoUpdate` health strings |
| `statusString(val)` | Maps WSC health integer codes to `'OK'`, `'WARNING'`, `'PROBLEM'`, or `'UNKNOWN'` |
| `changed` event | Emitted when WSC detects a security provider status change via `WscRegisterForChanges` |
| `WSC_SECURITY_PROVIDER_*` | Constants for provider type bitmasks (Firewall, Antivirus, AutoUpdate, Antispyware) |
| `WSC_SECURITY_PROVIDER_HEALTH_*` | Constants mapping to WSC health states (Good, NotMonitored, Poor, Snooze) |

## Usage Example

```javascript
// Only supported on Windows (win32 platform)
const secCenter = require('./win-securitycenter');

// Get current security status snapshot
const status = secCenter.status();
console.log(status.firewall);   // 'OK', 'WARNING', 'PROBLEM', or 'UNKNOWN'
console.log(status.antiVirus);  // 'OK', 'WARNING', 'PROBLEM', or 'UNKNOWN'
console.log(status.autoUpdate); // 'OK', 'WARNING', 'PROBLEM', or 'UNKNOWN'

// Listen for real-time security status changes
secCenter.on('changed', () => {
    const updated = secCenter.status();
    console.log('Security status changed:', updated);
});
```

> **Platform Note:** This module throws `'win-securitycenter not supported on this platform'` on non-Windows systems. Guard with `process.platform === 'win32'` before requiring.
