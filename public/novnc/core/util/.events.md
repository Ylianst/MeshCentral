Cross-browser event and pointer capture utilities for the noVNC HTML5 VNC client, providing normalized pointer event access, event propagation control, and a polyfill for `Element.setCapture()`.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `getPointerEvent(e)` | Function | Normalizes mouse and touch events, returning the relevant pointer from `changedTouches`, `touches`, or the event itself |
| `stopEvent(e)` | Function | Stops both propagation and default behavior of an event |
| `setCapture(target)` | Function | Captures mouse events to a target element; uses native `setCapture()` if available, otherwise injects a full-viewport proxy `<div>` |
| `releaseCapture()` | Function | Releases mouse capture and cleans up the proxy element and listeners |

## Usage Example

```javascript
import { getPointerEvent, stopEvent, setCapture, releaseCapture } from './events.js';

// Normalize pointer position across mouse and touch
element.addEventListener('mousedown', (e) => {
    const pointer = getPointerEvent(e);
    console.log(pointer.clientX, pointer.clientY);

    // Lock mouse events to this element during drag
    setCapture(element);
    stopEvent(e);
});

element.addEventListener('mouseup', (e) => {
    releaseCapture();
});
```

## Notes

- `setCapture` creates a fixed, full-viewport `<div id="noVNC_mouse_capture_elem">` as a proxy when native `Element.setCapture()` is unavailable (modern browsers)
- A `MutationObserver` mirrors the captured element's cursor style onto the proxy overlay for a seamless user experience
- Capture is automatically released on `mouseup` via the proxy, preventing stuck capture states
- `releaseCapture` preserves a reference to the captured element (`_elementForUnflushedEvents`) to correctly handle already-queued events (e.g. `contextmenu` in Edge) before nulling the pointer
