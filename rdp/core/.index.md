Barrel/entry-point module for the `node-rdpjs` core library that aggregates and re-exports the primary subsystem modules.

## Key Components

| Export | Description |
|--------|-------------|
| `layer` | Protocol layer abstractions for RDP communication |
| `type` | Type definitions and serialization primitives |
| `log` | Logging utilities |
| `error` | Error types and handling |
| `rle` | Run-Length Encoding (RLE) compression for bitmap data |

## Usage Example

```javascript
const rdp = require('./index');

// Access individual subsystems via the aggregated export
const logger = rdp.log;
const types  = rdp.type;

// Use RLE decompression for bitmap handling
rdp.rle.decompress(compressedBuffer, width, height);

// Create protocol layer
const protocolLayer = new rdp.layer.Layer();

// Handle errors
try {
  // ... RDP operations
} catch (e) {
  if (e instanceof rdp.error.ProtocolError) {
    logger.error(e.message);
  }
}
```

## Notes

- This file acts as the **single entry point** for the `node-rdpjs` core package — consumers only need to `require` this module to access all subsystems.
