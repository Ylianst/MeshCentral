Minified bundle of Font Awesome Free 6.7.2, providing SVG icon definitions and the core runtime for icon rendering in web applications.

## Key Components

- **Icon style mappings** – Resolves CSS class aliases (e.g., `fas`, `far`, `fab`) to canonical style names (`solid`, `regular`, `brands`) across four families: `classic`, `duotone`, `sharp`, and `sharp-duotone`
- **Global namespace** (`___FONT_AWESOME___`) – Attaches `styles`, `hooks`, and `shims` to `window` for cross-script coordination
- **`u()` / `addPack()`** – Registers icon packs into the shared style registry; supports a hook bypass via `skipHooks`
- **`d()`** – Normalizes icon definitions, flattening `{ iconName, icon }` objects to a plain lookup map
- **`o()`** – Returns a `Proxy` wrapping the family maps so unknown families fall back to `classic`
- **Built-in icon data** – Includes several SVG path definitions inline (e.g., `monero`, `hooli`, `yelp`, `cc-visa`, `aws`, `redhat`)

## Usage Example

Font Awesome loads this file automatically when included via a `<script>` tag or bundler. No direct API calls are typically needed, but you can inspect or extend the registry:

```javascript
// Access the shared Font Awesome global
const fa = window["___FONT_AWESOME___"];

// Register a custom icon pack
fa.hooks.addPack("fas", {
  "my-icon": {
    iconName: "my-icon",
    icon: [512, 512, [], "e001", "M0 0h512v512H0z"]
  }
});

// Inspect registered styles
console.log(fa.styles["fas"]);
```
