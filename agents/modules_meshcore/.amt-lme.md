`amt-lme.js` implements the Intel AMT Local Management Engine (LME) interface, handling APF (AMT Port Forwarding) protocol communication over HECI (Host Embedded Controller Interface). It manages TCP port forwarding between the host OS and Intel AMT firmware, enabling local manageability services (LMS).

## Key Components

- **`lme_object`** — Channel state object tracking AMT channel IDs, window sizes, local port, and connection status.
- **`stream_bufferedWrite`** — Custom duplex-style buffered stream supporting chunked reads and drain events for flow control.
- **`lme_heci`** — Main LME manager class that wraps a HECI connection and implements the full APF protocol state machine, including:
  - `APF_SERVICE_REQUEST` / `APF_SERVICE_ACCEPT` — Handshakes for `pfwd@amt.intel.com` and `auth@amt.intel.com`.
  - `APF_GLOBAL_REQUEST` — Handles `tcpip-forward` (binds local TCP servers per AMT port) and `cancel-tcpip-forward`.
  - `APF_CHANNEL_OPEN_CONFIRMATION` — Finalizes channel setup and wires buffered streams.
- **APF protocol constants** — Numeric opcodes (`APF_CHANNEL_OPEN`, `APF_CHANNEL_DATA`, etc.) per the Intel AMT Port Forwarding Protocol Reference.

## Usage Example

```javascript
var lme = require('./amt-lme');

// Create LME instance (optionally enable debug/bind-any modes)
var lmeInstance = new lme.lme_heci({ debug: false, bindany: false });

lmeInstance.on('connect', function () {
    console.log('LME connected to AMT firmware');
});

lmeInstance.on('bind', function (boundPorts) {
    console.log('AMT ports bound:', boundPorts);
});

lmeInstance.on('error', function (err) {
    console.error('LME error:', err);
});
```

> **Note:** Requires the native `heci` module (Intel MEI driver access) and optionally `amt-xml` for XML parsing. Set `lme_port_offset = -100` or pass `{ debug: true }` to redirect ports for LMS debugging without root privileges.
