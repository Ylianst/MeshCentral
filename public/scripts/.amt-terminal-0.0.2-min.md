A VT100/ANSI terminal emulator for Intel AMT (Active Management Technology) remote sessions, rendering terminal output as HTML within a specified DOM element.

## Key Components

- **`CreateAmtRemoteTerminal(divId, options)`** — Factory function that creates and returns a terminal instance bound to a DOM element
- **`t.Init(width, height)`** — Initializes the terminal buffer (default 80×25), sets up character/color arrays, and triggers initial draw
- **`t.ProcessData(data)`** — Main entry point for incoming data; handles UTF-8 decoding and feeds characters to the VT100 parser
- **`t.TermDraw()`** — Renders the terminal state to HTML, outputting colored `<span>` elements with CSS styling for foreground/background colors
- **`t.TermDrawLine(prefix, row, suffix)`** — Renders a single terminal row as an HTML string with color attributes
- **`t.TermHandleKeyDown/KeyUp/Keys`** — Keyboard event handlers that translate browser key events to VT100 escape sequences
- **`y(char, code)`** — Internal VT100/ANSI escape sequence state machine (handles CSI sequences, cursor movement, color codes, scrolling)
- **`B(char)`** — Internal character renderer that handles control characters (`\b`, `\t`, `\n`, `\r`) and writes to the screen buffer
- **`t.TermResetScreen()`** — Resets all terminal state to defaults
- **Color tables `K` / `D`** — Code page 437 / OEM character translation tables for high-byte characters

## Usage Example

```javascript
// Create a terminal in a div with id="terminal"
var term = CreateAmtRemoteTerminal("terminal", {
  protocol: 1,          // 1 = AMT SOL, default
  terminalEmulation: 1  // 1 = CP437, 2 = OEM
});

// Initialize to 80x25
term.Init(80, 25);

// Wire up to a WebSocket or AMT data source
term.parent = { send: function(data) { ws.send(data); } };

// Feed incoming bytes to the terminal
ws.onmessage = function(e) { term.ProcessData(e.data); };

// Handle keyboard input
document.getElementById("terminal").addEventListener("keydown", term.TermHandleKeyDown);
```

- Supports 16-color ANSI palette, reverse video, bold/bright attributes, and scroll regions
- Back-buffer stores up to 800 lines of scrollback history
- Designed to integrate with MeshCentral's AMT Serial-over-LAN (SOL) sessions
