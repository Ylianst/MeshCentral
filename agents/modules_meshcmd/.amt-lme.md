Implements the Intel AMT Local Management Engine (LME) interface, handling APF (AMT Port Forwarding) protocol communication between the MeshCentral server and Intel AMT hardware via HECI (Host Embedded Controller Interface).

## Key Components

- **`lme_object`** — Channel state tracker storing AMT/local IDs, window sizes, port, and status (`LME_CS_FREE`, `LME_CS_CONNECTED`)
- **`stream_bufferedWrite`** — Buffered duplex stream with `read`/`write` support and drain/readable events for managing channel data flow
- **`lme_heci`** — Main LME controller that connects to the HECI driver and processes APF protocol commands:
  - `APF_SERVICE_REQUEST` — Accepts `pfwd@amt.intel.com` and `auth@amt.intel.com` services
  - `APF_GLOBAL_REQUEST` — Handles `tcpip-forward` (binds local TCP server ports) and `cancel-tcpip-forward`
  - `APF_CHANNEL_OPEN_CONFIRMATION` — Establishes forwarding channels between local sockets and AMT

**APF Protocol Constants** — Numeric command identifiers (1–192) per the [Intel AMT Port Forwarding Protocol Reference](https://software.intel.com/sites/manageability/AMT_Implementation_and_Reference_Guide)

## Usage Example

```javascript
var lme = require('./amt-lme');

// Create LME instance (connects to HECI driver)
var lmeInstance = new lme.lme_heci({ debug: false, bindany: false });

lmeInstance.on('connect', function () {
    console.log('Connected to AMT LME');
});

lmeInstance.on('bind', function (boundPorts) {
    // Fires when AMT requests TCP port forwarding (e.g., port 16992/16993)
    console.log('Ports bound:', boundPorts);
});

lmeInstance.on('error', function (err) {
    console.error('LME error:', err);
});
```

> **Note:** Requires `heci` native module (Intel ME driver access) and optionally `amt-xml`. Set `debug: true` to offset ports by -100 for LMS debugging, or `bindany: true` to listen on all interfaces instead of loopback only.
