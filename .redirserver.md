HTTP redirect server module for MeshCentral that handles HTTP-to-HTTPS redirection, Let's Encrypt ACME challenges, and certificate serving on a configurable port.

## Key Components

- **`CreateRedirServer(parent, db, args, func)`** — Factory function that constructs and starts the HTTP redirect server instance
- **`performRedirection(req, res)`** — Redirects all HTTP requests to HTTPS, respecting alias ports
- **`hookMainWebServer(certs)`** — Called after the main HTTPS server starts; attaches AMT event, mesh settings, mesh agent, and domain redirect handlers
- **`CheckListenPort(port, addr, func)`** — Finds an available TCP port by incrementing from the specified port
- **`StartRedirServer(port, addr)`** — Binds the Express app to the resolved port and logs server state
- **`getCleanHostname(req)`** — Sanitizes and normalizes the request hostname, supporting `X-Forwarded-Host` headers

## Usage Example

```javascript
const redirServer = require('./redirserver');

redirServer.CreateRedirServer(parent, db, {
    port: 443,          // Main HTTPS port
    redirport: 80,      // HTTP redirect port
    redirportbind: null // Bind address (null = all interfaces)
}, function (port) {
    console.log('Redirect server started on port', port);
});

// After HTTPS server loads certificates, hook into the redirect server
redirServerObj.hookMainWebServer(certificates);
```

## Security Headers Applied

All HTTP responses include:

| Header | Value |
|---|---|
| `Strict-Transport-Security` | `max-age=60000; includeSubDomains` |
| `X-Frame-Options` | `SAMEORIGIN` |
| `X-Content-Type-Options` | `nosniff` |
| `Content-Security-Policy` | `default-src 'none'` |
| `X-XSS-Protection` | `1; mode=block` |

> **Note:** Let's Encrypt ACME challenge requests (`/.well-known/acme-challenge/`) are intercepted before redirection and handled directly via `parent.letsencrypt.challenge()`.
