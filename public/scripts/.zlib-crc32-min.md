Minified CRC-32 checksum implementation that extends the `ZLIB` global namespace with CRC-32 calculation and combination utilities, using a precomputed 256-entry lookup table for efficient computation.

## Key Components

| Export | Signature | Description |
|--------|-----------|-------------|
| `ZLIB.crc32` | `(crc, data, offset, length)` | Computes CRC-32 over a slice of a string or byte array using an 8-byte-unrolled loop |
| `ZLIB.crc32_combine` | `(crc1, crc2, len2)` | Combines two independent CRC-32 values as if the underlying data were concatenated |
| `r` (internal) | 256-element `Array` | Precomputed CRC-32 lookup table (ISO 3309 polynomial `0xEDB88320`) |
| `e` (internal) | `(table, value)` | GF(2) matrix–vector multiply used by `crc32_combine` |
| `n` (internal) | `(out, src)` | Squares a GF(2) matrix, enabling O(log n) length-doubling in `crc32_combine` |

## Usage Example

```javascript
// Single-pass CRC over a byte array
const buf = new Uint8Array([0x48, 0x65, 0x6c, 0x6c, 0x6f]); // "Hello"
const checksum = ZLIB.crc32(0, buf, 0, buf.length);
console.log(checksum.toString(16)); // e.g. f7d18982

// Single-pass CRC over a plain string
const strChecksum = ZLIB.crc32(0, "Hello", 0, 5);

// Combine two independently computed CRCs
const crc1 = ZLIB.crc32(0, buf1, 0, buf1.length);
const crc2 = ZLIB.crc32(0, buf2, 0, buf2.length);
const combined = ZLIB.crc32_combine(crc1, crc2, buf2.length);
```

> **Dependency:** `ZLIB` global must be defined (by `zlib.js`) before this file is loaded; the script calls `alert()` and aborts if it is missing.
