Brief description of `translate.js`: A command-line utility for MeshCentral that extracts translatable strings from Handlebars templates and JavaScript files, manages translation JSON files, and minifies web assets for the MeshCentral platform.

## Key Components

| Export / Function | Description |
|---|---|
| `setup()` | Installs required npm modules (`jsdom`, `esprima`, `html-minifier-terser`) before starting |
| `startEx(argv)` | Main async entry point; parses CLI commands and dispatches to handlers |
| `extractFromHtml(file)` | Extracts translatable strings from `.handlebars` and `.html` source files |
| `extract(langFile, sources)` | Writes extracted strings to a translation JSON file |
| `translateSingleThreaded(...)` | Applies a translation JSON to source files using a worker thread |
| `merge(src, target, lang)` | Merges a language from one translation file into another |
| `totext` / `fromtext` | Converts translation files to/from plain text format |
| `meshCentralSourceFiles` | Array of all Handlebars templates and email files targeted for translation |
| `minifyMeshCentralSourceFiles` | Array of files targeted for minification (views + public JS) |

**Supported CLI Commands:** `check`, `extract`, `extractall`, `translate`, `translateall`, `minify`, `minifyall`, `minifydir`, `merge`, `totext`, `fromtext`, `remove`

## Usage Example

```bash
# Check what strings can be extracted from a file
node translate.js CHECK ../views/default.handlebars

# Extract strings from source files into a translation JSON
node translate.js EXTRACT translate.json ../views/default.handlebars ../views/login.handlebars

# Extract all MeshCentral strings at once
node translate.js EXTRACTALL translate.json

# Translate all source files using a translation file
node translate.js TRANSLATEALL translate.json fr

# Minify all MeshCentral web assets
node translate.js MINIFYALL

# Export a language to plain text for editing
node translate.js TOTEXT translate.json french.txt fr

# Import translated plain text back
node translate.js FROMTEXT translate.json french.txt fr
```

**Source:** [`translate.js`](https://github.com/flamingo-stack/meshcentral/blob/main/translate.js) — Requires Node.js v8+; uses `worker_threads` for parallel translation on Node.js v12+.
