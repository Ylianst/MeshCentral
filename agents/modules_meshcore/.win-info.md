Windows-only utility module that queries system information including installed software, antivirus status, Windows Defender settings, pending reboots, and disk fragmentation data.

## Key Components

| Export | Description |
|--------|-------------|
| `qfe()` | Returns installed Quick Fix Engineering (hotfix/patch) records via WMI |
| `av()` | Queries `SecurityCenter2` for antivirus products, validating executable paths and returning enabled/updated status |
| `defrag(options)` | Runs `defrag.exe /A` on a specified volume and returns size, free space, and fragmentation stats as a Promise |
| `pendingReboot()` | Checks registry keys for pending reboot reasons (Component Based Servicing, Windows Update, File Rename, System Rename) |
| `installedApps()` | Spawns a child process to enumerate installed Win32 apps from the registry Uninstall key, returning a Promise |
| `installedStoreApps()` | Queries WMI for installed Microsoft Store (`Win32_InstalledStoreProgram`) applications |
| `defender()` | Returns Windows Defender status including real-time protection, tamper protection, and signature version/date |

## Usage Example

```javascript
const winInfo = require('./win-info');

// Synchronous calls
const patches = winInfo.qfe();
console.log('Installed patches:', patches.length);

const rebootReason = winInfo.pendingReboot();
if (rebootReason) console.log('Reboot pending due to:', rebootReason);

const avProducts = winInfo.av();
avProducts.forEach(p => console.log(`${p.product} - enabled: ${p.enabled}, updated: ${p.updated}`));

// Async calls
winInfo.defrag({ volume: 'C:' }).then(result => {
    console.log('Volume:', result.volume);
    console.log('Free:', result.free);
    console.log('Fragmented:', result.fragmented);
});

winInfo.installedApps().then(apps => {
    apps.forEach(app => console.log(app.name, app.version));
});
```

> **Note:** All exports throw a platform error on non-Windows systems. Ensure code runs on `win32` or guard with `process.platform === 'win32'` before calling.
