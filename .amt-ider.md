Handles server-side Intel AMT IDE Redirection (IDER) sessions over WebSocket, enabling remote disk image booting for managed devices via MeshCentral.

## Key Components

- **`CreateAmtIderSession(parent, db, ws, req, args, domain, user)`** — Factory function that initializes an IDER session for an authenticated user over an established WebSocket connection.

### WebSocket Command Handlers

| Action | Description |
|---|---|
| `ping` | Responds with a `pong` keepalive |
| `selector` | Returns UI prompt for disk image selection |
| `selectorResponse` | Initiates the AMT IDER redirect session |

### Internal Functions

- **`obj.close(arg)`** — Gracefully (`1`) or forcefully (`2`) terminates the WebSocket or underlying TCP socket
- **`processWebSocketData(msg)`** — Parses and routes incoming JSON commands from the browser
- **`onIderStateChange(sender, state)`** — Callback fired when the IDER redirect connection state changes
- **`iderSectorStats(mode, dev, total, start, len)`** — Callback reporting sector-level read/write statistics during redirection

## Usage Example

```javascript
// Instantiated by the MeshCentral server on WebSocket upgrade
const { CreateAmtIderSession } = require('./amt-ider');

const session = CreateAmtIderSession(parent, db, ws, req, args, domain, user);

// Session lifecycle is driven by WebSocket messages from the browser client.
// The browser sends a 'selectorResponse' action to trigger the IDER connection:
ws.send(JSON.stringify({
    action: 'selectorResponse',
    args: {
        floppyPath: '/images/boot.img',
        cdromPath: '/images/os.iso',
        iderStart: 1
    }
}));
```

> **Note:** The `selectorResponse` handler contains placeholder (`TODO`) logic — disk image selection and session parameters are currently hardcoded and intended for future implementation. See the source at [`amt-ider.js`](https://github.com/flamingo-stack/meshcentral/blob/main/amt-ider.js).
