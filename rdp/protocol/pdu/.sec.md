Implements the RDP security layer (`sec.js`) for node-rdpjs, handling encryption key derivation, security headers, client info packets, and license negotiation within the RDP protocol stack.

## Key Components

### Constants
- **`SecurityFlag`** — Bitmask flags for RDP security headers (e.g., `SEC_ENCRYPT`, `SEC_INFO_PKT`, `SEC_LICENSE_PKT`)
- **`InfoFlag`** — Client capability flags (mouse, Unicode, autologon, audio, etc.)
- **`PerfFlag`** — Performance flags controlling visual features (wallpaper, animations, theming)
- **`AfInet`** — Address family constants for client address fields

### Cryptographic Helpers
- **`saltedHash(input, salt, salt1, salt2)`** — Computes SHA1+MD5 salted hash per [MS-RDPBCGR §5.3.5](http://msdn.microsoft.com/en-us/library/cc241992.aspx)
- **`finalHash(key, random1, random2)`** — MD5 hash of key + two randoms
- **`masterSecret(secret, random1, random2)`** — Derives RDP master secret using A/BB/CCC salt inputs
- **`macData(macSaltKey, data)`** — Computes MAC checksum for packet integrity

### Data Structures
- **`rdpInfos(extendedInfoConditional)`** — Builds the client info PDU (credentials, domain, shell path)
- **`rdpExtendedInfos(opt)`** — Extended info for RDP5+ (client address, timezone, performance flags)
- **`securityHeader()`** — Two-field security header component (`securityFlag`, `securityFlagHi`)

### Classes
- **`Sec(transport, fastPathTransport)`** — Base security layer; handles send/receive with optional encryption flag
- **`Client(transport, fastPathTransport)`** — Extends `Sec`; manages RDP client connect flow, sends info packet, handles license negotiation

## Usage Example

```javascript
var sec = require('./sec');

// Create client security layer over an MCS transport
var client = new sec.Client(mcsTransport, fastPathTransport);

// Client automatically sends SEC_INFO_PKT on 'connect' event
// Set credentials before connecting:
client.infos.obj.userName.value = Buffer.from('Administrator\x00', 'ucs2');
client.infos.obj.password.value = Buffer.from('P@ssw0rd\x00', 'ucs2');

// Listen for decrypted data from the security layer
client.on('data', function(stream) {
  // handle incoming RDP PDU
});

client.on('fastPathData', function(secFlag, stream) {
  // handle fast-path input/output PDUs
});
```
