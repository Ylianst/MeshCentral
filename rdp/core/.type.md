Binary stream serialization/deserialization type system for the RDP protocol implementation, providing a hierarchy of typed primitives that can be read from and written to binary streams.

## Key Components

| Export | Description |
|--------|-------------|
| `Stream` | Buffer wrapper with offset tracking for sequential read/write operations |
| `CallableValue` | Base class supporting both static values and dynamic function-based values |
| `Type` | Abstract base with conditional, optional, and constant read/write support |
| `Component` | Composite type that aggregates multiple sub-types (tree node) |
| `SingleType` | Leaf type backed by a fixed-width Buffer read/write callback |
| `UInt8` | 1-byte unsigned integer |
| `UInt16Le` / `UInt16Be` | 2-byte unsigned integer (little/big endian) |
| `UInt32Le` / `UInt32Be` | 4-byte unsigned integer (little/big endian) |
| `BinaryString` | Variable-length raw buffer type |
| `Factory` | Dynamic type built at read/write time via a factory function |

## Usage Example

```javascript
var type = require('./type');

// Define a composite message structure
var message = new type.Component({
    version: new type.UInt8(1, { constant: true }),
    length:  new type.UInt16Le(0),
    payload: new type.BinaryString(Buffer.from('hello'))
});

// Serialize to stream
var stream = message.toStream();

// Deserialize from a raw buffer
var incoming = new type.Stream(rawBuffer);
message.read(incoming);
console.log(message.obj.version.value); // 1

// Dynamic value via function
var dynamic = new type.UInt32Le(function() { return Date.now() & 0xFFFFFFFF; });
```

## Type Options

All types accept an `opt` object:

| Option | Effect |
|--------|--------|
| `conditional` | Function — skip read/write when returns falsy |
| `optional` | Skip read if stream has insufficient data |
| `constant` | Validate read value matches the original; throws `ProtocolError` on mismatch |
| `readLength` | Slice the stream to a fixed length before reading (used by `Component` and `BinaryString`) |
