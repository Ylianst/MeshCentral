Browser feature detection module for the noVNC HTML5 VNC client, providing runtime checks for touch support, cursor URI capabilities, scrollbar layout, OS platform, browser identity, and rendering engine.

## Key Components

### Exported Constants
- **`isTouchDevice`** — Boolean flag detecting touch support via `ontouchstart`, `navigator.maxTouchPoints`, and a live `touchstart` listener that updates the value on first touch
- **`dragThreshold`** — Pixel threshold for drag gestures, scaled by `devicePixelRatio`
- **`supportsCursorURIs`** — Boolean indicating whether the browser supports `data:` URI scheme cursors
- **`hasScrollbarGutter`** — Boolean indicating whether the browser renders scrollbars that consume layout space

### OS Detection Functions
- `isMac()`, `isWindows()`, `isIOS()`, `isAndroid()`, `isChromeOS()`

### Browser Detection Functions
- `isSafari()`, `isFirefox()`, `isChrome()`, `isChromium()`, `isOpera()`, `isEdge()`

### Rendering Engine Functions
- `isGecko()`, `isWebKit()`, `isBlink()`

## Usage Example

```javascript
import {
    isTouchDevice,
    dragThreshold,
    supportsCursorURIs,
    hasScrollbarGutter,
    isMac,
    isChrome
} from './browser.js';

// Adjust UI for touch vs. pointer input
if (isTouchDevice) {
    enableTouchControls();
}

// Use custom cursors only when supported
if (supportsCursorURIs) {
    canvas.style.cursor = `url("${cursorDataURI}") 2 2, default`;
}

// Apply macOS-specific keyboard shortcuts
if (isMac()) {
    bindKey('Meta+C', handleCopy);
}

// Adjust layout when scrollbars consume space
if (hasScrollbarGutter) {
    container.style.paddingRight = `${scrollbarWidth}px`;
}
```

> **Note:** Browser/OS detection functions should be used sparingly. Prefer feature detection (e.g., `supportsCursorURIs`) over platform sniffing where possible.
