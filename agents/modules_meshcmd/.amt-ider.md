Implements Intel AMT IDE Redirection (IDER) protocol, enabling remote boot of AMT-managed devices from virtual floppy or CD-ROM images over a network connection.

## Key Components

- **`CreateAmtRemoteIder()`** — Factory function returning an IDER session object with protocol state management
- **`obj.Start()`** — Initializes session counters and sends the `OPEN_SESSION` (0x40) command to begin IDER negotiation
- **`obj.Stop()`** — Tears down the IDER session and delegates to the parent transport
- **`obj.ProcessData(data)`** — Accumulates incoming bytes and dispatches complete IDER frames via `ProcessDataEx()`
- **`obj.ProcessDataEx()`** — Parses IDER command frames (e.g., `0x41` OPEN_SESSION) and validates sequence numbers
- **`obj.SendCommand(cmdid, data, completed, dma)`** — Frames and transmits an IDER command with sequence tracking
- **`obj.SendCommandEndResponse()`** — Sends SCSI sense/status responses (0x51)
- **`obj.SendDataToHost()`** — Sends SCSI read data (0x54) to the AMT device
- **`obj.SendGetDataFromHost()`** — Requests a SCSI write chunk (0x52) from the host
- **`obj.SendDisableEnableFeatures()`** — Sends boot trigger commands (0x48) — OnReboot, Graceful, or Now
- **Pre-defined `Buffer` constants** — Static Mode Sense response arrays for floppy, LS-120, and CD-ROM device emulation

## Usage Example

```javascript
const CreateAmtRemoteIder = require('./amt-ider');

const ider = CreateAmtRemoteIder();
ider.parent = parentTransport; // must expose .xxSend() and .Stop()
ider.floppy = { size: floppyBuffer.length, /* read method */ };
ider.cdrom = null;
ider.iderStart = 0; // 0 = OnReboot, 1 = Graceful, 2 = Now
ider.debug = true;

// Called by parent transport on connection state change
ider.xxStateChange(3); // 3 = connected → triggers Start()
```

## Notes

- Protocol ID is `3` (IDER); sequence numbers are validated per-frame and out-of-order frames trigger a stop
- Supports virtual **floppy** (512-byte sectors) and **CD-ROM** (2048-byte sectors) images
- `sectorStats` callback (optional) receives sector counts for progress reporting
