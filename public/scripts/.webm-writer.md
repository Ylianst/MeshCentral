Provides a writable stream interface over an `ArrayBuffer` for encoding binary data, plus a `BlobBuffer` class for managing sequential or overwrite-capable blob-based I/O — used to construct WebM video files in the browser or Node.js.

## Key Components

### `ArrayBufferDataStream`
A low-level binary stream writer backed by a `Uint8Array`:

| Method | Description |
|---|---|
| `seek(offset)` | Move write cursor to an absolute position |
| `writeByte(b)` / `writeU8(b)` | Write a single byte |
| `writeU16BE(u)` | Write a 16-bit unsigned int, big-endian |
| `writeDoubleBE(d)` | Write a 64-bit float, big-endian |
| `writeFloatBE(d)` | Write a 32-bit float, big-endian |
| `writeString(s)` | Write ASCII string bytes |
| `writeEBMLVarInt(i)` | Write EBML variable-length integer (auto-sized) |
| `writeUnsignedIntBE(u, width?)` | Write unsigned int, big-endian |
| `measureEBMLVarInt(val)` | Returns byte width needed for EBML VINT encoding |
| `measureUnsignedInt(val)` | Returns byte width needed for the value |
| `getAsDataArray()` | Returns a `Uint8Array` view up to current position |

### `BlobBuffer`
A promise-based sequential buffer supporting both in-memory and file-backed (`FileWriter` / Node.js `fs`) writes with limited overwrite support.

## Usage Example

```javascript
// ArrayBufferDataStream — write EBML-encoded data
var stream = new ArrayBufferDataStream(64);
stream.writeString("webm");
stream.writeEBMLVarInt(1000);
stream.writeDoubleBE(30.0); // frame rate
var bytes = stream.getAsDataArray();

// BlobBuffer — append blobs sequentially
var buf = new BlobBuffer(require('fs'))(fd);
buf.write(new Uint8Array([0x1A, 0x45, 0xDF, 0xA3])); // EBML header bytes
```

## Notes

- Exported as `module.exports` in Node.js; attached to `window` in browsers.
- EBML VINT encoding supports up to 35-bit values (~32 GB addressable range).
- `BlobBuffer` overwrites must not cross previously written block boundaries.
