Handles multi-touch gesture recognition for noVNC's HTML5 VNC client, translating raw touch events into high-level gesture events (tap, drag, pinch, etc.).

## Key Components

**Constants**
- `GH_ONETAP`, `GH_TWOTAP`, `GH_THREETAP` — tap gesture flags
- `GH_DRAG`, `GH_TWODRAG`, `GH_PINCH`, `GH_LONGPRESS` — motion gesture flags
- `GH_INITSTATE` — bitmask with all gestures initially possible
- `GH_MOVE_THRESHOLD`, `GH_ANGLE_THRESHOLD` — movement/direction sensitivity thresholds

**`GestureHandler` Class**
- `attach(target)` — binds `touchstart`, `touchmove`, `touchend`, `touchcancel` listeners to a DOM element
- `detach()` — removes all listeners and clears pending timeouts
- `_touchStart(id, x, y)` — tracks new touch points; eliminates impossible gestures via bitmask state
- `_touchMove(id, x, y)` — updates position/angle data; resolves PINCH vs. TWODRAG via angle delta comparison
- `_touchEnd(id, x, y)` — finalizes gesture detection; fires `gesturestart`/`gestureend` events
- `_hasDetectedGesture()` — returns `true` when state bitmask resolves to exactly one gesture (single bit set)
- `_pushEvent(type)` — dispatches custom gesture events to the target element

## Usage Example

```javascript
import GestureHandler from './gesturehandler.js';

const handler = new GestureHandler();
const canvas = document.getElementById('vnc-canvas');

handler.attach(canvas);

canvas.addEventListener('gesturestart', (e) => {
    console.log('Gesture started:', e.detail.type);
});

canvas.addEventListener('gesturemove', (e) => {
    if (e.detail.type === 'pinch') {
        console.log('Pinch scale:', e.detail.scale);
    }
});

canvas.addEventListener('gestureend', (e) => {
    console.log('Gesture ended:', e.detail.type);
});

// Cleanup when done
handler.detach();
```
