Automatically generated lookup table mapping Unicode codepoints to X11/RFB keysym values, derived from the X11 `keysymdef.h` header file.

## Key Components

- **`codepoints`** — A large static object mapping Unicode codepoints (hex keys) to their corresponding X11 keysym values (hex values), covering Latin Extended, Greek, Cyrillic, Hebrew, Arabic, and other character sets used in RFB (Remote Framebuffer Protocol) keyboard event handling.

- **Lookup functions** (referenced at bottom of file) — Utility functions that use the `codepoints` table to convert between Unicode and keysym representations at runtime.

## Usage Example

```javascript
import { codepoints } from './keysymdef.js';

// Look up the X11 keysym for Unicode codepoint U+0160 (Š / Latin capital S with caron)
const keysym = codepoints[0x0160]; // → 0x01a9 (XK_Scaron)

// Convert a character to its keysym
function unicodeToKeysym(codepoint) {
    if (codepoints[codepoint] !== undefined) {
        return codepoints[codepoint];
    }
    // Fallback: Unicode codepoints in 0x0100–0x10FFFF map directly
    if (codepoint >= 0x0100) {
        return codepoint | 0x01000000;
    }
    return codepoint;
}

const keysym = unicodeToKeysym('Š'.codePointAt(0));
```
