Minified build of the [Moment.js](https://momentjs.com/) date/time library, providing comprehensive date parsing, manipulation, formatting, and localization utilities for JavaScript environments.

## Key Components

| Export/Feature | Description |
|---|---|
| `moment()` | Core factory function for creating moment date objects |
| `moment.parseTwoDigitYear` | Configurable two-digit year parser (68+ → 1900s, else 2000s) |
| `moment.updateOffset` | Hook for timezone offset updates |
| `moment.suppressDeprecationWarnings` | Toggle deprecation console warnings |
| `moment.deprecationHandler` | Custom handler for deprecation events |
| `moment.momentProperties` | Array of properties copied during moment cloning |
| Date token formatters | Tokens: `YYYY`, `MM`, `DD`, `HH`, `mm`, `ss`, `ZZ`, `x`, `X`, etc. |
| Locale/i18n support | Month names, weekday names, ordinals, long date formats |
| ISO week support | `isoWeek`, `W`/`WW` tokens, week-of-year calculations |
| UTC utilities | `moment.utc()`, `_isUTC` flag, UTC getter/setter bridge |

## Usage Example

```javascript
// CommonJS (Node.js)
const moment = require('./moment-min');

// Parse and format a date
const m = moment('2024-06-15');
console.log(m.format('MMMM Do YYYY')); // "June 15th 2024"

// Manipulate dates
const next = moment().add(7, 'days').format('YYYY-MM-DD');

// UTC mode
const utc = moment.utc('2024-06-15T12:00:00Z');
console.log(utc.isValid()); // true

// Two-digit year parsing
moment.parseTwoDigitYear = (e) => parseInt(e) + (parseInt(e) > 68 ? 1900 : 2000);

// Suppress deprecation warnings
moment.suppressDeprecationWarnings = true;
```

## Notes

- **UMD bundle** — compatible with CommonJS (`require`), AMD (`define`), and browser globals (`window.moment`).
- This is a **minified/production build**; for debugging, use the full `moment.js` source.
- Source available at [`moment-min.js`](https://github.com/flamingo-stack/meshcentral/blob/main/moment-min.js) in this repository.
- Moment.js is in [maintenance mode](https://momentjs.com/docs/#/-project-status/); consider [Luxon](https://moment.github.io/luxon/) or [date-fns](https://date-fns.org/) for new projects.
