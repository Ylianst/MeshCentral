Wrapper class for zlib deflate (data compression) used in the noVNC HTML5 VNC client, built on top of the pako zlib library.

## Key Components

**`Deflator` (default export)**
- `constructor()` — Initializes a ZStream with a 100KB output buffer and default zlib compression level
- `deflate(inData)` — Compresses a `Uint8Array` of input data using `Z_FULL_FLUSH`, handling multi-chunk output automatically; throws on zlib errors

## Usage Example

```javascript
import Deflator from './deflator.js';

const deflator = new Deflator();

const rawData = new Uint8Array([72, 101, 108, 108, 111]);
const compressed = deflator.deflate(rawData);

console.log(compressed); // Uint8Array of compressed bytes
```

## Notes

- Uses `Z_FULL_FLUSH` to ensure all pending output is flushed on each call — important for streaming protocols like VNC
- Output is collected in 100KB chunks (`1024 * 10 * 10`) and concatenated if input is large enough to overflow the initial buffer
- The stream (`this.strm`) is reused across calls; input references are cleared after each compression to avoid memory leaks
