Implements Diffie-Hellman key exchange in pure JavaScript, providing key generation and shared secret derivation without relying on the Web Crypto API's native DH support.

## Key Components

- **`DHPublicKey`** — Lightweight wrapper for a DH public key, exposing `algorithm` metadata and `exportKey()`.
- **`DHCipher`** — Core DH cipher class with the following members:
  - `generateKey(algorithm, _extractable)` *(static)* — Generates a DH key pair given `g` (generator) and `p` (prime modulus) as `Uint8Array` values. Returns `{ privateKey, publicKey }`.
  - `_generateKey(algorithm)` — Internal method that converts `g`/`p` to `BigInt`, generates a random private key via `window.crypto.getRandomValues`, and computes the public key as `g^privateKey mod p`.
  - `deriveBits(algorithm, length)` — Computes the shared secret as `peerPublicKey^privateKey mod p`, returning the result as a `Uint8Array` of the requested byte length.

## Usage Example

```javascript
import { DHCipher } from "./dh.js";

// Both parties agree on g and p (generator and prime modulus)
const g = new Uint8Array([/* generator bytes */]);
const p = new Uint8Array([/* prime modulus bytes */]);

// Alice generates her key pair
const alice = DHCipher.generateKey({ g, p }, true);
const alicePublic = alice.publicKey.exportKey();

// Bob generates his key pair
const bob = DHCipher.generateKey({ g, p }, true);
const bobPublic = bob.publicKey.exportKey();

// Each party derives the same shared secret
const aliceSecret = alice.privateKey.deriveBits({ public: bobPublic }, 256);
const bobSecret = bob.privateKey.deriveBits({ public: alicePublic }, 256);

// aliceSecret and bobSecret are identical Uint8Arrays
```

## Dependencies

Relies on [`bigint.js`](https://github.com/flamingo-stack/meshcentral/blob/main/bigint.js) for `modPow`, `bigIntToU8Array`, and `u8ArrayToBigInt` utilities, and on `window.crypto.getRandomValues` for secure private key generation.
