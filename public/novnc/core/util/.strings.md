Utility module from the noVNC HTML5 VNC client that provides UTF-8 string encoding and decoding functions.

## Key Components

- **`decodeUTF8(utf8string, allowLatin1)`** — Decodes a UTF-8 encoded string using `decodeURIComponent`/`escape`. Accepts an optional `allowLatin1` flag; when `true`, decoding failures silently return the original string instead of throwing a `URIError`.
- **`encodeUTF8(DOMString)`** — Encodes a DOM string to UTF-8 using `encodeURIComponent`/`unescape`.

## Usage Example

```javascript
import { decodeUTF8, encodeUTF8 } from './strings.js';

// Encode a string to UTF-8
const encoded = encodeUTF8('Hello, wörld!');
console.log(encoded); // UTF-8 byte string

// Decode a UTF-8 string
const decoded = decodeUTF8(encoded);
console.log(decoded); // 'Hello, wörld!'

// Decode with Latin1 fallback (safe for legacy VNC servers)
const safeDecode = decodeUTF8(someLegacyString, true);
```

## Notes

- Uses the legacy `escape`/`unescape` pattern for UTF-8 conversion, which is compatible across environments but considered deprecated in modern JS — suitable here for low-level VNC protocol handling.
- The `allowLatin1` fallback is particularly useful when handling strings from VNC servers that may send Latin-1 encoded data rather than strict UTF-8.
