A unified interface for legacy cryptographic algorithms not natively supported by the Web Crypto API (`SubtleCrypto`), providing a consistent API surface for both synchronous and asynchronous cipher implementations.

## Key Components

**`LegacyCrypto` class** — Central registry and dispatcher for legacy crypto operations, supporting the following algorithms:

| Algorithm | Implementation |
|-----------|---------------|
| `AES-ECB` | `AESECBCipher` |
| `AES-EAX` | `AESEAXCipher` |
| `DES-ECB` | `DESECBCipher` |
| `DES-CBC` | `DESCBCCipher` |
| `RSA-PKCS1-v1_5` | `RSACipher` |
| `DH` | `DHCipher` |
| `MD5` | `MD5` |

**Methods:**
- `encrypt(algorithm, key, data)` — Encrypts data using the key's bound algorithm
- `decrypt(algorithm, key, data)` — Decrypts data, validating algorithm/key consistency
- `importKey(format, keyData, algorithm, extractable, keyUsages)` — Imports raw-format keys only
- `generateKey(algorithm, extractable, keyUsages)` — Generates a new key for a supported algorithm
- `exportKey(format, key)` — Exports raw-format keys only
- `digest(algorithm, data)` — Computes a hash digest (e.g., MD5)
- `deriveBits(algorithm, key, length)` — Derives bits via DH or similar key agreement

## Usage Example

```javascript
import LegacyCrypto from "./crypto.js";

// Import a raw AES-ECB key
const key = await LegacyCrypto.importKey(
    "raw",
    rawKeyBytes,
    { name: "AES-ECB" },
    false,
    ["encrypt", "decrypt"]
);

// Encrypt data
const ciphertext = await LegacyCrypto.encrypt({ name: "AES-ECB" }, key, plaintext);

// Compute an MD5 digest
const hash = await LegacyCrypto.digest("MD5", data);
```

> **Note:** Only `"raw"` key format is supported for `importKey` and `exportKey`. Algorithm names must exactly match the registered identifiers (e.g., `"AES-ECB"`, `"DH"`).
