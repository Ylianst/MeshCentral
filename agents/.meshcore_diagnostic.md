Diagnostic agent script that runs after MeshAgent connects to detect, repair, and recover a failed or missing Mesh Agent service installation.

## Key Components

- **`start()`** — Main diagnostic entry point (triggered 10 seconds after connection). Checks for an existing agent service and branches into install or recovery logic.
- **`getMeshAgentService()`** — Retrieves the local Mesh Agent system service via `service-manager`, returning `null` if not found.
- **`getARCHID()`** — Detects the current platform/architecture and returns the corresponding MeshCentral agent binary ID (e.g., `6` for x86_64 Linux, `4` for Windows x64, `16` for macOS).
- **`DownloadAgentBinary(path, ID)`** — Downloads the appropriate agent binary from the connected MeshCentral server over HTTPS.
- **`ConfigureAgent(agent)`** — Writes a `.msh` configuration file alongside the agent binary, populating `MeshID`, `ServerID`, `MeshServer`, and optional proxy settings.
- **`sendServerLog(msg)`** — Sends diagnostic log messages back to the MeshCentral server via the `diagnostic` command action.
- **`finished()`** — Logs completion and stops the `meshagentDiagnostic` service.
- **`giveup()`** — Logs failure and calls `finished()` when diagnosis cannot proceed.

## Usage Example

This script is not called directly — it runs as a background diagnostic service (`meshagentDiagnostic`) and self-terminates when done. The diagnostic flow is:

```javascript
// Automatically triggered on MeshAgent 'Connected' event:
// 1. Wait 10 seconds, then call start()
// 2. If no service found → download binary → install → configure
// 3. If service found but stopped → attempt start → re-download if needed
// 4. If service running → log success → stop diagnostic service
```
