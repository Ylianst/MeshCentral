Translates browser `KeyboardEvent` properties into RDP scancodes, bridging the Web Keyboard API to the Remote Desktop Protocol's scancode format.

## Key Components

- **`KeyMap`** — Maps W3C `KeyboardEvent.code` string values (e.g., `"Enter"`, `"ShiftLeft"`) to their corresponding RDP scancode hex values (e.g., `0x001C`, `0x002A`). Covers standard keys, function keys F1–F24, numpad, media keys, and extended keys (prefixed `0xE0xx`).

- **`UnicodeToCodeFirefox_FR`** / **`UnicodeToCodeChrome_FR`** — Fallback lookup tables mapping legacy `keyCode` integers to W3C key code strings, specific to French keyboard layouts in Firefox and Chrome respectively. Required because `event.code` was not universally supported in older browsers.

- **`UnicodeToCode_EN`** — Fallback `keyCode`-to-code-string map for English keyboard layouts, shared across both Firefox and Chrome.

- **`UnicodeToCode`** — Nested lookup object organizing fallback maps by `{ browser: { locale } }` for clean dispatch.

- **`scancode(e)`** — Primary export. Accepts a `KeyboardEvent`, detects the current locale (via `Mstsc.locale()`) and browser (via `Mstsc.browser()`), then resolves the correct scancode using `event.code` first, falling back to `keyCode`-based lookup. Attached to `Mstsc.scancode`.

## Usage Example

```javascript
document.addEventListener('keydown', function(e) {
  var code = Mstsc.scancode(e);
  if (code) {
    sendRdpKeyEvent({ scancode: code, isDown: true });
  }
});

document.addEventListener('keyup', function(e) {
  var code = Mstsc.scancode(e);
  if (code) {
    sendRdpKeyEvent({ scancode: code, isDown: false });
  }
});
```

> **Note:** Locale support is limited to `'fr'` and `'en'`; all other locales fall back to `'en'`. The `event.code` property takes precedence over the legacy `event.keyCode` fallback path.
