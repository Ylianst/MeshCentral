Reusable UI component library for MeshCentral's web interface, providing standardized modal dialogs, status cards, and icon upload widgets to reduce duplication across `default3.handlebars`.

## Key Components

| Class | Purpose |
|-------|---------|
| `ModernModal` | Bootstrap-based modal wrapper that consolidates `setModalContent()` + `showModal()` into a single `openModal()` call |
| `ModernCard` | Status-aware card renderer with dynamic icon/color updates for `default`, `success`, `warning`, and `danger` states |
| `IconUploadComponent` | Reusable icon upload widget supporting file upload, URL input, live preview, and removal — delegates persistence to page-level callbacks |

## Usage Example

```javascript
// ModernModal: open a confirmation dialog
const modal = new ModernModal('confirmModal', { size: 'medium' });
modal.show('Delete Device', 'Are you sure?', () => deleteDevice(id), 'Delete');
modal.hide();

// ModernCard: render a status card
const card = new ModernCard(document.getElementById('deviceCard'), {
    title: 'Agent Status',
    icon: 'fa-desktop',
    status: 'success',
    actions: [{ label: 'Restart', class: 'btn-danger', onclick: 'restartAgent()' }]
});
card.render();
card.updateStatus('warning'); // live update without re-render

// IconUploadComponent: custom icon picker with upload callback
const iconComp = new IconUploadComponent('agentIcon', document.getElementById('iconContainer'), {
    label: 'Agent Icon',
    currentValue: '/images/agent.svg',
    onUpload: async (key, file) => uploadToServer(key, file),
    onRemove: (key) => clearIcon(key),
    normalizePreviewUrl: (val) => `/api/icons/${val}`
});
iconComp.render();
```

## Notes

- `IconUploadComponent` registers itself on `window.iconUploadComponents[iconKey]` for inline HTML event handler access.
- Migrating existing `setModalContent` / `showModal` pairs in `default3.handlebars` to `ModernModal.show()` is expected to reduce ~200 lines of template code.
- Source: [`ui-components.js`](https://github.com/flamingo-stack/meshcentral/blob/main/ui-components.js)
