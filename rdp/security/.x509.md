ASN.1-based X.509 certificate structure definitions for parsing DER/BER-encoded certificates, implementing [RFC 5280](https://tools.ietf.org/html/rfc5280) data structures used in RDP (Remote Desktop Protocol) security handshakes.

## Key Components

| Function | Description |
|---|---|
| `X509Certificate()` | Top-level certificate structure: `tbsCertificate`, `signatureAlgorithm`, `signatureValue` |
| `TbsCertificate()` | To-Be-Signed certificate body with version, serial, issuer, validity, subject, and public key |
| `SubjectPublicKeyInfo()` | Algorithm identifier + public key bit string |
| `RSAPublicKey()` | RSA public key structure with `modulus` and `publicExponent` integers |
| `Name()` / `RDNSequence()` | Distinguished name hierarchy built from `RelativeDistinguishedName` sets |
| `Validity()` | Certificate validity window (`notBefore` / `notAfter`) as UTC or Generalized Time |
| `AlgorithmIdentifier()` | OID + optional parameters for signature/key algorithms |
| `Extensions()` | Sequence of X.509 v3 extensions (OID, critical flag, value) |

## Usage Example

```javascript
var x509 = require('./x509');
var asn1 = require('./asn1');

// Parse a DER-encoded X.509 certificate buffer
var certStructure = x509.X509Certificate();
certStructure.decode(derBuffer);

// Access parsed fields
var subject = certStructure.tbsCertificate.subject;
var notAfter = certStructure.tbsCertificate.validity.notAfter;

// Parse an RSA public key from SubjectPublicKeyInfo bit string bytes
var rsaKey = x509.RSAPublicKey();
rsaKey.decode(subjectPublicKeyBytes);

console.log(rsaKey.modulus, rsaKey.publicExponent);
```

## Notes

- All structures use the `asn1` library's universal types (`Sequence`, `Choice`, `SetOf`, `SequenceOf`, etc.)
- Optional fields (`issuerUniqueID`, `subjectUniqueID`, `extensions`) use implicit/explicit ASN.1 context tags per RFC 5280
- Only `X509Certificate` and `RSAPublicKey` are exported — all other functions are internal structural builders
