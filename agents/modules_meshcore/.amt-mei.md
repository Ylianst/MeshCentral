Intel AMT MEI (Management Engine Interface) PTHI client for communicating with AMT firmware via the HECI driver. Provides a queued, callback-based API to query AMT device information.

## Key Components

- **`amt_heci` (constructor)** — Singleton-pattern class that manages a shared HECI connection and request queue (`g_internal`) for PTHI (Platform Trust Hardware Interface) communication.
- **`sendCommand(cmd, data, callback, ...args)`** — Core method that enqueues a raw PTHI command and lazily opens the HECI connection when needed.
- **`getCommand(chunk)`** — Parses a raw binary response buffer into a structured `{ IsResponse, Command, Status, Data }` header object.
- **`retry_pthi_later()`** — Internal retry handler that attempts to re-establish a dropped PTHI connection up to 20 times.

### High-Level Query Methods (all callback-based)

| Method | AMT Command | Returns |
|---|---|---|
| `getVersion(cb)` | `26` | BIOS version + firmware version list |
| `getUuid(cb)` | `0x5c` | Formatted UUID string |
| `getProvisioningState(cb)` | `17` | State int + `PRE`/`IN`/`POST` string |
| `getProvisioningMode(cb)` | `8` | Mode int + mode string + legacy flag |
| `getEHBCState(cb)` | `132` | EHBC boolean |
| `getControlMode(cb)` | `107` | Control mode int + mode string |
| `getMACAddresses(cb)` | `37` | Dedicated + host MAC addresses |
| `getDnsSuffix(cb)` | `54` | DNS suffix string |
| `getHashHandles(cb)` | `0x2C` | Array of hash handles |

## Usage Example

```javascript
var mei = require('./amt-mei');
var pthi = new mei();

// Get AMT firmware version
pthi.getVersion(function(version) {
    if (version) {
        console.log('BIOS:', version.BiosVersion);
        version.Versions.forEach(function(v) {
            console.log(v.Description + ':', v.Version);
        });
    }
});

// Get provisioning state
pthi.getProvisioningState(function(state) {
    if (state) {
        console.log('State:', state.stateStr); // "PRE", "IN", or "POST"
    }
});

// Get device UUID
pthi.getUuid(function(result) {
    if (result) console.log('UUID:', result.uuid);
});
```

## Notes

- All requests are serialized through an internal FIFO queue; the HECI connection is opened on first request and closed when the queue drains.
