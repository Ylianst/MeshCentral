Intel AMT MEI (Management Engine Interface) PTHI communication module. Provides a JavaScript interface for sending commands to and receiving responses from Intel AMT firmware via the HECI (Host Embedded Controller Interface) driver.

## Key Components

- **`amt_heci` (constructor)** — Singleton-style class managing the AMT PTHI connection queue and HECI channel lifecycle
- **`g_internal`** — Shared internal state holding the request queue (`_rq`), active HECI handle (`_amt`), and error count
- **`retry_pthi_later()`** — Retries PTHI connection up to 20 times with 250ms delays on failure
- **`sendCommand(cmd, data, callback, ...args)`** — Enqueues a raw PTHI command and manages connect/disconnect lifecycle
- **`getCommand(chunk)`** — Parses raw HECI response bytes into a structured header object
- **`getVersion(callback)`** — Retrieves AMT BIOS and firmware version strings
- **`getUuid(callback)`** — Retrieves the AMT device UUID (formatted as standard hyphenated UUID)
- **`getProvisioningState(callback)`** — Returns provisioning state (`PRE`, `IN`, `POST`)
- **`getProvisioningMode(callback)`** — Returns provisioning mode (`NONE`, `ENTERPRISE`, `SMALL_BUSINESS`, `REMOTE_ASSISTANCE`)
- **`getControlMode(callback)`** — Returns control mode (`CLIENT`, `ADMIN`, etc.)
- **`getMACAddresses(callback)`** — Returns dedicated and host MAC addresses
- **`getDnsSuffix(callback)`** — Retrieves the AMT DNS suffix string
- **`getHashHandles(callback)`** — Retrieves certificate hash handles

## Usage Example

```javascript
var amt = require('./amt-mei');
var pthi = new amt();

// Get AMT firmware version
pthi.getVersion(function(version) {
    if (version) {
        console.log('BIOS:', version.BiosVersion);
        version.Versions.forEach(function(v) {
            console.log(v.Description + ': ' + v.Version);
        });
    }
});

// Get device UUID
pthi.getUuid(function(result) {
    if (result) console.log('UUID:', result.uuid);
});

// Check provisioning state
pthi.getProvisioningState(function(result) {
    if (result) console.log('State:', result.stateStr); // "PRE", "IN", or "POST"
});
```

> **Note:** Requires the `heci` native module to be available in the MeshAgent environment. Commands are automatically queued and the PTHI connection is opened/closed on demand.
