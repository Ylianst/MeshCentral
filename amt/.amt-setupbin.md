Parses and decodes Intel® AMT `Setup.bin` provisioning files, extracting structured configuration records and variable identifiers used for AMT platform setup.

## Key Components

- **`CreateAmtSetupBinStack()`** — Factory function returning the parser object `o`
- **`o.AmtSetupBinCreate(version, flags)`** — Creates a new Setup.bin file object with header metadata initialized
- **`o.AmtSetupBinDecode(file)`** — Decodes a raw Setup.bin binary string, validating the GUID header and parsing chunk-based data records
- **`AmtSetupBinSetupGuids`** — Array of 16-byte GUIDs identifying Setup.bin format versions 1–4
- **`AmtSetupBinVarIds`** — Lookup table mapping module/variable IDs to types and human-readable names (e.g., MEBx passwords, provisioning keys, network settings)

## Usage Example

```javascript
var stack = CreateAmtSetupBinStack();

// Decode an existing Setup.bin binary string
var decoded = stack.AmtSetupBinDecode(setupBinFileContents);
if (!decoded) {
    console.error("Invalid or unrecognized Setup.bin file");
} else {
    console.log("File version:", decoded.fileType);
    console.log("Major version:", decoded.majorVersion);
    console.log("Records consumed:", decoded.dataRecordsConsumed);
    console.log("Records:", decoded.records);
}

// Create a new Setup.bin object (version 2, no flags)
var newBin = stack.AmtSetupBinCreate(2, 0);
console.log("New Setup.bin header:", newBin);
```

## Notes

- The file is parsed in 512-byte chunks; the first chunk is the file header and subsequent chunks are data records.
- Version 2 files require specific ordering: current MEBx password → new MEBx password → manageability selection.
- Variable types: `0` = binary string, `1` = char, `2` = short, `3` = int, `4` = GUID.
